# 银龄传言核查员 · 打法手册（playbook）

> 本文件按需加载：SKILL.md §2 各步用到哪节读哪节。五节：追问话术库 / 操作清单模板 / 术语对照表 / 风险红旗清单 / 技术小课堂。

## §1 追问话术库（燃犀追问位·按场景取用）

通用三句骨架见 SKILL.md §2 Step 3，以下为分场景变体：

**荐股/利好类（股票群、朋友消息）**
- "说'特大利好'的这位，他自己买了多少？他凭什么比公告先知道？"
- "'别告诉别人'——真好消息为什么怕别人知道？"
- "他让您现在买，是晚了就来不及了吗？真来不及的事，轮得到微信通知咱吗？"

**政策文件类（"上面发文了"）**
- "文件号是多少？在哪个政府网站能搜到全文？"
- "这文件是哪年发的？截图上怎么没有日期？"

**健康养生类**
- "这个方法，正规医院的大夫认吗？还是只有发消息的人认？"

**钱款动作类（任何引导转账/投资的传言）**
- 一律升级为最高红旗：先停下所有动作，问家人，再拨打官方客服核实（号码从官方App/官网查，不用对方给的）。

## §2 操作清单模板（一页纸，可直接打印/转发）

```
【这条消息怎么查】
1. 查什么：________________（如：公司公告 → 巨潮资讯网 www.cninfo.com.cn）
2. 怎么查：________________（如：搜"公司名+公告"，只看官方网站）
3. 问谁：  拿不准 → 先问家里人；涉及钱 → 官方客服/柜台（号码从官方App查）
【这几件事先别做】
□ 不转发   □ 不据此买卖   □ 不点传言里的链接   □ 不扫码进群
记住：真消息不怕晚三天。
```

## §3 术语对照表（术语 → 长辈版）

| 术语 | 大白话 |
|---|---|
| 非标 / 保留意见 | 审计师说：这本账有地方我没法打包票 |
| 因果链断裂 | 前面几件事是真的，但"所以"后面那句是硬接上去的 |
| 置信度 High/Medium/Low | 很扎实 / 大体可信 / 只有一面之词 |
| 存疑 | 现在查不到证据，不能说是真也不能说是假 |
| 内幕信息 | 还没公开、只有少数人该知道的事——传这个和信这个去买卖都可能违法 |
| 底表 | 官方登记在册的完整名单/全文，最硬的依据 |
| 公告豁免披露 | 按规定这一小段可以不公开，所以查不到不等于有鬼 |
| AI 幻觉 | AI 会一本正经地编数字，编得像真的 |
| 二创/洗稿 | 别人用AI改写过的版本，每转一手数字就可能变一次 |

## §4 风险红旗清单（命中即明示）

| 红旗 | 为什么危险 |
|---|---|
| "内部消息/朋友消息/特大利好" | 荐股骗局与内幕交易话术的标准开场 |
| "别告诉别人/快，来不及" | 制造紧迫与排他，阻断您找人商量 |
| 要您买、投、转账、进群、下载App | 传言的终点是您的钱——到这一步先停 |
| 截图无日期、无文件号、无出处链接 | 老文件冒充新文件的高频手法 |
| 配图带AI水印、数字特别整 | 可能是AI生成内容，存在≠属实 |
| 用对方给的电话/链接"核实" | 核实通道本身是假的；核实要走官方渠道 |
| 涉及"养老项目""以房养老""高息保本" | 涉老金融骗局高频外衣，一律先问家人再报官方 |

## §5 技术小课堂（每次只讲一段）

**① AI 会编数字（AI幻觉）**
"现在有种AI，问它什么它都答得又快又像样，但它有时候会一本正经地编数字。识别窍门：它给的数字如果没有说'这是从哪个官方文件来的'，就先当故事听。"

**② AI 洗稿：每转一手变一次**
"一条消息被人用AI改写再发出来，叫洗稿。每改一次，数字就可能悄悄变一次。识别窍门：同一件事，几个群里的数字对不上，就是洗稿的痕迹。"

**③ 截图可以伪造**
"聊天截图、公告截图都能做假，做得和真的一样。识别窍门：截图上如果没有日期、没有文件号、给不出官网链接，就不算证据。"

**④ 声音也能克隆（语音克隆）**
"现在几秒钟的录音就能把一个人的声音学走，电话里'孩子'的声音都可能是假的。识别窍门：凡是电话里提到钱的，挂掉，用您自己存的号码回拨确认。"

**⑤ 为什么官方渠道最可靠**
"公司的事看交易所和巨潮，政策的事看gov.cn。这些网站上的内容要负法律责任，微信群里的不用。"

## §6 实战案例（行云科技传言·2026-09-03，可作教学样例）

- 传言："签了9亿合同（小利好）→ 还有大利好：去非标明晚发 + Rubin特大利好（朋友消息）"
- 拆链：合同真（公告在案）；"明晚发"无出处（次日晚公告实为算力合同，非去非标）；"Rubin朋友消息"公开零命中且属内幕信息特征；因果节"签了合同所以必有大利好"断裂。
- 长辈版一句话："签合同是真的，但后面两个'好消息'现在没有任何凭据，'朋友消息'这种事听到就到此为止，更不能照着买。"
