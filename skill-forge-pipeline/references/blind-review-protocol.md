# 外池盲评最小落地协议 —— 技能锻造管线 v2.3（D 节点配套）

> 适用：宿主无独立子代理能力时，D 节点降级为外池 API 盲评（独立 LLM 实例评同一证据包）。本协议为最小可落地闭环，R30 外池审判即按此执行。

## 一、证据包全件清单（缺件先列清单暂停，不进 D）

开评前由送检方核点并随包提交清单：

| # | 必备件 | 说明 |
|---|---|---|
| 1 | SKILL.md | 含 frontmatter 全文 |
| 2 | 全部 scripts/ | 逐一列文件名+版本号，不得只列代表件；纯提示词/工作流型技能（N 节点变体）无 scripts 时注明「无脚本」，全件=SKILL.md + 关键 references + dry-run 用例集，不得以缺 scripts/ 判缺件 |
| 3 | 关键 references/ | 评审要核的引用文档（如 dryrun 套件、本协议） |
| 4 | 版本基线 | .bak 链首环版本号（大修模式必附） |
| 5 | FORGE_REPORT.md（短链轮次） | 票数、残余、宣称-实证差记录 |

**缺件处置**：判官收到包先核对清单——缺件时**先列缺件清单并暂停，不得进入评分**；补齐后重发全包。判官不得从文本推断依赖存在与否（首锻实证：verify_edit.py 实体存在却被两判官误判为幽灵依赖）。

## 二、判官独立性约束

1. 每位判官必须是**独立实例**（独立会话/独立 API 调用），严禁与被评技能的锻造者同上下文自评；
2. 判官之间互不可见对方评分（盲评），先各自出分后汇总；
3. 判官不可用需同族替补时，**必须披露**替补关系及模型族，登记进 FORGE_REPORT；
4. 判官非独立（如被发现共享上下文）本轮作废，不进投票。

## 三、统一输出契约（每位判官单份评审单必须全含）

1. **9 维逐项评分**：每维 1-10 分 + **行号证据**（引用文件:行号），无证据行该维无效；
2. **bug hunt ≥2**：至少 2 个具体缺陷（脚本可执行者必含实跑反例），写不清复现路径的不计；
3. **verdict**：`KEEP` | `REVISE` 二选一，禁止骑墙；
4. **mandatory 改前→改后**：每条必修项给「改前原文 → 改后建议」对，空泛建议不计；
5. 加权短板 Top3（供女娲 delta 排序用）。

## 四、投票汇总

1. 判官数为**奇数**（默认 N=3），多数决：better/worse 票数≥2 方生效；
2. margin 判定与平局轮处置按 SKILL.md「margin 操作定义」执行（含 same 票的非多数 → 平局轮）；
3. 判官不可用（超时/拒答/输出不合契约）→ **降级登记**：记其缺席原因，剩余奇数票继续；偶数残局时补一位披露过的同族替补，仍不足则本轮暂停；
4. 全部票数、缺席登记、替补披露写入 FORGE_REPORT。

## 附录 · 9 维 rubric 1/5/10 分锚定表

| 维 | 1 分锚 | 5 分锚 | 10 分锚 |
|---|---|---|---|
| 1 触发词覆盖 | 触发词空泛或全是自称，真实用户说法不命中 | 主场景触发词在，但缺场景化限定或显式同义词 | 场景化触发词覆盖首锻/大修/同义说法，误伤面有边界说明 |
| 2 工作流可执行性 | 只有理念口号，无步骤可跟 | 步骤有序号但输入输出含糊，个别断链 | 每步输入/输出明确，主链短链大修三径皆闭环无断链 |
| 3 失败分支完备性 | 无失败分支，默认一切顺利 | 有失败提及但无处置路径 | 失败 if-then 三段式齐全，熔断/回滚/平局等边界分支全有主 |
| 4 检查点显性 | 无任何过程闸口 | 有检查点但无准出判据 | 关键节点均有 🔴 显性准出检查，不齐不流成文 |
| 5 可执行具体性 | 全是抽象原则，无命令无模板 | 有命令样例但参数或路径虚指 | 命令/契约/清单可直接照抄执行，退出码与输出格式成文 |
| 6 资源整合可达 | 引用资源不存在或幽灵依赖 | 资源在但路径/版本未锚定 | 资源全件清单化、版本号在案，宿主特定路径有可移植性标注 |
| 7 架构与正交 | 节点职责重叠，同一件事多处打架 | 主辅链分工基本清楚但变体条款散置 | 主链/短链/变体职责正交，单一源无重复定义 |
| 8 实测表现 | 无任何自检，或自检只测 happy path | 有自检但负断言缺失或证据不可复现 | 确定性负断言套件可复跑 PASS，或 dry-run 用例集含正/负/边界例 |
| 9 反例与黑名单 | 无反模式记录，重蹈无防 | 有黑名单但无替代做法 | 反模式每条配替代做法，且来自实证抓包记录 |
