# 技能锻造管线 v2.4.1（主链 N-C-D + 短链 N⇄D）

> 结构来源：首锻实证（context-pruner，FORGE_REPORT.md）——原五节点 N-C-D-N-D 运行中自然塌缩为
> 「主链一次 + 修-评短循环」三拍；本版把该塌缩正式化，并给出排列组合的取舍依据。

## 排列组合优化（为什么是这个形状）

| 候选形状 | 评 | 判 |
|---|---|---|
| N-C-D-N-D（旧案） | 第二个女娲是全职再造——实际只产出增量修复，节点冗余 | 淘汰 |
| **N-C-D +（N⇄D 短链）** | 主链一次成形（造→写→评），短链只做「增量修复⇄paired 复评」直到收敛 | **采用** |
| N-D-C | 先评后写：评的对象未成文，rubric 无的放矢 | 淘汰 |
| C-N-D | 先写后造：把未提炼的方法过早形式化，返工率高 | 淘汰 |
| D 先行（大修模式） | 对象已存在时从评估切入：基线快照→D→（N⇄D），见 §大修模式 | 变体保留 |

**短链收敛判据（满足任一即出链）**：①paired 多数判 better 但 margin=slight 且连续两轮（HL-4）——此径出链时残余必须全部登记 FORGE_REPORT；②残余全部属「非本平台/文档级」。
**触顶熔断（非收敛）**：MAX_ROUNDS=3 触顶且末轮 worse → 强制回滚至基线版本、标记 `FAILED: 超过最大迭代次数未收敛`，拒绝交付并移交人工；触顶但 keep 链完整（无 worse）→ 可按①②出链；触顶且 keep 但①②均不满足 → 强制出链：残余全登记 FORGE_REPORT、版本标 `MAX_ROUNDS_REACHED`，禁止续轮，移交用户裁量是否再开新轮。

**margin 操作定义**：3 票中 better 票数≥2 且其中 slight 票数≥1 → margin=slight；3 票全 better 且均非 slight → margin=clear；worse 票数≥2 → 判 worse（revert）；2 better（均非 slight）+1 same → margin=moderate：keep 生效、计入收敛所需 better 多数，但不计入 margin=slight 连续计数；**非多数（含 same 票，如 1better+1worse+1same）→ 平局轮：不 keep 不 revert、不计入收敛连续计数，delta 减量后重评；连续 2 平局视同触顶熔断**。

**9 维 rubric 枚举**（1-10 分/维，锚定表见 references/blind-review-protocol.md 附录）：1 触发词覆盖 2 工作流可执行性 3 失败分支完备性 4 检查点显性 5 可执行具体性 6 资源整合可达 7 架构与正交 8 实测表现（须确定性套件或 dry_run 标注）9 反例与黑名单。
**短链内女娲只做 delta**（增量修复），禁止全职重写——全职重写走 §探索性重写，须用户明示。

## 主链三节点（一次成形）

### N · 女娲（创造）
从实战记录或需求提炼：核心方法论一句话、反模式黑名单 ≥3 条、诚实边界 ≥2 条。
产物：技能目录 + 核心脚本 v1.0.0（含 --smoke 自检）。**纯提示词/工作流型技能变体**：不强制造脚本，自检以 dry-run 用例集（≥3 个典型 prompt 的预期行为描述，样板见 references/dryrun-suite.md）替代 --smoke。
**🔴 N 准出检查**：核心方法论一句话在、反模式黑名单 ≥3 条在、诚实边界 ≥2 条在——三项不齐不得流向 C。

### C · 仓颉（成文）
SKILL.md 必备件：frontmatter（触发词+何时用，≤1024 字符，禁空话尾巴）、工作流（序号+每步输入输出）、失败模式 if-then 三段式、🔴 显性检查点、反模式黑名单专章、自检命令、Runtime 中立。
**🔴 C 准出检查**：上述必备件完整性清单逐项核在——任一项缺失即回退 N 补料，不得带病流向 D。

### D · 达尔文（压测）
**🔴 D 前置闸（证据包缺件暂停）**：评审证据包必须含全件（SKILL.md + 全部 scripts + 关键 references）——纯提示词/工作流型技能（N 节点变体）无 scripts 时，全件=SKILL.md + 关键 references + dry-run 用例集，不得以缺 scripts/ 判缺件。开评前先核全件清单——缺件时**先列缺件清单并暂停，不得进入评分**；否则判官只能从文本推断依赖缺失（首锻实证：verify_edit.py 实体存在却被两判官误判为幽灵依赖）。落地细则见 references/blind-review-protocol.md。
spawn **独立** judge 子代理（禁同上下文自评）——本条款依赖宿主子代理能力（如 Kimi Code Agent/AgentSwarm）；**无此能力的宿主降级为外池 API 盲评**（独立 LLM 实例评同一证据包，如 forge_review.py 模式），判官非独立本轮作废不进投票。9 维 rubric 逐项打分+行号证据；必含脚本 bug hunt ≥2、干跑典型 prompt、加权短板 Top3、改前→改后建议。

## 短链 N⇄D（收敛迭代）——三闸全程生效

**短链第 0 动（首锻适用）**：首锻模式短链首轮 delta 前，须对 D 首评通过版建 .bak 快照（paired revert/熔断的唯一回滚对象）；大修模式此步即大修第 0 步，不重复。

**闸 1 · 改必验闸（最高纪律）**：每处 patch 后同一回合内跑确定性验证：
`python scripts/verify_edit.py <文件> "<新串>" [--must-not "<旧串>"] [--test "<自检命令>"]`
宣称「已修复」必须附验证输出原文；未验宣称记为**宣称-实证差**，写入 FORGE_REPORT 并主动呈给判官（首锻实证：两次假宣称全被抓包）。空串 must/must-not 属于用法错误（exit 2），空断言闸门拒绝空过。

**闸 2 · replace 失配防呆**：改代码优先精确编辑工具；必须程序化 replace 时写后断言 `new_string in content`，失配即停。

**闸 3 · 判官三视角标配**：paired 复测固定三视角——结构（文档与流程）/ 实证（代码与实测）/ 对抗用户（高频路径与误伤面）；独立 resume 续评保同尺；宿主降级为外池 API 盲评（无状态实例）时，paired 复评 prompt 必须嵌入前轮评审单摘要（各判官 verdict+9维分+top3 短板），以锚定同尺；未嵌摘要的复评票作废；奇数多数决。

短链每轮：女娲 delta 修（带双闸）→ paired 三判官 → 多数 better=keep / worse=revert / 非多数=平局轮（delta 减量重评，连续 2 平局熔断）→ 收敛判据满足即出链。

## 大修模式（D 先行变体）

适用：对象技能已存在，从评估切入而非从零创造。

- **第 0 步 · 基线快照（强制）**：对目标全件（SKILL.md + 全部 scripts + references）建 `.bak` 基线快照并记录版本号——此为短链 revert 与触顶熔断的唯一回滚对象；无快照不得进 D。
  输入：目标技能目录全件。输出：`.bak` 版本链首环 + 基线版本号登记。
- **第 1 步 · D 首评**：按 D 节点规则（前置闸+9 维 rubric+bug hunt）对基线版出评审单。
  输入：基线快照 + 全件证据包。输出：评审单（分数+行号证据+改前→改后建议）。
- **第 2 步 ·（N⇄D）短链**：按短链规则逐轮 delta 修与 paired 复评，收敛或熔断。
  输入：评审单 + 上轮产物 + `.bak` 版本链。输出：收敛终版（含 FORGE_REPORT）或熔断回滚至基线。

## §探索性重写（全职再造，须用户明示）

触发：用户明示「推翻重写」「全职重做」当前技能，且接受旧版仅作参考。与短链 delta 的界限：短链内女娲**只做增量修复**；凡需重构方法论骨架、更换核心脚本、重排工作流者，即越出 delta 边界，必须走本节并获用户明示。
节点编排：**N 全职再造 → C 成文 → D 压测 → 短链 N⇄D 收敛**——即重跑一次主链（旧版 .bak 保留为回滚基线与 paired 对照物），而非插队进既有短链。

## 自检设计纪律

1. --smoke 必须含**负断言**（来自判官 bug 清单的反用例），只测 happy path 视为无效；
2. 逻辑层验证优先级：**确定性边界用例套件 > 判官投票**；
3. 自检平台可移植性边界必须写明；
4. 注释即承诺：注释机制描述必须与代码行为一致，判官逐句核。

## 反模式黑名单（管路自身）

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 宣称修复但未附验证输出 | 改必验闸：verify_edit.py 输出原文随宣称走 |
| 2 | string.replace 静默失配后继续 | 写后断言 `new in content`，失配即停 |
| 3 | 同上下文自评自改 | 判官必须独立子代理，paired 同尺比较 |
| 4 | 拿绝对分数 delta 当棘轮 | paired 奇数多数决；绝对分只做 triage |
| 5 | 为凑 MAX_ROUNDS 硬改 | margin 递减即收（HL-4），残余非平台项可收官 |
| 6 | smoke 只测 happy path | 负断言必须来自判官 bug 清单 |
| 7 | 判官单视角 | 结构/实证/对抗用户三视角标配 |
| 8 | 短链内全职重写（delta 变 re-create） | 全职重写须用户明示（§探索性重写条款） |
| 9 | 版本漂移（内文自称与包名/frontmatter 不一致） | 版本单一源：description 起首与正文标题统一，变更只改一处说明行 |
| 10 | 空断言闸门（空串 must 空过） | verify_edit.py v1.1.0：空 must/空 must-not 属用法错误 exit 2 |

## 触发后第一件事

只问一件：「首锻还是大修？锻什么、本体素材是什么？」——首锻走 N-C-D+短链；大修走 §大修模式（第 0 步快照→D+短链）。默认值：三视角判官、MAX_ROUNDS=3、奇数 N=3。
