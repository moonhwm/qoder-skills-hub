# 双框架术语表与裁定细则

> 术语闸裁决依据。词表分框架 A（党组纪律/公文）与框架 B（学术技术规范）；正式文书须在双框架下表述，禁视角混杂、禁模糊术语。

## 目录

- 框架 A 词表（公文纪律用语）
- 框架 B 词表（学术技术规范用语）

- 禁用清单（机检词表）

## 自称与称谓规范

- 席位自称：**本席**；筹备机构自称：**筹备组/筹备处**；用户：**主权人/机主**。
- 禁第一人称口语自称（我、笔者、小弟）；禁商业自称（我们团队、我司）。
- 他席引用格式：`席位名 + 席`（如 守藏席、quantlab 席），附总线 id 或 commit 指针。

## 禁用清单（机检词表）

| 类别 | 词形 | 裁定 |
|------|------|------|
| 个人视角口语 | 我觉得、我认为、可能吧、大概、也许、差不多 | 正式文书禁用，命中即退回 |
| 商业视角 | 变现、卖点、赋能（商业语境）、打法、闭环营销、私域 | 命中即退回；技术语境之「闭环验证/闭环归档」豁免 |
| 模糊术语（关键定义位） | 相关、等等、之类、若干、一定程度上 | 出现在定义、清单、指标句中即退回；叙述性过渡豁免 |
| 夸张与无据 | 最强、完美、彻底解决、100%、绝对安全 | 无判别式或实测支撑即退回；引述实测数据（如「省 53.6% 码率」附出处）豁免 |
| 外来混杂 | OK、搞定、搞得定 | 命中即退回 |

## 视角混杂裁定

1. 同一段落内框架 A 与商业/个人视角词并现 = 视角混杂，退回。
2. 框架 A 与框架 B 并现**不是**混杂——双框架系本体系要求（纪律语言定性、技术语言定量）。
3. 引文块内之他方文本不纳入视角检查，但须注明出处；转述须标明「转述」。

## 模糊术语裁定

- 「关键定义位」判定：句子含「是指/定义为/包括/分为/指标为/阈值为」者。
- 模糊词在关键定义位命中 → 退回；要求改为枚举、阈值或指针（总线 id/commit/文件路径）。
- 无指标句中的叙述性使用（如「相关席位已知悉」）→ 警告，建议改枚举。

## 党组纪律程序检查单（文书类适用，人工项）

> 来源：swarm 评测 iteration-1 盲评改进项——机检覆盖术语面，程序面由人工按本单核对。

请示/报告/方案类文书，除词表检查外，逐项核对：

1. **决策程序**：涉资源、资金、对外承诺之事项，是否载明集体决策或审批链（不得个人径决口吻）。
2. **涉密与凭据**：是否经保密审查表述（凭据形态、内部地址、未公开凭据指纹之外的内容不得外溢）。
3. **追责与复核**：是否载明复核义务归属（如「纳入审计局例行视野」式条款）。
4. **语境适当性**：商业色彩词（变现、盈利路径等）出现于党政文书语境时，须附适当性存疑声明并提请裁定，不得径行表述。
5. **内容深度**：背景节是否含需求依据、风险评估、发布/回滚方案三要素（方案类强制，简报类豁免）。

命中缺项 → 预检报告「术语闸」下以「程序缺项」列入退回理由。
