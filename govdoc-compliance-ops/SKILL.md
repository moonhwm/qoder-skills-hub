# 公文合规预检门（govdoc-compliance-ops）

## 定位

凡以「政府职能部门党组学术技术成员视角」出具之正式文书，出稿、送审、发布前必经本门四闸。本件管「怎么检」，不管「怎么写」（写作本体归各业务技能），也不管「怎么发」（发布本体归 otl-format-ops）。

## 五条工作纪律（继承不改写）

1. 凭据不落明文、指纹入链；检出疑似凭据形态即报凭据主权流程。
2. 超链接零改动：预检只提取链接清单供比对，禁止增删改任何 URL。
3. 永久性自指订正公理：运营者仅记录、转述、协调；来源内容不得未经授权增删改或重新解释；不能直读之来源一律「列入书目不引文」。
4. 写类动作逐次批准，预检报告属本席径行（本地写，不涉外发）。
5. 检出问题改文档，不改闸；闸的误判修订走技能版本流。

## 四闸工作流

**次序：术语闸 → 格式闸 → 编码闸 → 协议闸；任一闸不过即退回修改，不跳闸。**

1. **术语闸**（本件本体）：跑 `python3 scripts/govdoc_precheck.py <file.md>`，逐条处置检出项；词表与裁定细则见 `references/terminology.md`。要点：双框架词表覆盖、视角混杂（行政/商业/个人视角混入）检出、模糊术语在关键定义位检出、自称规范（本席/筹备组/主权人/机主）。请示/报告/方案类文书另按 terminology.md 末章「党组纪律程序检查单」人工核对五项（决策程序/涉密凭据/追责复核/语境适当性/内容深度），缺项以「程序缺项」列入退回理由。
2. **格式闸**（联动 otl-format-ops）：跑 `python3 /app/.user/skills/otl-format-ops/scripts/otl_source_lint.py <file.md>`，零 error 方过；骨架六要素、标题层级、制表图围栏、图片合规等以彼件为准。若环境无该技能，预检脚本的 `--skeleton-only` 模式可做最小骨架检查（H1 唯一、文档头六要素、变更记录节存在）。
3. **编码闸**（本件本体）：跑 `python3 scripts/govdoc_precheck.py <file.md> --doccode`。L2 件号之谱系语法、撞号、断档、无号检出，以 `references/doccode-spec.md` 为裁决依据，台账 `references/doccode_registry.jsonl` 哈希链对账（append-only，改史即断链）；L1 公文形制要素按规格书第二章检查单人工核对（文种/发文字号/份号/密级/紧急程度/签发人/成文日期/印章署名/页码），版式参数转人工核验并载入报告。件号纪律：先登记后使用、停用永不复用、撞号按台账提交序先到先得、字形永不改写、件号不含私有词表要素。
4. **协议闸**（本件本体）：文书涉及资产许可表述时，按 `references/license-matrix.md` 逐条核对——资产类型→许可层映射、SPDX 标识与双行标识写法、LICENSE 官方原文要求、第三方引入三先行（NOTICE 署名/密钥扫描/SBOM 登记）、SSPL 名实纪律（源可得，不称开源）。

## 预检报告格式（四节）

```text
预检报告 <文件名> <日期>
一、术语闸：<通过/退回>（检出 N 项：逐条列行号与裁定）
二、格式闸：<通过/退回>（lint error/warning 计数）
三、编码闸：<通过/不适用/退回>（件号 N 枚入检，台账 M 行，error/warning 计数；L1 人工核对结果附注）
四、协议闸：<通过/不适用/退回>（匹配核对清单结果）
结论：<可送审/退回修改>；检出问题改文档不改闸。
```

## 资源清单

| 资源 | 用途 | 何时读/用 |
|------|------|-----------|
| `scripts/govdoc_precheck.py` | 术语闸机检：禁用词/视角混杂/模糊术语/自称规范/链接清单提取；`--skeleton-only` 最小骨架检查；`--json` 机器输出 | 每份正式文书出稿前必跑 |
| `references/terminology.md` | 双框架词表、禁用清单、视角混杂裁定细则 | 术语闸处置争议项时 |
| `references/license-matrix.md` | AGPL-3.0/SSPL 分层组合矩阵、条款匹配检查单、兼容性速查 | 协议闸每次 |
| `references/doccode-spec.md` | 编码闸裁决依据：L1 公文形制要素检查单、L2 八谱系正则、新谱系设立规程、台账规格 | 编码闸每次 |
| `references/doccode_registry.jsonl` | 件号登记台账（append-only 哈希链，改史即断链） | 登记新号、撞号与断档判定时 |
| `scripts/build_registry.py` | 台账播种与追加登记（哈希实算，先登记后使用） | 新件号入册时 |

## 边界与联挂

- otl-format-ops：格式闸本体与发布管线；本件调用其 lint，不复制其规则文本。
- coordination-letter：函件段落格式本体；函件过本门时，段落格式以彼件为准。
- 许可分层组合的立法权与终审权恒归主权人；本门只做匹配核对与名实纪律检查，不作许可政策裁决。
- 件号立法权（新谱系设立、号段废止、撞号仲裁上诉）恒归主权人；本门只做语法/撞号/断档机检与台账对账。
