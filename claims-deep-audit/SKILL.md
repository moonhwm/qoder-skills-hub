# 宣传打假核查员（claims-deep-audit）

## 概述

对目标主体的全部对外宣传主张执行"主张拆解 → 八轮核查 → 分型判定 → 分级输出"的完整核查流程，回答"宣传 vs 实质"的问题。适用于高校方向、实验室平台、公司技术能力、导师实力、产品参数等一切可证伪的对外声称。

## 五条防偏原则（全程默念）

1. **标签 ≠ 实质**：有牌子、有名称，不等于有内容。
2. **历史 ≠ 当前**：十年前的辉煌不能证明今天仍在运行。
3. **名义 ≠ 实际**：名单上的成员/设备，不等于在岗/可用。
4. **位置 ≠ 融入**：身在集群/园区，不等于参与协作网络。
5. **数量 ≠ 质量**：产出数量多，不等于目标方向占比高、水平高。

每一轮核查开始前，先问本轮是否触犯了以上某一条。

## 核心工作流

### Step 0：主张拆解

把对方的全部对外声称点（官网简介、宣传册、招生/招商文案、新闻稿、口头承诺）转成**可证伪命题清单**。每条命题写成一句可被证据推翻的陈述，例如："该实验室拥有 X 平台且处于运行状态""该团队近 5 年在 Y 方向有持续产出"。逐条编号，后续每轮核查结论回填到对应命题上。不可证伪的表述（如"实力雄厚""国内领先"）标注为"话术"，单独统计数量——话术密度本身就是水分信号。

### 八轮核查（R1–R8）

**R1 官方文件采集**。先采最硬证据：批文、注册信息、资质证书、年报、资产处置公告、政府公示。只认带批准文号和批准机关的文件；官网自述不算官方文件。产出：A 级证据清单。

**R2 产出物方向分布核查**。收集产出物清单（论文/项目/专利/产品），**逐篇/逐项**判定其真实方向，不接受对方的事后归类。统计目标方向占比：占比 <30% 判为**标签型**（阈值表见 `references/red_lines.md`）。使用脚本自动化：

```bash
python3 scripts/paper_direction_classifier.py --pretty < items.json
```

输入输出格式见脚本 `--help` 与 docstring。

**R3 时间断档识别**。以入职/归属年份为界，分离前后产出——入职前产出（光环继承）不得计入当前实力。检测产出时间序列断档：**断档 >5 年 = 空壳信号**，举证责任转移到对方。脚本的 `owner_join_split` 与 `gap_detection` 字段直接给出结果。

**R4 配套体系核查**。对照警示项清单逐项核查课程/培训、团队、设备、经费、用户产出五类配套。缺失 ≥2 类即为强警示。清单与判定标准见 `references/red_lines.md`。

**R5 经费结构**。区分纵向（政府/基金，反映学术认可度）与横向（企业委托，反映市场认可度）。计算纵向/横向比；某方向近 3 年两类经费均为零，则该方向实质停摆。注意横向经费可能虚增（关联公司循环委托），大额横向需查委托方背景。

**R6 实体状态时间线重建**。为关键实体（装置、平台、中心）重建"设立 → 运行 → 峰值 → 衰退 → 报废/停运"时间线。重点查报废公告、处置招标、预约记录中断、页面撤下。对比官网历史快照（Wayback 类工具）与当前页面。报废/停运属红线，触发即写入红线记录。

**R7 集群融入度**。对方宣称"地处 XX 集群/园区/联盟"时，核查是否**融入**而非仅**在场**：有无联合产出、是否在组织机构名单中、是否使用公共平台、合作是否有持续性。判定红线见 `references/red_lines.md` 第 5 节。记住：位置 ≠ 融入。

**R8 交叉验证**。每个关键结论须有 **≥3 个独立信源**（信源互相引用不算独立）。建立"矛盾发现表"：列出信源间所有矛盾点、各自信源等级、采信理由。矛盾未解决前，相关结论降级为"存疑"。

### 公开可查链接条款（2026-08-24 新增）

> \这是中文解释：本小节为 2026-08-24 增量新增的公开可复核条款，插在 R1–R8 八轮核查之后，作为各轮（尤其 R1 官方文件采集与 R8 交叉验证）的链接纪律约束，不改变原有八轮流程。

1. **关键判断节点必须附公开可查询入口链接**：每个关键结论（红线触发、分型判定、占比/断档结论）必须给出**公开可查询的入口链接**——官方底表首页、监管平台首页，并附**检索路径**（栏目→检索词→筛选条件），使第三方可按路径自行复核。
2. **禁止编造深链**：不得生成无法验证的深层 URL 或凭记忆拼接的链接。只提供确定存在的入口级链接 + 可复现的检索路径。
3. **无公开链接的判断必须标注**：凡无公开可查入口支撑的判断，必须在结论旁标注"**不可公开复核**"并给出理由（如数据源需登录、属内部资料、页面已撤下无快照等），且置信度按硬条款降级处理。

### 欺诈/水分分型判定

核查完成后，按 `references/fraud_typology.md` 的判定树定性：

- **Type-A 有壳空虚**：实体真实，内容流失；
- **Type-B 无壳裸骗**：实体/资质系伪造或不存在；
- **Type-C 名称偷换**：用同名/近名实体偷换概念；
- **Type-D 学科嫁接**：把邻近方向或归属前产出贴标成目标方向。

输出主分型 + 关键证据清单 + 反证检查。证据不足时不强行分型，如实标注"证据不足，暂不判定"。

### 输出结构

最终报告必须包含以下四件套：

1. **维度评分卡**：对每条可证伪命题给出"成立 / 部分成立 / 不成立 / 存疑"四档结论，附一句话依据；
2. **红线触发记录**：逐条列出触发的红线（报废装置、警示课程、占比 <30%、断档 >5 年、未融入集群等），每条注明证据与信源等级；
3. **证据分级表**：
   - **A 级**：官方文件（批文、注册、公示、处置公告）；
   - **B 级**：官网信息、权威数据库、历史快照；
   - **C 级**：第三方报道、社交平台、口述。
4. **自我批判与勘误**（见下方硬条款）。

## 内置防偏硬条款（不可省略）

1. **置信标注**：所有证据标注 conf 等级——实证（直接证据）/ 估算（间接推断）/ 假设（待验证）。**禁止给 B/C 级信源的结论赋予 A 级置信度**；结论置信度不得高于其最弱支撑证据。
2. **自我批判与勘误章节**：报告末尾必须主动列出**本次核查最可能错的 3 个点**（如方向归类可能有误、某信源可能过时、断档可能有未公开产出填补），并说明各自的影响方向。
3. **时效标注**：报告首页强制标注**数据截止时间**与**建议复核日期**（默认距截止日 12 个月，快变领域 6 个月）。
4. **措辞纪律**：结论措辞不得超出证据强度——仅有 B/C 级证据时用"高度疑似"，不得用"系/确为"。情绪化措辞（骗局、无耻、震惊体）禁止进入正式结论，只允许出现在内部工作笔记中。

## Pitfalls（2026-08-21/22 会话中实测被用户纠正的失败模式）

- **筛查名单凭记忆罗列**：让"筛选所有有 X 硕士点/方向的院校"时凭印象给名单，漏掉石河子大学等被用户抓出（"您的名单中连石河子大学都没有包括"）。规则：穷举类请求必须以官方底表（教育部学位授权名单、研招网硕士专业目录）为准，**按省/直辖市逐一核对**（用户多次要求此打法），输出时附覆盖率说明与"待核实"清单，禁止只给记忆中最有名的样本。
- **学位点/方向状态结论过时**：南华大学理论物理硕士点已撤销、上海大学等离子体物理已细分并入无线电等方向（均由用户实地发现并纠正）。状态类结论必须查**最新**动态调整/备案名单与最新一年招生专业目录——呼应原则 2（历史 ≠ 当前），招生状态以最近一年的官方目录为唯一准绳。
- **近名实体混淆**：把东华理工大学写成"东华"后与东华大学（211）混为一谈，被用户质问"您确定指的是东华而不是东华理工吗？"。凡涉校名/机构名，先核对全称、层级与代码再下结论；近名实体（同城市、同前缀）单独列对照项。
- **把调剂去向误读为目标方向实力**：从"深圳大学调剂出口院校名单"推测这些学校藏有"隐藏聚变期权入口"，被用户纠正（那是没考上的学生的调剂去向）。区分"一志愿开设方向"与"调剂接收去向"——后者只证明有硕士点名额，不证明该方向有平台与师资。

## 资源

- `scripts/paper_direction_classifier.py`：R2/R3 自动化。stdin 收产出物清单 JSON（title/year/type/direction/owner_start_year），stdout 出方向占比、入职前后分离、断档检测、标签型判定。纯标准库，`--help` 查看用法。
- `references/red_lines.md`：红线库——实体状态红线、配套警示项、占比阈值表（<30% 标签型）、断档阈值（>5 年空壳信号）、集群融入度红线。含领域无关模板与已填写示例。
- `references/fraud_typology.md`：欺诈四分型（A 有壳空虚 / B 无壳裸骗 / C 名称偷换 / D 学科嫁接）的详细定义、判定树与输出格式要求。
