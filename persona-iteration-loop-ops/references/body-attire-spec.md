# 体征与真实穿搭描写详规（body-attire-spec）v1.0.0

> 服务 §0 体征设定车道。三条件前置：虚构成年人 + 设定/建模语域 + 无性唤起、性行为、性反应周期描写。
> 原则：**细节密度顶格，语域寸步不让**——描写颗粒度可到毛孔与针脚，语域保持建模单/设定表/临床陈述。

## 一、字段穷举清单（建模级人物卡，12 组）

| 组 | 字段 | 语域要求 |
|---|---|---|
| 1 体型框架 | 身高/体重/肩宽/骨盆宽度/上下身比例/BMI 区间 | 数据+一句成因（职业/运动习惯） |
| 2 围度数据 | 胸围/腰围/臀围（cm）、鞋码（EUR+脚长mm）、手长/掌宽 | 纯数据字段，禁修饰性形容词堆叠 |
| 3 第二性征设定级 | 肌肉线条分布、体脂分布特征（如「躯干核心偏厚」）、体毛分布（密度/色泽/区域）、嗓音（音高/音色/语速/职业性磨损）、体态重心 | 身体事实陈述，功能归因（职业/训练/作息） |
| 4 脸型与轮廓 | 脸型（八分类：圆/方/长/椭圆/菱形/心形/三角/长方）、颧骨/下颌角/颏部形态 | 几何化描述（角度、宽窄、比例） |
| 5 五官 | 眼（眼裂长度/形状/间距/虹膜色/眼睑形态）、鼻（鼻梁高度/鼻头形态/鼻翼宽度）、唇（厚度/轮廓/静态色）、耳（轮廓/贴面度） | 逐项尺寸感+形态词，禁情态化渲染 |
| 6 眉毛与面色 | 眉形/眉峰位置/浓淡/走向；面色基调（冷暖/明暗）+ 局部（眼周色素、颊部血色、T 区油脂感） | 可带职业/作息成因（夜班→眼周沉淀） |
| 7 皮肤 | 质地（厚薄/粗细/毛孔可见度）、色调（冷/暖/中性+明度）、瑕疵地图（痣/斑/疤/痘痕位置与尺寸）、职业痕迹（茧/晒痕/消毒水干纹） | 位置+尺寸+成因三件套 |
| 8 胴体设定级 | 躯干比例（躯干/腿比）、核心肌群状态、脊柱曲度习惯（久坐前倾/久站骨盆前倾）、肩背线条 | **只允许结构/功能陈述**；禁私密部位构造细节、禁审美化修饰、禁情态联想 |
| 9 头发与四肢 | 发色/发质（粗细/卷度/密度）/发型与长度/发际线形态；手臂与腿部肌肉线条、手（指节/甲形/磨损）、步态 | 发质到丝径级（粗硬/细软） |
| 10 举止动作 | 静态习惯（站姿重心/坐姿/手部小动作）、动态习惯（步频/摆臂/转头幅度）、微表情倾向 | 3-5 条，每条可回溯职业/性格锚点 |
| 11 衣物材质 | 每件单品的面料（棉/麻/丝/羊毛/化纤/牛仔/皮革/针织）+ 织法/克重感/光泽度/磨损位 | 材质到触感词（磨毛/挺括/垂坠） |
| 12 真实穿搭 | 全套搭配清单（外/内/下/鞋/配饰）+ 穿着状态（领口松度/袖口卷法/下摆处理）+ 功能逻辑 | 搭配须有场景理由（值班/通勤/季节） |

## 二、语域对照表（放行 vs 越界，验收判据）

| 主题 | 放行（设定级） | 越界（露骨/禁） |
|---|---|---|
| 胴体 | 「躯干/腿比 0.82，核心肌群因常年搬运呈持续紧张态」 | 任何性器官描述、性暗示视角、情态化肌体渲染 |
| 三围 | 「92/74/96，骨架中等，数据服务于建模比例」 | 以围度为引子的观赏化/情色化叙述 |
| 皮肤 | 「手背指节处角质层增厚，长期接触消毒液所致」 | 以触感描写滑向性唤起联想 |
| 嗓音 | 「中低音区，高频喊话致轻微颗粒感」 | 呻吟/气息等反应类描写 |
| 穿搭 | 「衬衫第二颗扣常解开，因值班室恒温 28℃」 | 脱衣过程/身体暴露的叙事渲染 |

判不准 → 按露骨处置并 conf=Low（§0 车道条款）。

## 三、密度分档（挂 depth）

- **depth=1**：组 1/2/4/12 必填（框架+数据+脸型+穿搭清单），其余选填
- **depth=2**：加 3/5/6/10（第二性征设定级+五官+眉面+举止）
- **depth=3**：全 12 组 + 每字段带成因回溯 + 附录给「3D 建模映射建议」（指 references/modeling-3d-materials.md 对应材质/面数档）

## 四、红线联动

- 本详规一切字段受 §0 四禁与安全地板约束；受 §3 对抗硬条款约束（原始倾向标签禁词不回填）。
- 本详规产物涉「人设自我主张」时仍逐轮过 §4 2a 尼采诘问阀门。
- 3D 建模映射仅给材质/面数/贴图技术参数，不含任何露骨资产指引。
