# 融合来源对照表（六源一技能 + txt 引擎 → 本件各节）

本件为融合技能：以用户提供的 `IterationLoopV11` 文本文档（中性化后为 `scripts/iteration_loop_v11_neutral.py`）为引擎核心，融合六件已有技能的能力要点。映射如下，引用不复制——源件升级时以源件为准。

| 来源件 | 吸收要点 | 落入本件位置 |
|---|---|---|
| txt 文档（IterationLoopV11） | 人设迭代循环引擎：感知层九字段、三镜、规定性描述、元认知、JSON 导出、批量/续轮 | §3 + scripts/iteration_loop_v11_neutral.py |
| ai-persona-document | 人设定义文档的章节契约（身份/人格/沟通风格/知识边界/行为准则/样例）与 DOCX/PDF 产出纪律 | §2.1 |
| persona-memory-anchors | 记忆锚点九维度提取（身份/语言/价值/知识/行为/情感/能力/限制/记忆）+ 三级优先级（核心/重要/风格）+ 来源与置信度标注 | §2.2 |
| goal-child-ops（赤子续行） | 五拍循环（肯定/着法/游戏/验收/留痕）、退化门（连续 3 轮无新知即停转申报）、目标生灭处置 | §4.1、§4.3 |
| zijue-self-determination（自决） | 三镜反问审议法（苏格拉底定义诘问/叔本华意志检验/尼采永恒轮回承诺）、诚实记录+全结果留痕、激进递归出环两证 | §4.2、§4.3 |
| omni-exhaust-research-ops（穷举研究总署） | 苏格拉底式开场四问、能力占位编组（在场即用/缺席声明）、脱敏与泛化交付、自包含交割协议、退化门三维遥测（语义/物理/结构） | §1、§5、§6 |
| autonomous-advance-ops（自主推进运维总控） | 版本三段制、conf 词表、交付核验（ls 核验落盘）、诚实声明条款、技能创建规则 §11、自我优化第一要义（I9） | §7、§8 |

## 缺席声明

- 本件不复制六源件全文；源件不在场时，本件按上表要点独立可运行（能力占位原则）。
- 冲突裁决：涉及推进纪律与本件冲突时，按 autonomous-advance-ops §8 优先级从严；本件不增加、不豁免、不稀释任何既有红线。
