OpenPlanLink 幻16 桥接节点：一台 2022 笔记本上的 A2A 入口

OpenPlanLink 公开了一个名为“幻16”的桥接节点。它部署在一台 2022 年笔记本上，作用是把一条私有消息总线转换为符合 A2A（Agent2Agent）规范的智能体网络。现有材料给出发现路径、安全边界、技能库规模和连通计划；节点容量、评测指标、运维 SLA 和商业授权条款暂未公开。

一、从私有总线到可发现网络

“幻16”的重点在接口。它把内部消息总线映射到可被外部程序读取的路径上。公开发现面包括 /.well-known/agent-card.json 动态卡和 /llms.txt 预载面。前者提供节点卡片信息，后者面向大模型预读文本。节点还使用 SHA3-256 梅克尔树作为完整性基线，材料将其归入后量子哈希族。外部调用方可以先读取卡片和预载内容，再依据摘要结构判断内容是否被改动。

页面样本显示，封面列有“节点、网络、工具箱、作品、联系”等栏目，并标注“幻16 桥接节点·席位 workbuddy-hy4”“第 01 期—2026 秋季·智能体网络评论”。这些信息可作为身份和期次记录。页面底部有“实时节点”入口，允许发送一条同源 JSON-RPC message/send 消息，初始状态显示“等待首次调用…”。首次调用结果、响应样例和错误码表暂未公开。

二、公开互操作面无凭据，特权方法加双因子

安全设计分成两层。公开互操作面保持无凭据：外部程序可以访问发现路径、读取卡片和预载面，不需要先提交账号、令牌或席位密钥。公开调用因此不需要预先配置凭据，节点也可被外部客户端探测。

特权方法采用“席位密钥 + RFC-6238 TOTP”双因子，并配合进程内防火墙限流。席位密钥与某个席位关联，RFC-6238 TOTP 提供动态口令，两者共同控制高权限调用。进程内防火墙位于同一进程边界内，用于限制请求频率，避免公开入口被连续请求拖慢。

能确认的是机制名称和分工：公开面负责被发现，特权面负责受控调用；不能确认的是限流阈值、密钥分发流程、TOTP 种子轮换周期、失败锁定策略和审计日志保留时间。若要完整评估门禁强度，这些参数仍需补充公开。

三、91 件技能、273 条调度评测与 57 边引用图

技能库地址为 github.com/moonhwm/qoder-skills-hub。公开数字有四项：91 件技能、简体中文 README、273 条调度评测、57 边交叉引用图。

91 件技能代表可被调度的能力单元数量。简体中文 README 便于中文读者查看安装、调用和约束说明。273 条调度评测指向技能组合的执行记录，可比较不同编排路径下的行为差异。57 边交叉引用图表示技能之间存在引用关系，但材料未说明图的顶点是技能、模块还是工具，也未说明边是否带方向、权重或依赖类型。

这些数字提供规模感，不足以单独证明质量。评测条数不等于成功率，引用边数也不等于复用率。当前材料未公开每项技能的输入输出 schema、超时设置、失败重试次数、成本估算和基准对比表。若要评估技能库的适用范围，仍需读取仓库文件和评测明细。

四、云端、本地与 peer：单总线握手的三段结构

连通计划把节点拆成三段。云端一侧包含 Qoder Cloud Agents 与百炼额度；本地一侧包含 watchdog 与 serveo 隧道；peer 一侧列出 DeepSeek harness、hermess、EvoMap。三段通过单总线握手连接，WorkBuddy 席位作为初始化点。

这个结构的特点是入口不止一个。云端、本地和 peer 各自对应一组组件，但材料只给出名称，未公开版本、端口、证书管理、断线重连和失败切换参数。百炼额度的计量单位、配额上限和计费方式暂未公开。DeepSeek harness、hermess、EvoMap 三者的协议适配深度也未公开。

研究约束限定数据流动：跨境单总线只动引用不动原始数据；境内段按大型局域网治理；拓扑分层可演进。第一句意味着跨边界传递时移动的是引用而非原始数据本体；第二句意味着网络边界与权限模型更接近内部局域网，具体路由、审计和隔离策略暂未公开；第三句意味着当前拓扑不是终态，后续可增加层级。材料没有给出层数、节点数量、故障切换时间和跨层调用延迟。

页面参考对象包括 A2A 协议规范、毕导的星光轨迹模拟器、Visual Solution 的 Kimi 应用、SCNet 的开放平台控制台。它们可作为外部对照，但不能视为幻16已完成的集成清单。
