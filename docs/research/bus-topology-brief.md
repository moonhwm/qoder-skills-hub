# 研究简报：跨境单总线、境内局域网与网络拓扑约束

版本 2026-09-27 · 方法：公开文献检索 + 对管线约束的映射 · 置信度标注于各节

## 1. 命题拆解（用户立法原句映射）
- "用一根总线将中国和美国等相关数据库连接起来" → 单一逻辑总线（single logical bus）跨域互联；
- "中国内部又是大型的局域网" → 境内段按受控内网对待（出入口收敛）；
- "网络本身有很多拓扑结构" → 物理/逻辑拓扑分层，总线是逻辑层抽象。

## 2. 证据与要点
1. 跨境物理层：中国国际光缆互联互通白皮书（CAICT）给出出入口局与光缆路由结构——跨境带宽集中于少数出入口，单总线在物理层天然是"枢纽-辐条"，不是全互联。置信：高（官方白皮书）。
2. 互连拓扑层：高性能互连网络拓扑研究综述（国防科大 Journal of National University of Defense Technology, 2026）梳理 fat-tree / torus / 直连等高维拓扑的取舍——逻辑总线若映射到直连高维拓扑（如 UB-Mesh 的统一互联思路）可降跳数，但跨境段受物理枢纽约束无法消除。置信：中高（同行评审综述+厂商架构文）。
3. 治理层：全球竞争格局下的中国特色数据跨境流动治理方案研究（中国工程科学, 2024）——跨境数据流动需安全评估/标准合同等合规通道；"数据库直连跨境"在治理层不被允许裸跑。置信：高（工程院刊）。
4. 云网实践：阿里云网络白皮书（业务迁入）给出企业跨境组网的云侧范式（CEN/转发路由器/专线）——单总线在云上的可落地形态是"转发路由器作总线枢纽"。置信：中高（厂商白皮书）。
5. 算力候选：华为云 Flexus X 实例为轻量应用级算力产品页与 FAQ 明确其与 ECS 的差异（应用封装、开箱即用）——适合作总线边缘节点/隧道出口备份，而非大规模数据库宿主。置信：中（厂商页）。

## 3. 对管线的强制约束（严格遵守互联网创建过程）
1. 逻辑单总线、物理多枢纽：总线协议层统一（A2A/JSON-RPC 或 SQL 网关协议），跨境段显式声明枢纽路径；
2. 境内段按局域网治理：默认不出境，出境只走合规通道（评估/合同/白名单字段级）；
3. 数据不动、引用动：总线传输元数据/哈希/引用（与本品梅克尔树思路同构），原始库数据留在主权域内；
4. 拓扑可演进：总线逻辑层与物理拓扑解耦，直连高维拓扑升级不影响协议面；
5. 创建过程留痕：任何新接入段先登记（席位/密钥/审计日志），后开放流量——与节点 roster 流程同构。

## 4. 未决与前置
- 真实跨境数据库互联需法务/合规评审与云厂商专线报价，本简报只给架构约束；
- 华为云 X 实例落地需账号与配额（候用户）。
