# 人设建模套件（persona-modeling-kit）

## §0 定位与边界

本件是**人设建模的双引擎合一**：
- **正向引擎（doc 线）**：需求 → 人设定义文档（规定 AI 应如何行事）；
- **逆向引擎（anchors 线）**：材料 → 人格记忆锚点 → 人设档案（还原理应如何行事）。

两引擎共享同一套**章节契约 9 节**与**锚点九维度**——正向按节写、逆向按维拆，同一人设可正逆互验（文档能拆回锚点、锚点能拼回文档，这是本套件的质量自检法）。

不覆盖：人设迭代循环训练与融合演进（persona-iteration-loop-ops 的活，本件供其文档底座）；非人设类文档。

## §1 路由：先判引擎

| 用户输入 | 引擎 | 流程 |
|---|---|---|
| 「建/写一个人设文档、系统提示词、角色定义」 | 正向 | §2 |
| 「复刻/还原/提取锚点/分析这个人设」 | 逆向 | §3 |
| 「验证这份人设文档/档案一致性」 | 正逆互验 | §4 |
| 两样都要 | 先逆后正 | §3 → §2 |

## §2 正向引擎（需求 → 文档）

1. **需求采集**：人设名/身份、源材料（虚构/历史/真人/原创/职业角色）、语言（默认随用户，中文居多）、深度（简档 1–2 页 / 全规格 5+ 页）、用途（system prompt/自定义指令/团队 onboarding/创作参考）。
2. **范围定节**（章节契约 9 节，详见 [references/structure_contract.md](references/structure_contract.md)）：

| 用途 | 必备节 |
|---|---|
| 快速人设 | ①身份 ②性格 ③沟通风格 |
| 完整角色 | 九节全含（含背景、关系、示例对话） |
| 职业角色 | ①身份 ⑤知识域 ⑥行为准则 ⑦回应模式 |
| 系统提示词 | ①②③ + ⑧边界 + 示例 |

3. **内容生成**：每节写具体不写笼统（「友好」→「以『很高兴见到你』式问候开场」）；抽象特质必配实例；边界（不做什么）与能力同等重要。
4. **样式套用**：[references/style_contract.md](references/style_contract.md)（冲突已裁决，直接遵行）。

**章节契约 9 节**：①身份与角色定义 ②性格档案 ③沟通风格 ④背景与情境 ⑤知识域 ⑥行为准则 ⑦回应模式 ⑧示例互动 ⑨版本与元数据。

## §3 逆向引擎（材料 → 锚点 → 档案）

1. **材料采集**：文档/URL/对话日志/人设名。仅有人名时先检索公开介绍与用户共识，不足则向用户确认关键特征。
2. **锚点提取**（九维度，统一编号）：

| 编号 | 维度 | 要义 |
|---|---|---|
| A | 身份定位 | 核心身份、角色、服务目标 |
| B | 语言风格 | 用词、句式、语气、修辞习惯 |
| C | 价值观与原则 | 核心信念、道德边界、优先级 |
| D | 知识边界 | 专长域、知识截止、局限声明 |
| E | 行为模式 | 回应结构、思维风格、交互习惯 |
| F | 情感表达 | 情感温度、共情方式、幽默度、礼貌层级 |
| G | 特殊能力 | 差异化特征、招牌技能 |
| H | 限制与禁忌 | 红线、禁做事项、规避话题 |
| I | 记忆与上下文 | 历史信息处理、是否记得用户 |

3. **分级标注**：核心锚（不可变，改了人设就走样）/重要锚（稳定应保）/风格锚（可微调）；每锚注来源依据+置信度（高/中/低）。
4. **档案生成**：封面（人设名/版本/日期）→ 人设概览（一句话定位+特质摘要）→ 锚点明细表（按维度，含维度/锚述/优先级/置信/来源）→ 行为示例（Ex-01 起编号，2–3 个典型场景）→ 使用说明与注意事项。

## §4 正逆互验（质量自检）

- 文档 → 拆锚点：九维度是否都可从文档中拆出非空锚点？拆不出=文档缺维，返工。
- 锚点 → 拼文档：核心/重要锚是否都能映射到 9 节中某一节？映射不上=契约漏项，返工。
- 互验结果写入当轮留痕（通过/缺维清单）。

## §5 输出策略与样式

- **默认 DOCX**；用户明示 PDF/PPTX/Markdown 则从之。
- 中文内容全程 CJK 字体；混排统一字体族不断档。
- 样式细则与冲突裁决表见 [references/style_contract.md](references/style_contract.md)；章节字段语义见 [references/structure_contract.md](references/structure_contract.md)。

## §6 运行适配

- 长文档：先通读标关键段再按维提取；对话日志：只分析人设回应侧；多源材料：先合并去重再注来源差异。
- 指定版本复刻：标明版本标签与差异点；多人设对比：各自独立提锚再加对比章。
- 版本三段制；合并后源两件（ai-persona-document、persona-memory-anchors）退役参考档在注册处，禁止再各自升版。
