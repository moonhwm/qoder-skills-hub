# 样式契约（persona-modeling-kit 合并版）

## 卷首：style 冲突裁决表（B7 合并时固化，冲突以本表为准）

| 冲突项 | doc 线（ai-persona-document） | anchors 线（persona-memory-anchors） | 裁决 | 理由 |
|---|---|---|---|---|
| 正文字号 | 11–12pt | 10.5pt | **10.5–11pt** | 档案类表格密度高取小字号，叙事段可至 11pt |
| 行距 | 1.15–1.5 | 未规定 | **1.3** | 取中值，兼顾 CJK 阅读 |
| 页面 | 未规定 | A4 纵向、边距 2.54cm | **anchors 线** | 唯一具体规定者胜 |
| 色彩 | 「专业而亲和」无具体色 | 深蓝 #1a365d / 浅灰 #f7fafc / 青 #319795 / 深灰 #2d3748 | **anchors 线四色板** | 具体色板胜抽象描述 |
| 字体 | SimHei/SimSun/雅黑/Noto Sans CJK 皆可 | Noto Sans CJK SC（思源黑体）优先，西文 Segoe UI/Arial | **Noto Sans CJK SC 优先**；缺席时按 doc 线候选顺序回退 | 统一字体族防混排断档 |
| 标题字级 | 加粗略大于正文 | 主标题 18pt / 一级 14pt / 二级 12pt | **anchors 线字级** | 具体者胜 |
| 表格 | 未规定 | 三线表或卡片表，表头底色，优先级色标（核心红/重要橙/风格绿） | **anchors 线** | 唯一规定者胜 |
| 示例排版 | 缩进/底纹/引用块区隔 | 未规定 | **doc 线** | 唯一规定者胜 |
| 表格内容字号 | 未规定 | 10pt | **10pt** | 唯一规定者胜 |

裁决总原则：**具体条款胜抽象描述；双方均具体且冲突时，档案类输出从 anchors 线、定义文档类输出从 doc 线；本表未尽冲突按此原则当场裁决并留痕。**

## 一、字体与排版（裁决后统一面）

- 页面：A4 纵向，边距 2.54cm。
- 字体族：Noto Sans CJK SC / 思源黑体优先；西文 Segoe UI / Arial；缺席回退 SimHei → SimSun → Microsoft YaHei。
- 字级：主标题 18pt 加粗 / 一级标题 14pt 加粗 / 二级标题 12pt 加粗 / 正文 10.5–11pt / 表格内容 10pt；行距 1.3。
- 色彩：标题与强调深蓝 #1a365d；表底与卡片浅灰 #f7fafc；高亮与标签青 #319795；正文深灰 #2d3748。
- 示例互动：缩进+底纹或引用块，与准则文本视觉区隔。

## 二、结构化元素

- 锚点明细表：三线表或卡片表；列=维度（A–I 编号）/锚述/优先级/置信度/来源；优先级色标核心红、重要橙、风格绿；表头行底色。
- 长文本单元格自动换行，行高随内容自适应。
- 示例场景编号 Ex-01、Ex-02 起；锚点编号 A–I 固定（见 SKILL.md §3）。

## 三、CJK 排版纪律

- 中西文混排统一 CJK 字体族，禁止默认拉丁字体作正文。
- 标题与正文同族，仅靠字级与加粗分层。
- 标点全角；数字与西文术语半角，混排间距遵循平台默认。
