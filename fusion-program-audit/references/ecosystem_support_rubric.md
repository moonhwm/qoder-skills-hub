# 生态三维判定要旨（Ecosystem Support Rubric）

**何时读我**：七步检索（尤其 Step 7 企业合作与集群融入度）之外，需要独立判定某校聚变方向背后的**市场侧与学术侧生态**——企业级支持、集群支持、学术共同体——并评估其证明力时读本文件。典型触发：学校宣传"与 XX 聚变公司深度合作""地处聚变之都""国际领先""院士/学会任职"，或评估 D2 平台实体性、D6 产业区位、D7 就业通道、D8 科研产出时需要外部交叉验证。本文件与 `policy_support_rubric.md` 互补：政策要旨管**政府侧**，本文件管**市场侧+学术侧**；与 Type A–E 欺诈类型学兼容——生态三维是独立证据维度，不改变分型逻辑，只改变证据权重与红线判定（交互硬条款见第三节）。**第四维"人才流向信号"（用脚投票=强信号、编制扣人=弱信号、核心成员批量离职=生态降级）另见 `talent_flow_signals.md`，与本文件互指，流动事件基准见 `case_anchors.md` 锚点 8**。数据截止 2026-08-24。

## 二、证明力使用规则

1. **强信号可单独支撑** D6/D7/D8 加分与"有生态"结论；中信号需两条叠加；弱信号仅作线索，须由强/中信号回填。
2. **装置机时公开记录与装置署名论文是集群维的实质性最高信号**——能接入 EAST/HL-3 机时说明通过了装置运行方的同行筛选。
3. **时效纪律**：生态证据以近三年为准（同政策要旨"历史 ≠ 当前"条款）；创始人已离职、联合实验室近三年无产出的按降权处理。

## 三、与 Type A–E 的交互硬条款

1. **宣称与某商业公司深度合作，但工商股权、招投标、双方官网交叉全部零记录 → 叠加 Type-B 嫌疑**：校企合作宣称属可证伪命题，零记录且话术密度高时在主分型上叠加标注"企业背书虚构"，对接 Type-B 无壳裸骗的认定逻辑（claims-deep-audit R 系交叉验证）。
2. **学术共同体零发表零会议记录却宣称"国际领先/一流" → 叠加 Type-A 嫌疑**：Nuclear Fusion/PPCF/PST 检索近 5 年零第一单位聚变论文、历届全国等离子体会议程序册查无报告，同时宣传"国际领先"，构成"有壳空虚"的学术侧证据，写入评级卡证据清单。
3. **接入集群装置机时有公开记录 = 实质性强信号，可作反证推翻 Type-A/B 初判**：机时记录、装置署名论文属 A/B 级证据，发现即触发误判自修正（参照西安交大 0.50→7.50 翻转规程）。
4. **生态维度与分型不互相替代**：企业级支持强但校内无招生入口/无师资仍按 Type-D/E 处理（研究真实但与考生脱节）；集群地理内零合作记 ❌ 不记 ⚠️（位置 ≠ 融入）。
5. **名称降格**：把"参会"说成"会议报告"、把"供应商"说成"联合研发"、把"集群所在地"说成"集群核心成员"，对接 Type-C 名称偷换；宣传名称与工商/批文实体不一致触发既有红线。

## 四、与政策支持要旨的分工与三侧交叉验证

- **分工**：`policy_support_rubric.md` 管政府侧（国家/省/校三级）；本文件管市场侧（企业级）与学术侧（学术共同体），集群维横跨两侧（大科学装置为政府侧资产，接入机时为市场/学术行为）。
- **三侧交叉验证流程**：① 政府侧按政策要旨定层级 → ② 市场侧查企业级支持三维信号 → ③ 学术侧查共同体信号 → ④ 汇总裁定：
  - 三侧**至少一侧有硬信号（强级）** → 记"有生态"，按信号强度进入十维评分；
  - 三侧**全为中/弱信号** → 记"生态存疑"，D6/D7 加分设上限，标注待复核；
  - 三侧**全零且宣传大词密集** → 高风险，叠加"生态背书缺失"标注，对接政策要旨交互规则 3（零支持+大词=叠加 Type-A/B 嫌疑）。
- **冲突处理**：三侧结论冲突时以信源等级高者为准；企业官网自述与工商登记冲突时以工商登记为准。

## 五、判定迭代预期与复核触发

- 常规复核同评级卡周期（默认 12 个月，快变领域 6 个月）；生态结论标注查证日。
- 即时触发事件：头部商业公司新融资/新装置节点（洪荒 170、CTRFR-1、和龙-2 等兑现或跳票会改写企业维权重）；新联合实验室揭牌或撤销；新集群载体挂牌（聚变科创城、聚能小镇扩容）；目标校导师新当选学会职务或顶刊断档 >5 年；**核心团队成员批量流向/流出实质平台或出现扣人争议（触发 `talent_flow_signals.md` 第四维复核）**。
- 版本诚实：复核后按误判自修正规程追加勘误条目，禁止无痕改写。
