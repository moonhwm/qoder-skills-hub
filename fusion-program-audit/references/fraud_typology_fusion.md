# 聚变方向欺诈类型学 Type A–E

源自《高校核聚变方向跨学院检索范式 V2.0（收敛版）》第 2.4 节，Type-E 为西安交大误判复盘后新增。本文件给出定义、与 `claims-deep-audit` 四分型的映射、判定树与输出格式。分型不互斥，报告中必须指明**主分型**并附关键证据清单；证据不足时如实标注"证据不足，暂不判定"。

---

## 一、五型定义

### Type-A 有壳空虚型（Hollow Shell）
- **特征**：有聚变学科/导师/装置的"壳"，但全部空虚——装置烂尾或报废、产出与宣传方向错位、师资老化断代。
- **识别方法**：七步检索法 + 装置状态四分类核查 + 导师产出逐篇核查。
- **典型证据**：装置签约多年未放电且第三方定性报废；团队顶刊论文全为其他装置/其他技术路线的数值模拟；方向带头人近 10 年无新国家级项目。
- **典型案例**：南华大学（F 级 1.73/10）。聚变方向完全集中在核学院、无跨学院分布——"方向集中但实质空虚"是 Type-A 的典型形态。

### Type-B 无壳裸骗型（Outright Fabrication）
- **特征**：无聚变学科/导师/装置，宣传纯属虚构。
- **识别方法**：七步检索法全部阴性，且官方底表（研招网目录、学位授权名单、项目公示）查无对应实体。
- **典型案例**：暂无定案（多数"无聚变"院校并不宣传，不构成欺诈——**无壳但不宣传 = 无欺诈，更安全**；只有无壳且宣传才定 Type-B）。

### Type-C 名称偷换型（Name Substitution）
- **特征**：有 070204 等离子体物理学科代码，但导师实际方向为空间等离子体/低温等离子体应用/夸克胶子等离子体，与核聚变无关。
- **识别方法**：Step 1 重点核查导师论文的**原始**方向，逐篇判定，不接受事后归类；聚变方向占比 <30% 即触发。
- **典型案例**：长沙理工大学物理与电子科学学院（070204 招生，实为空间等离子体）——原误判形态，后修正并入 Type-D。

### Type-D 学科嫁接型（Discipline Grafting）
- **特征**：学校某学院存在真实聚变研究，但与招生方向/宣传归属脱节——研究在甲学院、招生在乙学院，或把邻近方向产出贴标为聚变。
- **识别方法**：七步检索法发现跨学院不一致；核对招生专业代码与导师实际所在学院。
- **典型案例**：长沙理工大学——电气学院黄剑锋教授有 ITER 项目（应用超导/超导磁体）为真，但 070204 招生在物理学院且方向为空间等离子体（Type-C→Type-D 修正案例）。

### Type-E 跨学院分散型（Cross-College Dispersion，领域新增）
- **特征**：聚变方向**真实存在且实力强**，但分散在多个学院，无统一招生入口。注意：**Type-E 不是欺诈，是结构性风险**——评级可高（A 档），但必须向考生提示"入错门"风险。
- **识别方法**：七步检索法发现 ≥2 个学院有聚变方向，而招生简章未明确标注跨学院联合培养机制。
- **典型案例**：西安交通大学（物理学院激光聚变 + 电气学院 Z 箍缩 + 能源学院无聚变）、华中科技大学（物理 J-TEXT + 电气聚变与等离子体研究所 + 能源核工程，2026-04 设聚变研究中心统筹）、清华大学（工物系 + 核研院 + 机械系 + 电机系 + 能源系 + AIR + 星环聚能）。
- **对考生的实际影响**：优势是学校整体实力强；劣势是考生可能入错学院、导师方向不匹配；行动要点——先走七步法明确分布学院，直接联系目标导师确认招生代码，核实跨学院选课/双导师机制，确认学位类型（理学 0702 vs 工学 0808/0827）。

## 二、与 claims-deep-audit 四分型映射表

| 本技能（聚变领域） | claims-deep-audit（通用） | 映射说明 |
|---|---|---|
| Type-A 有壳空虚 | A 有壳空虚 | 直接对应；本技能将"壳"特化为装置/学科/导师三壳 |
| Type-B 无壳裸骗 | B 无壳裸骗 | 直接对应；注意"无壳不宣传"不定欺诈 |
| Type-C 名称偷换 | C 名称偷换 | 直接对应；本技能特化为"等离子体"名称下三大阴性方向偷换 |
| Type-D 学科嫁接 | D 学科嫁接 | 直接对应；本技能特化为跨学院归属脱节与邻近方向贴标 |
| Type-E 跨学院分散 | 无对应（领域新增） | 非欺诈，是真实布局的结构风险；通用框架未覆盖 |

复用规则：R1-R8 八轮核查、占比 <30% 标签型阈值、断档 >5 年空壳信号、红线机制、证据 A/B/C 分级与 conf 标注均**引用 claims-deep-audit 的 `references/red_lines.md` 与 `references/fraud_typology.md`，不在此复制**。冲突时以本技能的领域阈值（装置状态四分类、聚变方向占比）为准。

## 三、判定树

按顺序自问，第一个命中"是"的即为主分型：

```
Q1. 七步检索是否全阴（无任何聚变实体）且学校仍宣传聚变方向？
    是 → Type-B 无壳裸骗
    否 ↓
Q2. 宣传/招生所用名称与实际研究内涵是否不一致
    （070204 名下实为空间/低温/夸克胶子等离子体；"核聚变工程"名下实为材料处理/电气控制）？
    是 → Type-C 名称偷换
    否 ↓
Q3. 是否存在真实聚变研究，但与招生方向/宣传归属跨学院脱节？
    是 → Type-D 学科嫁接
    否 ↓
Q4. 壳（学科/导师/装置）真实存在，但装置烂尾/报废、产出错位、断档 >5 年、占比 <30%？
    是 → Type-A 有壳空虚
    否 ↓
Q5. 聚变真实且实力强，但分散 ≥2 个学院、无统一招生入口？
    是 → Type-E 跨学院分散（结构风险提示，非欺诈）
    否 → 不作欺诈定性（实质布局）
```

- Q1-Q2 依赖 A 级证据（官方目录、批文），不可用官网自述作答。
- 多型同时命中时，按危害等级 B > A > C > D 取主分型（E 单独标注），其余列为次分型。
- 每个分型结论必须附**反证检查**：至少列出一条可能推翻本分型的证据及其核查结果；若无，写明"未找到反证"。

## 四、输出格式要求

1. 主分型（+次分型）与一句话定性；
2. 关键证据清单：每条标注信源等级（A/B/C）与 conf（实证/估算/假设）；
3. 反证检查记录；
4. 置信表述：仅 B/C 级证据时用"高度疑似"，禁止"系/确为"；情绪化措辞不得进入正式结论。
