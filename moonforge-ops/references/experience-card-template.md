# 经验卡模板（experience card template）

> 每个核查过的案例落一张卡。字段不齐不称为卡；「未知」是合法值，留空不是。
> 卡片为 markdown 表格，一张案例一张表，可直接并入技能 references 或研究文书。

| 字段 | 填写口径 |
|---|---|
| 案例锚 | 链接/ID/出处（如 BV 号、仓库 commit、分享页 URL）；无锚不收卡 |
| 证据级 | 三级之一：**代码匹配级**（工程文件/仓库可见）/ **提示词展示级**（创作者晒出提示词或流程）/ **创作者账号级**（仅自述，未独立核实） |
| 制作路径 | 四路径之一：代码渲染动画 / 控制软件 / 剪辑素材 / 编排外部视频模型（定义见 production-paths.md）；混合路径全列并注明主路径 |
| 可见输入 | 实际可见的输入清单与字符量区间（提示词、素材清单、预置 skill）；隐藏输入单列 |
| 隐藏输入 | 成片外观看不到但制作必需的输入（参考片、内部循环、人工返工）；未知即写「未知」 |
| 成本口径 | 账面 API 等价 vs 缓存命中须分列；含币种与日期；未知写「未知」 |
| 失败与返工 | 创作者自曝或可查证的失败/返工/止损记录；无则写「未见披露」 |
| 可复用要点 | 1–3 条，须能从证据级直接推出；禁止超越证据的发挥 |
| 核查人与日期 | 谁核查、何时核查（复核时另起一行，不改原行） |

## 填卡纪律

1. 「创作者账号级」卡不得作为方法论依据，仅作灵感参考，且引用时必须带级别标注。
2. 卡内一切数字须可钻取到证据锚；无锚数字不入卡。
3. 复刻行为边界：仅可复刻「可见视觉元素」并标注「非工作流依据」；不得声称还原其制作路径（证据级不足时）。
