# 五维评分细则与量化标准

## 1. 医疗过错程度 (权重 0.30)

### 评分标准

| 分值区间 | 过错等级 | 典型表现 |
|----------|----------|----------|
| 0-20 | 无过错 | 完全符合诊疗规范，已尽合理注意义务 |
| 21-40 | 轻微过错 | 文书瑕疵、告知不充分，但不影响诊疗决策 |
| 41-60 | 一般过错 | 检查遗漏、用药剂量偏差，可补救 |
| 61-80 | 明显过错 | 误诊、延误治疗、手术方案选择不当 |
| 81-100 | 严重过错 | 违反核心诊疗规范、重大技术失误 |

### 量化指标
- 是否违反《临床诊疗指南》或《技术操作规范》：+20分
- 是否违反科室核心制度（三级查房、疑难病例讨论）：+15分
- 同类过错在院内是否发生过：+10分
- 过错是否属于"低级错误"（如左右侧混淆、药物过敏未核对）：+25分

---

## 2. 因果关系强度 (权重 0.25)

### 评分标准

采用 **"若无则不" (but-for) + 实质因素** 双测试。

| 分值区间 | 因果强度 | 说明 |
|----------|----------|------|
| 0-20 | 无因果关系 | 损害系患者自身疾病自然转归 |
| 21-40 | 轻微因果 | 医疗行为仅加速损害发生，非主要原因 |
| 41-60 | 次要因果 | 医疗行为与患者自身因素共同导致 |
| 61-80 | 主要因果 | 若无医疗过错，损害大概率可避免 |
| 81-100 | 直接因果 | 医疗过错是损害发生的唯一或决定性原因 |

### 量化指标
- 鉴定意见认定因果关系参与度：直接映射（0%-100%）
- 时间关联性（过错发生后损害发生的时间间隔 < 24h）：+10分
- 医学文献支持该过错导致该损害的概率 > 70%：+15分

---

## 3. 损害后果严重性 (权重 0.20)

### 评分标准

| 分值区间 | 后果等级 | 典型表现 |
|----------|----------|----------|
| 0-20 | 轻微 | 暂时性不适，无后遗症 |
| 21-40 | 一般 | 需延长治疗，轻度功能障碍 |
| 41-60 | 较重 | 中度伤残，部分丧失劳动能力 |
| 61-80 | 严重 | 重度伤残，完全丧失劳动能力 |
| 81-100 | 极严重 | 死亡或植物人状态 |

### 量化指标
- 死亡：100分
- 一级伤残：95分
- 二级伤残：85分
- 三级伤残：75分
- 四级伤残：65分
- 精神损害（严重精神痛苦）：+5至+15分

---

## 4. 注意义务违反 (权重 0.15)

### 评分标准

| 分值区间 | 违反程度 | 说明 |
|----------|----------|------|
| 0-20 | 未违反 | 已尽同等专业水平医师合理注意义务 |
| 21-40 | 轻微违反 | 一般性注意不足，未造成实质风险 |
| 41-60 | 一般违反 | 未履行常规检查或观察义务 |
| 61-80 | 明显违反 | 未履行核心注意义务（如术后观察） |
| 81-100 | 严重违反 | 故意忽视危险信号或患者主诉 |

### 关键注意义务清单
- 术前评估义务（禁忌症筛查）
- 术中监测义务（生命体征持续观察）
- 术后观察义务（引流、出血、感染征象）
- 危急值报告与处置义务
- 转诊义务（超出本院救治能力时）

---

## 5. 免责/减责事由 (权重 0.10, 反向计分)

### 评分标准（原始分，引擎自动反向）

| 分值区间 | 免责强度 | 说明 |
|----------|----------|------|
| 0-20 | 无免责事由 | 患者无过错，医疗方承担全部责任 |
| 21-40 | 轻微减责 | 患者未如实告知病史，但非主要原因 |
| 41-60 | 一般减责 | 患者拒绝合理建议，但未完全阻断因果链 |
| 61-80 | 显著减责 | 患者自身疾病极难控制，医疗过错系次要因素 |
| 81-100 | 完全免责 | 不可抗力、患者故意或重大过错 |

### 常见免责事由
- 患者或其家属拒绝签字同意合理治疗方案
- 患者隐瞒关键病史或过敏史
- 不可抗力（突发地震、停电导致设备失效，且医院无过错）
- 现有医疗技术无法预见或防范的并发症
- 紧急情况下为抢救生命采取的合理冒险措施
