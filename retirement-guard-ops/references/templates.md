# retirement-guard-ops 模板库

## 模板 A：注意力债主审计表（§1 用）

| # | 债主（事项/角色/系统） | 每周索取我注意力的形式 | 频次/周 | 可否自动化 | 可否委托 | 处置（自动化/委托/压缩/保留亲办） |
|---|---|---|---|---|---|---|
| 1 | 终审权本身 | 裁决拍板 | — | 否（合法不可推翻） | 否 | 压缩为《每周终审一页纸》 |
| 2 | 写回队列 | 技能安装确认 | ≤1 | 半 | — | 攒批满 10 轮一键安装 |
| 3 | （自填） | | | | | |

判定规则：「坚定保皇党」= 处置列只能填「保留亲办」且频次≥3 的事项。保皇党不是敌人，是退休工程的成本中心——逐项压价。

## 模板 B：每周终审一页纸（§2 用）

```
# 每周终审一页纸 YYYY-MM-DD
## ① 待拍板（仅列真正需要我的，每条≤3行：事项/选项/建议）
## ② 已自治（本周系统自动完成事项清单，一行一条，如有异常标 ⚠）
## ③ Loop 假期件（本周我主动放手的认知域，防认知投降的反向记录）
## ④ 下周预告（系统已排程将发生的事，我知悉即可）
——本周零裁决也照发，空页即「无保皇党作乱」的实证。
```

## 模板 C：退休影响评估三问（§3 用，任一为「是」则该项不得自动化）

1. 该事项出错时，损失是否不可逆？（是→保留亲办）
2. 该事项是否涉及批准权的让渡？（是→保留，批准只能被给予不能被代理）
3. 自动化该事项是否会让我失去对某领域的最低感知（认知投降）？（是→保留「假期式参与」：每周至少读一次摘要）
