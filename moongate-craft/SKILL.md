# 沉浸式大门锻造术（moongate-craft）

> 立法锚：**「可感知的承诺 = 可断言的钩子；看不见的引擎 = 空心壳。」**
> 实证来源：不断表达主站 R7–R9 三轮实战（月门昼夜双相、6 支序章池、星云全景、B 站式布局改造）。

## 〇、定位与正交性

| 邻席 | 管什么 | 本技能让渡 |
|---|---|---|
| vibecoding-webapp-swarm | 通用 React 应用、复杂状态管理 | 多页 CRUD/仪表盘归它；本技能只管**单页沉浸大门**这一窄域 |
| batch-download | 批量发现与下载视频素材 | 素材获取归它；本技能管素材**进站后的**序章池组织与轮换纪律 |
| archify | 架构/流程静态图 | 图归它；本技能管可交互三维场景 |

## 一、核心方法论（一句话）

**大门 = 一颗可自由把玩的实体（three.js 场景）× 一套有出处的时间判决（授时引擎）× 一池会轮换的开场（序章媒体池）× 一套处处可断的钩子（QA hooks）——四者缺一，门不立。**

## 二、诚实边界（置顶）

1. AI 生成素材（星云图、序章视频）必须在页面与交付报告中如实标注来源与性质。
2. 科学模拟画面（如 Schwarzschild 黑洞着色器）页面须自带「模拟，非真实影像」标注。
3. QA 结论只认钩子实测输出与截图，不认记忆、不认目测、不认「应该好了」。
4. 账号/凭据类隐私：页面只展示哈希（如 SHA3-256），明文永不出现在 HTML/JS/日志中。

## 三、六段 workflow（每段：输入 → 动作 → 输出）

### 段 1 · 场景立法
输入：用户的意象词（月/星/黑洞/星云…）。
动作：定实体（主天体）、光（主光+轮廓光）、相机（FOV 与初始距离）、语义远端（缩小全景看到什么——星云/银河/太阳系，**不是虚无**）。
输出：场景清单（实体/光源/相机/远端语义）。
🔴 检查点：远端语义未定义 → 不得开工（用户缩到最远会看到什么都不知，门无纵深）。

### 段 2 · 授时双相
输入：用户地理位置策略（定位/IP/兜底城市）。
动作：三级回退判决链——精确天文量（月出月落/日出日落，如 SunCalc）→ 粗回退（日出日落）→ 兜底（固定时段，如北京 [6,18)）；判决**依据、来源、下次重算时刻**必须常显在屏（LIVE 徽章），并配 ≥1 条可点开的参考出处。
输出：相位函数 `phaseOf(now, geo)` + 常显徽章 DOM。
🔴 检查点：徽章不存在或不含判决依据 → 判「空心壳」，返工（实证：用户原话「授时仿佛就是一个空的中心空壳」——引擎真实但不可见 = 没做）。

### 段 3 · 序章池
输入：候选视频/动画清单。
动作：池化（≥2 支）+ 随机选取 + **反重复**（localStorage 记上次，命中即重摇）+ 每支带署名（UP主/BV号/性质标注）。
输出：PROLOGUE 数组 + 反重复选取器 + 署名渲染。
🔴 检查点：单支硬编码或随机无反重复 → 返工。
**降级路径（素材未齐）**：若候选仅 1 支 → 允许先行交付单支序章，但须 (i) 页面标注「序章池未齐（1/2）」、(ii) 反重复器接口保留（池就位即自动生效）、(iii) 交付报告列入待补清单；gate_check 对此档判 WARN 而非 FAIL。零候选则不得交付序章段。

### 段 4 · 全域自由交互
输入：段 1 场景清单（实体/相机/远端语义）。
动作：拖拽/缩放/惯性**不做命中检测门**——任意位置左键拖拽即转（击中实体仅附带彩蛋），滚轮全域缩放；俯仰解除钳制（全向翻滚，越极自然翻面）；缩放上界给到远端语义完全显影（如星云穹顶 opacity=1）；移动端双指 pinch 同权。
输出：onDown/onMove/onWheel 三处理器 + 钳制常量表。
🔴 检查点：`onWheel` 内存在实体命中前置（如 `if (!pick(x,y)) return`）→ 判「死板轴」，返工（实证：命中门导致用户「无法缩小看全景」）。

### 段 5 · 双相柔化（昼相专用）
输入：段 2 相位函数 + 段 1 实体清单。
动作：昼相下暗色实体不得硬边贴底——着色器级环境混合（如 `u_daybg` uniform 混入暖乳白底+CMB 斑纹+残星）+ CSS 羽化（radial-gradient mask + 柔光 box-shadow）双 layer；黑圆必须「化入」亮底。
输出：着色器补丁 + CSS mask。
🔴 检查点：昼相截图黑圆边缘无过渡带 → 返工（实证：用户原话「黑洞怎么与白昼如此地分明」）。

### 段 6 · QA 钩子与验证
输入：段 1–5 全部产物。
动作：`window.__<gate>` 暴露 {state, cam, orbit:{yaw,pitch,roll}, phase, nebula, pro, texturesOk…}；Playwright 套件断言——门可达 / 拖拽改 orbit / 滚轮改 cam 且远端 nebula>0 / 徽章含判决依据 / 序章池 ≥2 且反重复 / 零 console error。
输出：qa_*.py + 截图证据 + 断言表。
🔴 检查点：断言表缺「交互」与「远端」两项 → 套件无效，重写。

## 四、失败模式（if-then 三段式）

1. **若** 用户报「转不动/缩不远」→ **则** 先查处理器是否被命中检测或钳制常量门住（`grep -n "pick.*return\|Math.min" intro.js`），解除后重测 orbit/cam 钩子 → **否则**查 pointer capture 与 passive listener 冲突。
2. **若** 用户报「某某功能是空壳」→ **则** 不是引擎缺失而是可见性缺失——加常显徽章暴露判决链，而非重写引擎 → **否则**（引擎确假）按段 2 三级回退重建。
3. **若** FUSE 挂载点（/mnt/…）编辑疑似丢失 → **则** 停手，改走 tmp→remove→sleep(0.3)→copy→sha256 复读五连；sha 不符即重来，禁信任 naive write → **否则**（非 FUSE 盘）正常写。
4. **若** 序章视频黑屏 → **则** 抽帧验亮度均值（<5 即黑），换时间点重切；h264+yuv420p+faststart 三件套缺一不可 → **否则**查 Referer UA 防盗链头。
5. **若** 昼相实体仍生硬 → **则** 检查是否只改了 CSS 未动着色器（或反之）——双 layer 必须同时落地 → **否则**调 mask 过渡带宽度。

## 五、反模式黑名单

| # | 反模式 | 替代做法 |
|---|---|---|
| 1 | 命中检测门住基础交互（拖拽/缩放须先点中实体） | 全域输入 + 数值钳制；命中只触发彩蛋 |
| 2 | 引擎真实但界面不可见（空心壳） | 常显 LIVE 徽章：判决结果+依据+来源+重算时刻 |
| 3 | 暗实体硬边贴亮底（白昼黑圆） | 着色器环境混合 + CSS 羽化双 layer |
| 4 | 缩放上界锁死，远端是虚无 | 远端语义化：星云/银河穹顶淡入 |
| 5 | 信任 /mnt naive 编辑 | FUSE 五连写盘纪律，sha256 复读断言 |
| 6 | 序章单支硬编码/纯随机可重复 | 池化 ≥2 + localStorage 反重复 |
| 7 | QA 靠目测与记忆 | window.__* 钩子 + Playwright 断言表 |

## 六、自检

```bash
python3 scripts/gate_check.py --smoke        # v1.1.1：26 项断言（含 14 负断言）；只测 happy path 视为无效
python3 scripts/gate_check.py <项目目录>      # 静检既有大门（PASS/WARN/FAIL/ERROR 四级词表）
```

从零起步先读 [起步模板 setup](references/setup.md)：three.js 钉版骨架 / SunCalc 引入 / Playwright 断言模板。

## 七、已知边界

- 静检为正则级启发式，不能证明交互真实手感——最终以 Playwright 实测为准。
- 天文精度依赖 SunCalc 级库；毫秒级授时需求（科研）超出本技能范围。
- 视频素材版权与署名由用户自负；本技能只管轮换与标注纪律。
