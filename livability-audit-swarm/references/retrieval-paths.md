# 检索路径（retrieval paths）——外部信源分层与登记规范

> 用途：审计/评估过程中需要**外部检索**城市宜居参数（hpi/rir/收入/榜单等）时，
> 按本文件选信源、填登记条目，并用 `scripts/retrieval_registry_check.py` 校验。
> 本文件只管「去哪查、怎么登记、登记是否合规」；参数进不进总分由
> `references/audit-roles.md` 与判定规范（R1–R11）裁决，本文件不越权。

## 1. 分层信源策略（L0–L4）

| 层级 | 信源 | 典型内容 | conf 上限 |
|---|---|---|---|
| L0 官方底表 | 国家统计局（stats.gov.cn）、各市统计局、住建部门 | 人均可支配收入、住宅成交参考价、住房租赁指导/监测数据 | A |
| L1 官方延伸 | 统计年鉴、政府公报、统计公报 | 年度收入、人口、住房存量等 | A |
| L2 权威第三方 | 中指院（中指云）、克而瑞、贝壳研究院 | 房价/租金指数、成交监测、租赁报告 | **B**（上限） |
| L3 商业平台与媒体榜单 | 链家/贝壳挂牌价、第一财经「新一线」城市分级榜、各类宜居榜单 | 挂牌价、城市分级、榜单排位 | **C**（上限） |
| L4 社媒风评 | 知乎/小红书/贴吧等风评帖 | 主观口碑、向往度情绪 | **隔离层：永不进总分**（v48 裁定延续，见 SKILL.md 硬条款 5） |

选用原则：**就高不就低**——L0/L1 可得的参数不得退用 L2/L3；L2/L3 仅作 L0/L1 缺失时的估算来源或交叉验证。L4 只允许进筛选/标注层，登记时即打隔离标记。

## 2. 数据类型 → 入口映射表

> URL 均为**入口首页**（检索纪律见第 3 节，禁止编造深链）；检索路径写法「栏目 → 检索词 → 筛选」。

| 参数 | 首选入口（首页） | 检索路径 | 备选入口 | conf 上限 | 有效期 |
|---|---|---|---|---|---|
| hpi 房价收入比 | 各市统计局 https://www.stats.gov.cn （国家）/ 市统计局门户 | 统计数据 → 「住宅销售价格」或房价收入比专题 → 选城市+年度 | 中指院 https://www.cih-index.com （市场研究 → 房价收入比报告） | B（自建比值=A/B 取收入与房价两侧较低者；第三方报告=B） | 6 个月 |
| rir 房租收入比 | 各市住建部门（住房租赁监管/租赁指导专栏） | 政务公开 → 「住房租赁」→ 租金指导/监测月报 → 选行政区 | 贝壳研究院 https://www.ke.com （研究院 → 租赁报告）；链家 https://www.lianjia.com → 城市分站 → 租房挂牌（C） | B | 6 个月 |
| 人均可支配收入 | 国家统计局 https://www.stats.gov.cn | 统计数据 → 年度数据 → 「人民生活」→ 居民人均可支配收入 → 按城市/城镇筛选 | 各市统计局《统计年鉴》《国民经济和社会发展统计公报》（市统计局门户 → 统计公报栏目） | A | 12 个月 |
| 城市分级 | 第一财经 https://www.yicai.com | 检索「新一线城市魅力排行榜」→ 最新年度榜单 → 查目标城市档位 | 新一线城市研究所（第一财经旗下）榜单发布稿 | C | 6 个月 |
| 宜居榜单排位 | 各榜单发布方首页（如中外城市竞争力研究会、经济学人智库中文版转引页） | 发布方门户 → 检索「宜居城市 排行」→ 取最新年度 | 权威媒体转载（注明转引来源） | C | 6 个月 |
| 聚变企业密度 | 国家企业信用信息公示系统 https://www.gsxt.gov.cn | 检索 → 经营范围含「核聚变/聚变能源/超导磁体」→ 按登记机关（城市）筛选计数 | 各市科技局/发改委公示（市府门户 → 政务公开 → 产业名单）；行业报告（B） | B | 12 个月 |

| 向往度代理指标 | 官方人口/人才公报（市统计局 → 统计公报 → 常住人口增量、人才净流入） | 统计公报 → 「人口与就业」→ 年度常住人口增量 | 商业招聘平台人才流动报告（C）；社媒向往度帖（L4 隔离，仅标注层） | B（官方公报派生）/C（商业报告） | 6 个月 |

## 3. 检索纪律

1. **宁给官方入口首页 + 检索路径，禁止编造深链**：url 只填确认可达的入口首页或权威发布页；具体定位靠 `entry_path`（栏目 → 检索词 → 筛选）文字描述，禁止凭印象拼深层 URL。
2. **URL 可达性抽查**：每轮登记后对新条目 url 做抽查（HEAD/GET 可达即可），不可达的降级为 `no_public_url_reason` 登记并说明。
3. **check_date 必填**（YYYY-MM-DD，实际查证当日），禁填未来日期。未来日期判定**以 UTC 为基准**（钉死，避免多机/跨时区判决翻转）：check_date 超过 **UTC 今日 +1 天** → 校验错误（exit 1）；晚于 UTC 今日但 **≤ +1 天** → 仅 WARNING（时区容差，吸收 UTC↔本地时区跨日误差），不阻断。
4. **有效期**：快变参数（房价/租金/榜单类：hpi、rir、livability_rank、city_tier、aspiration_proxy）**6 个月（实现固定 183 天近似）**；慢变参数（收入年度值、企业/装置类：income、fusion_density、fusion_access）**12 个月（实现固定 365 天近似）**。校验脚本按 183/365 天单一口径判定，超期条目不得直接引用，须复检或标注。
5. **无公开链接必须填 `no_public_url_reason`**（如「仅年鉴纸质版」「需政务申请获取」），不得留空 url 了事。
6. 检索登记文件统一放 `workspace/retrieval/entries.json`（约定见 references/livability-doc-registry.md「外部检索登记」），改动后必跑 `scripts/retrieval_registry_check.py`。

## 4. 检索条目 JSON schema（entries.json）

顶层为**数组**，每条字段（**下表以外的未知字段一律容忍：忽略不报错**，不得依赖其语义）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| city | string | 是 | 城市名（如「广州」） |
| param | string | 是 | 参数标识，建议取值：hpi / rir / income / city_tier / livability_rank / fusion_density / fusion_access / aspiration_proxy |
| value | number 或 string | 是 | 参数值（榜单档位等质性值可用 string） |
| unit | string | 是 | 单位（如「倍」「%」「元/年」「档」「位」；无量纲填「-」） |
| url | string | 是* | 入口首页或权威发布页 URL（http/https 整串匹配，须带域名——拒绝纯 IP host 与含 `@` userinfo 的 URL）；*无公开链接时填空字符串 `""` 并填 no_public_url_reason |
| entry_path | string | 是 | 检索路径（栏目 → 检索词 → 筛选） |
| source_type | string | 是 | `官方底表` / `官方延伸` / `权威第三方` / `商业平台` / `社媒风评` |
| check_date | string | 是 | YYYY-MM-DD，不得为未来日期 |
| conf | string | 是 | `A`（实证）/ `B`（估算）/ `C`（假设） |
| falsifiable_test | string | 是 | 可证伪检验：如何复核该值（如「重查统计公报 2024 居民收入章节，偏差超 ±5% 即推翻」） |
| no_public_url_reason | string | 可选 | url 为空时必填；url 非空时忽略 |
| calc_meta | object | hpi/rir 应填（v1.5 起；缺失仅 WARNING，历史条目过渡） | 自建比值口径元数据：hpi 为 `{"price":…,"area_sqm":90,"income":…,"household_size":2.8}`，rir 为 `{"rent_monthly":…,"income":…,"area_sqm":45}`；字段须正的有限数，回算与 value 偏差 >2% 为校验错误。口径定义见第 9 节 |
| comparability | string | 可选（v1.7） | 跨城口径可比性：`full`（口径完全可比）/ `proxy`（代理口径，如城镇收入代全体）/ `stale`（滞后口径，如用上年值）；非法值 → 校验错误。缺省条目不参与 --merge 口径混杂检测（第 9.4 节，仅一次性 WARNING 建议补登） |
| source_chain | string | 可选（v1.7） | 证据链：`direct`（官网/公报原文直取）/ `indirect`（媒体/第三方转引）；非法值 → 校验错误。**indirect 且 conf 为 A 或 B → 校验错误**（转引条目 conf 上限 C，见第 5 节）；缺省视为 direct 不校验 |
| evidence_band | string | 可选（v1.7，fusion_* 条目） | fusion 证据带：0–1 区间字符串如 `"0.70-0.90"`（半角连字符，两端各为 [0,1] 内数值且下界 ≤ 上界）；脚本仅校验格式、不强制填写，格式非法 → 校验错误。阶梯表见第 10 节 |

## 5. conf ↔ source_type 一致性规则

| source_type | 允许的 conf |
|---|---|
| 官方底表 / 官方延伸 | A / B / C |
| 权威第三方 | B / C（**上限 B**，标 A = 越级错误） |
| 商业平台 | C |
| 社媒风评 | C，且**隔离层，永不进总分** |

- 越级（如商业平台标 A、权威第三方标 A）= 校验错误（exit 1），必须降级 conf 或换高层信源重查。
- **source_chain=indirect（媒体/第三方转引）conf 上限 C**（v1.7 硬规则）：转引条目标 A/B = 校验错误，须降级至 C 或直取发布方原文改标 direct。背景：历轮宜居榜单条目均系媒体转引（case-3/case-4「转引存疑」遗留），转引不得给出实证/估算级置信。
- **进总分的参数（hpi/rir 等）不得直接采用 C**：C 级来源只能标「假设」并作降级处理（交叉验证、敏感性标注或暂不计入），引用时须在审计报告说明。

## 6. 偏差阈值表（审计比对用）

evidence 角色按本表复核「登记值 vs 文档现值」：

| 参数 | 阈值 | 超阈值处理 |
|---|---|---|
| hpi 房价收入比 | ±15% | → finding，medium 起 |
| rir 房租收入比 | ±15% | → finding，medium 起 |
| 人均可支配收入 | ±5% | → finding，medium 起 |
| 宜居榜单排位 | ±2 位 | → finding，medium 起 |
| 城市分级 | ±1 档 | → finding，medium 起 |
| fusion_density 聚变企业密度 | 无数值阈值（质性参数）：证据指针存在性核查——url/entry_path 可复核、信源层级与 conf 一致即可 | 指针缺失/不可复核 → finding，low 起 |
| fusion_access 聚变装置可及性 | 无数值阈值（质性参数）：证据指针存在性核查，口径同上 | 指针缺失/不可复核 → finding，low 起 |
| aspiration_proxy 向往度代理 | 无数值阈值（质性参数）：证据指针存在性核查，口径同上 | 指针缺失/不可复核 → finding，low 起 |

未列入本表的参数按「口径核对」处理，不设数值阈值。登记值与文档值不同源时，先核对口径（年度/行政区/挂牌 vs 成交）再判偏差；口径不一致本身登记为低一档 finding 并在 falsifiable_test 里写清。

## 8. 九城实战校准（case-3-cities 三城 24 条登记 exit 0（0 错误/7 警告）+ case-4-cities 2026-08-24 六城 49 条 `--merge` exit 0（0 错误/17 警告全预期）+ case-5-cities 2026-08-24 九城 74 条 `--merge` exit 0（0 错误/29 警告全预期））

> 供后续检索者校准预期；数值均已按第 2/3 节纪律检索并附 falsifiable_test，引用前仍须复检有效期。
> 案例3 覆盖广州/深圳/长沙；案例4 将历史三城按第 9 节口径重算并新增西安/合肥/南昌新城检索（检索质量评级 A，grader 5/5 数值核实 + 5/5 深链实测可达）；案例5 新增成都/绵阳/上海三城 25 条、九城合并 74 条（检索质量评级 A 持平，grader 联网抽查 5/5 精确属实，双 TZ 复跑同 verdict 同警告集）。
> 注（v1.7 起）：case-4 同命令警告数 16→17（+1 条「无错误条目缺 comparability 建议补登」一次性 WARNING，见 §9.4），exit 0 不变；case-4 存档 merge_check_output.json 为 v1.6 时 16 警告快照，v1.7 起不再逐字节复现。

- **A 级可得**：income 三城均官方公报直取（深圳 84945 元/年公报原文可开、长沙 66396 元/年统计深链实测可达、广州 80591 元/年）；其余参数三城均无 A 级口径。
- **B 级**：house_price/rent（网签/中介协会/第三方报告，注意网签 vs 挂牌口径差，广州网签 26420 元/㎡ vs 中指挂牌约 3.3 万）；hpi/rir 无官方直接发布，只能**自建比值**（B，取收入与房价两侧较低 conf；三城户均人口口径不统一，进库前须先统一）。
- **C 级**：city_tier/livability_rank 榜单类（多系转引，发布方原文常未命中，引用前须按 falsifiable_test 核原文）；长沙 rent/rir 偏 C（贝壳/链家成交租金交叉验证前不升 B）。
- **聚变产业证据的城市差异（fusion_* 只能 B 级质性指针）**：深圳**有实体**（两家核聚变公司注册+联合实验室+Helimak）；广州**有供应链/投资侧**（东方重机 ITER 部件制造、激光等离子体研究院，无在运装置）；长沙**主体外迁**（鸿鹄聚变 2025 迁上海、本地主体稀少）——同为 fusion_access，三城证据形态完全不同，登记时 entry_path 须写清实体/供应链/外迁哪一种。
- **检索纪律教训**：check_date 判定以 UTC 钉死（v1.4 起），登记校验结论必须声明运行 TZ，跨机复跑须同 exit code（详见 references/convergence-loop.md 实战定律⑤）。
- **西安（case-4 新城）**：income 仅 2024 年值可得（45082 元/年全体，A，公报直取）；rent 为挂牌均价口径（C，1500 元/月，rir=0.3993 随 conf=C 降级提醒）；fusion 证据形态为**装置共建 + 主体外迁并存**（电磁驱动聚变大科学装置西安部分 2026-08 单路脉冲源验收、西安交大核聚变科学与技术研究院揭牌；陕西星环聚能 2025-11 迁上海），登记时 entry_path 须正/负两向证据并写。
- **南昌（case-4 新城）**：income 公报仅发布城镇/农村分列值、**无全体合并值**，登记取城镇口径 59609 元/年并在 falsifiable_test 写明（全体值补发后 hpi/rir 须整体重算重标）；「星火一号」聚变-裂变混合堆总投资约 200 亿在建（一期瑶湖科学岛、2029 建成目标，conf B 指针扎实）但评分文档 INDUSTRY 字典缺席 → 系统性低估 finding（E3，候选 0.60 排期）；livability_rank 为亚洲榜第 22，**转引存疑**（C，引用前须核发布方原文）。

## 9. 自建比值口径（硬规范，v1.5 起）

> 背景：case-3-cities 实战暴露三城 hpi 自建比值口径不一（户均人口 2.62/2/3 各取一值），
> 跨城不可比（三城比对报告遗留事项）。**本节为 hpi/rir 自建比值的唯一口径来源**；
> 历史条目（广/深/长）的口径差异一律按本节重算登记，新旧值分列。

### 9.1 hpi 房价收入比

**`hpi = P × A_std ÷ (I × n_hh)`**

| 符号 | 含义 | 取值口径 |
|---|---|---|
| P | 住宅单价（元/㎡） | 检索值，成交价优先于挂牌价，口径写入 entry_path |
| A_std | 标准户型面积 | **90㎡**（标准两居），统一钉死 |
| I | 人均可支配收入（元/年） | 检索值，官方公报优先（第 2 节） |
| n_hh | 户均人口 | **2.8**，统一钉死以便跨城可比。注：七普城镇户均约 2.62–3.0 区间，2.8 为区间中枢假设，**conf=C 级假设，须随七普分区数据复核**（写入 falsifiable_test） |

检索到**现成第三方 hpi**（如中指院房价收入比报告）时，必须**同时登记其口径**
（其面积/收入/户均假设写进 entry_path 或 falsifiable_test），与按本节自建值**分列
两条登记**，不得只记裸值；第三方值 conf 上限 B（第 5 节），自建值取收入与房价两侧
较低 conf。

### 9.2 rir 房租收入比

**`rir = rent_1br × 12 ÷ I`**

- rent_1br：一居室月租，**标准面积 45㎡**；若来源为折算单价（元/㎡·月），须注明来源
  口径（**成交价优先于挂牌价**，写进 entry_path）。
- I：同 9.1，官方公报优先。
- **value 一律登记为公式直接结果的比值**（如 0.35，而非 35.3%）；百分数展示由下游
  报告层换算，避免与 calc_meta 回算口径错位。历史百分数条目重算登记时新旧分列。
  脚本对缺 calc_meta 的 hpi/rir 条目做形态提示：unit 含 `%` 或 rir value>3 →
  WARNING「疑似百分数形态」（v1.6，不阻断）。
- rir 的 `calc_meta.area_sqm`（钉死 45）**不参与脚本回算**（公式右侧无面积项），
  仅作钉死值口径校验：≠45 → WARNING「偏离统一口径」（v1.6）。

### 9.3 calc_meta 强制随条目

每条 hpi/rir 条目必须携带 `calc_meta` 对象，字段与公式一一对应：

- hpi：`{"price":…, "area_sqm":90, "income":…, "household_size":2.8}`
- rir：`{"rent_monthly":…, "income":…, "area_sqm":45}`

校验脚本（retrieval_registry_check.py v1.5 起）执行：**回算** `price×area_sqm÷(income×
household_size)`（rir 为 `rent_monthly×12÷income`）与登记 value 比对，相对偏差 **>2% →
错误**（value 与 calc_meta 不自洽）；calc_meta **缺失 → WARNING**（新规范提示，历史
条目过渡）；calc_meta 非对象 / 缺口径字段 / 字段非正的有限数 → 错误。

脚本校验范围声明（v1.6）：calc_meta.area_sqm/household_size **偏离本节钉死值**
（hpi 90/2.8；rir 45）→ WARNING「偏离统一口径」，不阻断历史条目；>2% 判定含
1e-9 epsilon 容差（数学恰好 2% 放行，消除浮点边界抖动），错误文案打印实际偏差到
4 位小数；hpi/rir 带 calc_meta 但 value 为非空白 string → **错误**（自建比值参数
不得登记质性值，无法回算比对）。

### 9.4 多文件合并校验（--merge）

`retrieval_registry_check.py --merge f1.json f2.json ...`：逐文件先各自校验（错误照常报，
消息前缀文件名），再跨文件检测——同一 (city, param) 多次登记且 value 相对偏差 **>5% →
错误（值冲突，须核对口径后保留一个）**；**≤5%（含相等）→ WARNING（重复登记取新：以
后出现文件/条目为准）**；质性 string 值不等即冲突。输出合并覆盖矩阵（城市×参数合计）
与总 entry 数；退出码契约同单文件（0/1/2）。

比较口径补充（v1.6）：比较前对 city/param/质性 value 做**空白归一化**（strip，吸收
录入空格，尾空格不另立键也不另判冲突）；可数值化的 string 值（如 `"10"`）先 float()
数值化，与数值按同一 5% 偏差口径比较（`"10"` 与 `10.0` 视为同值）；--merge 的
重复/冲突检测覆盖同一 (city,param) 的全部登记，**含同一文件内部的重复**（单文件
模式不做此项检测）。

口径混杂检测（v1.7）：同一 param 的**跨城**条目（仅限填了合法 comparability 的
无错误条目）comparability 取值 **≥2 种**（full/proxy/stale 任意混杂，proxy+stale
无 full 同样触发），且横跨 ≥2 个
城市——→ WARNING「**口径剪切：该参数跨城横比须先对齐**」，按取值列出城市分组
（如 full: 广州、深圳；proxy: 南昌；stale: 西安），不阻断。缺 comparability 的
条目不参与混杂检测，仅**一次性** WARNING 建议补登（历史条目过渡；对接 case-4
grader 遗留：西安 2024 年滞后值、南昌城镇代理口径混入六城 income 横比）。同城同
param 的取值混杂不属跨城横比，不出本 WARNING。单文件模式不做此项检测。

## 10. fusion 证据阶梯表（E1 型质性评分裁决标尺，v1.7）

> 用途：fusion_* 质性评分（如评分文档 INDUSTRY 字典分）冲突裁决的**可复现标尺**，
> 对接 references/convergence-loop.md 实战定律⑥（E1 型质性评分裁决须先读字典语义
> 头注再定性）。裁决顺序：先按头注定性（判「谁低估/谁虚高」），再按本表把该城证据
> 形态映射到建议分值带，避免凭感觉给分。

| 证据形态 | 建议分值带 | 例 |
|---|---|---|
| 在运聚变大科学装置+链主企业 | 0.90–1.00 | EAST+BEST+聚变新能（合肥） |
| 在运装置或重大在建工程 | 0.70–0.90 | HL-2M（成都）/神光III（绵阳） |
| 注册企业+联合实验室，无大装置 | 0.50–0.70 | 深圳 |
| 供应链/投资侧间接证据 | 0.30–0.50 | 广州 |
| 主体外迁/稀少 | ≤0.40 | 长沙 |

fusion_* 条目（fusion_density/fusion_access/fusion_facility/fusion_industry 等）
可随条目登记可选字段 `evidence_band`：0–1 区间字符串（如 `"0.70-0.90"`，半角连字符、
下界 ≤ 上界），标明该城证据形态所处分值带；校验脚本仅校验格式，不强制填写
（第 4 节）。

**声明**：本表为裁决辅助、非数值义务——分值带是证据形态的建议映射，不替代逐案
推理；但用于比对审计时，若评分文档现值落在该城证据带之外 → 登记偏差 finding
（medium 起，处置口径对齐第 6 节阈值表）。
