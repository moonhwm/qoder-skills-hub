# 三语料落款规范（结项报告文学化层）

落款是结项报告的收尾一行（≤2 行），不是装饰堆砌：用三语料各安其位，**溯源纪律优先于文采**。

## 1. 萧红（白描体 · 可实引，首选）
- 库：`/mnt/agents/upload/萧红文本/xh_corpus.db`（13,044 段、186 文档、FTS5 trigram + BM25，繁简归一）
- 检索工具：`/mnt/agents/output/tools/xh_fts.py`；辅助：`白描标注语料.jsonl`、`编年总目.md`
- 纪律：**凡用引号必须 FTS 实引**（返回文档+年份+段落号可核），例：「火烧云」4 段在案。引不得靠记忆。
- 适用：账本「三省吾身」的白描式收束——省就是省，超就是超。

## 2. 尼采（箴言体 · 拟作标注）
- 库：`/mnt/agents/upload/nietzsche_books/`（epub/mobi/azw3 两册）+ 指纹矩阵 `gov/09_游乐场研究卷/尼采书架指纹矩阵_v2_全尺度.json`
- 现状：译文版本混杂（指纹含译者信号，诚实标注在案），**不做逐字实引**；落款用「拟尼采体」并标「拟」字。
- 适用：预算哲学一句（如预算即权力意志的节流——拟）。

## 3. 海德格尔（存在论语体 · 缺藏在册，禁伪引）
- 现状（2026-09-22 勘查，conf=A）：upload 全域无海德格尔文本专藏；在案证据=`gov/09_游乐场研究卷/晨报附页三_R24-27` 明确登记「海德格尔/维特根斯坦文本：云席沙盒内无藏，待桌面席投喂或主理人直传」。
- 纪律：**入库前一律拟体且标「拟」，禁引号、禁《存在与时间》式伪引**；入库后回填本节路径。

## 通用格式
```
—— 书记官落款 · <萧红实引（档号）｜拟尼采｜拟海德格尔 三选一>
```
超限时建议萧红（白描承重），宽裕时拟尼采，存在级复盘（任务黄了/账本救了场）用拟海德格尔。
