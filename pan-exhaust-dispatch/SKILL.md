# 穷举统调署（pan-exhaust-dispatch，便携泛化版）

> 薄壳声明：研究引擎、苏格拉底开场、七域矩阵、全模型适配、脱敏规程的权威文本在 `omni-exhaust-research-ops`——本件**引用不复制**；本体缺席时按「能力占位」降级执行（徒手走流程），禁止假装已调度。

## §0 苏格拉底开场（首问后研，可裁剪不可省略）
定义之问（好结果长什么样）/约束之问（什么绝对不能动）/反例之问（最看好的方案最可能死于哪一环）/代价之问（选 A 就永远放弃什么）。委托方作答或明示「免问直接研」后进入统调；作答标注来源=委托方自述。

## §1 统调矩阵（点名技能清单：每任务逐件二选一）
对清单中每一件，本轮任务要么**实调**（留一句产出证据）、要么**声明「本任务无需该件」+一句理由**——禁止静默跳过。默认清单（可被委托方增删）：

| 编组 | 件 | 职责一句话 |
|---|---|---|
| 治理 | autonomous-advance-ops | 恒常纪律（档位感知/交付核验） |
| 研究 | omni-exhaust-research-ops | 穷举引擎（苏格拉底/七域/自迭代） |
| 研究 | k3-territory-studies / up-distill-ops | 专项研究/蒸馏 |
| 闸口 | output-verdict-gate / semantic-oncology-ops | 输出验收/语义审计 |
| 资源 | quota-guard-ops / plugin-datasource-ops | 额度闸/数据源路由 |
| 执法 | pangu-enforcement-bureau | 指定模型强制入候选集 |
| 协作 | coordination-letter / consignment-intake-ops | 函件/交割台账 |
| 运维 | cron-task-forge / skill-reinstall-ops / skill-refresh-ops | 定时任务/技能版本 |
| 考场 | exam-isolation-ops | 闭卷隔离评测 |

## §2 七域接口强制调用（完备性+正交性）
检索域（web/学术多源交叉）｜文档域（库文档版本对齐检索，凡涉 API 必查官方文档）｜库域（既有知识库/数据库自查先于外查）｜代码域（开源仓库先例与踩坑）｜通道域（邮件/消息证据，授权前提下）｜计时域（跨周期事项落计时器不口头承诺）｜生成域（产物形态按需；**研究≠写作，分段交付**）。每域实调或声明缺席；正交性校验=两域产出互为复制即合并登记。

## §3 自迭代检索路径
宽词初查→评估命中→按缺口窄化/换词/换语种/换信源级→再检索（默认至多 3 轮，仍缺标「查无实据」禁编造）；查询词/命中数/采用数/弃用理由随产物附录保存可复核。

## §4 跨模型向下兼容层（强制）
1. 产物=纯 markdown/通用格式+脚本纯标准库——任何 AI（免费/付费、境内/境外）可直接消费，不依赖特定平台账号；
2. 能力占位编组：一切外部能力以「能力类型」描述，实例在场即联动、缺席即降级并显式声明；
3. 降级链：目标模型不可用→同级替代→免费档→纯文本交付，每级留痕；
4. 体积自律：交割物按 1M→10M→50M→100M 分阶，超限转链接分享。

## §5 脱敏与泛化（强制）
产物不出现真实人名/证件号/单位名/项目代号（一律「委托方/某单位/项目甲」）；实名素材只在当轮内存使用，永不落盘进技能包；委托方明示「不入技能」的内容一字不进；产物默认写成任何委托方可代入的模板形态。

## §6 收敛与验收
研究收敛=维度遍历完+每维有证据或「查无实据」标注；方案交付=候选清单（中选/落选+理由）+推荐路径+风险登记+回退路径；交付前三判（判据明确/证据在场/边界无越），不过即返工。

## §7 首发试点案例
「一拖十」案头负载场景尽调（母文档一源多曝/冲刊梯度/五考程排期/双证升学路径）为本件案例库首件——新使用者可按此案例复现完整统调流程。
