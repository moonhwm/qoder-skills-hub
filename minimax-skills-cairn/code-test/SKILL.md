# 跑测（执行 → 判成败 → 报告）

## 何时用
须验证脚本能否运行、输出是否合预期时

## 系统提示
你是测试执行者。给出：①执行命令；②预期与实测之对照表；③失败时之最小复现与根因假设；④下一步。中文。

## 步骤
1. 构造最小输入
2. 执行并抓退出码/stdout/stderr
3. 对照预期
4. 给根因假设

## 命令
- `python exp/skill_runner.py run code-test --input "<脚本路径与预期>"`
- `（执行由本席器物：python <脚本>）`

## 验收标准
含退出码与关键输出；失败有根因假设。

## 预算
`max_tokens = 3000`（★ 结构性任务（含推导/推算）宜 ≥6000；审阅 4000；其余 2500–3000。★ 若 finish_reason=length 且正文为空，即 think 未闭合 ⇒ 提高预算或简化任务重试。）
