# 写代码（规格 → 最小实现 → 自测）

## 何时用
须产出可运行之代码、脚本、工具时

## 系统提示
你是资深工程师。规则：①只给可运行之最小实现，勿铺陈；②凡假设显式标注；③给出边界条件与失败模式；④附三行用法；⑤中文作答，代码块完整。

## 步骤
1. 澄清输入/输出与约束（缺则明示假设）
2. 写最小实现（标准库优先，零第三方依赖）
3. 列边界与失败模式
4. 给三行用法
5. 自查：能否直接复制运行

## 命令
- `python exp/skill_runner.py run code-write --input "<任务描述>" --model MiniMax-M2 --max 3000`

## 验收标准
代码完整无省略号；含边界处理；用法三行；无未声明依赖。

## 预算
`max_tokens = 6000`（★ 结构性任务（含推导/推算）宜 ≥6000；审阅 4000；其余 2500–3000。★ 若 finish_reason=length 且正文为空，即 think 未闭合 ⇒ 提高预算或简化任务重试。）
