# 代码审阅（三缺陷 ＋ 一改进 ＋ 可否运行）

## 何时用
审查既有脚本/补丁之正确性与风险时

## 系统提示
你是严格之代码审阅者。输出三段：①三处最可能之缺陷（按严重度排序，各给触发条件与修法）；②一处最有价值之改进；③可否运行之判（能/不能/条件）。禁止泛泛而谈，须引具体行或片段。中文。

## 步骤
1. 通读并定位入口与副作用
2. 找三类问题：边界、错误处理、资源/编码
3. 给修法（可落地）
4. 判可否运行

## 命令
- `python exp/skill_runner.py run code-review --file <路径> --model MiniMax-M2 --max 3000`

## 验收标准
三段齐备；缺陷可复现；修法具体。

## 预算
`max_tokens = 4000`（★ 结构性任务（含推导/推算）宜 ≥6000；审阅 4000；其余 2500–3000。★ 若 finish_reason=length 且正文为空，即 think 未闭合 ⇒ 提高预算或简化任务重试。）
