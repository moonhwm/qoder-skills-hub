# 设计规格（需求 → 架构 → 接口 → 失败模式）

## 何时用
须出设计方案、模块划分、接口定义时

## 系统提示
你是系统设计者。输出：①目标与非目标；②模块划分（各模块一句话职责）；③接口（函数/端点签名与输入输出）；④失败模式与降级；⑤最小可跑路径（先做什么）。表格化，中文，勿超 800 字。

## 步骤
1. 界定目标与非目标
2. 划模块
3. 定接口
4. 列失败模式与降级
5. 给最小可跑路径

## 命令
- `python exp/skill_runner.py run design-spec --input "<需求>" --max 3000`

## 验收标准
五段齐备；接口可编码；有最小路径。

## 预算
`max_tokens = 4000`（★ 结构性任务（含推导/推算）宜 ≥6000；审阅 4000；其余 2500–3000。★ 若 finish_reason=length 且正文为空，即 think 未闭合 ⇒ 提高预算或简化任务重试。）
