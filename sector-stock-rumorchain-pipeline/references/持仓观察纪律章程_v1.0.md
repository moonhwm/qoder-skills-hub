# 持仓观察纪律章程 v1.0（2026-09-09 机主令立法）

> 免责锚：本章程及哨兵一切产出仅为信息采集与观察留痕，不构成投资建议；无目标价、无评级、无买卖指令；禁外发。
> 立法依据：机主令「这些照片里面的股票是我目前的状况，您也得留意一下，写入相关纪律或者章程吧，并进行全体广播」
> 及机主批评「一点观察义务下的相关责任都不负吗？」——本章程即对该批评的制度性回应。

## 一、观察对象四分（以 watchlist.json 版本为准）
1. **实盘在仓档（高关注）**：当前账户实证在仓标的。每交易日哨兵日扫+事件库关键词扫双轨；红黄档信号即报，不得过夜。
2. **历史观察线（低关注·蓝档静默）**：2026年内已清仓标的及文档在案历史标的。不入日常扫描队列；事件库月例复看一次；出现重大事件（退市/立案/重组）升级黄档即报。
3. **观察码档**：哨兵采集固化代码（非持仓），维持低关注。
4. **新入册**：名单修订须机主口令，留痕理由与来源；文档层推定一律标 conf 等级。

## 二、信号分档与呈报义务
- **红档**（立案、退市风险、重大诉讼、实控人变更、辟谣公告）：发现即报，当轮呈机主，附一级信源链接。
- **黄档**（减持、质押、问询函、业绩预告大幅变动、传闻发酵）：当日报告内显性标注，不埋尾行。
- **蓝档**（日常讨论、无实质信息）：静默入台账，不呈报、不打扰。
- **通道受阻**（反爬/验证页）：如实报障，严禁「如实报零」冒充无信息（v2.2.1 起脚本层强制）。

## 三、信源升级链
股吧/社媒（L3 传闻层）→ 事件库/公告库（L2 事件层）→ 交易所公告/公司公告（L1 一级信源）。
凡呈报红/黄档信号，必须尽力升级到 L1 复核；无法升级者标 unverified，不得写成确定事实。

## 四、隐私与分发铁律
- 持仓数量、成本、金额、盈亏、账号**永不**入 .skill 分发包、广播、报告正文；只入本地私藏层台账（注册处，永不随包分发）。
- 广播与分发件只含：代码、名称、关注级别、纪律要旨。
- OCR 截图成果仅内部学习，不外发。

## 五、合规四件（不可拆卸）
首行免责锚 / 无目标价 / 无评级 / 禁外发。凡「验证/达成/有效」先证伪后出口。

## 六、责任留痕
每次扫描留 jsonl 台账；每轮锚定以 playlog 为准；观察失职（应报未报）记 bad 并呈机主。
