# 五段式管线细则（执行前读）

## 总则：实质先行

1. 可见答复必须是实质内容本身，禁止以流程叙述代替回答。
2. 任何交付物（含中间轮）禁止全占位骨架；「成稿轮再补」是禁句。
3. 形式校验（脚本、checklist）只对实质内容运行；对占位内容跑校验视为浪费工时。


对应 SKILL.md §2。行业=占位符 `{行业}`，个股=占位符 `{代码}`。

## S1 数据采集

- 探针：每个金融数据源先一次最低成本调用；撞墙（quota 类）→ 改零额度通道并声明；EMPTY_DATA → 换检索式。
- 插件整体缺席：按 SKILL.md §0.1 降级至公开通道，采集照做、conf 降档；S1 不存在「跳过」选项。
- 行业数据：出货量/行情/政策/驱动因素；个股数据：近两年日线（反转研判核心证据）、多期财务三表、估值、公告、股东、资金。
- 标的核验：个股代码有效性为 S1 首动作（一轮检索即可）；无效则显式降级+补正路径，声明写入 plan.md 与成稿文首。
- 落盘：原始返回一律 `/mnt/agents/output/research/{topic}/`；简报注明调用接口、失败项、缺席维度。
- 产出契约：`{topic}_brief.md`（数字紧邻来源+日期）。

## S2 研报写作

- 大纲先行落盘 `{name}.agent.outline.md`；章节分组按依赖轮次派发；一章一任务。
- 个股章研判纪律：分短期/中长期两层；给确认/破坏信号；结论用把握三档【比较确定/一般/再看看】；风险前置；不做买卖指令。
- 图表：matplotlib 低饱和配色（如 DUSK），图片存输出目录、正文相对路径引用、图注带（来源，日期）。
- 简版口径：允许单章成稿，但行业主线判断与个股分层研判（确认/破坏信号+把握三档）一项不可少。
- 产出契约：`{name}_sec{NN}.md` → 组装 `{name}.agent.final.md`，记 sha256[:16] 指纹。

## S3 舆情谣言链

- 采集：多空双向 ≥8 条传言（压缩模式 ≥2 条，但每条必须真实采集、真实定断；公告/权威媒体/自媒体/论坛分级标注），落盘传言清单。
- 拆链：一节一个可证伪陈述；任一因果节断裂 → 链条整体不成立；AI 二创内容不可作事实节（conf 上限 Low）。
- 交付四表：链节判定表（chain_check.py 校验）、文件三问表、幻觉捕获表、底表差分表（不适用须显式声明）。
- 登记：全部断言进证据链 JSON（evidence_register.py 校验零错误）；冲突永不压制。
- 产出契约：`{code}_rumor-chain_{date}.md` + claims/checklist JSON。

## S4 输出审议闸

- 派单要点：材料包指纹写入所有角色简报；控/辩/调查员三方互不可见；辩方 ≥3 条独立反对（证据指针+杀伤力评级）；评审 5 席盲评 4/5；监管门只审程序。
- 辩方意见 → 主程序机械修订 → 复审；修订后必做「grep 零残留 + 三层产物级联」验证（SKILL.md §3.2/§3.3）。
- 实质先行纪律：可见答复必须是实质内容本身，禁止以流程叙述代替回答。

## 压缩模式速查

见 SKILL.md §2 压缩表（同表）：S1 ≥5 真实数字 / S2 主线+分层研判 / S3 ≥2 条真实拆链 / S4 闸位声明 / S5 md+免责。压缩的是工作量，不是真实性。

## S5 成稿与归档

- docx 转换走在场 docx 技能；遵循在场字体规范（如宋体/Times New Roman）。
- 归档：按案分目录；卷宗含 verdict_log（指纹链、表决记录、勘误登记、数据源留档指针）。
- 若用户点名自决纪律（zijue-self-determination）：诚实记录（bad 自报/他揭）+ 广播（零 PII，写动作按授权执行）。
