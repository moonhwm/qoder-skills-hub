## §1 定位与诚实声明

名不配人设=空名。名层实证赌注（见吸收简报，conf=实测）：配齐人设锚点的命名方案在委托方感知实验组中同理心评分 β=0.32、信任 β=0.27——实验组规模小、单轮感知评分、未施盲评，β 仅作方向性参考，统计功效不足在卷，禁作因果断言（2026-09-16 外池 A5 建议强化）。

**接口性质声明**：本件交接包是**本署自定义供给包**，供给包本体不是对方技能的既有字段契约。对接技能 `persona-iteration-loop-ops`（用户侧技能库）的 §2 人设建模层定义为其文档**实有结构**：§2.1 人设定义文档九章节（身份与角色定义／人格画像／沟通风格／背景与情境／知识边界／行为准则／响应模式／样例交互／版本与元数据）；§2.2 记忆锚点九维度（身份定位／语言风格／价值观与原则／知识边界／行为模式／情感表达／特殊能力／限制与禁忌／记忆与上下文）+三级优先级（核心锚／重要锚／风格锚）+BasePersona 六字段（姓名／年龄／性别／倾向／职业／压力特征+extra）。本署供给包按下表显式映射进对方字段体系；映射是**本署提出的对接建议**，使用方有权按其 §2 自有流程取舍。

**版本快照（防虚构/防漂移）**：上述对方结构核读自 `/app/.user/skills/persona-iteration-loop-ops/SKILL.md`，版本 **v1.0.5**，核读日期 **2026-09-16**，映射日期同。对方技能版本变更时本映射必须重核（对应 SKILL.md §8 失败模式 10）；核读不到对应章节时禁止引用其结构，只能交付供给包本体。

## §2 供给包内容与映射

| 本署供给 | 内容 | 映射对方九维度 | 优先级建议 |
|---|---|---|---|
| 名与字（含定读） | 授名结果+多音字注音 | 身份定位 | 核心锚 |
| 身份叙事 | 典故→职能→性格一句链（名/字/篇目转译为岗位叙事） | 身份定位、价值观与原则 | 核心锚 |
| 非人身份声明 | 模板句：「我是 X 席 Y，AI 数字座席」类 | 身份定位、限制与禁忌 | 核心锚 |
| 行为风格 | 从诗旨提取的三条行为约定（如小星→勤谨值守、无衣→协同赴难） | 行为模式、语言风格 | 重要锚 |
| 典故出处 | 篇目+原文句（canon-pool 已验证条目） | 记忆与上下文（来源依据） | 随各锚标注 |

## §4 交接规程

1. 名定当轮产出交接包，与谱系 JSON 同卷归档；
2. 锚点变动（改名/改字/改叙事）当轮重产交接包并标版本；**对方技能无「重锚」程序，本署不虚构其规程**——使用方接到新包后按其 §2.2 自有流程重新提取锚点，旧锚留痕；
3. 叙事禁编造典故：只能转译 canon-pool 已验证条目，不得为贴岗虚构原文；样例交互若演示，须按其 §2.1 红线显式标注「演示用虚构」；
4. 脱敏红线：叙事中不出现真实人名/单位/项目代号（一律「某单位/项目甲」）；
5. 批量场景（如千例样本库）：只交前 N 席的完整供给包，其余以 schema 占位由使用方实例化——千例全量叙事另立任务，不冒充已完成。
6. **「缺锚点」判定标准**（2026-09-16 外池 A4 判后增）：交接包缺锚点＝下列任一——①anchors 四键（身份定位／价值观与原则／行为模式／限制与禁忌）任一空数组或缺键；②base_persona 六字段任一缺键且未显式占位；③narrative 空串。批量场景以 schema 占位交付**不算缺锚点**，但占位包必须带 `"status": "template_pending"` 显式标记且字段全集可实例化；无标记的占位包按缺锚点论处，交付不合规。
