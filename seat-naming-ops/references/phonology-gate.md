# phonology-gate.md 音韵闸定稿

> 定稿依据：学术尽调 DD-PHON-2026-09-16-001（scholar 八次调用，文献地图 11 靶件；规范层/描述层双层定性）。机审实现：scripts/name_audit.py。

## §1 规则总表（硬六软五）

审姓+名全名（两字或三字），声调取现代普通话四声（1阴平 2阳平 3上 4去），多音字按 canon-pool.md §4 定读。

| 编号 | 规则 | 级别 | 判据 |
|---|---|---|---|
| R1 | 逐字声调全同 | FAIL | 全名各字声调相同（1-1-1、2-2-2 等） |
| R2 | 姓与名首字同韵母 | FAIL | finals[0]==finals[1] |
| R3 | 首尾同声母（回环） | FAIL | 三字名 initials[0]==initials[2]（零声母除外；两字名退化为 R4 不重复计） |
| R4 | 姓与名首字双声 | FAIL | initials[0]==initials[1]（零声母除外——接合处两零声母记 N3 不判 FAIL；名内两零声母同例不另注，口径在卷）；y/w 按转写约定计声母（w+w／y+y 接合仍判 R4，吴娃类 FAIL 属约定内自洽） |
| R5a | 上声连读链 | FAIL | tones[0]==3 且 tones[1]==3 |
| R5b | 名内仄仄相连 | FAIL | tones[1]∈{3,4} 且 tones[2]∈{3,4} |
| N1 | 名内叠韵 | NOTE | finals[1]==finals[2]，成例豁免（李重华「叠韵如两玉相扣，取其铿锵」） |
| N2 | 名内双声 | NOTE | initials[1]==initials[2]，成例豁免（「双声如贯珠相联，取其婉转」） |
| N3 | 相邻同组声母 | NOTE | 同组：唇 bpmf／舌尖中 dtnl／舌根 gkh／舌面 jqx／翘舌 zhchshr／平舌 zcs／零 yw∅ |
| N4 | 首尾同韵 | NOTE | 三字名 finals[0]==finals[2] |
| N5 | 末字平仄取向 | NOTE | 平=响亮外放，仄=沉稳内敛；按口味参数取舍 |

**复姓适用**：判据随 surname_len 重映射——R2/R4/R5a 作用于接合处（姓末字×名首字），R3/N4 首尾=姓首字×名尾字，R5b/N1/N2 仍只作用名内两字；复姓内部二字不施判据。name_audit.py 已实现参数化（2026-09-16 backlog）。

**W 系观察注记**（机检辅助，不属软五 N 系）：W1 字级碰撞登记（collision-blocklist.json ming_watch）、W2 警示姓回读（吴/梅/莫/贾/卜/查，surname_watch）、W3 语义回读词库（semantic-watch.json 双音负义组合 v1）——不拦截、只标记，交付前人工复核；现行机检为策展规则 v1 非穷尽词库。**分工口径**：姓氏级否定回读由 W2 整姓覆盖（吴厚德类「无+名整体」回读），W3 管名内与非警示姓连读的双音组合（扩池防线；现策展池零命中属结构性预期——池内无 de2/neng2 等名首字，词库价值在扩池时兑现，不冒充现库防线）。

**两字名适用**：R5a 照常判定（判据仅涉前两字，姓 3 声+名 3 声即 FAIL，「李想」类正属此戒）；R3 退化为 R4；R5b/N1/N2/N4 须名内两字方触发。全表见 SKILL.md §3 两字名适用表（2026-09-16 A4 指谬修订）。

NOTE 留痕不否决；FAIL 一票否决。

## §2 双层定性（尽调校准结论）

**规范层（五条证实）**：R1-R5 皆有命名学规范文献支撑——汪红艳 2002「在姓名中慎用同声母韵母字」；张燕春 2002「平仄相间常使名字叫起来富有音乐感」；赵越 2001《人名用字与上声姓氏的声调搭配》（上声姓氏搭配警示，R5a 之源）；郑燕萍 2007 声韵字调谐音四维调查。其中 **R5b（名内仄仄相连 FAIL）为张燕春 2002 平仄相间描述之从紧升格**——描述层审美取向升格为 FAIL 属本署合规选择，非规范文献明令，特此声明防夸大（2026-09-16 外池 A5 指摘在案）。

**描述层（实证审美，外推须声明）**：
- 盧柏宏《中文姓名聲調探析》（NYCU 硕士论文 2010，N=20,200 语料+感知实验）：尾字声调偏好 2声>1声>4声>3声（二声过半）；尾字平:仄≈3:1；双名 16 组合 4-2 居冠、3-3 殿后；最不喜仄-仄；全名两两抑扬相间比例居高；姓氏声调不影响双名声调选择。
- Cao et al.（ISCSLP 2002，N≈992,500）：人们对名字声调模式有偏好，姓氏声调对给定名字声调模式影响很小。
- 陈泽源等 2024（现代语言学 12(10):763-769，N=865）：三字名平仄平 33.94%、平平平 22.22%；双声 5.80-7.61%、叠韵 2.90-9.13%（故 N1/N2 定 NOTE 不定 FAIL）；姓平声 73.91-75.34%；谐音名多为积极义。

**校准要点**：R1 措辞=「逐字声调全同」（早期「三平调」口径作废）；描述层排序只作 NOTE 级参考，不升格为 FAIL；命理断命类来源一律拒用。

## §3 机审规程

1. 多音字先人工定读（canon-pool §4），禁机器猜读——任 rén 不 rèn、景行 jǐng xíng 不 háng、绸缪 chóu móu 不 chōu móu，坑皆在卷；
2. 逐名出判：PASS / PASS-NOTE（附 NOTE 清单）/ FAIL（附触发规则编号）；
3. FAIL 处置：换姓优先于换名（典池条目验证成本高，姓氏池可替换成本低）；换姓后重审；
4. 批量审计结果随谱系 JSON 归档，判官可复算；
5. 转写约定：y/w 作声母处理（wen→w+en，yi→y+i），ü 写作 v（数据层如 surnames-65.json 作 lü3/nü3，name_audit.py 读入时 replace("ü","v") 归一，两写法等价，实证在卷）；与 uen/ieng 式写法差异属转写层，只可能影响 N3/N4 级 NOTE，不动 FAIL 判据（沈秉文 N4 在卷即此约定之果）。

## §4 诚实边界

- 闸是规范层工具：过闸担保「不犯已证实忌讳」，不担保「好名」；
- 描述层审美排序来自特定样本（台湾语料/特定年代人名库），跨语境外推必须声明；
- R5b「名内仄仄」为盧柏宏双名统计之强信号（仄-仄最不喜、3-3 殿后），本闸升格为 FAIL 属从紧口径，裁决留痕；
- 古今音变不论：闸只审现代普通话读音（座席名用于当代称呼场景）；涉古音拟构属另一研究课题，本件不承诺。
