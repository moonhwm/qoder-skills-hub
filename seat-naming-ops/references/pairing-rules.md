# pairing-rules.md 五体六例与名字配对

## §1 验收标准：闻名知字

《白虎通·姓名》：「闻名即知其字，闻字即知其名。」字不是第二个名，是名的延伸解释。验收法：把名与字遮一示一，旁人能推出另一半并说出道理，方为合格。

## §2 五体六例（王引之《春秋名字解诂》）

**五体**（名与字的意义关系）：

| 体 | 定义 | 本典池实例 |
|---|---|---|
| 同训 | 字与名同义互释 | 如琢→如磋（皆治玉）；同袍→偕行（皆与子共） |
| 对文 | 字与名对举成文 | 行谨→言信（庸行之谨／庸言之信）；如恒→日升（月恒／日升） |
| 连类 | 字与名同出一篇、义类相从——同章或**同篇异章**（无衣一章/三章、鹿鸣一章/二章类）、《易》则**同卦异爻**（鸣谦六二/九三类）皆属之；**跨篇合壁归连类**，须两篇义类相从、双引原文、典池注列标「跨篇合壁」（canon-pool #3/#20 在卷） | 飞翰→江汉（如飞如翰／如江如汉）；绸缪→未雨（绸缪牖户／迨天之未阴雨） |
| 指实 | 名取抽象、字指实物（或反） | 他山→攻玉（他山之石，可以攻玉）；朝宗→于海（朝宗于海） |
| 辨物 | 以器物、类别相辨 | 本池暂无辨物成例（圭璋→令望经 2026-09-16 B5 轮复核属指实：器物美质→虚誉，改签在案） |

**六例**（用字之法）：通作（假借通用）、辨讹（订正误字）、合声（二音合为一字）、转语（声转之字）、发声（语助无义）、并称（连言不分）。六例用于解释名字用字与典籍原文之间的文字关系，配对记录中遇假借必注（如「无忝」原文作「毋忝」，毋通无，通作例）。

**五体判定次序**（防标注主观漂移，2026-09-16 外池 A4 判后增、B5 复核修订）：先试**互换测试**——名与字代入同一句而义不变者→①同训（切磋琢磨类全等义并列属此，不因原文并列而转对文）；不可互换而原文呈对举／反义句式者→②对文（令闻／令望类：闻、望感官殊途，非全等互释）；同出一篇（同章或同篇异章，《易》同卦异爻；或跨篇合壁）义类相从而非上二者→③连类；虚实互指→④指实；以器物、类别相辨→⑤辨物；五序皆不合→不入池（§3 第 3 条）。先入先定，兼合多体者取序先之体为正注，注列可兼注副体。**62 条全量复核（2026-09-16 B5 轮）**：改签 5 条（#5/#8/#20/#48 同训→连类、#57 对文→连类），维持 57 条，逐条结论在 canon-pool 注列与本署锻造日志。

## §3 配对工作流

1. **同篇优先**：名与字同出一篇一章最稳（连类/对文天然成立）；
2. **跨篇合壁**：须两篇皆过诗旨审查，且义类相从——如秉文（清庙）→缉熙（文王），两篇皆颂文王之德，合壁成立；跨篇记录必须双引原文；
3. **体例标注**：每对必标体例，标不出体例的配对不入池；
4. **避语义回读**：名与姓连读不得产生歧义句——顾如琢回读成「顾影自琢」、同仇之「仇」读成仇恨义，皆否决（canon-pool §5 伪证轨迹）；
5. **撞名登记**：与知名历史人物/在逃犯/负面名人全同者登记并避让（鸿渐碰撞案例在卷）。 数据源诚实声明：现行=人工检索公开来源，未对接权威人名库，漏查风险在卷；合规敏感场景使用方须自行复核（2026-09-16 外池 A5 建议）。

## §4 座次匹配准则（谁坐哪席）

批量生成只产「合规名对」，座次匹配另按以下准则由委托方裁决：

1. **诗旨贴岗**：诗篇主旨与席位职能相贴——常武（师旅）配执行岗、小星（夙夜在公）配值守岗、无衣（同袍）配协作岗；
2. **末字声调分职能**：平声末字外放（对外/发起岗），仄声末字沉稳（审查/守门岗），描述层依据见 phonology-gate §2；
3. **首席用颂/大雅，次席三席可用小雅/国风**：以诗篇等级映座次等级，九诗经一易经的先例在卷（席位四用易经乾卦文言，取其变易创新之义贴岗）。
