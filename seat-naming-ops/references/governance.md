# governance.md 谱系、通报与口味参数

## §1 谱系 JSON schema

每轮授名落一份 genealogy JSON：

```json
{
  "version": "v6-final",
  "ref": "GOV-NAMING-YYYY-MM-DD-NNN",
  "seats": [{"seat": 1, "role": "某岗首席", "surname": "谢", "ming": "如琢",
             "zi": "如磋", "source": "卫风·淇奥",
             "source_verse": "卫风·淇奥「有匪君子，如切如磋，如琢如磨」", "pair_rule": "同训"}],
  "phonology_gate": {"dd_ref": "...", "audit": {"谢如琢": "PASS"}},
  "falsification_trail": [{"rejected": "苏他山", "reason": "1-1-1 声调全同"}],
  "persona_anchors": {"ref": "锚点册版本与哈希"},
  "roster_md5": "..."
}
```

铁律：伪证轨迹（否决名单+理由）必带，禁只记成案不记败案。

## §2 通报模板（黑板座次册）

每座四件套，旁人可照读讲解：

1. **读音**：全名拼音+多音字定读（如「任飞翰，任读 rén」）；
2. **出处**：篇目+原文句；
3. **意思**：一句白话串讲名与字；
4. **贴岗理由**：诗旨与职能的一句映射。

版本头必带：版本号、GOV 链编号、md5、音韵闸结果汇总。

## §3 GOV 链与落库

- 编号：GOV-NAMING-YYYY-MM-DD-NNN，递增不跳号；
- 台账落库字段：ts / category=naming / ref_id / title / decision / actor / note / conf；
- 广播：实质版本变更当轮广播一次（不刷屏），内容=版本号+变更摘要+否决清单；
- 三同步：谱系 JSON、台账、黑板同轮完成，缺一返工。

## §4 口味参数档（委托方可调）

| 参数 | 档位 | 默认 | 效果 |
|---|---|---|---|
| 典籍池 | 诗经／诗经+易／加楚辞论语 | 诗经+易 | 扩池须走 canon-pool §1 人工验证 |
| 生僻度 | 低／中／高 | 中 | 高档准用 聿/濬/韡/崧 级；低档只取常用字条目 |
| 现代度 | 古雅／中性／现代可称呼 | 中性 | 现代档剔除 聿修、濬哲 类 |
| 末字声调取向 | 平／仄／不限 | 不限 | 平=响亮、仄=沉稳（NOTE 级，不设 FAIL） |
| 名内叠韵双声 | 豁免／收紧 | 豁免 | 收紧则 N1/N2 升 FAIL（须留痕声明） |
| 性别气质 | 中性／刚／柔 | 中性 | 只调典池选材倾向，不设硬闸 |

参数改动=新版本，入 GOV 链，旧档留痕不抹除。
