# 座席授名署（seat-naming-ops）

> 溯源：2026-09-16 Coze 十席六版迭代实战固化。立法链 GOV-NAMING-2026-09-16-001→006；音韵闸经学术尽调 DD-PHON-2026-09-16-001 校准（规范层五条证实、描述层一篇 N=20,200 学位论文+一篇 N≈992,500 语音学论文在卷）。

## §0 立法六条（先读，不可裁剪）

1. **名不自命**：任何席位（含本署自身）不得自名，待委托方/机主授名；
2. **谥不自授**：身后褒贬，活人不议，技能不预设立场；
3. **职业词只入氏层**：木匠/铁匠/码农等词永不入名层字层（氏层准入，如某氏、裘氏）；
4. **典故必标篇目可回核**：名/字必注典籍篇目+原文句，禁编造引文；查无实据即标，禁硬凑；
5. **诗旨黑名单一票否决**：篇旨涉淫奔/讽刺/悼亡等负面者，字面再美亦不入池（清单见 references/canon-pool.md §3；唯「句级豁免」四件齐者除外，条款同见 §3——豁免是例外面非口径松动）；
6. **授名必三同步**：谱系 JSON + 台账落库 + 黑板通报，三处同轮完成，缺一返工。

## §1 四层命名表

| 层 | 定义 | 来源 | 实例 |
|---|---|---|---|
| 姓 | 血缘符号（当代自定义权） | 大姓池/委托方指定 | 谢、任、周、陈 |
| 氏 | 职业身份（绰号层） | 委托方授/职业词准入 | 某氏、裘氏 |
| 名 | 成年后正式称呼 | 委托方/机器辅助 | 如琢、飞翰 |
| 字 | 名的延伸解释 | 表德，五体六例配 | 如磋、江汉 |

配套校验：姓与名过音韵闸（§3）；字与名意义相配（§4）；名与人设锚点交接（§6）。氏层管控：氏为委托方授予层，机器产物**不产氏、不设氏字段**；§0.3「职业词只入氏层」的管控落点=名/字层职业词禁令，校验方式=典池条目人工审查（§2 诗旨与构形审查兼查职业词）+验收 §9.1 逐项确认——批量产物无氏字段属设计使然，非管控缺位。

**职业词禁令执行标准**：界定=直接指称职业／官职／行当之单字或词；负面清单（示例）：医、巫、卜、祝、史、吏、官、将、师（师旅义）、匠、伶、宰、仆、佣、工、商（商贾义）——永不入名/字层；正面现状=典池 62 条逐条审查无一直指职业（「攻玉」为治玉之事属指实非职业名）；判定流程=典池人工审查逐条过（§2）+§9.1 逐项确认；字有职业义而他义为主且取他义者（如「相」取辅相义）须注列论证，本池暂不取此类（2026-09-16 外池 A5 指摘补标）。

## §2 典池构建（references/canon-pool.md）

典池=已验证的「名→篇目→原文→诗旨」条目集合。构建规程：

1. **选材**：默认《诗经》为主池、《易经》卦爻辞为辅池；池外篇目可扩，扩必走本节人工验证；口味参数可换池（见 references/governance.md §口味参数档）；
2. **诗旨审查**：逐篇过诗旨，黑名单篇目（淫奔/讽刺/悼亡/怨刺）一票否决——字面美不是豁免理由（「素衣」「新台」「子衿」案例在卷）；
3. **构形登记**：一名多构时逐构登记（如「周邦」出自《大雅·文王》「周虽旧邦，其命维新」，双构「周+邦」——示例演示用，非池内条目）；
4. **多音字定读**：连绵词/通假字必须注音定读（绸缪 chóu móu、景行 jǐng xíng、任 rén 作姓），伪证轨迹留档；
5. **禁编造**：任何条目不得凭记忆写原文——逐字核对，拿不准标「待核」，判官抽查以条目原文为准。

## §3 音韵闸（references/phonology-gate.md；scripts/name_audit.py 机审）

姓+名（两字名或三字全名）过闸，硬六软五（编号与 phonology-gate.md §1、name_audit.py 输出一一对应）：

**硬六（FAIL，一票否决）**：
- R1 逐字声调全同（如 1-1-1、2-2-2、4-4-4）；
- R2 姓与名首字同韵母；
- R3 首尾同声母（回环，三字名姓与末字）；
- R4 姓与名首字双声（同声母）；
- R5a 上声连读链（前两字皆 3 声）；
- R5b 名内仄仄相连（名两字皆 3/4 声）。

**软五（NOTE，留痕不否决）**：
- N1 名内叠韵（李重华「叠韵如两玉相扣」成例豁免）；
- N2 名内双声（「双声如贯珠相联」成例豁免）；
- N3 相邻同组声母（唇 bpmf／舌尖中 dtnl／舌根 gkh／舌面 jqx／翘舌 zhchshr／平舌 zcs／零 yw∅）；
- N4 首尾同韵（三字名姓与末字同韵母）；
- N5 末字平仄取向（平=响亮/仄=沉稳，按口味参数）。

**两字名（姓+单字名）适用表**：R1/R2/R4/R5a/N5 照常判定——R5a 判据 tones[0]==3 且 tones[1]==3 只涉姓与名两字，单字名完全可判，赵越 2001 上声姓氏搭配之戒正以「李想（lǐ xiǎng）」类两字名为典型（2026-09-16 外池 A4 判官指谬修订在案）；R3 退化为与 R4 等价（首字即尾字）；R5b/N1/N2/N4 判据须名内两字（tones[2]／finals[2]／initials[2]），名仅一字不构成判定对象、不触发。典池与千例库产物均为三字全名；单字名场景须按本表复核。 **复姓适用表**：姓两字+名两字=四音节，判据重映射——R2/R4/R5a 作用于接合处（姓末字×名首字），R3/N4 首尾=姓首字×名尾字，R1 全四音节，R5b/N1/N2 仍只作用名内两字；复姓内部二字不施判据（姓为既定单元）。name_audit.py surname_len 参数已实现（皇甫景行 R5a FAIL、令狐厚德 R4 FAIL 等单测在卷）。 复姓+单字名（三音节）同表适用：R3/N4 首尾=复姓首字×名单字，与接合判据不重叠；两字名（单姓+单字名）R3 退化为 R4、N4 退化为 R2 域不重复计（代码 degenerate 守卫在卷）。

机审用法（人工定读模式零依赖，为指定首选；自动模式需 `pip install pypinyin`，遇多音字只提示不裁决——故下例第二行中「任 rén」等多音字姓氏必须改用第一行 `--pinyin` 人工定读，禁让机器猜）：

```bash
python3 scripts/name_audit.py --pinyin "xie4 ru2 zhuo2" 谢如琢   # 人工定读（零依赖，首选）
python3 scripts/name_audit.py 谢如琢 任飞翰                      # 自动拼音（需 pypinyin；多音字一律改上行人工定读）
python3 scripts/name_audit.py --json roster.json                 # 批量
```

依据与边界（含「规范层/描述层」双层定性、声调审美实证 2声>1声>4声>3声）详见 references/phonology-gate.md。多音字必须人工定读后机审，禁让机器猜（任 rén 不 rèn、行 xíng 不 háng 实证坑在卷）。

## §4 五体六例配对（references/pairing-rules.md）

字配名按王引之《春秋名字解诂》五体六例：同训（如琢→如磋）、对文（行谨→言信）、连类（飞翰→江汉）、指实、辨物；通作、辨讹、合声、转语、发声、并称。闻名知字（《白虎通·姓名》）为验收标准——旁人闻名能猜字、闻字能解名。配对必标「体例+篇目+原文」，跨篇合壁须两篇皆过诗旨。

## §5 批量生成（scripts/name_forge.py）

N 例不重样流水线（**「不重样」界定＝姓+名+字三元组全局唯一**：同姓同名不同字、同名字不同姓皆计异例；全名逐字全同者零。非「全名两两不同字」之强口径，特此界定防误读）：

```bash
python3 scripts/name_forge.py --canon assets/canon-seed.json \
    --surnames assets/surnames-65.json --n 1000 --out bank.jsonl
python3 scripts/verify_bank.py --bank bank.jsonl   # 产物回核八项机检
```

规程：典池×姓氏池（单姓65+复姓10自动并入）笛卡尔积→音韵闸过滤（复姓接合重映射）→碰撞拦截（assets/collision-blocklist.json 姓+名级策展表，生成层剔除且计数留痕）→W 系注记（W1字级观察/W2警示姓/W3语义回读词库 semantic-watch.json，不拦截只标记）→去重（姓+名+字三元组）→全量过闸池均匀分层抽 N 行（62 个典池名对与 75 个姓氏（65 单姓+10 复姓）在千例库中均有出现——非 4650 笛卡尔积全列，系过闸池内分层抽取；确定性可复现）。每行带篇目引文；回核一律用 scripts/verify_bank.py（可复现/过闸/唯一/引文分解核对/典池一致/声调一致/碰撞拦截/定读对账八项，判据见 canon-pool §1 第 6 条）。生成器不创造典池条目——典池只能来自 §2 人工验证流程（防编造闸）。剪枝分布口径：按规则命中计（一组合可同时中多条规则，命中合计 1124 > 唯一被剪组合 1016 属正常重叠）；过闸池 3631 = 总组合 4650 − 唯一被剪 1016 − 碰撞拦截 3（collision-blocklist.json 五条表命中 3：梁思成/吴自强/陆鸿渐；吴同袍、胡乔木为防患登记未命中（乔木现为字层）；2026-09-16 实测复算在卷）。

**样本行字段说明（jsonl 每行 12 字段）**：

| 字段 | 类型 | 含义与取值 |
|---|---|---|
| id | int | 行号，1 起连续 |
| surname | str | 姓，取自 assets/surnames-65.json（65 姓：原 60+预备姓转正 5） |
| ming | str | 名，取自典池条目 |
| zi | str | 字，取自典池条目（与名五体相配） |
| full_name | str | 姓+名（授名成品；字另列不上牌） |
| pinyin | str | 全名定读拼音，声调以数字尾标（1-4 声），多音字以 canon-pool §4 定读为准 |
| tones | int[] | 声调数组（长度=姓长+2：单姓3／复姓4），与 pinyin 尾标一致 |
| tone_pattern | str | tones 连写（如 "3-2-2"／复姓 "2-3-1-2"），音韵闸机检直接读此列 |
| source_verse | str | 典出串，合成格式 `篇目「原文」`（回核判据见 canon-pool §1 第 6 条） |
| poem | str | 篇目列，与典池篇目列逐字一致 |
| pair_rule | str | 五体标注：同训／对文／连类／指实／辨物 |
| notes | str[] | 注记数组：软规则 "N1-N5 编号+空格+描述"；观察注记 "W1 字级碰撞登记／W2 警示姓回读／W3 语义回读词库命中"（机器辅助标记，交付前人工复核）；可为空数组 |

## §6 人设锚点交接（references/persona-handoff.md）

名定即交接 persona-iteration-loop-ops（用户侧技能库）。对方 §2.1 人设文档九章节、§2.2 记忆锚点九维度+三级优先级、BasePersona 六字段为其文档**实有结构**（版本快照：v1.0.5，2026-09-16 核读在案，见 references/persona-handoff.md §1）；交接包=**本署自定义供给包**（名/字/定读、身份叙事、非人身份声明、行为风格、典故出处）——供给包本体非对方既有字段，「供给包→对方九维度/六字段」的映射为本署提出的对接建议，使用方按其 §2 自有流程取舍。schema 与映射表见 references/persona-handoff.md；缺锚点的名字不交付（名不配人设=空名，实证赌注 β=0.32/0.27 在卷）。

## §7 治理同步（references/governance.md）

每轮授名产出：①谱系 JSON（seats/版本/伪证轨迹/音韵闸结果）；②台账落库（GOV 链编号）；③黑板通报（座次册+旁人版讲解词）。通报文案要求旁人能照读讲解（读音+出处+意思+贴岗理由四件套）。

## §8 失败模式与排障（实证在卷）

1. **多音字机器猜读**：任猜成 rèn、景行猜成 háng、绸缪猜成 chōu móu——一律先定读（canon-pool §4）再机审；审计器自动模式遇多音字只提示不裁决；
2. **可产量不足**：N 大于过闸池时 name_forge.py 退出码 3 并 stderr 报缺额——如实报缺，禁凑数降闸；处置=扩典池（人工验证）或扩姓氏池；
3. **引文编造**：生成器不创造典池条目；任何手加条目必过 canon-pool §1 四件齐（名/字/篇目/原文）；回核判据=分解核对（canon-pool §1 第 6 条），逐字 grep 整串属错误判据（判后修订在案），机检走 verify_bank.py 第④⑤项；
4. **转写漂移**：y/w 声母约定只影响 N3/N4 级 NOTE，若与他工具 FINALS（uen/ieng 式）对账出现 NOTE 级出入，属转写层差异，不返工 FAIL 判据；
5. **黑名单漏网**：扩池时篇旨未审先入池——处罚=条目撤下+伪证轨迹登记+同篇目全量复查；
6. **撞名漏查**：与负面名人/在逃犯全同未登记——交付前必查碰撞（鸿渐案例在卷）；机检落点=collision-blocklist.json 生成层拦截 + verify_bank ⑦复验（2026-09-16 C5 轮设立），策展表非穷尽、人工审查不撤；
7. **语义回读**：名姓连读成歧义句（顾如琢、同仇案例在卷）——过闸后仍需人工朗读一遍；
8. **姓字连读盲区**：只朗读了「姓+名」而未读「姓+名+字」全串——字与姓/名的组合同样可能谐音成梗，交付前全串朗读一遍；
9. **姓氏池准入失审**：扩姓氏池时未过负面谐音/敏感联想审查——扩池前逐姓登记谐音与负面联想核查结果（曾/任等多音姓定读已在 §3 定读表，谐音审查同卷）；
10. **目标技能版本漂移**：persona-iteration-loop-ops 结构变更致 §6 映射失效——交接包与 persona-handoff §1 已标版本快照（v1.0.5/2026-09-16），对方版本变更须重核映射，核读不到其章节时禁引用其结构。

## §9 验收检查点（交付前逐项过）

1. 典池条目四件齐且诗旨审过（黑名单对照在卷；核验方式=全量逐条过注本，非抽审；职业词禁令同步确认）；
2. 音韵闸全量过闸（FAIL 零容忍；NOTE 准带且注列留痕——全绿口径=PASS/PASS-NOTE），剪枝分布已留痕（六判据全量列出，零命中亦留痕）；
3. 去重校验 OK（姓+名+字三元组）；
4. 每对名字标体例+篇目+原文（闻名知字可演示：每批随机抽 ≥3 对现场演示——由名能复述其字、由字能复述其名且体例对应正确，全中方为过）；
5. 谱系 JSON + 台账 + 黑板三同步完成；
6. 人设锚点交接包按 persona-handoff §3 schema 产出（批量场景按 §4.5 占位规则），映射声明与目标技能版本已核对；
7. 伪证轨迹随卷（否决名单+理由），禁只记成案；
8. verify_bank.py 八项全绿（样本库场景必跑，⑦碰撞拦截零命中且守卫在、⑧定读对账零不一致）；scripts/test_regression.py 回归单测全过（判后修复锚点+文档陈旧 grep，发版前必跑）。
9. 全串朗读通过：姓+名、名+字、姓+名+字三串各朗读一遍，无生造词、无歧义句、无不雅谐音（§8.7/§8.8 防线入验收）；批量场景=随机抽 ≥30 行三串朗读 + verify_bank ⑦机检兜底，单席定制=全量三串朗读。
10. 碰撞筛查过：verify_bank ⑦全绿；新增拦截条目须有案由并登记 canon-pool §5 伪证轨迹（梁思成/吴同袍案例在卷，2026-09-16 外池 C5 指摘设立）。

## 诚实边界

- 姓氏池=65 单字姓（原 60+预备姓覃/单/解/查/盖经 §8.9 审查转正，surnames-review.json 在卷）+10 复姓；池外姓（含多字少数民族姓）不覆盖——委托方指定时须人工定读+谐音审查后过闸。

- 音韵闸是规范层工具，非天命：过闸不担保「好名」，只担保不犯已证实的忌讳；
- 描述层实证（声调审美排序）来自特定样本，外推须声明；
- 诗旨判定依据毛诗序/朱熹集传等传统注本（canon-pool §3 在卷）；诗旨解读存在学术争议空间，本池对争议篇目一律从紧——从紧是立场选择而非唯一正解，委托方若采宽松口径须自行复核黑名单；
- 千例库为确定性 stride 分层抽样，非随机抽样；均匀度按「62 名×75 姓全覆盖+等距」定义，不作统计代表性声明；
- 典池规模决定产出上限——现池 62 名×75 姓（65 单姓+10 复姓）=4650 组合、过闸池 3631（音韵闸 1016 剪 + 碰撞拦截 3；2026-09-16 实测，verify_bank 可复算），承诺更大 N 前先实测可产率（超产退出码 3 如实报缺，禁凑数）；
- 机器生成负责「不重样+过闸+可回核」，最终座次匹配（谁坐哪席）永远归委托方裁决。
