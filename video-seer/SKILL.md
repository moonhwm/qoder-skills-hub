# video-seer

不依赖重型库（纯标准库 + 系统 ffmpeg/ffprobe），把一支 mp4 拆成「可读」的结构化材料。

## 工作流

1. 运行：
   ```bash
   python3 scripts/video_seer.py <video.mp4> [--frames 8-12] [--outdir /tmp/video-seer-frames]
   ```
2. 产出（`<outdir>/<视频名>/` 下）：
   - `frame_XX_t*.jpg`：等间隔抽帧（宽 ≤768），数量 ≤12
   - `report.json`：ffprobe 元数据 + 场景切换点（时刻+分数）+ 每帧亮度/对比/饱和/色偏 + 帧差运动强度曲线
   - `report.md`：上述内容的 markdown 骨架，末尾留「观看笔记」空位
3. 用视觉能力（read_file 逐张看 jpg）读关键帧，结合 report 中的切镜密度、运动曲线、明暗/色调统计，在「观看笔记」处写结论。

## 参数约定

- 场景切换阈值默认 `gt(scene,0.3)`，可用 `--scene-thresh` 调。
- 抽帧默认 10 张，按时长等间隔取中点，避免黑场首帧误导。

## 诚实边界

- 抽帧 ≠ 理解全片：帧间动作细节、转场动效、文字滚动只能部分推断。
- 不做音轨分析（无对白/配乐判断），如需另接音频工具。
- 运动强度来自 64x36 灰度帧差，是粗粒度信号，不区分镜头运动与主体运动。
- 亮度/色调基于 16x16 缩样的均值统计，局部光效可能被平均掉。
