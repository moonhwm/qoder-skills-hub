## 1. 迭代收敛 8 步流程

1. **全量读取**：读入全部面板与信源，列出数据清单（来源、年份覆盖、信源等级）；
   未列清单不得开始评分。
2. **基准版评分**：用当前权重产出 v1 基准（评分、模式判别、冲稳保分档）。
3. **交叉信源检查**：执行 §3 的 5 维验证，逐维记录发现。
4. **错误清单分级**：把发现整理为错误清单，按重大/中等/轻微三级分类（见 §4）。
5. **修正重算**：应用修正产生 v(n+1)；每版必须给出"v(n) → v(n+1)"对照
   （字段修正、模式重判、评分与排名变化）。
6. **收敛判定**：计算本轮相对上轮的最大评分变化 Δmax；按 §2 判定是否收敛。
7. **版本回溯纠错**：收敛后执行 v1→vN 全版本 diff 审查，确认无遗留自相矛盾。
8. **收敛声明**：输出收敛状态、置信度配比、top3_likely_wrong 与最终诚实判定。

纪律：
- **每轮必落盘**：每轮产物（评分 JSON、错误清单、对照表）写入工作目录并核验存在，
  杜绝"声称完成但未落盘"。
- **版本号诚实**：版本号单调递增；未达收敛标准不得在标题宣称"最终/收敛版"。
- **未收敛降级**：收敛前一切结论标"未收敛"，措辞降一级交付。

## 2. 收敛标准（4 级）

| 级别 | 标准 | 含义 |
|---|---|---|
| L0 未收敛 | Δmax ≥ 0.05 | 继续迭代 |
| L1 弱收敛 | 0.005 ≤ Δmax < 0.05 | 可用于内部讨论，禁止对外交付 |
| **L2 收敛** | **Δmax < 0.005 且连续 3 轮** | **可交付的默认门槛** |
| L3 严格收敛 | Δmax == 0.0000 且连续 3 轮 | 数据完全冻结时的强收敛 |

- Δmax = 同一权重下、同一学校集合、相邻两轮评分的最大绝对变化。
- 新增/删除学校、变更权重、新增信源 → 收敛计数**清零重计**。
- 仅修正非评分字段（如文字表述）不清零，但需记入变更日志。

## 3. 交叉验证 5 维范式

每轮迭代对全部在库学校执行 5 维验证：

1. **面板内部一致性**：派生字段复算（一志愿率、调剂率、复试通过率），与记录值对账
   （即 panel_validate 的 C1-C5）。
2. **官方信源对照**：面板数值 vs 官网/研招网/官方公告逐校核对；冲突按
   `references/source_confidence.md` §4 处理。
3. **跨版本一致性**：本轮结论 vs 历史版本结论 diff；任何"结论反转"必须能归因到
   具体新证据，归不了因 = 存在隐性错误，回第 4 步。
4. **跨方法交叉**：同一数据用 ≥2 种独立方法（如本技能轻量评分 vs 其他评分范式/排序法）
   跑一遍；排名剧变的学校列入复核名单。
5. **反向压力测试**：用 `references/admission_patterns.md` §4 三项偏见清单逐条反问
   当前结论；命中任一条即回第 4 步登记修正。

## 4. 版本回溯纠错流程

收敛判定时执行一次全版本回溯（v1→vN）：

1. **逐版 diff**：列出每版相对前版的全部断言变化。
2. **错误清单**：把确认的错误按三级分类——
   - 🔴 重大：影响模式判别或冲稳保分档归属（如把 γ 陷阱误判为保底校、关键数值方向性错误）；
   - 🟡 中等：影响评分但不改变分档（如调剂名额趋势误判、权重口径偏差）；
   - 🟢 轻微：表述/遗漏类（如人才流动、排名数据遗漏）。
3. **修正与重跑**：重大/中等错误修正后重跑评分并清零收敛计数；轻微错误可并入下一版。
4. **变更日志**：每项修正记录（字段/断言、旧值、新值、证据、影响）。
5. **防再发**：把错误模式补进偏见清单或校验规则（如新增 panel_validate 检查项）。
