## 1. 三录取模式判别规则

判别优先级：**先 β → 再 γ → 再 α → 都不满足=未定型**（β 的"零调剂"证据最硬，γ 的"备胎"
风险最需优先排除）。判别使用最新 3 年（不足 3 年降级置信度并标注）。

| 模式 | 判别规则（需同时满足） | 证据强度要求 |
|---|---|---|
| **β 零调剂堡垒** | ① 连续 ≥3 年 transfer_admit==0（或 transfer_rate ≤0.05）；② 期间 first_choice_rate ≥0.90 | 需 ≥3 年实证；仅 1-2 年零调剂不得判 β |
| **γ 高调剂陷阱** | ① 最新年 first_choice_rate <0.30；② 复试后大量刷人：retest_pass_rate <0.50 **或** transfer_rate >0.70 | 复试通过率是硬指标；仅一志愿率低不足以判 γ |
| **α 一志愿过线即录** | ① 一志愿 retest_pass_rate ≥0.98（≈100%）；② 调剂为**补录非竞争**：first_choice_admit == retest_count（进复试者全录），调剂是计划未满的额外名额，不构成对一志愿的竞争 | 必须区分"补录"与"竞争型调剂"：若一志愿进复试者被刷且名额被调剂占据，则不是 α |
| **未定型 mixed** | 以上均不满足 | 给出最近似模式 + 缺什么证据，禁止强行归类 |

**关键辨析**（档案中最易误判处）：
- "总录取 > 计划" + "一志愿全录" ⇒ 调剂是**额外补录**，α 成立；一志愿率数字低不改变对一志愿考生的事实。
- "一志愿率低" + "复试通过率也低" ⇒ 学校在一志愿复试中大量刷人、名额留给校外调剂 ⇒ γ。
- "一志愿率低" + "复试通过率 100%" ⇒ α（一志愿报得少，但报了过线就录）——与 γ 完全相反。

## 2. 每模式对一志愿考生的真实含义

| 模式 | 真实含义 | 决策要点 |
|---|---|---|
| α | 单向成功路径：过线即进复试、进复试即录取；调剂不挤占一志愿 | 核查"筛选前置"（见偏见2）：通过率 100% 可能只是进复试人少；查进复试线是否等于国家线 |
| β | 高门槛、高保护：一志愿生源充足，学校不接收校外调剂；复试刷人少 | 风险全部前置到初试：必达分是硬门槛；无调剂窗口风险，即使复试被刷也无调剂压力（但也无退路） |
| γ | 一志愿考生是备胎：学校把名额留给 985/211 落榜调剂生，"名校落榜生避风港" | **切勿误判为"双非保底校"**；一志愿报考=以己之短攻彼之长；原则上从保底链剔除 |
| 未定型 | 证据不足或模式切换中 | 列入观察名单，补数据后重判；交付时显式标"未定型" |

## 3. 调剂窗口风险六层解构

当目标校存在调剂环节且考生可能落入调剂时，必须逐层解构"窗口时间极短"的含义：

### 3.1 时间层——"闪电战"操作难度
普通调剂窗口 24-48h；极短窗口（如 14h，00:00-14:00）内只能锁定 1-2 校、无暇比对。
**窗口越短，准备与信息的价值越高，临场发挥空间越小。**

### 3.2 信息层——信息优势决定成败
关键信息重要性降序：① 知道"什么时候开系统" > 分数高低；② 知道"导师联系方式" > 复试内容；
③ 知道"优先级规则的实际操作" > 规则文本。无内部信息渠道、无校友网络、无实时监控能力的
考生在短窗口下结构性劣势。

### 3.3 竞争层——优先级档位的实际含义
官方调剂优先级（如 A&B>A>B>C>D>E）按本科背景定档。C/D 档（跨学科背景）在 14h 窗口下
**实际竞争力趋近于零**——高档位考生上午即填满名额。

### 3.4 风险层——一志愿失败后的"断崖式风险"
四路径概率树（示例结构，概率需按校实证填充）：
- 路径1 进复试→被刷→窗口已关→GAP（灾难性）
- 路径2 未进复试→窗口已关→GAP（灾难性）
- 路径3 进复试→录取（成功）
- 路径4 未进复试→调剂成功（短窗口下概率趋近 0）
**高调剂率+短窗口校的成功路径往往只有路径3 一条，一旦偏离即 GAP。**

### 3.5 结构层——"调剂依赖型" vs "一志愿保护型"

| 维度 | 调剂依赖型 | 一志愿保护型 |
|---|---|---|
| 调剂率 | 高（如 >40%） | ≈0% |
| 学校意图 | 主动寻求外部优质生源 | 优先保护一志愿 |
| 一志愿考生地位 | 备胎 | 核心 |
| 风险结构 | 单向高风险 | 双向稳定 |

"22+20"式的录取结构（一志愿+大额调剂并存）是学校**主动选择**高调剂率的证据——
若学校想保护一志愿，完全可以压缩调剂名额。

### 3.6 心理层——"调剂去向丰富"的反向解读
看到"调剂去向含顶尖 985"时反向解读：985 考生调剂进来 = 985 考生一志愿落榜的降级选择，
而非该校是一志愿首选目标。调剂去向丰富 ≠ 培养质量背书。

### 窗口风险评级三因子（pattern_classify.py 实现）

| 因子 | 高 | 中 | 低 |
|---|---|---|---|
| 窗口时长 window_hours | ≤24h（含 14h 级） | 24-48h | >48h |
| 优先级档位 priority_tier | D/E | C | A&B/A/B |
| 一志愿保护度 | γ 型或 first_choice_rate <0.3 | α 型或未定型 | β 型 |

合成规则：任一因子=高 且保护度≠高 → 风险=高；全低 → 低；其余 → 中。
**任一因子缺测 → 该因子按"未知"处理，综合评级不得高于"中"，并标注"窗口未知"**；
三因子全缺测 → 输出"窗口未知（缺测），按中风险保守处理"。

## 4. 三项系统性偏见警示（交付结论前逐条自查）

### 偏见1："调剂去向丰富"的正面偏见
| 之前假设 | 解构后 |
|---|---|
| 调剂去向丰富 = 培养质量高 = 正面 | 调剂去向丰富 = 学校常年招不满一志愿 = **负面信号** |
| 调剂来源含 985 = 学校吸引力强 | = 学校主动寻求外部优质生源 = 对一志愿考生不利 |
| 调剂名额多 = 机会多 | = 学校更重视调剂生源质量 = 一志愿保护弱 |

### 偏见2："一志愿过线即录"的过度乐观
| 之前假设 | 解构后 |
|---|---|
| 一志愿复试通过率 100% = 一志愿保护强 | = 进复试的人少 = **筛选在复试前已完成**（筛选前置） |
| 必达分低 = 门槛低 = 容易录取 | 必达分低 = 复试线低 ≠ 录取线低 |

配套核查：一志愿率低意味着大量一志愿考生未进复试；未进复试者在短窗口下直接失去调剂机会。

### 偏见3："调剂规则"的形式主义解读
| 之前假设 | 解构后 |
|---|---|
| 调剂规则明确 = 公平竞争 = 有机会 | 规则明确 ≠ 实际操作公平 |
| 优先级 C/D 档 = 中等竞争力 = 可以尝试 | 极短窗口内规则变成"先到先得"而非"按优先级" |

**自查口令**：本结论是否把"调剂多/去向好"当加分？是否把"通过率 100%"当保护？
是否把规则文本当实操？任一为是 → 回到 §1 重判。
