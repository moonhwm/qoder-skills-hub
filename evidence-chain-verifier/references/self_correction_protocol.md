# 自修正协议与公开复核链接规范

SKILL.md Step 3/5 的细则。附链与发生修正时读本文件。

---

## 1. 勘误流程（发现错误时的固定动作）

触发条件：自查发现或用户指出先前结论错误。**不得悄悄改写历史输出**，按以下四步执行：

### Step A 勘误表

落盘 `{主题}_errata_{日期}.md`，每条勘误四列：

| 原结论 | 新结论 | 证据 | 影响范围 |
|---|---|---|---|
| "X 机构具有 Y 资质"（conf: Medium） | "未查到 Y 资质备案"（conf: High） | 监管平台检索无记录（E2，2026-08-23） | 报告第 3 节结论、评分卡第 2 项 |

影响范围必须追到所有引用了原结论的下游内容（报告章节、评分、建议）。

### Step B conf 降级

受波及条目的 confidence 按新证据重定级；只降不升（除非补充了新的独立信源）。

### Step C 措辞降级

措辞不得超出证据强度，按此阶梯降级：

```
"系 / 确为 / 证实"  →  "高度疑似"  →  "存疑 / 未能证实"
```

仅有 E4/E5 级证据时，起点不得超过"高度疑似"。情绪化措辞（骗局、无耻、震惊体）禁止进入正式结论。

### Step D 版本号诚实递增

- 修正类更新：同一大版本内递增小版本——v1.0 → v1.1 → v1.2；
- **不跨大版本掩盖修正**（禁止把勘误包装成 v2.0 全新版）；
- 仅当核查对象或范围发生根本变化时才升大版本，且必须保留旧版勘误记录；
- 文件名体现版本：`{主题}_report_{日期}_v1.1.md`。

## 2. 版本与报告头部模板

每份报告首页固定：

```
版本: v1.1（v1.0 勘误：资质结论修正，见 errata 文件）
data_cutoff: 2026-08-23
建议复核日期: 2027-08-23（快变领域 2027-02-23）
```

## 3. 公开复核链接书写规范

核心纪律：**宁给官方入口首页 + 检索路径，不给编造的具体深链。**

- 只写你**实际访问过**或**确认为官方入口**的 URL；禁止凭 URL 规律拼凑深链（ID、参数多半编造）；
- 格式：`入口页 URL ｜ 检索路径：第一步 → 第二步 → 看什么字段`；
- 入口页须是该平台的首页或一级查询页（如 `https://www.example.gov.cn/search`），不是具体结果页；
- 若链接来自二手转述且未亲验，标注 `（未亲验，复核时先打开确认）`；
- 无法给出任何公开入口时，回到登记表填 `no_public_url_reason`，禁止假装有链接。

## 4. 官方入口清单模板（按领域，"入口页 + 检索路径"格式范例）

以下入口域名为常见官方平台的公开入口类型示例；**使用时必须亲验当前可用性**，失效或域名变更时在勘误表中记录并替换。

### 教育 / 学历 / 招生

| 平台 | 入口 | 检索路径示例 |
|---|---|---|
| 研招网（硕士专业目录） | `https://yz.chsi.com.cn/` | 首页 → 硕士专业目录查询 → 选省市 → 选学科门类/专业 → 核对招生单位名单 |
| 学信网（学历学籍查询） | `https://www.chsi.com.cn/` | 首页 → 学历查询 → 本人/零散查询 → 输入证书编号 |
| 教育部监管平台 / 名单公示 | `https://www.moe.gov.cn/` | 首页 → 公开 → 名单/公告检索关键词（如"学位授权点名单"）→ 下载官方底表 |
| 中留服（国境外学历认证） | `https://www.cscse.edu.cn/` | 首页 → 认证院校名单/查询入口 → 按国家地区检索院校 |

### 法律 / 司法

| 平台 | 入口 | 检索路径示例 |
|---|---|---|
| 裁判文书网 | `https://wenshu.court.gov.cn/` | 首页 → 输入当事人/案由关键词 → 按法院层级/年份筛选 → 核对案号 |
| 执行信息 / 失信名单 | 中国执行信息公开网 `http://zxgk.court.gov.cn/`（失信名单在 `/shixin/` 路径） | 入口页 → 输入姓名/企业名 + 证件号 → 核对立案时间（使用时亲验当前可用性，域名变更时在勘误表记录） |

### 企业 / 工商

| 平台 | 入口 | 检索路径示例 |
|---|---|---|
| 国家企业信用信息公示系统 | `https://www.gsxt.gov.cn/` | 首页 → 输入企业全称/统一社会信用代码 → 看登记状态、行政处罚、经营异常 |
| 天眼查 / 企查查（第三方辅助） | 各自官网首页 | 仅作线索；关键结论必须回到公示系统（E2）核实 |

### 其他领域

按同一格式扩展：`平台 ｜ 官方入口首页 URL ｜ 检索路径：… → 看什么字段`。找不到官方入口的领域，写明"该领域无公开底表"，相关断言 confidence 上限为 Low 并填 `no_public_url_reason`。

## 5. 反证检查

每次修正与每份报告收尾时，至少列一条**可能推翻当前结论的证据**及其核查结果；未找到反证时写明"未找到反证，检索了 A/B/C 三个方向"。反证检查不通过（找到反证）立即回到本文件第 1 节走勘误流程。
