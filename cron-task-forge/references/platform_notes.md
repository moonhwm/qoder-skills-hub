# Kimi 定时任务平台实测约束（2026-08-29 实测，conf=empirical 除标注外）

| # | 约束/语义 | 实证来源 |
|---|---|---|
| 1 | 名称上限 50 字、正文上限 8000 字（编辑弹窗计数器实测 16/50、278/8000） | 用户截图 |
| 2 | `update_cron_job` 改正文=**整体替换**；列表接口只回截断前缀，服务端全文 agent 不可全读——改正文前必须拿到用户粘贴的全文并存档 | ERR-FAL02-01 |
| 3 | `status=paused` 保留全部内容可随时恢复；优先于删除 | 花未眠处置 |
| 4 | 提醒绑定**创建时所在会话**——触发轮的成本随该会话上下文长度增长；长会话里的任务可考虑迁往短会话重建（需用户配合，agent 无法跨会话绑定） | 成本分析轮 |
| 5 | 任务卡挂「额度不足 去升级」徽标 = 账号 quota 见底，到点可能无法执行；按 k3-interaction-ops 条款 1 处理（不硬推、报用户、等刷新） | 用户截图 |
| 6 | 定时任务 UI 支持「过期时间」字段（实测默认约 3 个月）——长周期任务建议显式设过期防永久挂账 | 用户截图 |
| 7 | cron 五字段（分 时 日 月 周）；工作日档 `0 8 * * 1-5`；每周一 `0 4 * * 1`；每月 1 日 `0 9 1 * *` | 本任务实盘 |
| 8 | 触发后 agent 的执行上下文 = 提醒正文 + 所在会话；卡正文须自包含（绝对路径、重建命令、报告口径），不能假设读到某个会话记忆 | 花未眠标本 |
