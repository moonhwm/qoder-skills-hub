## §8 依赖环境自包含（self-containment）
- 一切产物脚本仅依赖 Python 标准库或已 vendored 资产：证据链校验（evidence_register.py）、语义审计（semantics_audit.py）、迭代日志（iteration_log.py）均为纯标准库
- 网站产物：主题 CSS/字体（ET Book base64 内联）/工具库全部本地化，**禁止外部 CDN 引用**；单文件版 `site/dist/single.html` 0 外部依赖、file:// 直开
- 环境自检清单（每轮迭代首轮动作）：`python3 -c "import agent_gw"`、`ls` 关键脚本路径（ifind_tool.py / cli.mjs / 三个用户 skill 脚本）、`node --version`。任一缺失 → 显性报告"环境降级"并给出修复命令，禁止静默绕过

## §9 哈希链与时间戳（防篡改留痕）
- 每轮迭代收尾对全部产物计算 SHA-256 并链接：`chain_node = SHA256(prev_node + file_hash)`，root 写入 `data/hash_chain.json`，含 ISO 8601 带时区时间戳
- 校验方法（任何人可复核）：重算任一文件哈希与登记值比对；重放全链验证 root 一致性
- 本轮 root：`256cf1f297841faea95bd0667614f25e…`（18 节点，2026-08-28T04:1x+08:00 生成；网站发布后产物变更将于下一轮重铸链）
- cron 每轮必须在产物首行打印数据快照时间戳；哈希链 root 变化即版本递增的客观依据

## §10 热拔插（hot-plug 技能与接口注册表）
- 每轮迭代开头执行库巡检：`ls <技能安装位> | wc -l`、`ls /app/.agents/skills | wc -l`、`ls /app/.agents/plugins`，与上轮基线比对，**新增 skill 自动进入候选评估**（本轮实证：user 库 39→41）
- 接口通畅检测：对任务所需接口做最小调用探针（如 iFinD `describe` / Wind 单标的轻量查询）；失败按宪章 v1.0 §7 显性化，连续 2 轮失败熔断
- 新 skill 接入标准：与既有技能边界不重叠（衔接不重造）、有脚本则先 `--help`/`--smoke` 自检、首次使用产物 conf≤Medium 直至通过一次人工复核
- 拔插记录写入当轮迭代日志（接入/弃用/原因）

## §11 网页交付固化（publishable snapshot per major iteration）
