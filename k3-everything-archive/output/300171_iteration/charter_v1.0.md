## 1. 标的与研究边界
- 标的：300171.SZ 东富龙（制药装备→生物工艺装备/耗材转型中）
- 形态：公开信息结构化整理（**中性表述，禁用"优势/霸权"比较级**）
- 边界：仅用 C1 官方数据通道（iFinD/Wind/Gildata 插件）+ 法定披露原文；禁止 web 数值来源；不构成投资建议；无目标价；无评级语汇；仅供个人研究，禁止对外分发

## 2. 数据路由（优先级序）
1. **先行指标（枢纽节A3）**：合同负债环比、存货中发出商品、应收账款账龄 → iFinD 资产负债表+附注
2. **财务三表**：近3年+2026H1（若已披露，窗口期优先）→ iFinD 主源，Wind 校验
3. **分部兑现**：生物工艺/耗材收入与毛利率 → 年报/中报分部披露；颗粒度不足时降级为合同负债+调研纪要三角，conf≤Medium
4. **行情估值**：现价、PE-TTM、市值 → 双源交叉；附 PE-Band 历史分位与可比公司（楚天科技、新华医疗）对照
5. **股东/治理**：回购、增持、质押、减持 → iFinD holders + Wind financial_docs 公告
6. **舆情/研报**：Gildata / xhcj-news → 仅作命题线索，不作数值来源
7. **催化剂日历**：2026H1 中报披露状态（8/31 截止）→ 第一优先查证

## 3. 命题登记表（预注册证伪条件）
| 命题 | 类型 | 证伪/降级触发线 |
|---|---|---|
| H1 行业capex回暖传导至订单 | 因果 | 合同负债连续2季环比降>10% → 降级 |
| H2 生物工艺/耗材放量兑现 | 事实+因果 | 分部增速<整体增速 或 毛利率未改善 → 证伪 |

## 4. 数据口径仲裁（固化条款）
- 主源：定期报告原文为终极基准；iFinD 主提取，Wind 校验
- 差异 <0.5% 记噪声；0.5–2% 查口径并 conf≤Medium；>2% 字段禁用+入 top3_likely_wrong
- 数值三要素强制：[来源库, 报告期, 调整前/后/TTM]
- 追溯重述全序列统一调整后口径并声明

## 5. 收敛标准（防滥用版）
- 连续2轮无 High 错点 **且** 该2轮内含≥1次独立源切换重算 + ≥1次扰动测试
- 抽样回检 ≥20% 已登记证据
- 基线隔离：前轮结论仅作待验证假设，不得回流为事实
- 全部关键断言入证据链登记（claim/source/url或no_public_url_reason/check_date/falsifiable_test/conf）

## 6. 披露日历联动
- 2026-08-28 处于中报披露窗口（8/31截止）：若 2026H1 中报未出，订单/回款/减值类断言自动 conf≤Medium 并标注"数据停留于Q1"
