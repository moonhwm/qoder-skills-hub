# Verifier v2 — 散户解读文档验收标准

适用对象：`doc/` 下的策略解读文档（Markdown 源稿）。
判定：`lint_doc.py <file>` exit 0 = 自动项 PASS；C 类由独立评审判定。

## A. 合规与措辞（自动）
1. 禁止承诺性词汇：稳赚 / 保本 / 包赚 / 承诺收益 / 无风险 / 必涨 / 躺赚。
2. 必须包含风险揭示章节（含"不构成投资建议"表述）。
3. 必须包含名词解释（面向散户）。

## B. 结构完整性（自动）
4. 必备章节：策略概述、入场、仓位（资金管理）、出场、风控、局限与风险。
5. 长度：1500–6000 字（散户可读篇幅）。
6. 至少 1 个具体数字计算示例（仓位/止损换算）。

## C. 事实一致性（评审，对照 strategy/tofflon_300171_final.py）
7. 文档中每个策略参数/规则必须与代码一致：MA10/30/60、ATR14×2.5、
   风险 2%、硬止损 -8%、放量 1.2×20 日均量、100 股整手、现金 95%、
   滑点 0.04 元、佣金万三最低 5 元、14:30 执行、创业板 20% 涨跌停。
8. 不得夸大策略能力；回测局限（快照不可用走兜底）需如实说明。
9. 散户适配：专业术语首次出现必须有白话解释；不得堆砌未解释术语。

## 收敛定义
- lint exit 0 且评审无 MUST-FIX（仅措辞类 OPTIONAL 视为收敛）。
