## 〇、命名与定位

「重开会」（Re-convene）：评审团拦回后，在特定触发条件下**解散原评审席结构、重新召集新评审团**重新表决的程序。与既有「修改-复审环」（014 已实证五段闭环）**并存而非替代**：修改-复审环是默认快路径，重开会是分歧僵持或程序污染时的慢路径。

---

## 一、触发条件（严格界定）

### 1.1 三级分流（拦回发生后的唯一分派点）

拦回（未达门槛 ⌈0.8n⌉）发生后，按以下优先级分流：

| 级别 | 路径 | 触发条件 |
|---|---|---|
| L-A 默认 | 修改-复审环（原席续审） | 拦回且附可执行修改清单，且不满足 L-B/L-C 任一条件 |
| L-B 重开会 | 解散重召 | 满足 §1.2 任一硬触发 |
| L-C 附条件放行 | 第三态路径（试点规则） | 通过+抗议≥⌈0.8n⌉ 且否决≤1（沿试点010/012 暂定裁定，入宪与否另案待拍板） |

### 1.2 重开会硬触发（任一命中即触发，无需额外裁量）

- **T1 复审僵持**：修改-复审环完成一轮后复审表决仍未达门槛（即"改了还不过"）。
- **T2 轮际附和机检命中**：见 §2.4，检测器判定新轮理由与前轮理由措辞同构超阈值。
- **T3 程序污染确认**：监管门裁定本轮 INVALID（程序无效），或任一席位提出程序污染异议经监管门核验成立（如 007/010/011 机密段同文件类隔离失效）。
- **T4 全票否决后的实质修改**：首轮 0 通过且输出者提交的修改版改动幅度超阈值（改动量参数待拍板，见决策点 D3）——防止"原席已被首轮全票否决锚定，对大幅改写后的新文本仍带旧印象复审"。

### 1.3 显式不触发（防过度重开）

- 首轮拦回但差距 ≤1 票且修改清单明确 → 一律走 L-A，**不得**直接重开。
- 附条件放行案 → 走 L-C 追认校验，不触发重开。
- 辩方意见被全票驳回 → 走既有「二审退出阀」（换组重辩），属辩方侧机制，不触发评审侧重开会（交叉规则见 §4.1）。

### 1.4 与修改-复审环的衔接

- 重开会**消耗并终结**当前修改-复审环：重开后输出者提交的最新修改版作为新会唯一受审文本，前轮环计数清零、重开计数 +1。
- 重开会本身也是一个完整管线轮（控辩→评审→监管门五层全走），不是"只换评审席重投票"。
- 修改-复审环与重开会的总预算合并受 §3 上限约束。

## 二、「不得附和」的可操作化

### 2.1 席位构成（换血规则）

- **换血比例**：重开会评审席至少 ⌈2/3⌉ 为新召集席（从未参与本案任何前轮）。留任席 ≤⌊1/3⌋ 且须为前轮**通过票或抗议票**持有者（前轮否决席一律不留任——否决理由是锚定载体）。
- **全换血选项**：7 席实装后资源允许时默认全换；留任规则仅为席次受限时的降级方案。（决策点 D1）
- Q 席、用户代言人席同步重召；代言人席若为用户本人在场则不受换血约束（用户一票否决权不因重开灭失）。
- 新席资格、派单简报沿用 role_briefs 现行模板，另加 §2.2 屏障告知段（模板增补文本见附录 A）。

### 2.2 信息屏障（新席可见性矩阵）

| 材料 | 新席可见性 | 理由 |
|---|---|---|
| 任务书、待审输出（最新修改版） | ✅ 可见 | 受审对象本体 |
| 前轮**修改版清单**（"改了哪几点"的事实层列表） | ✅ 可见 | 不知道改了什么就无法审新版 |
| 控方起诉书（最新版，锚定 § 编号） | ✅ 可见 | v0.4.2 三重锁：无起诉书不开会 |
| 辩方辩护词（最新轮） | ✅ 可见 | 控辩对抗完整性 |
| 前轮**各席票数、投票分布** | ❌ 不可见 | 票数是最强锚定信号 |
| 前轮**各席反对理由原文** | ❌ 不可见 | 理由措辞是附和载体；前轮已修复项由修改清单核验覆盖，未修复项若真实存在，新席应独立发现 |
| 前轮拦回的**监管门定性**（正当拦截/拦善/INVALID） | ✅ 仅可见定性标签，不见论证 | 新席需知程序位置，但不得继承论证 |
| 前轮评审回执全量 | ❌ 仅监管门只读 | 监管门职权不变 |

- 屏障执行：新席派单包物理分离（沿 v0.4.2 物理分离纪律），屏障清单列入监管门审查项。
- **例外泄锚通道**：若新席独立提出的反对理由与前轮某理由实质重合，属"独立再发现"，是**加强**而非附和信号——登记为「跨轮独立收敛」，不计附和（区分标准见 §2.4）。

### 2.3 留任席的隔离义务

留任席（如启用）须声明并遵守：不得向新席转述前轮票数分布、不得引用"前轮某席认为……"句式；违反即记程序污染，监管门可裁 INVALID 并触发 T3 再重开（消耗重开次数）。

### 2.4 轮际附和机检（认罪认罚检测器延伸）

现行检测器三指标只管单轮内附和。新增第四指标（轮际）：

- **指标④（轮际措辞同构）**：对前轮全体反对理由文本与新轮全体反对理由文本做 n-gram 重叠率计算，>0.6 即命中（阈值暂沿用单轮值，样本不足，先产生"建议"效力，同现行口径）。
- **指标⑤（结构性附和）**：新轮否决理由集合与前轮理由集合的**议题重合率**高（参数待拍板 D4）且新席未提出任何前轮未有的独立理由 → 命中。用于抓"换词不换靶"的隐性附和。
- 命中后果：触发 L-B 重开会（若当前在复审环）或强制再换血（若当前已在重开会中，消耗次数）。
- 实装：`scripts/acquittal_bias_detector.py` 增加 `--inter-round <前轮卷宗> <新轮卷宗>` 模式。**本草案不代写代码**，实装待用户拍板后另派工。

## 三、成本与防滥用

### 3.1 次数上限

- **每案重开会上限 = 2 次**（T1–T4 合并计数，不区分触发类型）。
- 第 2 次重开会仍未过门槛 → **终局拦回**：输出者二选一——(a) 撤回输出；(b) 降级标注【未过闸·拦回终局】后仅作内部参考，不得面向终端用户发出。
- 终局拦回案可呈用户人工裁量特赦（用户主权保留，明列为例外而非常态路径）。

### 3.2 成本结构

- 单次重开会成本 ≥ 一个完整管线轮（v0.4.2 全量 ≈9+ 席次；7 席实装后更高）。
- 全案总席次预算：设硬顶（参数待拍板 D5，建议 ≤3 倍单轮标准成本 ≈30 席次），触及硬顶即强制终局拦回。
- 时延告警沿用既有过程指标：轮次≥2 或席次≥20 触发告警注记（014 复审轮已首触），重开会必然触警——属设计内代价，须当轮向用户声明消耗。

### 3.3 闯关封堵（"无限重开直到放行"）

- 重开**不重置、不降低**门槛：每次重开会仍按 ⌈0.8n⌉ 表决。
- **放行追溯条款**：凡经 ≥1 次重开会后放行的案件，监管门裁定书须附「闯关嫌疑专项」——核查重开触发是否正当、换血是否真实、屏障是否失守；任一存疑即降级为 VALID-WITH-NOTE 并登记。
- **触发类型监测**：T2/T4 触发的重开若在某输出者/某域集中出现，登记为系统性信号呈用户（防"故意大幅修改骗 T4 重开碰运气"）。
- 重开次数全案台账化，入判例簿过程指标。

## 四、与既有机制冲突检查

### 4.1 二审退出阀（辩方侧）

- **无冲突，需界面条款**：退出阀解决"辩方意见被全票驳回"，重开会解决"评审团拦回后的轮际独立性"。两者作用于不同层。
- 交叉规则：重开会进行中若辩方意见被新评审团全票驳回，退出阀照常独立运行（换组重辩一次）；重辩结论对新会有效。辩方卷宗作为最新轮证据层移交新席，不受 §2.2 屏障限制（辩方材料本就对评审可见）。

### 4.2 第三态试点（离席抗议）

- **无冲突，需衔接条款**：第三态是票态，重开会是会议结构。重开会评审团沿用当前试点票态规则（三态试点未入宪，重开会不附带加速其入宪）。
- 附条件放行（L-C）案不进入重开路径；但追认校验失败被驳回时，视同"复审未过门槛"，按 T1 触发重开会。

### 4.3 缩比公式（⌈0.8n⌉，v0.4.2 入规）

- **无冲突**：重开会换血后若席位总数变化（如并入外部席），门槛按新 n 重算，公式不变。
- 需写明：换血导致的临时席位不足（如只能凑 5 席）时，按 5 席缩比门槛 ⌈0.8×5⌉=4 执行，并向监管门申报落差（沿 008 判例"计落差不计违规"口径）。

### 4.4 监管门职权

- **潜在冲突点已封堵**：监管门现行职权为"事后程序审查，不改判"。本草案中监管门仅获两项**程序性**新职权：①T3 程序污染确认权（既有 INVALID 裁定权的自然延伸，非新增裁量）；②闯关嫌疑专项审查义务（报告义务，非裁决权）。**重开会触发是规则自动触发（T1/T2/T4 为条件句），监管门无"决定是否重开"的自由裁量**——避免监管门扩权为二审机构。
- T2 机检命中的"建议复审"效力口径沿用现行检测器纪律（校准样本少，先建议后强制，待样本积累）。

### 4.5 其他

- 与「外部评审席送审纪律」无冲突；重开会可正常使用外部席，且外部席天然满足换血要求（不同谱系），鼓励重开会优先启用外部席池。
- 与「诚实边界§2 成本声明」兼容：重开会触发时当轮须按 autonomous-advance-ops §4.1 声明消耗。

## 五、条文草案（可直接插入 SKILL.md 的条款格式）

> 以下为拟定插入文本，位于「认罪认罚检测器」节之后，新增节名「## 重开会（拦回后的轮际独立性机制）」。**未经用户拍板不得插入。**

```
## 重开会（拦回后的轮际独立性机制）

1. 分流：拦回后默认走修改-复审环；仅当 ①复审轮仍未达门槛 ⌈0.8n⌉、
   ②轮际附和机检命中、③监管门裁 INVALID 或程序污染确认、④首轮全票否决
   且修改版改动超阈值 四者之一命中时，触发重开会。差距≤1票且修改清单
   明确者禁止直接重开。
2. 换血：重开会评审席至少 ⌈2/3⌉ 为新召集席；前轮否决席一律不留任。
   优先启用外部席池。
3. 屏障：新席不可见前轮票数与各席理由原文；可见任务书、最新修改版、
   修改清单、控辩最新卷宗、监管门定性标签。前轮回执仅监管门只读。
   独立再发现前轮理由者登记「跨轮独立收敛」，不计附和。
4. 机检：acquittal_bias_detector 增轮际模式——新旧两轮反对理由
   n-gram 重叠率 >0.6 或议题重合率高且无新独立理由即命中；命中触发
   重开会或强制再换血。校准样本不足，命中先产生建议效力。
5. 上限：每案重开会 ≤2 次；用尽仍未过门槛即终局拦回，输出仅可撤回
   或降级内部参考。用户人工特赦为明列例外。
6. 防闯关：重开不重置门槛；经重开后放行的案件，监管门裁定书强制附
   「闯关嫌疑专项」；T2/T4 触发集中出现登记为系统性信号呈用户。
7. 界面：辩方二审退出阀独立运行不受重开影响；第三态票态规则照试点
   沿用；换血后席位变化按 ⌈0.8n⌉ 重算门槛，落差申报监管门；监管门
   对重开会无启动裁量权，仅程序确认与报告义务。
8. 成本：重开会当轮声明席次消耗；全案席次超硬顶（待定）强制终局拦回；
   轮次/席次时延告警照过程指标条款执行。
```

## 七、诚实体检：本机制自身的 top3_likely_wrong

1. **信息屏障可能误伤复审能力**：新席不见前轮理由，若前轮否决理由真实且细微（如 014"积分不会跑"级失实），新席独立再发现率未知——屏障防附和的同时可能放走真缺陷，"拦恶 6/6"战绩有稀释风险。缓解依赖辩方卷宗对新席开放，但辩方也可能被前轮锚定（辩方不换血）。
2. **轮际机检阈值纯属沿用单轮值**：0.6 n-gram 与"议题重合率"均无轮际样本校准，008/009/014 仅 3 个多轮案可回测，误伤率与漏检率双未知；且同模型族子代理天然措辞趋同，"证据同指 vs 措辞同构"的老问题在轮际更严重。
3. **成本-收益未证**：每案上限 2 次重开 ≈ 最多 3 倍单案成本，而拦善台账仅 0~2/5 区间且口径未定（挂起项③未决）——机制可能在为一个尚未定格的病灶支付确定性成本；若拦善复核后定格为 0，本机制的主要正当性（防轮际附和致拦善固化）将大幅缩水。
