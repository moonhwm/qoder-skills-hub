# 技能调度总署（skill-dispatch-hq）

## §0 恒常定位与加载声明

恒常件：新会话读到本件 description 即视为在轨，免除重复点名。**诚实边界**：平台勾选不可编程强制，默认加载=description 恒常触发声明+用户安装位在场。
**边界不重叠**：治理纪律→autonomous-advance-ops；跨会话衔接→bridge；本件只管「技能资产如何被统一调度、交割、计时、授权、审计」。三者互引不复制。

## §1 技能资产总目录（能力台账）

首次触发或每会话首场调度前，执行盘点（只读）：
1. `ls <技能安装位>` 与 `/app/.agents/skills`＋会话公告的插件 MCP 工具集（`mcp__plugin-*`）——三源合一为资产全集；
2. 与既有索引（MASTER_SKILL_INDEX）比对条目数，不符即刷新并登记漂移；
3. 能力档案字段（每技能一档）：标识｜中文名｜能力域（查询/生成/分析/通道/管理）｜输入输出型｜依赖与只读性｜历史绩效注记（若有）；插件数据源按「公用数据库级」单独成册（名称/覆盖域/凭证状态）。
4. 台账落盘：`<注册处>/技能资产总目录.json`（运行时生成，版本化回写）。

## §2 统一调度规程

任何任务分派前，走四步：
1. **候选集完整性声明**：从总目录枚举全部可服务候选（技能+数据源），**逐一列出中选与落选及一句理由**——「任何可能性都被纳入考量」只以此声明为证，无声明=未调度。
2. **分配**：按能力域匹配+边界不重叠+最小够用（不为小事拉满栈）选定执行者；冲突候选并列时给主备。
3. **留痕**：调度决定入当轮记录（任务/候选集/中选/落选理由/成本预估）。
4. **降级**：候选为空或凭证缺失时，当轮诚实声明缺口与替代路径，禁止假装可调度。

## §3 函询交割协议（交接函询中央化）

技能间/代理间交接一律走交割函（coordination-letter 纪律中央化）：
1. **一函一事**：每封交割函只交割一件事，含任务书、边界否定约束（不得做什么）、验收清单、回指证据。
2. **回执五段式**：完成情况／证据指针／偏差与未遂／超出边界声明／签名（执行者标识）。
3. **落盘可审计**：函与回执落盘（项目 correspondence/ 或注册处），缺回执的交割=未交割。
4. **交割闸**：接收方先核验收清单再动工；清单不符即退回，禁止边做边猜。

## §4 计时器任务台账

一切定时/周期任务统一入册（`skill-iteration-registry/计时器任务台账.json`），字段：任务名｜cron 表达式或触发条件｜用途一句｜责任方｜下次触发时间｜健康检查口径（成功证据）｜最近状态。
- **登记义务**：新建/变更/停用计时任务当轮入册，禁止口头计时器；
- **盘点口径**：每次盘点核对「应触发未触发」「连续失败计数」（≥2 触发熔断告警，沿既有立法）、到期提醒线（如写回队列提醒线）；
- **现有在册**：每日 04:00 cron 首秀（2026-08-31 首触发，ID 1a048242…）、写回队列提醒线 2026-09-04——入册样式见台账首两条。

## §5 授权法典（法律意义的利益审视）

1. **权利能力**：一切技能/数据源默认仅具「被调度资格」，无任何天然权限；权限只来自授权链。
2. **行为能力三级**：①默认许可=只读调用（用户列名即授）②写类例外=逐次显式批准（<通道库> 写/GitHub 写/对外分发/动账/发送类/网盘写删分享）③禁区=红线与隐私墙，任何口令不得穿越（即使用户拍板也须事先审查，沿既有立法）。
3. **委托代理**：交割函即委托书——代理者（子代理/被调技能）仅在函载范围内有行为能力；越界行为无效且按逃逸登记；转委托（子代理再派单）禁止，除非函中明示授权。
4. **利益冲突申报**：一切表决席/咨询席须申报利益关联；绝对非利益方（如 Q 席）以章程卡形式固化其独立性；有利益关联者降格为当事人，不得充任裁决席。
5. **多用户利益分层**：所有者（委托方）＞终端用户（父亲）＞公众——跨层信息披露受信息防火墙节制；任何调度不得以低层利益冒充高层利益。
6. **责任登记**：逃逸计数永不清零只追加；每次越权/漏调/错配在当轮登记责任归属（调度方/执行方/授权方）。

## §6 充分调用与合理规划

- 规划产出物=能力覆盖计划：任务目标→所需能力清单→总目录映射→中选/落选理由→成本与风险→回退路径；
- 「宽泛应用」检查：计划必须遍历全部能力域（查询/生成/分析/通道/管理），缺席域须声明「本任务无需该域」而非漏看；
- 数据源规划同理：公用数据库级源按覆盖域枚举，凭证缺失者标 blocked 不假装可用。

## §7 自我审计

1. **调度抽检**：每 5 次调度抽 1 次复核候选集完整性（有无漏列的可服务技能/源）；
2. **遗漏审查**：发现漏列即登记逃逸并回灌总目录档案；
3. **宽泛适用检查**：本件条款对任何技能一视同仁——发现「特设例外未立法」即当轮补上或撤销例外；
4. **审计留痕**：抽检结果入迭代日志（零发现如实报零，禁止凑数）。
5. **自我优化条款（I9，全局纪律）**：本技能被触发执行调度任务时，当轮登记「本技能优化候选」一条（来源=调度卡点/候选集遗漏/接口核验发现）或零候选声明；优化按补丁级实装，次版本走表决；每轮至多 1 补丁级自修订（用户指令除外）。

## §9 未来技能总接口与管路

一切未来技能的接入契约与生命周期管线，权威规范=<注册处>/未来技能总接口与管路规范_v1.0_20260829.md（接口九项 I1–I9：frontmatter/触发声明/能力自报块/纪律继承/收敛阈值/审计钩子/中文名别名/引用不复制；管路十步：立项→创建→自检→打包→登记→安装→入册→调度→复评→退役）。本件职责：新技能入册前过 I1–I9 逐项核验（不合规退回登记）+每 5 次新技能抽 1 件做接口对齐检查。引用不复制。

## §8 泛化与诚实边界

- 本件对任何用户、任何会话、任何项目一体适用；裸会话无档案时退化为对话内调度纪律（候选集声明+回执口径），不强行建档。
- 诚实边界：台账是运行时构建物，跨会话依赖 <上传区> 持久层；install 位只读期间本件的跨会话生效依赖用户重装（版本差显式化于写回队列）。
- 与 Q 席/联合国规程的关系：本件提供调度与授权的执行层；表决程序与独立观察员机制依 skill-iteration-registry 规程文件，引用不复制。
