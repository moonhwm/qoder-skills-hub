# 辩方律师结构化体制设计 v1.0.0（输出审议机制·控辩模拟层）

> 2026-08-30 · 触发：委托方指令「增加辩方律师的相关必要性结构化体制，彻底模拟相关团队，以期望彻底抵消（过于认罪认罚）的相关表述【最后落实后才考虑相关可能性松动及逃逸】」
> 立法依据：联合国映射表决规程 v2.0 / Q席章程卡 / exam-isolation-ops 角色结构隔离 / autonomous-advance-ops §7.13 答案隔离
> 状态：**设计稿，作为试点002命题的受审内容之一，未经评审团表决不得实装**

## 一、问题定义：什么是"过于认罪认罚"

司法借喻：认罪认罚从宽制度下，若辩护缺位，被追诉人可能为求从宽而承认不实指控。映射到本体系：

- **审议场域的"认罪认罚"** = 评审席对命题/草案的快速附和——首轮即 4/5 通过、反证栏空白、评审意见模板化雷同。试点001已实证其苗头：三轮表决均为 4/5，唯一的反对票全部来自制度性强制的第5席（魔鬼代言人）；若无该席，即为三轮全票——**全票在同模型族下不构成信息**（提案三已论证）。
- 根因：同模型收敛（autonomous-advance-ops 诚实边界第3条）+ 角色激励缺失（评审席无"找茬"职责，只有"判断"职责；判断的省力均衡是通过）。

## 二、体制目标

把"反对"从**一票之力**（魔鬼代言人席）升级为**一支有组织的团队**（辩方律师团），使任何输出在通过审议闸前，必须经受职业化对抗性审查。设计原则：**先彻底硬化，松动与逃逸审查殿后**——本版只立刚性条款；任何豁免/降级通道待实装运行后另案审议。

## 三、角色编制（彻底模拟辩护团队）

| 角色 | 职责 | 隔离要求 |
|---|---|---|
| **辩方首席律师** | 通读受审输出，撰写《辩护词》——即"为何不应急着通过"的完整论证 | 只见受审输出+任务书；不见生产者思路、不见控方材料 |
| **辩方调查员** | 独立取证：核查受审输出中的事实、数据、引文、逻辑链，专找破绽 | 只带核查清单出门，可用数据源复核；不见控方与评审 |
| **控方代表** | 撰写《起诉书》——受审输出的合格性论证（为何应通过） | 同样隔离；其角色存在是为了防止辩方独角戏变成新的单边 |
| **评审团** | 5席，盲评控辩双方材料后独立投票 | 不见彼此意见、不见生产者、只控辩材料+证据指针 |
| **监管门** | 事后程序审查（不改判）：隔离是否成立、辩方是否实质履职、有无串供痕迹 | 只见程序证据包（指纹/简报/回执），不评内容 |
| **主程序** | 排程、归档、登记 | **永不扮演任何角色**（exam-isolation-ops 第一原则继承） |

## 四、辩方履职刚性条款（防"形式辩护"——本体制的核心硬化）

1. **必反义务**：辩方首席律师每案必须提出 ≥3 条独立反对理由或登记《无法反对说明书》（说明为何遍寻不得，并附检索/推导过程）；空手而归且无说明书 = 履职失败，换人重辩。
2. **取证义务**：辩方调查员对受审输出的每个可证伪主张至少抽查 30%（不足 3 条则全查），产出《取证报告》列明每项的核查结论（属实/不实/无法核）。
3. **对抗深度**：辩方意见若被评审团全票驳回，自动触发**二审**——换一组新鲜子代理重辩一次；二审仍全票驳回方可关闭辩方通道。此条款防止评审团与辩方同时收敛导致的"假对抗"。
4. **认罪认罚检测器**（程序化指标，任一命中即强制辩方介入，不得豁免）：
   - 首轮表决 ≥4/5 通过且各席反对理由字符数 <50；
   - 连续 3 案无一反对票；
   - 评审意见 n-gram 重叠率 >0.6（同构附和信号，沿 exam-isolation-ops isomorph 方法）。
5. **利益冲突**：辩方不得由受审输出的生产者同会话扮演；控辩双方与评审团三方互相不可见（结构隔离）。

## 五、与既有机制的接口

- 嵌入点：三轮自问（输出者自查）→ **控辩对抗（本层，新增）** → 评审团 4/5×3 轮 → 监管门 → 登记。辩方材料随卷归档，供监管门与后续追责调取。
- 表决规程不变：评审团仍 4/5 超级多数 ×3 轮稳定（试点001实证）；辩方无投票权（辩护是程序权利不是表决权，类比 Q 席观察员地位）。
- 用户特权不受影响：委托方一票否决权恒在（§8 立法）；本体制是他缺席期间对"附和偏倚"的结构性补位，不代行其否决权。

## 六、松动与逃逸条款（殿后，按用户指令排序最后）

本版**不设**任何豁免通道。松动可能性（如低风险输出免检、辩方简化程序）须同时满足：①实装运行 ≥5 案并有遥测数据；②专项议案经评审团 4/5 + Q席观察；③逃逸登记（沿 §7.6 逃逸三问：为何松/谁受益/代价谁担）。在此之前，辩方团队为一切实质性输出的强制配置。

## 七、诚实边界

1. 全部角色仍是同模型族子代理——辩方的"对抗性"是结构激励而非独立心智，收敛偏倚只能削减不能根除；
2. 成本倍增：每案至少 3 个辩方/控方子代理 + 5 评审 + 1 监管，quota 敏感场景须按 autonomous-advance-ops §4.1 先声明消耗；
3. 司法隐喻是设计脚手架，不主张与真实诉讼程序等价；不得以此体制对外宣称"已通过法律级审查"。

## 八、v1.0.1 补丁（2026-08-30，试点002 否决理由四处置）

1. **二审退出阀（成文）**：二审仍被评审团全票驳回后，辩方通道关闭；监管门如认定二审驳回存在明显程序瑕疵，可裁定**终审一次**（第三组新鲜辩方），终审再驳回即终局关闭，不得再启。死循环风险由此闭合。
2. **检测器阈值**：三项阈值（字符<50／连续3案无反对／n-gram>0.6）标注为**设计初值**，试点003/004 实测后校准回写；校准前检测器命中仅产生「建议复审」效力，不强制。
3. 版本号升 v1.0.1（补丁级，沿版本三段制）。

## top3_likely_wrong

1. "认罪认罚检测器"三项阈值为设计值无实证校准（首轮即可能误伤正常快速通过）——待试点002 实测；
2. 二审条款在强收敛场景可能死循环（重辩仍被驳回再重辩）——缺退出阀，待评审团指摘；
3. "辩方无投票权"可能使对抗流于表演（意见可被评审团无视）——是否给予辩方"延迟权"（延迟一轮表决）未决，留作议案。
