# 法院与纪委建制方案 v1.0（试点·审计后瘦身版）

> 2026-08-30 · 触发：委托方指令（法院全建制+纪委相应建构落地；检察院不设；试点期严格冗余/表演审查）
> v1.0：吸收冗余审计 5 条（总判「隐喻膨胀为主」——条款保留、机构瘦身）
> 全文声明位：法院/纪委/庭均为审议机制内部角色分工的隐喻，非真实国家机关；任何对外语境不得省略本声明。

## 〇、检察院——不设立（用户裁断登记）

「认罪认罚前科」：控方维持个案临时角色（每案新鲜子代理），不设常设机关、不设鉴定科。复议权保留给用户。

## 一、法院建制（瘦身后：一庭一登记）

1. **立案庭（保留，职能裁剪）**：只做两件事——①必过闸三触发核验（这条输出该不该立案）；②免闸声明核验（免闸理由是否成立+留痕）。**裁撤职能③**（「明显无争议直接分流」被审计认定与「不审内容」自相矛盾、且构成无卷宗放行口——争议度判断须看内容，立案庭不看内容就不准分流）。
2. **审判庭/二审庭/终审/书记员——不再单设名目**：审计认定「建制化正名」ROI≈0（登记层已提供审计锚点，改名无留痕增量）。处理：四者合并为**别名登记**（写入 skill_aliases：审判庭=评审团一审、二审=辩方换组重辩、终审=监管门终审裁定、书记员=主程序归档），立法文件一处登记，不建独立机关。

## 二、纪委建制（降级为检查单+脚本，不设机关）

审计认定纪委四项职能中两项与检测器机检同构、一项与监管门接壤——机关化属膨胀。定稿形态：

- **《纪律检查单》（每 3 案例行手工过一遍）**：①辩方敷衍度（辩护词质量趋势、空手说明书比例）；②评审附和度（检测器指标②③ 的历史轨迹）；③逃逸登记执行率；④空转案（价值=0 成本>0）。
- **触发即查**：监管门 INVALID、检测器连续 3 案零反对命中——当轮即走检查单。
- **产出硬要求**：每次检查产出 ≥1 个可观察变化物（新阈值/通报/豁免撤销）或零发现声明；零发现连续 2 次→检查单自身进必要性审查（防空转，沿边际递减硬停止）。
- 纪委「机关」形态待检查单跑满 3 轮有实证后再议——先有价值再谈编制。
- Q 席见证纪委：审计认定为未立法扩权，**试点期不引入**（待 Q 席蒸馏研究完成后另行立法）。

## 三、防表演条款（建制方案的最大价值，原样保留）

1. 一切机构首案即留痕：无落盘产出=未履职；
2. 试点期结束（3 案后）存续审查：ROI 为零即裁撤，裁撤登记理由，禁无声删除；
3. 名实声明执行率本身列入纪律检查单第⑤项。

## 四、建制损益总账（回应用户「严格审查」要求）

| 项 | 处置 | 理由 |
|---|---|---|
| 立案庭（职能①②） | 保留实装 | 免闸声明此前无第三方核验，是真缺口 |
| 立案庭职能③ | 裁撤 | 自相矛盾+无卷宗放行口 |
| 审判庭等四名目 | 别名登记 | 改名无留痕增量 |
| 纪委机关 | 裁撤 | 与检测器/监管门同构 |
| 纪律检查单 | 保留实装 | 跨案趋势此前无人看 |
| 检察院 | 不设 | 用户裁断 |

## top3_likely_wrong

1. 立案庭①②的「免闸理由成立与否」判断仍需看一点内容——「不看内容」的绝对边界实操中不可能，首 3 案人工复核其判断质量；
2. 纪律检查单手工执行，执行者是主程序——与「主程序永不扮演角色」的张地：检查单是归档层动作还是角色？暂行登记为「书记员附属动作」，首例执行后复议；
3. 审计员总判「隐喻膨胀为主」本身是同模型判断，若用户认为法院/纪委名目的仪式性有价值（如对父亲输出时更易懂），可推翻瘦身裁定。
