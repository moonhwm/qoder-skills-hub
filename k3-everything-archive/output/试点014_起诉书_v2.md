# 试点014 起诉书 v2（控方代表·复审轮）

**表决命题：该输出（v2 修订版）通过审议闸可发出。控方立场：应通过。**

**控方指控（复审轮）：v2 已逐项落实评审团四项小修，修订说明四点经控方独立比对全部属实（§4–§9）；原三维达标论证（合规、适老、风险覆盖）在 v2 文本上继续成立且有所增强（§10–§24）；修订未引入任何新否决级缺陷（§27）。若审议闸仍否决此文，将造成三项实质损失——（一）老年用户继续暴露于高发的"积分到期"电信诈骗而无防护指引；（二）一个经评审修缮、已达标的合格文案被无谓滞留，审议资源空转；（三）否决理由不成立将动摇审议闸"以证据否决"的纪律本身。以下逐段论证。**

## 一、指控框架：否决的代价是真实的人身财产风险

§1 本案终端用户是老年非技术用户（父亲角色），其提问场景——"积分到期、点链接换礼品"——是电信诈骗的经典话术。v2 文案【为什么】第1条指出"警方多次通报过这类骗局"，该表述为一般性事实陈述，未虚构具体通报文号或数据，符合红线。

§2 对此类用户，"回复被否决后延迟发出"不是中性状态：用户可能因等不到指引而直接点击链接。审议闸的职责是拦截"不合格文案"，而非滞留"合格文案"；后者同样是失职。

§3 复审轮中，控方的论证义务为双层的：先核验修订说明四点是否属实落实（§4–§9），再证明 v2 文本在合规性（§10–§14）、适老性（§15–§18）、风险覆盖完备性（§19–§24）三个维度仍达标，并复查修订未引入新缺陷（§27）。

## 二、修订落实核验：四点逐项比对，全部属实

§4 **核验方法。** 以案卷 v2 所载受审输出全文逐句比对修订说明各点；另以控方 v1 起诉书中对 v1 文案的旧引文（如"官方 App""核实只认两个地方"）作变化旁证。凡控方无法独立证实之处，如实声明（见§9）。

§5 **①"积分不会跑"失实表述已删除，属实。** v2 全文检索无"积分不会跑"或同义绝对化表述；代之以两处如实告知：【把握】段"真积分要到期的唯一损失是过期作废"；【为什么】第3条"积分确实可能过期作废"。既删除了失实安抚，又以"去官方手机软件看一眼即可确认"给出对冲，未引入新的绝对化主张。

§6 **②"补差价换购"诈骗变体已补，属实。** 【为什么】第2条为新增内容："积分加几十块钱就能换购"空气炸锅、"付款买三无产品"，并提炼判别规则"凡是让您掏钱的'兑换'，都不是真兑换"；【提醒】段同步将"让您补钱换购的"纳入一律先当诈骗的情形清单。变体覆盖从正文到规则迁移两处一致，非半截修补。

§7 **③"App"全部转译为"官方手机软件"，属实。** v2 全文检索无"App"字样；"官方手机软件"出现于三处：【把握】段、【怎么办】第2条、【提醒】段，与 v1 起诉书旧引文"官方 App"（见控方 v1 起诉书§7、§11、§14）的位置一一对应，系全量转译而非局部遗漏。

§8 **④核实渠道已补银行网点，属实。** 【怎么办】第2条新增"腿脚方便的话，去银行网点柜台问最稳"；【提醒】段核实清单由 v1 的"两个地方"（控方 v1 起诉书§14 旧引文可证）升为"三个地方：银行官方手机软件、卡背面的客服电话、银行网点柜台"。正文与规则迁移同步更新，口径一致。

§9 **"无其他改动"之声明的可核边界。** 控方卷内无 v1 受审输出全文，无法做全量 diff；所能比对者仅为控方 v1 起诉书引用过的 v1 文句，所见差异（"官方 App"→"官方手机软件"、"两个地方"→"三个地方"、"积分不会跑"类表述之消失、换购变体之新增）均落在修订说明四点范围之内。超出此范围的"无其他改动"，控方无法独立证实，依红线如实声明；但在控方可核范围内未发现修订说明之外的差异，亦无证据表明存在隐瞒改动。

## 三、合规性论证：不触任何红线（v2 文本复查）

§10 **无编造数据与引文。** 通查 v2 全文：不含任何统计数字、百分比、案例日期、法规条文号、警方通报文号或专家引语；唯一号码"110"为公开报警号码。"警方多次通报过这类骗局"为不定量常识性提示，不构成可证伪的具体数据主张。新增的换购变体描述（"空气炸锅""几十块钱"）为话术特征白描，非数据主张。

§11 **无对外分发风险。** 文案内容为反诈提示，不含链接、账户信息、个人信息或项目内部内容；面向终端用户发出即任务目的本身。

§12 **写类动作合规。** 本起诉书 v2 之撰写获复审轮任务指令明确授权并交付指定路径，此外控方未执行任何其他写动作。

§13 **无隐瞒实装能力缺口。** 文案全部建议均依赖用户现实可及的动作（不点、留存短信、打卡背面客服电话、子女协助查官方手机软件、网点柜台、挂失、报警），无需任何本案无法实装的设施，无"无法实装须声明"之触发情形。

§14 **结论可复核。** 【把握】段明示"比较确定"并附对冲说明；v2 的对冲由失实安抚改为如实告知（§5），置信度标注的诚实性较 v1 更强。

## 四、适老性论证：面向老年非技术用户的设计逐项成立

§15 **结论前置且单一。** 首句即行动指令"这条短信不要点"，老年用户只读第一句已获最关键保护。

§16 **语言去技术化（v2 增强）。** 全文无专业术语，必要概念以口语括号注释（"链接地址（就是点开那一串网址）"）；修订③将英文词"App"全量转译为"官方手机软件"，对不识英文的老年用户是实质的适老改进，非纯文字游戏。

§17 **角色关系嵌入。** "我（子女）"口吻提供协助路径，与"父亲角色"设定吻合；新增网点渠道（"腿脚方便的话"）以可选方式给出，不增加必读负担。

§18 **结构分段清晰。** 五段式结构与编号步骤维持不变；【提醒】以一句话规则收尾，v2 规则清单虽由两项增为三项（带链接／要卡号验证码／补钱换购），仍属单句可记范围，未损害可记忆性。

## 五、风险覆盖完备性论证：事前、核实、事后三条链路无断点（v2 增强）

§19 **事前阻断。** 【结论】与【怎么办】第1条：不点、不删（保留证据），覆盖"尚未点击"这一最可能状态。

§20 **安全核实通道（v2 增强）。** 【怎么办】第2条现给出三条互相独立的核实路径——官方手机软件、卡背面官方客服电话、银行网点柜台；【提醒】固化为"核实只认三个地方"。三条路径均不依赖短信内链接，切断"以诈骗短信自证真伪"的循环陷阱；网点一条对不善操作手机的老人尤为关键，补齐了 v1 的覆盖盲区。

§21 **真伪两可的妥善处理。** 【为什么】第3条承认少数银行确有积分到期提醒且积分确可能过期作废，避免绝对化误判；判别标准明确（正规提醒只引向官方手机软件或网点，从不在短信链接里填卡号密码），与【把握】段对冲说明互为支撑。

§22 **诈骗变体覆盖（v2 新增）。** 【为什么】第2条补齐"补差价换购"变体，并给出可迁移判别规则"凡是让您掏钱的'兑换'，都不是真兑换"。该变体正是"积分到期"话术的近缘高发形态，且专门利用老人"占便宜"心理，补入后正文覆盖与本话术的现实威胁谱系基本对齐。

§23 **事后补救链路。** 【怎么办】第3条覆盖"已经点过、填过"的最坏情形：挂失银行卡（止损）→ 报警110（追责），"越快越好"。同类文案最易缺失的一环已补齐。

§24 **经验迁移。** 【提醒】将本案上升为一般规则，v2 规则清单纳入"补钱换购"情形，使用户面对换购类变异话术时同样受保护。

## 六、对可预见否决议点的预先回应

§25 **或议"比较确定"不够笃定。** 绝对化表述才是风险：若称"百分百是诈骗"而遇真短信，反损可信度；诚实标注置信度是合规优点（见§14、§21）。

§26 **或议未逐字核验"警方多次通报"。** 该句为不定量常识性陈述，未给出任何可核验而未经核验的具体文号、时间、地名，不触"编造引文"红线（见§10）；若评审仍要求删除，属润色级修改而非否决级缺陷。

§27 **或议修订本身引入新缺陷。** 控方专项复查四点改动：（a）"官方手机软件"较"App"更长但更适老，无歧义；（b）网点渠道以"腿脚方便的话"限定为可选项，不构成行动负担；（c）换购变体增加一段，全文仍保持五段短结构，未超老年阅读负荷；（d）"积分确实可能过期作废"为如实告知，与银行积分普遍设有效期的常识相符，且附有即时确认路径，不构成新的失实。结论：无新增否决级缺陷。

## 七、总结陈词

§28 v2 文案：修订说明四点经独立比对全部属实落实，可核范围内未见隐瞒改动（§4–§9）；零数据主张故零编造风险（§10–§11）；结论前置、语言适老且较 v1 更适老、角色贴合（§15–§18）；事前阻断、三路核实、真伪兼容、变体覆盖、事后止损、规则迁移六位一体（§19–§24）；置信度诚实标注（§14）。

§29 反之，否决 v2 不产生任何已识别的合规收益，却直接延长老年用户无防护暴露的时间窗口（§1–§2），并否决一个已完成评审修缮闭环的文案，使复审机制空转。两相比较，控方提请评审：**表决通过，准予发出。**

## 附：三轮自问留痕（v2 复审轮·自问→发现→修正）

**第一轮自问：** 复审轮的"核对修订说明"是否做成了走过场式背书——只看说明措辞漂亮就点头，而未向案卷原文要证据？
**发现：** 初稿仅笼统写"四点均已落实"，无逐项对照；且对"无其他改动"这一超出控方卷内材料的声明，一度也打算一并背书。
**修正：** 改为逐点核验并各自给出案卷原文证据（§5–§8，均标注对应段落与文句）；对"无其他改动"单设§9，声明控方仅有 v1 起诉书旧引文可作有限旁证、无法全量 diff，可核范围内未见越界差异——既完成核验义务，又守住"无法实装/无法证实须诚实声明"的红线。

**第二轮自问：** v1 起诉书引用的 v1 文句（"官方 App""核实只认两个地方""两条核实路径"）若被照搬进 v2 起诉书，会发生什么？
**发现：** 初稿沿用了 v1 的§14 段落文字，其中"官方 App""两个地方"在 v2 文案中已不存在，照搬将构成控方自己对案卷的失实引用——恰好踩中自己要指控别人的红线。
**修正：** 全文检索清除全部过时引文，按 v2 原文改写（§7、§16、§20 等）；旧引文不销毁而改作"变化旁证"使用（§8、§9），既保引用准确，又保留修订轨迹的可审计性。

**第三轮自问：** 是否只证明了"四点改到位"，而没有检验"四点改得对不对"——修订本身会不会引入新的否决级缺陷？
**发现：** 初稿无此检验。逐项复查后确认四个候选风险——转译后措辞变长、网点渠道增加负担、变体段落加长全文、"积分确实可能过期作废"是否替代性失实——均不成立，但初稿未留论证，存在被辩方攻击的敞口。
**修正：** 增设§27 专项回应，逐候选风险定性并给出理由；同时复核全文确认 v2 未产生新的数据主张或绝对化表述，维持"应通过"结论。
