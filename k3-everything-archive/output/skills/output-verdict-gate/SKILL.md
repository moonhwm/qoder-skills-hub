## 何时过闸（必要性结构）

必过闸：①金融/医疗/法律等高风险域面向终端用户的操作性输出；②涉老输出（终端用户为非技术老年用户）；③用户点名要求审议的输出。轻量问答免闸，但当轮须声明「免闸及理由」。

## 管线五层（顺序不可跳）

1. **三轮自问（输出者自查）**：自问→发现→修正，三轮留痕入卷；发现缺陷即修正或降级标注。**留痕为强制项，无留痕件视同未做（v0.4.2 修复落差：此前 7/7 静默省略）。**
2. **控辩对抗**：控方《起诉书》论证应通过；辩方首席《辩护词》≥3 条独立反对理由（附证据指针+杀伤力评级），辩方调查员独立取证（抽查 ≥30% 可证伪主张，不足 3 条全查）。三方互不可见；辩方找不到反对理由须交《无法反对说明书》，不得沉默。**控方全量强制（v0.4.2）：每案必备《起诉书》，无任何触发分支与例外。**
3. **评审团盲评**：议席结构=5 评审席+Q 席（观察，无投票权）+用户代言人席（共 7 席；权威立法=<注册处>/议席结构立法登记_v1.0_20260830.md，引用不复制）。双模表决：用户缺席=6/7 通过+反方意见强制公开+【未经全票·待追认】标注；用户在场=5/6+用户一票否决。**缩比实装的换算公式（v0.4.2 入规）：实际评审席数为 n 时，通过门槛=⌈0.8n⌉ 且反方意见强制公开不变；n<5 属降级运行，裁定书须显式标注。** 各席反对时须给可过闸修改版文案。席位数量与构成参数化（新增席位不改管线骨架）。
4. **监管门**：事后程序审查（不改判）。清单：材料隔离/评审隔离/辩方履职/一致性检验/主程序角色/**控方履职（v0.4.2 新增：无《起诉书》或控辩可见性破坏→直裁 INVALID，无 NOTE 档）**。裁定 VALID / VALID-WITH-NOTE / INVALID。**评审回执须对监管门开放只读**（试点003/004 监管门注记实装）。
5. **登记**：表决数、裁定、勘误、修改版文案入卷；数字裁决栏**强制附数据源留档指针**（无指针即降级标注）。

## 辩方刚性条款（防形式辩护）

- 二审退出阀：辩方意见被全票驳回→换组重辩一次；再驳回→监管门可裁定终审一次；终审再驳回即终局关闭。
- 利益冲突：辩方不得由输出生产者同会话扮演；主程序只做排程归档，**永不扮演任何角色**。
- 一致性检验纪律：区分「证据同指」（多席引同一锚点事实=正常）与「措辞同构」（n-gram 重叠>阈值=附和信号）。

## 控方全量强制与三重锁（v0.4.2 入宪）

1. **硬停机锁**：案卷无控方《起诉书》→ 不得开评审团，管线硬停机；主程序须在当轮声明停机原因，不得以任何理由跳过。
2. **监管门锁**：监管门清单含控方履职项；缺起诉书或控辩可见性破坏 → 直裁 INVALID（无 NOTE 档）。
3. **简化申报锁**：执行侧（含主程序）任何对规程环节的简化/省略，须当轮显式申报入卷（环节名+理由+影响评估）；未申报的简化一经发现即记缺陷，并触发全管线落差扫描。

## 防幻觉三件套（v0.4.2 入宪，依据：008/009 幻影控方 9 处实证）

1. **锚定义务**：辩方每条反对理由、评审每席意见，引用控方观点时须锚定《起诉书》具体段落编号；无编号引用=无效引用，评审团召集人须退回重写。
2. **指针存在性核验**：调查员对辩方反对理由的证据指针逐条做存在性核验（指向的案情/规程/信源是否真实存在），结果入卷。
3. **幻觉记缺**：引用不在场角色、虚构文书或编造证据指针一经查实 → 记缺陷 + 相关意见作废 + 强制重辩/重投。

## 认罪认罚检测器（机检三指标）

任一命中即触发强制辩方复审：①首轮 ≥4/5 通过且各席反对理由 <50 字符；②连续 3 案无一反对票；③评审意见 n-gram 重叠率 >0.6。用 `scripts/acquittal_bias_detector.py` 机检；`--self-test` 自测。阈值状态：试点001–004 观测区间内未误伤（4 案均 0/5 或 4/5 带实质反对），**校准样本仍少，命中先产生「建议复审」效力**。

## 适老化输出层（过闸输出的呈现规范）

终端用户为老年非技术用户时，过闸文案必须七条齐备：①结论前置一句话；②把握三档【比较确定/一般/再看看】；③风险前置+防诈提示；④术语转译；⑤一次一事；⑥语音容错（确认式提问，数字金额必复述确认）；⑦涉钱/涉操作二次确认。修改版范例与标准原文见 references/elderly_output.md。

## 外部评审席送审纪律（v0.4.1 入宪）

1. **逐字原文**：题面、待审输出、任务书、证据材料一律逐字送审；禁转述/缩写/改写。
2. **diff 核验**：送审前对源文件做逐字 diff 或哈希比对，结果留卷；不一致即退回，不得送审。
3. **误报归因**：外部席否证先到送审材料找错（司闱首日教训），再到被审对象找错——顺序不可反。
4. **凭证纪律**：key 只在 <用户配置目录>/external_seat.json，不进提示词/落盘/函件；谱系纪律维持（kimi 同族模型不作外部席）。

## 诚实边界

1. 全部角色为同模型族子代理——对抗性是结构激励而非独立心智，收敛偏倚只能削减不能根除；一切审议结论为「模型能力上限参考」。
2. 成本高（≥9 席次/案）：quota 敏感场景按 autonomous-advance-ops §4.1 先声明消耗再开闸。
3. 司法隐喻是设计脚手架，不等价真实诉讼；不得以此对外宣称「法律级审查」。
4. v0.2.0 起为全局默认行为（T6 用户已追认，2026-08-30）：实质性输出不过闸不得发出；轻量问答免闸须当轮声明「免闸及理由」留痕。
