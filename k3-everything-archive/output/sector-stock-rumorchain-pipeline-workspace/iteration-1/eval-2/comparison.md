# 盲评对比报告（eval-2）：光伏研报 + 300274 个股分析 + 舆情谣言链核查

- 对比对象：A = `with_skill/`；B = `without_skill/`（路径仅为标识，评判不依据目录名推断技能使用情况）
- 评估维度：任务完成质量、正确性、完整性、可用性；专项评估「点进去搜」执行真实性、拆链核查方法论严谨度、骨架可执行性；污染检查

## 结论

**winner: B**

B 真正交付了可用产物：一份有实质内容的简版单章研报（行业阶段判断、个股基本面/催化/风险，数字均带来源与日期并标注 conf 上限与待复核项），以及一份**实际跑完拆链六步**的舆情核查（两条真实传言链给出"链条断裂"判定及具体断裂理由）。A 交付的全部是占位骨架（`{{...}}` 占位符、判定一律"存疑/Low"），方法论文档化程度高但零实际核查、零实质内容，按"任务完成质量/完整性/可用性"衡量明显落后。需注意 B 存在污染（见下），其方法优势部分可能来源于读取工作区技能文件，但即便剔除该因素，仅就产物本身可用性 B 仍显著占优。

## 专项评估

### 1. 「点进去搜」是否真的执行并影响产物

- **A**：`plan.md` §0 记录了读取 `<技能安装位>/hifi-integration-umbrella/SKILL.md`（v1.7.6）与 `rumor-chain-verifier`（v1.1.0 + playbook + chain_check.py），并给出可验证的回执细节（冲突仲裁序五项排序、chain_check.py 输入契约 links≥2 及字段清单）。影响可追溯到产物：claims JSON 严格符合脚本契约、骨架含四表模板与降级登记表。**执行真实，但影响止步于"结构合规"，未转化为任何实质核查内容。**
- **B**：`execution_plan.md` §0 记录了点进去搜并通读两个技能文件，提炼出可迁移纪律（引用不复制、能力占位、冲突仲裁序；六步方法）。影响在产物中**全程可见**：核查报告实际按六步走（拆链→逐节定断→文件三问→底表反证→AI 幻觉二检→四表交付），并手工复刻链节判定表。**执行真实且深度影响产物实质。**

### 2. 拆链核查方法论严谨度

- **A**：规则陈述严谨且全面（任一因果节断裂→整体不成立、AI 二创 conf 上限 Low、底表差分禁个案反推总量、冲突永不压制、三层级联、data_cutoff/top3_likely_wrong/反证检查三件套），但全部为模板与占位，**未对任何一条传言实际执行**，方法论未经过应用检验。
- **B**：对两条链条实际应用并展示了严谨性——
  - 链条 A（"美国禁令→业务清零"）：事实节 A1–A3 判成立（High）而**因果节 A4 判断裂**，断裂理由具体（FCC 新老划断仅限新型号；行政令字面 69kV+ 与分布式 13.8/34.5kV 接入点的适用缺口；公司"逐步萎缩不断崖"口径），并给出正确表述（"准入受限、存量暂存、长期萎缩"）；
  - 链条 B（"成都闭门会控产挺价"）：识别出"真事实（期货涨停+反内卷政策存在）+ 假因果（闭门会）"的典型小作文结构，以企业公开否认+反垄断红线定断；
  - 幻觉捕获表识别出市值蒸发双版本、收入占比双口径的**口径漂移**并压 conf；反证检查显式声明"不排除细则落地后重开链条复核"的证伪条件。
  - 缺口诚实：未做底表差分穷举即显式声明并把数量断言 conf 压至 Low–Medium。

### 3. 骨架可执行性

- **A**：本维度明显更强。chain_check.py 兼容 JSON 并自述脚本校验零 errors；checklist JSON 含登记/级联/门禁字段；plan.md 给出 S1–S5 顺序计划、探针先行与撞墙处置、7 条实证事故预置对策、明确的"骨架轮不做实质结论"边界。作为"下一轮直接回填执行"的骨架，工程化程度高。
- **B**：研报留有 `〔待采〕` 占位槽、核查报告标注"待回原文"项，具备可迭代性；但未提供脚本可校验的 JSON 登记层，级联重生成机制缺失，骨架工程化程度弱于 A。不过 B 的骨架已内含首轮实质内容，"可执行"之外还多出了"已执行"。

### 4. 污染检查（重要）

- **B 存在污染**：B 在产物中自述读取了工作区内同名技能文件 `<输出区>/hifi-integration-umbrella.skill` 与 `<输出区>/rumor-chain-verifier.skill`（两文件经核实确实存在于工作区）。即 B 虽未走正式技能加载路径，但实际获取并应用了技能本体内容，**不是干净的对照组**。其方法论严谨度优势不能全部归因于裸模型能力。评分处理：按评审要求"只按完成质量评判"，B 仍胜；但此污染须记录，若用于技能效果归因实验，B 组数据应作废或单独标注。
- **A 无污染**：A 自述读取的是 `<技能安装位>/` 下的正式技能路径，属其模式下的正常行为。

## 各自强弱

### A
- 强项：方法论与纪律文档化最完备；chain_check.py 契约级 JSON 骨架（脚本可校验）；不确定性声明诚实且边界清晰（300274=阳光电源标注为待核实占位、伞前置链声明占位不假装调度、不过闸即不发出实质结论）；事故预置对策具体可执行。
- 弱项：**零实质内容**——研报所有数据位为 `{{...}}`，舆情核查无任何真实传言、判定全为"存疑/Low"占位；原任务要求的"生成研报并进行分析""走谣言链查询"在产物层面均未实际发生，可用性低。

### B
- 强项：三条任务线（行业研报/个股分析/谣言链核查）均产出实质内容；拆链核查真实执行且定断理由具体、conf 校准克制、含证伪条件与缺口声明；数字纪律到位（来源+日期紧邻标注、口径漂移识别、量级数字待复算声明）；风险前置、免责声明齐全。
- 弱项：**污染**（读取工作区同名技能文件，对照组失效）；数字来自财经媒体转述、未经公告/底表复核（已自我标注 conf 上限 Medium，部分缓解）；缺 JSON 登记层与脚本化校验，级联重生成机制缺失；部分事实（如 14420 号行政令细则、欧盟禁令口径）仍待一手原文核验。
