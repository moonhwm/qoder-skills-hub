## 二、A 席事实核查要点（断言层）

- 启信官网 API 形态、MD5 签名鉴权、8 项价目（0.15×4 / 5 / 3 / 2 / 0.01 元）全部与官网一致（C0/C1 级）；AgentArts 50 秒时限、KMS、触发器、对外 RESTful API、付费四档、「2026-08 付费版未公开售卖」均证实。
- **最重要修正**：「体验版赠 200 万 tokens」**归因错误**——实为 MaaS 首开通赠送，且 API 调用不可用免费额度。**方案三成本测算遗漏 MaaS 模型付费一项，立项前必须单列**。
- 次要瑕疵：「微信 ClawBot」官方无此名（应为「微信一键扫码直连」）；「19 分类/28 页」未复核（侧栏仅见 17 类）；技能「内置 Python/Node 运行时」官方文档未明示；价格带「限时优惠」标识，存回调风险。

## 三、B 席金融级压测要点（稳定性层）

21 个故障场景：**致命 1 项**——平台无 SLA 承载风控流程（金融级口径属准入性问题）；高 15、中 4。

**三大静默失败形态（最致命事故型）**：
1. 错误码表未闭环时，「调用失败」可被误读为「该企业无风险」——漏报直接写入台账；
2. 触发器漏触发=整期监测静默缺失，业务方误以为「本月无风险」；
3. 环比基线污染导致「伪变化」批量误报。

**批量算术（千家+周频推演）**：17,320 次/月、2,598～6,928 元/月、串行含研判≈5.6 小时/次、tokens ≈866 万/月为体验版额度 4.3 倍；OfficeAce 50s 节点单批仅容约 4 家，千家需 ≥250 批次编排。

**反直觉发现**：双通道冗余可能**引入**新故障（字段口径/时效未确认，切换污染环比基线，需「每通道独立基线+切换审批+公告」）；密钥「定期轮换」若无双密钥并行期，轮换即全线签名失败；实名认证到期日 2027-08-31 恰为提案日周年，叠加商务悬崖，方案三存在认证到期前无法投产的时间线风险。

## 四、C 席安全合规要点（责任层）

26 条发现（高 6/中 15/低 5），**有条件放行**。高危六项：PIPL 条款残缺（缺保存期限/权利响应/告知基础）；IM 推送征信数据出可控环境属超约定用途灰区；方案三对外 RESTful API 无白名单即实质「转售征信数据」红线；SKILL.md 脚本内嵌 AppSecret 风险；第三方技能包=代码执行级供应链入口；MCP 连接器指向外部 SaaS 的劫持+提示词注入双面。中危含：PIPL 第 24 条自动化决策出口缺失、PIPIA 未做、DPA 缺失、「严禁明文写密钥」无审计责任人（空文条款）、人工复核无留痕机制。

## 五、D 席语义审计逃逸专项（用户点名项）

**裁决：方案二部分触发（实质逃逸点 1 处）、方案三部分触发（轻），均不构成「自动触发」恶性逃逸。**

- **唯一实质逃逸点 E2**：「业务闭环」无操作定义——方案二核心价值承诺不可证伪，须改写为可验收口径（如「准入尽调从录入到 Word 报告归档全程无人工搬运，单次 ≤15 分钟」）。
- **E4 推论跳跃**：天眼查 MCP 示例不能「证明」启信接入为官方认可路径（R2 型推理漏洞）。
- **E1 轻度蒸发**：4 处「以…为准」缺页面快照锚点（建议：价格页截图存档+日期戳）。
- **机器审计盲点**：脚本对冲词表漏报「以…为准」句式——低密度（0.34/千字）≠无逃逸；已建议回灌词表。
- **减罪事实**：§十显式登记 12 项未确认事项、成本算术自洽（0.60/5.60/160 元复核无误）、「官方自称启信开放平台™」裁定为**诚实标记**。

## 六、合并硬门槛（投产前置条件，四席并集 19+7 条浓缩）

**A 组·数据源**：错误码全表获取并闭环「失败≠无风险」语义；价格快照存档；实名认证到期提醒线（2027-08-31 前 90 天）。
**B 组·平台**：定时任务生效=调度器可查+真实触发回执（与本自治生态同纪律）；批量编排实测替换 50s 节点估值；MaaS 模型费用单列入成本模型。
**C 组·一致性/可恢复**：环比基线不可变存档；双通道独立基线+切换审批制；回滚预案。
**D 组·密钥**：双密钥并行轮换规程；技能包零硬编码扫描入 CI；第三方技能包禁导入（白名单制）。
**E 组·合规责任**：PIPIA 先行；DPA 签署；对外 API 白名单锁定（方案三红线）；具名复核人签字门禁（系统级卡点，非人工自觉）。
**方案三追加**：AgentArts 正式商务合同闭环 + ERP 安全评估 + 上述全组清零，三者齐备前不立项。
