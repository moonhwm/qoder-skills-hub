## 六、坑登记（路由研究线持续追加）
1. 双 key 契约：desc=`name`／调用=`data_source_name`+`api_name`+`params`；
2. desc 自描述对错误 key 静默返空模板——以各插件 SKILL.md 为唯一事实源；
3. 插件名→注册名映射（scholar→google_scholar）；
4. 参数契约各异（scholar 必带 file_path；pubchem 必带 by+value）；
5. ifind 实时价 api 对指数返 EMPTY_DATA（个股正常）——指数查询改道 wind 或换 api（待考）。
