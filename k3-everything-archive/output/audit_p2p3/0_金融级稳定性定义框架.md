# 金融级稳定性定义框架（本次审计的评判锚）

> 用户指令「需要极高稳定性，按金融级别定义」。本框架将该指令操作化为六维可判据口径，四席审计结论均映射到此六维。

## 六维口径（参照金融机构外包/生产系统管理口径）
1. **可用性**：关键链路单点故障清单化；年故障时间预算；备用通道的切换时延与数据差异仲裁规则。
2. **一致性**：客商主数据单一真源；环比比对基线的不可变存档；双通道结果差异的仲裁与留痕。
3. **可恢复**：RTO/RPO 目标显式化；回滚预案；凭证泄露应急手册。
4. **可审计**：每次调用的请求/响应/费用留痕；报告生成的人机责任分界；审计轨迹不可篡改（哈希锚定级）。
5. **成本闸**：单次/月度调用量与费用硬顶；价格漂移的告警线；充值资金有效期管理。
6. **合规与责任**：PIPL 最小必要；征信数据用途限定；自动生成内容必须经具名复核人签字方可入决策链（四人眼原则）。

## 就绪度分级
- **投产级**：六维全部有实证缓释，无致命/高危敞口
- **有条件投产级**：高危敞口有明确前置条件且可验证
- **试点级**：仅限小范围灰度，致命/高危敞口须挂账跟踪
- **不投产级**：存在致命敞口且无缓释路径
