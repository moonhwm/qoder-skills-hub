
启信慧眼 × 华为云 OfficeAce / AgentArts 整合方案提案
提案编号： QX-OA-2026-___（由信息技术部统一编号） 提案日期： 2026-08-31 提案单位： 湖南联盛物资贸易有限公司 · 经营部 密级： 内部资料，限联署审议使用
一、提案摘要
为提升供应商、客户准入核验与信用风险排查效率，公司拟将启信慧眼（data.qixin.com）的企业工商、司法、经营风险数据能力与华为云果办 OfficeAce / AgentArts 智能体平台整合，构建”客商准入尽调—存量风险扫描—风险信息推送”的数字化风控流程。公司已于 2026-08-31 完成启信慧眼平台企业实名认证（有效期至 2027-08-31），具备即时开通 API 的条件。建议”三步走”：近期以方案一（OfficeAce + 官方 MCP 连接器）快速落地，中期以方案二（自定义技能 / AgentArts 工作流调用官网 REST API）形成业务闭环，远期以方案三（AgentArts 风控智能体）实现系统级集成。
二、背景与现状盘点
（一）公司需求场景
公司主营物资贸易，日常经营中需对供应商、客户开展工商信息核验与信用风险排查，具体包括：新客商准入时的工商照面、股东、经营异常、失信被执行、行政处罚等基础尽调；存量客商的定期风险扫描与预警；尽调结果需形成 Word 尽调报告与 Excel 风险台账，并按周期推送至相关业务人员。
（二）已完成的准备工作
2026-08-31，公司已在启信慧眼数据开放平台（官方自称”启信开放平台™“）完成企业实名认证，有效期至 2027-08-31。认证完成后即可在控制台获取 AppKey / AppSecret，充值开通 API（充值金额自充值成功起 2 年内有效）。
（三）三条数据通道盘点
通道①：启信慧眼官网 REST API（api.qixin.com）。地址形如 https://api.qixin.com/APIService/{模块}/{方法}，JSON 返回，HTTP/HTTPS GET（部分接口支持 GET、POST）。鉴权为请求头携带 Auth-Version: 2.0、appkey、timestamp、sign（基于 AppSecret 的 MD5 签名）。接口覆盖工商信息、司法风险、经营风险、知识产权、企业报告、新闻舆情等 19 个官方分类，全量共 28 页，页面直接展示单价。
通道②：启信慧眼官方 MCP 服务。封装 200+ 企业数据能力（公开报道显示已落地腾讯 WorkBuddy），可通过标准 MCP 协议被智能体平台调用。
通道③：华为云云商店启信宝接口。卖家为上海生腾数据科技有限公司，在售商品含企业基础工商信息报告、企业商标列表信息、失信被执行企业查询等。购买后由 APIG 网关下发 AppKey/AppSecret，支持签名认证或简单身份认证（AppCode）；支持”按需”与”按需套餐包（按次预付费）“，仅 HTTP 2XX 计为有效调用扣次；0 元体验套餐包同一用户限购一次。
（四）平台侧能力盘点
OfficeAce：支持自定义技能（Skill），技能本质是”提示词+脚本资源包”（SKILL.md 规范），内置 Python/Node 运行时；调用外部 API 的官方推荐路径为 MCP 连接器，支持 Stdio / Streamable HTTP / SSE 三种传输（推荐 Streamable HTTP 接第三方 SaaS），可配置环境变量（敏感值加密）与自定义 Headers；支持飞书、微信（ClawBot）、钉钉、小艺等 IM 接入及定时推送。
AgentArts（智果）：完整智能体开发平台，支持单智能体、可视化工作流（含触发器定时任务）与多智能体；接入第三方 API 有三条成熟路径——HTTP 请求节点、自定义 API 插件（支持 OpenAPI 导入）、MCP 服务节点（密钥 KMS 加密）；智能体发布后可对外提供 RESTful API（POST /runtimes/{runtime_name}/invocations）供业务系统反向调用。OfficeAce 为 AgentArts 平台下子产品。

三、整合方案一（轻量级·快速落地）：OfficeAce + 自定义 MCP 连接器接入启信慧眼官方 MCP
（一）架构描述
业务人员在 OfficeAce 中自然语言提问（如”请核验某某公司的工商与失信信息”）→ OfficeAce 智能体经自定义 MCP 连接器（Streamable HTTP）→ 调用启信慧眼官方 MCP 服务（200+ 企业数据能力）→ 返回企业征信摘要 → 配合自写”客商尽调”技能按模板生成 Word 尽调简报。
（二）配置步骤
向启信慧眼申请官方 MCP 服务接入，获取接入地址与密钥；
在 OfficeAce 中添加自定义 MCP 连接器，传输方式选择 Streamable HTTP，填写启信 MCP 服务端点；
配置环境变量（API_KEY 等，敏感值加密存储）与自定义 Headers（Authorization Bearer）；
使用内置 skill-creator 技能以自然语言生成”客商尽调”技能（含尽调报告模板与排版脚本），或以手动导入方式上传符合 SKILL.md 规范的技能包；
联调测试并小范围试用。
（三）周期与成本
预计周期： 1–2 周。
成本构成： OfficeAce 订阅费用（个人版四档：体验版免费赠 500 积分、标准版 2,000 积分/月、高级版 4,000 积分/月、旗舰版 10,000 积分/月，具体金额以客户端实际展示为准）＋ 启信慧眼充值费用。OfficeAce 官方连接器文档以天眼查 MCP（https://mcp.tianyancha.com/v1）演示同类企业征信服务接入，证明该场景为官方认可路径。
（四）优缺点
优点： 开发量最小、上线最快；无需编写签名逻辑；业务人员以自然语言即可完成查询与成文。
缺点： 依赖启信官方 MCP 的开放范围与接入条件（需与启信方确认）；批量、定时、流程化能力较弱；连接器是否受 OfficeAce 套餐档位限制尚未确认。
四、整合方案二（标准级·业务闭环）：自定义技能包 / AgentArts 工作流调用启信慧眼官网 REST API
（一）架构描述
以 OfficeAce 自定义技能包（SKILL.md + Python 脚本，实现 AppKey+MD5 签名鉴权）或 AgentArts 工作流（HTTP 请求节点 / 自定义 API 插件）直连启信慧眼官网 REST API（api.qixin.com），编排两条标准流程：
新客商准入尽调： 录入客商名称 → 依次调用工商、司法、经营风险接口 → 大模型汇总研判 → 生成 Word 尽调报告并归档；
存量客商定期风险扫描： 读取客商台账（Excel）→ 定时触发批量调用风险接口 → 比对上期结果 → 更新 Excel 风险台账 → 对命中风险的客商生成预警，经 IM 定时推送至经营部相关人员。

（四）周期与优缺点
预计周期： 2–6 周（含接口申请、签名脚本开发、流程编排、台账模板设计与试运行）。
优点： 接口按需精确选用、成本可控；形成”准入+存量扫描”业务闭环；产出物规范可归档；官网签名逻辑可在插件中封装复用。
缺点： 需实现 Auth-Version 2.0 签名鉴权，有一定开发门槛；HTTP 请求节点响应时限 50 秒且不支持 OAuth/流式，批量任务需控制节奏；接口实时价格可能随活动调整。
五、整合方案三（深度级·企业级数字员工）：AgentArts “客商风控智能体”
（一）方案描述
在 AgentArts 平台搭建”客商风控智能体”：以可视化工作流编排尽调与扫描流程，配置触发器定时任务实现周期性自动风险监测；视需要采用多智能体分工（信息采集、风险研判、报告撰写）；经自定义 API 插件或 HTTP 请求节点接入公司内部 ERP / 客商台账，实现客商主数据双向同步；风险结果经飞书 / 钉钉 / 微信推送至责任人；智能体发布后通过对外 RESTful API 供业务系统调用，将风控能力嵌入采购、销售流程。云商店启信宝接口作为备用/冗余数据通道，在官网通道异常或采购便利时切换使用。
（二）周期与成本提示
预计周期： 6–12 周（含需求梳理、与 ERP 联调、多轮测试与灰度上线）。
成本提示： AgentArts 体验版免费（2 成员、20CU、50 应用、1GB 知识库、赠 200 万 tokens）；付费档含团队标准版（10 人/80CU/月）、团队高级版（50 人/780CU/月）、企业专业版（200 人/3000CU/月）、企业旗舰版（1000 人）；截至 2026-08 付费版未开放公开售卖，需提交工单咨询，实施前应先确认商务条件。
（三）优缺点
优点： 企业级编排与定时能力，支持多智能体与知识检索；对外 API 使风控能力成为公司级公共组件；双数据通道冗余提升可用性；密钥经 KMS 加密，安全治理能力强。
缺点： 实施周期最长、投入最大；依赖信息技术部持续运维；付费版本商务条款待工单确认；与内部 ERP 的接口适配存在不确定性。

七、数据安全与合规要点
用途限定： 企业征信类数据仅限公司内部供应商/客户风控用途使用，不得对外转售、公开展示或用于约定用途之外的场景，具体以与启信慧眼及云商店签订的服务协议为准。
个人信息保护： 主要人员、董监高等接口数据涉及个人信息，应遵循《个人信息保护法》最小必要原则，限定知悉范围，报告流转与存档应受控。
密钥管理： 启信 AppKey/AppSecret 与 MCP 密钥优先使用 OfficeAce 环境变量加密、AgentArts KMS 加密机制存储，严禁明文写入代码、文档或即时通信工具；定期轮换。
账号体系独立： 启信慧眼开放平台账号（企业实名认证）与华为云账号（IAM/admin 权限）为两套独立体系，权限分别管理；OfficeAce 首次开通需 admin 权限，IAM 用户需 OAuth2 及 agentarts::createAgreement 权限。
有效期管理： 企业实名认证有效期至 2027-08-31，启信充值金额自充值成功起 2 年内有效，应建立到期提醒与续期机制；云商店 0 元体验套餐包同一用户限购一次，仅用于测试验证。
输出治理： 启用平台工具调用安全护栏、高危操作确认与敏感数据自动脱敏能力；自动生成的尽调报告须经业务人员复核后方可作为合作决策依据。
