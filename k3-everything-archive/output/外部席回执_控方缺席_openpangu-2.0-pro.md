# 外部席回执｜openpangu-2.0-pro｜议题：控方起诉书缺席

### 1. 控方缺席对管线效力是实质损害还是可接受的简化？请给出论证。

**结论：控方缺席对管线效力构成实质损害。**

**论证如下：**
- **规程意图与设计一致性**：管线第2层全名为“控辩对抗”，其设计意图明确为“控方论证应通过、辩方结构性反对，形成对抗”。控方《起诉书》是启动对抗的基础性环节，为辩方提供反对的标靶和论证指向。若控方缺席，则“控辩对抗”名存实亡，降格为“辩方单向审查”，破坏了规程预设的对抗性平衡。
- **辩方功能有效性**：规程要求辩方提供“≥3条独立反对理由（附证据指针+杀伤力评级）”，其反对理由需针对控方论证中的弱点。若控方《起诉书》缺失，辩方的反对将失去针对性，可能导致反对理由空泛、证据指针偏离，甚至因缺乏参照而增加《无法反对说明书》的提交率，削弱管线“拦善/拦恶”的实质判断能力。
- **缺陷事实的警示**：试点012/013的监管门注记已明确将“控方起诉书连续缺席”升级为“规程缺陷登记项”，执行侧自述“简化掉”控方件属于单方面偏离规程的行为。连续缺席表明这不是偶然疏忽，而是系统性简化，若不纠正，将导致规程权威性受损，并可能引发其他环节的随意简化。
- **战绩台账的局限性**：尽管近期“拦恶6/6”成功，但这可能依赖于辩方独立调查能力或案例本身的显著性，不能掩盖对抗性缺失带来的长期风险。而“拦善首轮3/4”中可能存在未公开的失败案例，或与控方缺席导致辩方反对不充分有关。管线效力和鲁棒性不能仅凭短期战绩评估。

综上，控方缺席破坏了第2层的对抗结构，实质损害了管线的制衡机制和判断精度，并非可接受的简化。

### 2. 若恢复，应采取何种形态（全量恢复/轻量恢复/特定条件下触发恢复）？

**建议：全量恢复。**

**理由如下：**
- **规程刚性要求**：规程原文明确“控方《起诉书》论证应通过”，未留简化余地。全量恢复最符合规程原文，避免执行侧再次自由裁量导致“简化”回潮。
- **对抗质量保障**：全量恢复确保控方提供完整论证，包括指控事实、证据链与法律依据，使辩方能基于充分信息进行结构化反对，产出高杀伤力理由，提升管线输出可靠性。
- **成本与效益平衡**：虽然全量恢复可能增加席次成本（每案≥9席次），但相较于因对抗不足导致的误判风险（如漏拦恶或错拦善），该成本是必要且合理的。可通过优化控方起诉书模板、标准化提交格式来减轻负担。
- **轻量恢复与特定触发恢复的弊端**：轻量恢复（如摘要版）可能遗漏关键论证细节，仍无法满足辩方需求；特定条件触发恢复（如仅复杂案件恢复）会引入判断门槛，增加执行复杂性，且可能因标准模糊导致规避。

因此，应强制要求控方《起诉书》作为第2层的必备输入，恢复其强制环节地位。

### 3. 若不恢复，第 2 层应如何改写以名实相符？

若坚持不恢复控方《起诉书》，则第2层必须彻底改写以反映“单方审查”实质，避免规程名实不符。建议改写如下：

- **更名**：将“控辩对抗”更名为“辩方审查制衡”或“辩方结构化审查”，明确本层为单方主导。
- **输入调整**：以案卷材料、证据清单等中立文件替代《起诉书》作为辩方审查基础，由管线运营方提供“案件摘要”以替代控方论证概要。
- **辩方义务重构**：保留辩方≥3条独立反对理由要求，但改为“基于案件材料提出反对”，并增设“审查要点指引”以辅助辩方聚焦。若无法提出反对，仍需提交《无法反对说明书》。
- **监管强化**：增设“辩方审查质量抽查”机制，由评审团对反对理由的杀伤力评级进行复核，避免因缺乏控方而敷衍。
- **成本重估**：因取消控方席次，可适当调整席次下限（如≥6席），但需确保辩方调查员独立取证权（抽查≥30%可证伪主张）不变。

此改写虽可名实相符，但放弃了控辩对抗的制衡优势，仅适用于控方长期缺位的特殊场景，且需配套措施防止辩方独大。

### 4. 您识别到的我们没想到的风险或视角。

- **控方缺席的动机风险**：执行侧“简化掉”可能源于控方资源不足、提交延迟或缺乏激励，而非有意规避。若强制恢复，需同步调查控方缺席根源（如是否因管线流程过严导致控方不愿参与），否则可能造成形式化提交（如敷衍文书），仍无效。
- **辩方能力依赖风险**：若控方恢复但质量低下，辩方可能因缺乏高质量反对标的而能力退化。建议建立“控方起诉书质量评级”机制，对低质起诉书启动补充程序，避免对抗流于形式。
- **评审团“离席抗议”的连锁反应**：背景中提到评审团正测试“离席抗议”第三票态。若控方缺席导致对抗不完整，可能触发评审团离席，影响管线输出稳定性。需将规程缺陷与评审团票态关联评估，防止系统失序。
- **试点偏差的泛化风险**：试点012/013的缺陷可能已扩散至其他试点，建议全面排查历史判例簿，评估控方缺席的普遍性及对“拦善/拦恶”战绩的真实影响，避免数据偏差。
- **跨域毒饵的应对漏洞**：背景提及“拦恶6/6（含两域毒饵）”，毒饵案可能依赖辩方调查员独立取证而非控辩对抗。若控方缺席，毒饵案仍可拦截，但复杂善类案件可能更依赖对抗，需区分案件类型评估恢复必要性。
- **成本转嫁风险**：全量恢复控方席次可能增加总席次成本，若预算固定，可能挤压其他环节资源（如辩方调查员取证）。需进行成本-效益模拟，确保恢复不导致整体效能下降。
