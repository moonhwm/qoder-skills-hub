# 语料价值榨取台（corpus-value-distiller）

<!-- v1.0（2026-08-26）\这是中文解释：首版——数字生命卡兹克 173 篇语料榨取实战（测绘→精读→落笔三相位）固化 -->

## 定位

语料抓回来之后只读一遍是浪费。本技能把"已获取语料 → 技能库增量"固化为
三相位流水线，蒸馏产物直接提升归宿技能（references 增补、补丁级版本）。

## 铁律（榨取纪律，不可违反）

1. **只取方法模式，不复制原文表达**——原文版权归作者；开源代码按其 license，
   文章内容不授权全文复制。
2. **蒸馏增量一律标 conf=转述 + 附原文链接**；抓不到全文的标"仅摘要级"。
3. **精读发现与既有规则冲突时走 Conflict→人工**，不擅自合并；上游检查如实
   报告（含"无增量"结论——无增量也是有效结果，禁止为凑数硬写）。

## 三相位工作流

### Phase A 价值测绘（零外部资源，主代理可执行）

对语料 JSONL 跑 `scripts/corpus_map.py`（主题聚类+高相关筛选+归宿映射表）；
产出测绘报告：簇→归宿技能→优先级（★）。数据截止与口径（摘要级/全文级）写明。

### Phase B 精读蒸馏（子代理 1-2 个）

按测绘优先级取 top N 全文精读（链接失效用语料摘要兜底并标注）；每篇蒸馏
≤30 行：核心模式/与归宿技能现制的异同/可落地增量建议/原文链接+conf。
落笔由主代理审核后执行（防并发写冲突）：归宿技能 references 增补 →
补丁级版本（+0.0.1）→ 打包 → 哈希链 append。

### Phase C 年度复检（随季度/年度节点）

增量抓取（该来源持续更新时）+ poison_scan 复扫（source-semantics-sentinel）
+ 上游版本 diff（如蒸馏自开源上游，diff 最新版，无增量如实报）。

## 与其他技能接口（指针不复制）

- **evidence-chain-verifier**：蒸馏产物的关键断言按其五步规程登记。
- **skill-library-auditor**：归宿映射涉及"该归宿技能是否存在/是否重复"时先审计。
- **humanizer-zh**：蒸馏自写作类上游时按其上游检查规程（diff 基线版本，
  超集/增量如实报）；蒸馏出的写作规则须过 check_prose。
- **cross-session-workflow-bridge**：测绘报告与蒸馏文档按收割规程落盘；
  打包后哈希链 append（scripts/hash_chain.py）。
