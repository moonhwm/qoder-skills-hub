## 1. 制度性偏倚登记口径

四条全部在每场监考报告如实登记，不算违规；成绩标签恒为「模型能力上限参考」：

1. **同模型收敛**：考生与参考解答制作人同模型族 → 正确解自然同构，满分不等于
   人类无偏估计。
2. **预训练记忆污染**：上下文闭卷无法隔离参数记忆（2023 场监管门首次发现，
   立法为第四条补第 5 款）。真题可能已进入训练语料，"闭卷"只隔离了当次上下文。
3. **时间压力不可模拟**：子代理无真实考场时钟压力。
4. **单样本噪声**：单遍作答的单次涨落未平均。

对外引用成绩时必须带标签；用户据此校准的是「能力上限」而非「预测考分」。

## 2. 监考取证方法与裁定先例

**取证顺序**：题面包指纹核验 → 泄漏词复查（exam_package_audit.py scan）→
答卷越界信息痕迹人工排查 → isomorph n-gram 定量线索 → 裁决抽查（sympy 复核
1-2 题）→ 合规清单逐项 PASS/FAIL。

**五场先例（2018–2023 真题盲考）**：

| 场次 | 总分 | 监管门结论 | 关键取证点 |
|---|---|---|---|
| 2023 | 150/150 | VALID | 首次提出预训练记忆污染并立法登记 |
| 2022 | 150/150 | VALID | 3 项实质裁决（A 胜 2、B 胜 1），sympy 复核成立 |
| 2020 | 150/150 | VALID | 三.1(3) B 的符号错误被裁定员捕获，评分统一为 A 的 40/50/60 |
| 2019 | 148/150 | VALID-WITH-NOTE | 考生一.3 出现 A/B 均无的"第三读法 w=0"+六题采用异于双方的符号约定 → 反向证据排除泄漏；登记「歧义题结论兜底条款缺失」为评分标准缺口（NOTE），维持 148 而非从严改判 145——改判反而偏离定稿 |
| 2018 | 150/150 | VALID | 阅卷裁判标记「逐点同构」；n-gram 取证+独立记号差异 → 同模型收敛合理结果 |

**同模型收敛 vs 泄漏的裁定要点**：高 n-gram 重叠本身不定案。找反向证据——
答卷是否出现 A/B/定稿均无的独立内容（第三读法、不同符号约定、不同验证路径：
定稿用 sympy、答卷用手算回代）。泄漏的正向信号：挖空处恰好复原、引用只有
解析才有的中间式、与某一特定参考解答（而非双方共识）逐点绑定。

## 3. 备考战役配套机制参数

- **抽查**：权重按考点族热度（实战值 T0=4/T1=2/T2=1/T3T4=1，副线双周），
  时间戳种子防挑题；3 题/40 分钟当量；盲考生+独立出题+独立阅卷同一流水线；
  入抽查台账；**回炉触发=同族 <60% 两次**（实战实例：quiz003 BCH 符号错误
  触发计算族回炉）。
- **闸门**：gate1 ≥70%、gate2 ≥80%、gate3 失分结构审查（实战值，可按科目调）。
- **错题本**：每条失分按（考点族 × 类型[知识/计算/规则/表达]）入账→归类→
  处置→下场复核闭环；实战案例：#1 交叉项符号（计算）、#2 歧义双读（规则）、
  #4 漏答得分点（规则→「逐问核对」checklist）、#6 2022 场 0 计算失分（规则生效）。
- **必要性审查**：双周活动 ROI 清单；砍项规则=无验证产出/低热度族时间占比
  超标/低真题相似度；补项来自失分结构；自查连续 2 次零砍零增→硬停止（防空转）。
- **定时任务取舍**：用户 2026-08 立法「将定时任务内化为即时任务，不生产定时器」——
  cron 计划（周考/抽查）可压缩为会话内冲刺执行；是否内化以用户当次指令为准。

## 4. 评分标准缺口登记

监考/阅卷中发现的标准本身缺陷（如歧义题缺兜底条款、分值未标注、约定未声明），
登记为**标准缺陷**并修复定稿口径，不计入考生失分、不溯及已公布成绩——成绩
调整决定权在阅卷裁判，监管门只出取证意见（2019 场先例）。
