# 考场隔离运维（exam-isolation-ops）

蒸馏自 2026-08 大工 806 备考战役实战立法（考场隔离协议 v1.1）：用户纠正「不能充当裁判、
身份证人、出题人、答题者和考场监考者于一身」后的五轮真题盲考（2023/2022/2020/2019/2018）
与多场抽查的验证规程。

## 第一原则（违反即整场作废）

1. **角色结构隔离**：考生、参考解答制作人 A/B、裁定员、阅卷裁判、监管门全部是**新鲜独立
   子代理**，各自只见被授权材料，彼此互不可见；主程序只做排程与归档，**永不扮演任何角色**。
2. **题面包先行**：任何角色开工前，题面包必须物理剥离答案/存疑注释/provenance/Help 文本，
   过泄漏扫描，记 sha256[:16] 指纹；指纹写入所有角色简报与监考报告。
3. **诚实边界如实登记**（制度性偏倚，非违规）：同模型收敛（考生与出题者同模型族，满分≠
   人类无偏估计）、预训练记忆污染（上下文闭卷无法隔离参数记忆）、时间压力不可模拟、
   单样本噪声。一切成绩标签为「模型能力上限参考」。

## 标准工作流（一场盲考的完整流水线）

0. **出题打包**（主程序或独立出题人）：从真题原件生成题面包 →
   `python3 scripts/exam_package_audit.py scan <题面包>` 必须 CLEAN →
   `fingerprint` 记指纹。题面包禁含：答案、分值提示、考点频次结论、难度元信息。
1. **考生作答**（新鲜子代理）：唯一可见材料=题面包；闭卷、单遍、顺序作答不回头；
   全程展示推导；可计算项回代验证；歧义处声明解读再作答（禁止揣测"标准答案意图"）；
   答完逐题自报把握程度。简报模板见 [references/role_briefs.md](references/role_briefs.md)。
2. **双参考解答**（A、B 两个互不可见的新鲜子代理，同样只见证面包）：独立完整解答+
   分值建议（合计满分）+逐题得分点清单；符号/积分/矩阵用 sympy/numpy 验证。
3. **裁定**（第三个独立子代理）：可见=题面包+A+B（**禁看答卷**）；逐题比对，凡分歧
   （数值/符号约定/解读/分值）用 sympy 独立重推导后裁定；歧义题裁定给分口径
   （双读给分须自洽）；产出《评分标准_定稿》。
4. **阅卷**（新鲜子代理）：只见答卷+定稿（题面与 A/B 均不可见）；逐题得分点命中/缺失，
   失分注明类型（知识/计算/规则/表达）×考点族；尺度一致不松紧；发现答卷与定稿
   逐点雷同到不自然程度→报告中标记供监管门，**不影响按标准给分**。
5. **监考取证**（监管门，新鲜子代理）：只审程序公正性，**不改分数**。合规清单逐项
   PASS/FAIL：题面包指纹核验一致、泄漏词复查、答卷是否含超出题面包的信息痕迹、
   `isomorph` n-gram 重叠定量线索、裁决抽查（sympy 复核 1-2 题）。裁定结论
   VALID / VALID-WITH-NOTE / INVALID；同模型收敛 vs 泄漏必须结合反向证据
   （独立记号、第三读法、推导路径差异）裁定，禁止仅凭重叠数值定案。
6. **登记**：失分入错题本（族×类型，入账→归类→处置→下场复核）；成绩+标签+指纹+
   各报告路径落盘；发现评分标准缺口（如歧义题兜底条款缺失）登记为标准缺陷而非
   考生失误。

## 备考战役配套机制（按需启用）

- **抽查**：加权随机抽题（权重按考点族热度，如 T0=4/T1=2/T2=1/T3T4=1），时间戳种子，
  3 题/40 分钟当量，走同一盲考流水线（盲考生+独立出题+独立阅卷），入抽查台账；
  **回炉触发**=同族 <60% 两次。
- **闸门**：阶段门槛未达（如 gate1 ≥70%、gate2 ≥80%、gate3 失分结构审查）不进入下一阶段。
- **必要性审查**：双周活动 ROI 清单，砍无验证产出项；自查连续 2 次零砍零增→硬停止，
  防空转。

## Pitfalls（实战教训，均为已发生事件）

- **身兼多角=舞弊温床**：单代理既出题又作答又阅卷，成绩无意义（用户原始纠正点）。
- **题面包带毒**：手写答案未挖空、附注含分值/频次结论——打包后必须 scan 为净才准开考。
- **满分不等于泄漏**：同模型族考生+出题者，正确解自然同构；监管门曾以反向证据
  （答卷出现 A/B 均无的第三读法、异于双方的符号约定）裁定 VALID。反之，挖空处恰好
  复原、引用只有解析才有的中间式=泄漏信号。
- **阅卷裁判越界**：裁判只见答卷+定稿；让它看题面或 A/B 会污染尺度。
- **主程序下场**：主程序扮演任何角色都会破坏隔离；只做调度、归档、登记。
- **成绩对外表述**：未带「模型能力上限参考」标签的满分是对用户的误导。
