# 出处登记册规范

> 生成器：`scripts/source_register.py`（输入清单 JSON + 证据 JSON → 输出
> 出处登记册.md）。本规范定义登记册的字段、摘要抽取规则与诚实标注格式；
> 手工补写条目时也必须遵守同一格式。

## 1. 文档骨架

```markdown
# 出处登记册
- 登记时间：YYYY-MM-DD HH:MM:SS +0800
- 归档管线：（一句话说明枚举→下载→登记链路）
- 总览：N 个分享链接，共 M 个文件；已获取正文 x 个，未获取正文 y 个
       （如实登记，未伪造任何下载成功或内容摘要）

## 版权与使用总注记
> 本文件由用户提供的公开分享链接获取，仅供用户个人学习使用，出处见链接；
> 如涉第三方版权，权利归原权利人所有。若任何权利人主张权利，本登记册所载
> 条目将配合删除。

## 逐文件登记
### 链接1：<分享URL>
- 清单时间：…（第 N 轮）；目录 a 个 / 文件 b 个；已获取正文 x / 未获取正文 y
| 文件 | 大小(字节) | 来源链接 | 获取时间 | 内容摘要 | 版权与使用注记 | 轮次时间戳 |
```

## 2. 逐文件字段

| 字段 | 取值规则 |
|---|---|
| 文件 | `` `relPath` ``（反引号包裹的完整相对路径）+ 有 mtime 时附"（分享方修改于 …）" |
| 大小(字节) | 清单中的 `size`；缺失填 `—` |
| 来源链接 | 完整分享链接 `https://www.jianguoyun.com/p/{hash}`，不写短链、不写域名代称 |
| 获取时间 | 该链接清单的枚举时间（`fetched_at`），精确到秒并带时区 |
| 内容摘要 | 按第 3 节抽取；未获正文按第 4 节标注。摘要中的 `\|` 需转义防破表 |
| 版权与使用注记 | 固定模板（见 references/legal_notes.md 第 1 节），逐字使用不改动 |
| 轮次时间戳 | 该文件出现过的所有轮次及其时间，形如 `round1 …；round2 …`；无证据填 `—` |

## 3. 摘要抽取规则

仅对**已实际下载到本地**的文件抽取正文摘要；摘要上限 500 字，空白归一化。

| 类型 | 规则 | 依赖 |
|---|---|---|
| `.pdf` | 自首页起拼接文本层，取前 500 字；无文本层（扫描件）注明"未做 OCR" | pymupdf |
| `.docx` | 正文段落拼接取前 500 字 | python-docx |
| `.xlsx` | 首个工作表首行表头，以 ` \| ` 连接 | openpyxl |
| `.txt/.md/.csv` | 直接读前 500 字 | 标准库 |
| 图片（png/jpg/…） | 注明"图片文件（PNG），未做 OCR" | — |
| 其他 | "依据文件名判断：{文件名去扩展名}" | — |

诚实约束：

- 依赖库缺失时写"未能抽取正文（缺少 pymupdf）"等如实说明，**不编造摘要**。
- 抽取失败（文件损坏等）写"摘要抽取失败（异常类型: 信息），仅登记文件名"。
- 摘要只截取、不改写、不臆补；截取内容即文件原文开头。

## 4. 未获取正文的诚实标注格式

固定句式（以 403 为例）：

> 依据文件名判断：{文件名去扩展名}（{扩展名大写}）；未获取正文（{原因}；本管线不绕过该限制）

原因按证据记录如实填写：

| 情形 | 原因写法 |
|---|---|
| 403 SandboxAccessDenied | 分享者设置了"仅预览/禁止下载"权限，下载接口返回 403 SandboxAccessDenied |
| 其他 HTTP 失败 | 下载未成功（HTTP {status} {errorCode}：{detailMsg 前 80 字}） |
| 无下载记录 | 未在证据中找到下载记录 / 本轮仅枚举未下载 |

禁止把"依据文件名判断"的猜测写成正文内容的陈述（如不得写"该文件包含
历年录取分数线"，除非真正抽取到了正文）。

## 5. 轮次与时间戳规则

- 每轮归档（枚举/下载尝试）产生独立轮次编号 `round{N}`，时间戳格式
  `YYYY-MM-DD HH:MM:SS +0800`。
- 登记册正文表格的"获取时间"保留**首次**枚举时间；后续轮次的状态变化
  通过"轮次时间戳"列与卷首/链接级轮次小节体现。
- 新一轮重跑时在登记册追加"第 N 轮重跑记录"小节：触发原因、接口复核
  结论、与上一轮清单的差异（新增/消失/大小变化）、本轮成败计数与证据
  文件指针。**追加不覆盖**，历史轮次小节原样保留。
- 证据文件（下载尝试证据.json）与清单文件（文件清单_*_第N轮.json）同样
  按轮次追加命名，永不覆盖。
