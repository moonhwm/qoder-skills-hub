# 法律与版权注记框架（诚实版）

> 本框架不是法律意见，而是本技能的诚实操作纪律：既不夸大权利、也不掩饰
> 灰色地带。所有注记与授权声明按本文模板原文使用，不自行"润色"成更强势的表述。

## 1. 字幕组式出处注记范本

归档自公开分享链接的每个文件，在出处登记册中携带以下注记（字幕组惯用的
"声明出处 + 限制用途 + 权利归属"三段式）：

> **本文件由用户提供的公开分享链接获取，仅供用户个人学习使用，出处见链接；**
> **如涉第三方版权，权利归原权利人所有。**

登记册卷首另加总注记一句：

> 若任何权利人主张权利，本登记册所载条目将配合删除。

使用要点：

- 注记**如实描述获取方式**（"用户提供的公开分享链接"），不得写成"已获
  权利人授权"等超出事实的表述。
- 注记不创设任何权利，只是标明出处与用途限制；它不能使侵权行为合法化，
  其作用是诚实与可追溯。
- 未获取正文的条目同样携带注记——登记的是"存在该文件"这一事实。

## 2. 去水印授权边界

去水印（`scripts/pdf_watermark.py clean`）只在同时满足以下条件时执行：

1. **对象限定**：用户本人已购买/自有的文档（如机构付费取得的内部讲义）。
   对他人享有版权的文档抹除水印可能损害权利人合法权益，本技能不提供该能力。
2. **显式授权**：必须携带 `--owned` 授权声明旗标，声明原文写入处理日志
   （`authorization` 字段），处理范围以声明为限（如"仅限本批 4 个链接内文档"）。
   无旗标一律拒绝执行（退出码 3）。
3. **技术限定**：只抹除**文本层**（跨页重复且命中水印用词的静态文字）与
   **注解层**（/Annots 中 Subtype 为 /Watermark 的标准水印注解）水印对象。
   - 加密/DRM 保护的 PDF：直接拒绝处理并记录原因，不破解。
   - 图像层水印：无法以合规手段界定边界，只报告不处理。
   - 跨页重复但未命中水印词的文字：按"疑似"处理，为避免误删正文不动。
4. **原件保留**：原件一律不动，输出 `*_cleaned.pdf` 副本；日志记录原件与
   副本双 SHA-256，可审计、可回溯。

## 3. 技术保护措施的灰色地带提示

《中华人民共和国著作权法》第四十九条、第五十三条对**技术措施**设有保护：
未经许可避开或破坏权利人为作品采取的技术措施，可能构成侵权；但法律同时
设有例外情形，且司法实践对"为个人学习目的处理自己合法取得的文档"如何
定性并不完全清晰——**这是灰色地带，本技能如实提示，不作"完全合法"的断言**。

由此导出操作纪律：

- 分享者设置的"禁止下载"属于访问控制：本技能**不绕过**，403 即止步留痕。
- 文档内的水印是否构成"技术措施"存在争议；因此即使对用户自有文档，
  也只做最小限度处理（文本/注解层），并保留原件与双 hash 日志。
- 用户若主张更激进的处理（破解加密、去 DRM、涂改图像层），一律拒绝并
  说明法律风险。

## 4. 公开工具索引登记规则

归档过程中借助的公开工具/脚本来源，按"只登记不复制"处理：

- 登记字段：工具名称、官方/来源 URL、许可证、用途一句话、登记时间。
- **只登记索引，不把第三方工具代码复制进归档产物**——避免再分发风险与
  许可证污染；需要使用时让用户按索引自行从官方渠道获取。
- 对来源链接本身已失效的工具，标注"链接已失效，仅存名称备查"，不另行
  寻找镜像转载。

## 5. 禁止事项清单

| 禁止 | 说明 |
|---|---|
| 伪造下载成功 | 403/失败必须如实记录，`saved_bytes` 不得虚构 |
| 伪造内容摘要 | 未获取正文只能按文件名判断并注明"未获取正文" |
| 绕过访问控制 | 不用代理池/撞库/漏洞等手段突破分享者权限设置 |
| 破解加密/DRM | 加密 PDF 直接跳过并记录，不做任何解密尝试 |
| 超授权处理 | 无 `--owned` 声明不去水印；声明范围外的文档不处理 |
| 涂抹证据 | 证据按轮次追加，不覆盖、不删除历史失败记录 |
