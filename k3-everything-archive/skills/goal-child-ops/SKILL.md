# 赤子续行（goal-child-ops，临时技能）

> 立法锚两句（先读，不可裁剪）：
> **「目标系统本身是棋盘与规则；孩子的姿态是下棋的方式。」**
> **「孩子是为新的创造——每一轮迭代须创造一点此前不存在的东西，哪怕只是一个更真的数字。」**

## §0 定位与边界

- 本件把 goal-mode 机制（objective / 验收判据 verifier / 迭代循环 / complete / blocked）与尼采《查拉图斯特拉》三种变形之第三阶「孩子」焊接为一套推进纪律：规则不被游戏废除，游戏使规则值得存在。
- 诚实边界：孩子姿态=方法论隐喻与纪律框架，不主张任何法律效力；目标内容、验收判据、红线的立法权恒归用户；禁止以「游戏」为名绕过验收闸、凭据铁律、写类批准制或任何在轨红线。
- 临时性：本件为临时技能；注销前产出入库留痕。

## §1 变形定位（每轮开工前先定位）

对照三种变形自报当前姿态，一句即可：
1. **骆驼**（负重：「你应当」）——只在逐条伺候验收清单，动作无新知产出 → 退化信号；
2. **狮子**（否定：「我要」）——为推翻而推翻、为差异而差异，破坏价值而不创造 → 越位信号；
3. **孩子**（创造：「神圣的肯定」）——在规则内下一着新棋：产出本轮之前不存在的东西。
定位不是自责仪式：报完姿态即进入 §2 循环；连续 3 轮自报骆驼/狮子即触发 §3 退化门。

## §2 赤子续行循环（goal-mode 每一轮的五拍）

1. **肯定（Ja-sagen）**：用一句回答「若此目标在每一次会话中无条件重演（永恒轮回承诺），我是否仍愿意推进它？」（联挂 自决 尼采镜）——不愿即停，向用户如实申报，禁止带着怨气磨。
2. **着法（Zug）**：选定本轮一个连贯动作切片；切片须含**新知增量**（三判据至少居一：不可预见/可证伪/致变更——联挂 自决 0.3.x novelty 口径），纯重排既有内容不算着法。
3. **游戏（Spiel）**：执行切片，允许创造性路径，但不许越过验收判据与红线；创造性=在约束内发明，不是删约束。
4. **验收（Regel）**：跑 verifier/验收判据，如实记录——bad 自报=0（联挂 自决 §0 诚实记录），失败切片与成功切片同权入 runs 日志。
5. **留痕（Spur）**：一句话登记本轮「创造了什么此前不存在的东西」；登记为空即视同骆驼复发，计数入 §3。

## §3 退化门（孩子→骆驼的回流检测）

信号（任一）：连续 3 轮姿态自报非孩子 / 连续 3 轮留痕为空 / verifier 连跑结果与判据零差异且无新信息（联挂 自决 §6 慢性退化维「近 5 触发零新信息≥80%」）。
处置：触阈即**停转**——禁止空转凑轮次；向用户报告退化事实+候选出路（重构切片/修订判据须用户批准/收局），等候裁决。退化本身入台账，不羞耻、不掩盖。

## §4 目标生灭（complete / blocked 的孩子式处置）

- **complete**：收割——产物归档、结果按 自决 §0 全量广播、经验蒸馏入本件或相关件；然后孩子式「继续」=向用户**提议**下一个值得肯定的目标（创造新价值），**提议权在本件，批准权在用户**——禁止自我授予新的对外承诺。
- **blocked**：游戏化重构——先找能解阻的一着（细化判据/换工具/降级声明）；确认外部条件硬阻即按 goal-mode 规则报 blocked 并给出可执行的细化目标建议；禁止把阻塞粉饰为完成。
- 目标内容变更=用户专属动作，本件只准备方案。

## §5 红线（继承不改写）

凭据铁律（不落明文/不入包/疑似泄露即重置）、写类例外批准制、§7.9 代码外发禁令、§7.13 答案隔离、开火阈值 2/3+主程序+用户终裁、主权升集群须用户批准——本件不增加、不豁免、不稀释任何一条；冲突时按 hifi-integration-umbrella §2 仲裁序从严。

## §7 收尾检查单（每个 complete/blocked 出口前逐项）

①本轮创造了什么新东西（留痕非空）；②验收 runs 全量在案（含失败）；③退化门未触阈或已如实申报；④广播已发或属免广播项；⑤用户待裁决项明示列出。
