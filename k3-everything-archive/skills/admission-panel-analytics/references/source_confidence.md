## 1. S/A/B/C/D 五级定义

| 等级 | 定义 | 典型情形 | 建议权重 |
|---|---|---|---|
| **S** | 官方 + 实证**双确认**：官方信源（学校官网/研招网/官方公告）与录取实证面板（如机构汇总的公示录取数据）**双源一致** | 官网确认招生数 + 面板实证录取数吻合 | 0.45 |
| **A** | 官方**或**实证**单源**：仅其一，但内容自洽、无反证 | 仅官方公告；或仅实证面板但多年自洽 | 0.30 |
| **B** | 官方但**缺录取实证**：官网有招生目录/复试细则，但无实际录取率数据，一志愿率/复试通过率为推测 | 新纳入观察、无面板覆盖的学校 | 0.25 |
| **C** | 转述：第三方高置信转述，无官方背书 | 论坛/自媒体/口头信息 | 0.15 |
| **D** | 推测/估算：模型外推、趋势预测、经验拍定 | 下一年规模/分数线预测 | 0.10 |

分级判定要点：
- **"双确认"要求两源独立且数值一致**；同一来源被两个渠道转载不算双源。
- 官方信源之间相互矛盾时，以**最新年度、最小颗粒度**（学院公告 > 学校总纲）为准，并记录冲突。
- 实证面板的权威来自其汇总的公示数据；引用时必须回溯到公示口径（年份、专业代码、是否含专项）。

## 2. 与 conf 三级的映射

| 信源等级 | conf | 脚本/交付中的使用约束 |
|---|---|---|
| S | `empirical` | 可直接进入模式判别与评分 |
| A | `empirical`（标注"单源"） | 可进入判别与评分；结论注明单源依赖 |
| B | `estimated` | 可进入评分但模式判别置信度上限=中；必须提示"补录取实证" |
| C | `estimated`（低） | 仅定性参考；不得单独支撑模式判别 |
| D | `assumed` | 禁止进入判别；仅用于情景讨论，输出必须标"推测" |

逐字段映射：同一 record 内不同字段可不同级——用 `conf_fields` 逐字段覆盖
（如 total_admit=S、must_score=B）。record 级 conf 取各字段最低级。

## 3. 缺失数据处置

1. **宁缺毋造**：缺测=null 并登记 missing，禁止 0 填充、禁止无声推测填补（规范详见
   `references/panel_schema.md` §4）。
2. **缺失即降级**：关键字段（total_admit/first_choice_admit）缺失 → 该年记录禁入模式判别，
   整校 conf 上限降一级。
3. **B 级观察名单**：官方但缺录取实证的学校列入"观察名单"，交付时显式标注
   "⚠️ B 级数据，缺乏录取率实证"，并给出补数据清单（需获取哪些年份的哪些字段）。
4. **外推隔离**：跨年预测只进 `forecast` 对象，conf=assumed（D 级）；张量/趋势外推的
   异常值（如外推必达分显著越界）必须标注"模型外推误差"并剔除出评分输入。
5. **缺测字段的评分中性化**：score_panel 对缺测项按中性值处理并逐项列入 assumptions，
   禁止静默按最优值计算。

## 4. 双源冲突处理

1. 发现冲突 → 记录冲突项（字段、两源数值、来源）→ 以官方最新口径为准修正。
2. 修正后**必须重跑受影响的判别与评分**，并给出"修正前 → 修正后"对照
   （字段值、模式判定、评分、排名变化）。
3. 冲突修正计入版本变更日志（见 `references/iteration_protocol.md` §3 版本回溯）。

## 5. 置信度配比声明范式

每份正式分析报告的末尾必须声明数据置信度配比，格式：

```
数据置信度：S级 __% + A级 __% + B级 __% + C级 __% + D级 __%
（按进入评分的字段数加权；D 级仅出现于 forecast 与情景讨论）
```

判别规则：S+A 合计 <50% 时，全部结论降一级措辞（"建议"→"倾向"），
并在 top3_likely_wrong 中列入"信源基础薄弱"。
