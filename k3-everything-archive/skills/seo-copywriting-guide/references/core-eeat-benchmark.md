# CORE-EEAT 80 项内容质量基准

> 本文件为 seo-copywriting-guide 的完整质量基准库。SKILL.md 第 2 步加载其中的 16 项核心约束；需要完整 80 项审计时使用本文件。
> 四大类别：C = Content（内容与意图）、O = Organization（结构与组织）、R = Reliability（证据与可信度，对应 E-E-A-T）、E = Experience（体验与互动）。

## Content-Type Weight Table

按内容类型调整各类别权重（合计 100）。写作时优先满足高权重类别的条目。

| 内容类型 | C 内容 | O 结构 | R 可信度 | E 体验 | 关键条目（必须全过） |
|---|---:|---:|---:|---:|---|
| Blog 博客 | 35 | 20 | 25 | 20 | C01, C02, O01, R01, R04 |
| How-to Guide 教程 | 25 | 35 | 20 | 20 | C02, O01, O06, E07, R01 |
| Landing Page 落地页 | 30 | 20 | 25 | 25 | C01, C06, R07, E04, O02 |
| Product Review 评测 | 25 | 15 | 40 | 20 | R01, R04, R07, C02, E07 |
| Comparison 对比文 | 25 | 25 | 35 | 15 | R01, R04, O08, C03, C10 |
| Listicle 清单文 | 30 | 30 | 20 | 20 | C03, O01, O06, O09, E07 |
| News/Newsjack 资讯 | 30 | 20 | 35 | 15 | C02, R01, R02, R03, C01 |
| Thought Leadership 观点 | 35 | 15 | 35 | 15 | C01, C10, R04, R08, R11 |
| Landing Docs 文档型 | 20 | 35 | 30 | 15 | O01, O08, R01, O06, C02 |
| YMYL（健康/金融/法律） | 25 | 15 | 45 | 15 | R02, R03, R09, R10, R12 全部强制 |

## C 类：内容与意图（C01–C20）

| ID | 条目 | 判定标准 |
|----|------|---------|
| C01 ★ | Intent Alignment 意图对齐 | 标题承诺必须与正文交付一致 |
| C02 ★ | Direct Answer 直接回答 | 核心答案出现在前 150 词内 |
| C03 ★ | Query Coverage 查询覆盖 | 覆盖 ≥3 个查询变体（同义词、长尾词） |
| C04 | Search Journey 搜索旅程 | 覆盖用户从认知到决策的下一阶段问题 |
| C05 | Semantic Keywords 语义关键词 | 使用 LSI/实体共现词，而非关键词堆砌 |
| C06 ★ | Audience Targeting 受众定位 | 明确声明"本文适合……" |
| C07 | Pain-Point Opening 痛点开场 | 开场点明读者痛点或问题场景 |
| C08 | Depth vs SERP 深度超越 | 内容深度超过当前 SERP 前 5 名的平均水平 |
| C09 | Unique Angle 独特视角 | 含至少 1 个竞品内容没有的原创观点或数据 |
| C10 ★ | Semantic Closure 语义闭环 | 结尾回答开场问题并给出下一步行动 |
| C11 | Keyword Placement 关键词位置 | 主关键词出现在 H1、首段、至少 1 个 H2 |
| C12 | Title CTR 标题点击力 | 标题含数字/年份/利益点之一，≤60 字符 |
| C13 | Meta Description | 150–160 字符，含主关键词与行动号召 |
| C14 | URL Slug | 短、含主关键词、无停用词 |
| C15 | Freshness 时效性 | 数据/案例标注年份；过时内容标注更新日期 |
| C16 | Content-Length Fit 篇幅适配 | 篇幅与该关键词 SERP 均值匹配（±30%） |
| C17 | Cannibalization Check 自相残杀检查 | 不与同站已有页面竞争同一关键词 |
| C18 | FAQ Coverage | 覆盖 People Also Ask 中 ≥3 个问题 |
| C19 | Actionable Takeaway 可执行收获 | 每节至少 1 个读者可立即执行的动作 |
| C20 | CTA Alignment 行动号召对齐 | CTA 与搜索意图阶段匹配（信息型不强推购买） |

## O 类：结构与组织（O01–O20）

| ID | 条目 | 判定标准 |
|----|------|---------|
| O01 ★ | Heading Hierarchy 标题层级 | H1→H2→H3 不跳级 |
| O02 ★ | Summary Box 摘要框 | 含 TL;DR 或 Key Takeaways |
| O03 | Scannable Layout 可扫读 | 列表、加粗、表格替代大段文字 |
| O04 | Jump Links 跳转链接 | 长文（>2000 词）含锚点目录 |
| O05 | Logical Flow 逻辑流 | 节与节之间有承接句 |
| O06 ★ | Section Chunking 分节单主题 | 每节单一主题；段落 3–5 句 |
| O07 | Table Usage 表格化 | 对比类信息用表格呈现 |
| O08 ★ | Anchor Navigation 锚点导航 | 目录含跳转链接 |
| O09 ★ | Information Density 信息密度 | 无废话填充；术语全文一致 |
| O10 ★ | Multimedia Structure 多媒体结构 | 图片/视频有说明文字且承载信息 |
| O11 | Internal Linking 内链 | ≥3 条相关内链，锚文本描述性 |
| O12 | External Linking 外链 | 权威来源外链在新标签打开且标注来源 |
| O13 | Featured Snippet Format 精选摘要格式 | 定义句/步骤列表/表格至少其一符合摘要抓取格式 |
| O14 | Schema Readiness 结构化数据就绪 | 内容结构可被 FAQ/HowTo/Article schema 标记 |
| O15 | Mobile Readability 移动可读性 | 短段落、无宽表格溢出 |
| O16 | Section Length Balance 节长均衡 | 无单节占比 >40% |
| O17 | Numbered Steps 编号步骤 | 流程类内容用编号而非纯叙述 |
| O18 | Bold Key Terms 关键术语加粗 | 每屏 ≤3 处加粗，突出核心概念 |
| O19 | Quote/Callout Blocks 引用块 | 关键结论用引用块或提示块区隔 |
| O20 | Footer Navigation 页脚引导 | 结尾给出相关内容导航 |

## R 类：证据与可信度（R01–R20）

| ID | 条目 | 判定标准 |
|----|------|---------|
| R01 ★ | Data Precision 数据精确 | ≥5 个带单位的精确数字 |
| R02 ★ | Citation Density 引用密度 | 每 500 词 ≥1 条外部引用 |
| R03 | Source Authority 来源权威 | 引用来源为官方/学术/行业权威 |
| R04 ★ | Evidence-Claim Mapping 证据-主张映射 | 每个主张都有证据支撑 |
| R05 | First-Hand Experience 一手经验 | 含实测/亲用/原创案例证据（E-E-A-T 之 Experience） |
| R06 | Expert Quote 专家引述 | 含具名专家观点或作者资历声明 |
| R07 ★ | Entity Precision 实体精确 | 人名/机构/产品使用全称 |
| R08 | Original Research 原创研究 | 含自制图表/调查/测试数据 |
| R09 | Author Byline 作者署名 | 作者身份与资历可查 |
| R10 | Disclosure 利益披露 | 联盟营销/赞助关系明确披露 |
| R11 | Balanced View 观点平衡 | 列出反方观点或局限性 |
| R12 | Fact-Check Pass 事实核查 | 所有事实性陈述可在 2 个独立来源验证 |
| R13 | Date Stamping 日期标注 | 统计与价格数据标注获取日期 |
| R14 | Link Health 链接健康 | 无死链；外链域名权威 |
| R15 | Terminology Accuracy 术语准确 | 专业术语使用符合行业标准定义 |
| R16 | Claim Restraint 措辞克制 | 不使用"最佳/第一"等无法证实的绝对化表述 |
| R17 | Methodology Note 方法说明 | 评测/对比类内容说明评测方法 |
| R18 | Update Log 更新日志 | 长青内容含修订记录 |
| R19 | Image Attribution 图片署名 | 非原创图片标注来源 |
| R20 | AI-Content Polish 去 AI 痕迹 | 无模板化套话；通过人工通读 |

## E 类：体验与互动（E01–E20）

| ID | 条目 | 判定标准 |
|----|------|---------|
| E01 | Page Speed 加载速度 | 正文无拖慢加载的未优化大图 |
| E02 | Reading Level 阅读难度 | 句式与目标受众匹配（大众内容 ≤ 初中阅读级） |
| E03 | Tone Consistency 语气一致 | 全文语气统一，无人称漂移 |
| E04 ★ | Above-Fold Hook 首屏钩子 | 首屏给出继续阅读的理由 |
| E05 | Visual Breaks 视觉节奏 | 每 300–400 词有一个视觉元素或版式变化 |
| E06 | Comment Prompt 评论引导 | 结尾提出引导讨论的问题 |
| E07 ★ | Practical Tools 实用工具 | 含可下载模板/清单/计算器 |
| E08 | Share Trigger 分享触发 | 含高引用价值金句或统计图 |
| E09 | Next-Step Link 下一步链接 | 结尾链接到旅程下一篇内容 |
| E10 | Accessibility 无障碍 | 图片 alt 文本、对比度、语义化标签 |
| E11 | Localization Fit 本地化 | 度量衡/货币/案例符合目标地区 |
| E12 | Jargon Control 术语控制 | 首次出现术语给出解释 |
| E13 | Example Density 示例密度 | 每个抽象概念配 ≥1 个具体示例 |
| E14 | Story Element 叙事元素 | 至少 1 个场景化叙事片段 |
| E15 | Error-Free 零错误 | 无拼写/语法错误 |
| E16 | Voice Search Fit 语音搜索适配 | 含问答式小标题 |
| E17 | Dark-Pattern Free 无暗黑模式 | 无误导性按钮/强制弹窗文案 |
| E18 | Multi-Format Hint 多格式提示 | 关键内容可被改写为视频/播客脚本 |
| E19 | Return Value 回访价值 | 内容值得收藏（清单/模板/工具类） |
| E20 | Exit-Intent Fit 离开意图匹配 | 结尾 CTA 与读者离开原因匹配 |

## 评分方法

1. 逐项判定：通过（1）/ 部分（0.5）/ 未通过（0）/ 不适用（剔除）。
2. 类别分 = 类别内得分率 × 该类权重（见 Content-Type Weight Table）。
3. 总分 = 各类别分之和（满分 100）。
4. 分级：A ≥85 可发布；B 70–84 小修后发布；C 55–69 需重写部分章节；D <55 推倒重写。
5. 标 ★ 的 16 项为核心条目：任一未通过则总分上限为 B。
6. YMYL 内容：R09/R10/R12/R13 任一未通过即不予发布。
