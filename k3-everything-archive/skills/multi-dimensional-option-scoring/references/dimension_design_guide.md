# 维度设计指南

本指南规定多维度评分中"维度"的完整定义方法。每个维度必须包含四要素：
**分值标准表（0–10 锚点）+ 证据来源要求 + 核查要点 checklist + 可计算关键指标**。
缺任一要素的维度不得进入打分。

---

## 1. 分值锚点写法

锚点必须是**可观察、可验证的事实描述**，禁止用"好/一般/差"这类循环定义。
每个维度至少给出 4 个锚点（0–2 / 3–4 / 6–7 / 9–10 档），中间分值允许线性插值。

反面示例（禁止）：

> 9-10 分：收益很高；0-2 分：收益很低。

正面示例（必须效仿）：

| 分值 | 锚点描述 |
|------|----------|
| 9–10 | 近 3 年复合收益率 ≥ 25%，且经审计或第三方数据源可核实 |
| 6–7  | 近 3 年复合收益率 12%–25%，来源可靠但仅覆盖部分年份 |
| 3–4  | 收益率 0%–12%，或仅有发行方自述数据 |
| 0–2  | 历史亏损，或完全无可核实业绩记录 |

## 2. 证据分级（conf）

每个分值必须标注 conf 等级，映射到数值用于置信度加权：

| 等级 | 含义 | 数值 | 判定标准 |
|------|------|------|----------|
| empirical（实证） | 一手或可交叉验证的数据 | 1.0 | 官方统计、审计报告、可复算的原始数据、两个以上独立来源相互印证 |
| estimated（估算） | 基于实证外推或代理指标 | 0.6 | 行业报告推断、可比对象类比、有明确假设链条的估算 |
| assumed（假设） | 无直接证据的假设 | 0.3 | 单一来源无法核实、纯逻辑推演、利益相关方自述 |

**硬规则**：禁止给 B 级（estimated）数据 A 级（empirical）置信度。
当证据等级存疑时，一律向下取档。

## 3. 核查要点 checklist 模板

每个维度附 3–6 条核查项，打分前逐条确认。模板：

```
维度：<名称>
- [ ] 数据来源是否为原始出处（非转载/摘要）？
- [ ] 数据时间范围是否覆盖决策窗口？截止时间是何时？
- [ ] 是否存在利益相关方（卖方/平台/推荐人）扭曲数据的动机？
- [ ] 关键指标是否可用第二种独立方法复算？复算结果是否一致？
- [ ] 最差情形（数据乐观偏差 30%）下分值会如何变化？
- [ ] 该维度的 conf 等级是否与证据强度匹配？
```

## 4. 可计算关键指标

每个维度必须给出至少一个可计算公式，使分值可复核。常用指标：

- 收益类：复合年化收益率 = (终值/初值)^(1/n) − 1
- 风险类：最大回撤、波动率（收益率序列标准差 × √周期）
- 流动性类：日均成交额 / 持仓规模；退出所需天数
- 匹配类：重合度 = 满足要求的子项数 / 要求总数
- 成本类：总拥有成本 = 显性成本 + 隐性成本（时间×时薪 + 切换成本）

## 5. 负权重项设计规则

负权重项（negative_items）用于表达"做得越差扣分越多"的风险，与正向维度互补：

1. **score 表示风险严重度**（0–10，越大越危险），weight 为负数，乘积即扣分。
2. 扣分幅度上限：单项 |weight × score| 不得超过总分范围的 30%，防止单项一票否决（除非该风险确实是欺诈信号，此时直接判 F 档而非扣分）。
3. 负权重项同样必须标注 conf；conf 越低，说明风险是否真实存在都不确定，必须在报告中明示。
4. 常见负权重项示例：调剂/退出窗口风险、合规与牌照风险、关键人依赖、利益冲突、数据造假迹象。
5. 负权重项数量建议 ≤ 3；超过 3 个说明该选项风险结构复杂，应考虑直接降级而非堆叠扣分。

## 6. 完整示例：评估一个在线硕士项目平台

**维度 1：学位认可度（weight 0.30）**

| 分值 | 锚点 |
|------|------|
| 9–10 | 发证院校为教育部承认高校，学位与全日制完全等同，学信网可查 |
| 6–7  | 院校正规但学位标注"非全日制/在线"，主流雇主认可 |
| 3–4  | 境外院校未经留服认证，或认可度存在公开争议 |
| 0–2  | 无法核实发证主体，或被曝光为"野鸡大学" |

- 证据来源要求：学信网/留服中心查询截图 + 至少 2 个雇主或招聘平台的明确要求（conf: empirical）
- 核查 checklist：
  - [ ] 学信网/留服查询结果是否为本人实时查询而非招生方提供？
  - [ ] 目标行业近 12 个月招聘 JD 是否明确接受该学位形式？
  - [ ] 招生宣传中的"认可"表述是否有书面出处？
- 关键指标：认可雇主占比 = 明确接受的 JD 数 / 抽样 JD 总数（抽样 ≥ 50 条）

**维度 2：投入产出比（weight 0.25）**

| 分值 | 锚点 |
|------|------|
| 9–10 | 总成本 < 1 年预期薪资增量，回本周期 < 2 年 |
| 6–7  | 回本周期 2–4 年 |
| 3–4  | 回本周期 4–8 年，或薪资增量依赖乐观假设 |
| 0–2  | 回本周期 > 8 年或无法估算 |

- 证据来源要求：学费官方页面 + 目标岗位薪资报告（conf: estimated，因薪资增量是外推）
- 关键指标：回本周期 = 总成本（学费 + 学习时长 × 时薪机会成本）/ 年薪资增量

**维度 3：时间灵活性（weight 0.25）**

| 分值 | 锚点 |
|------|------|
| 9–10 | 完全异步，无强制直播/驻场，可暂停学籍 |
| 6–7  | 有少量同步环节但可协调 |
| 3–4  | 每周固定直播 ≥ 4 小时或有阶段性驻场 |
| 0–2  | 实质等同脱产 |

- 证据来源要求：培养方案原文 + 在读学员访谈（conf: estimated）
- 关键指标：每周刚性时间 = 直播课时 + 作业截止约束折算小时数

**负权重项：项目停办/跑路风险（weight −0.20）**

- score = 风险严重度：办学主体成立 < 3 年记 7 分以上；有投诉或诉讼记录记 9 分
- 证据来源要求：工商信息、裁判文书网、投诉平台（conf: empirical 若查得记录，否则 estimated）
- 若发现伪造办学资质 → 不扣分，直接判 F 档

**打分输入示例（可直接喂给 scoring_engine.py）**：

```json
{
  "option": "X 平台在线硕士",
  "dimensions": [
    {"name": "学位认可度", "score": 7.0, "weight": 0.30, "conf": "empirical"},
    {"name": "投入产出比", "score": 5.5, "weight": 0.25, "conf": "estimated"},
    {"name": "时间灵活性", "score": 8.0, "weight": 0.25, "conf": "estimated"},
    {"name": "师资与课程质量", "score": 6.0, "weight": 0.20, "conf": "assumed"}
  ],
  "negative_items": [
    {"name": "项目停办风险", "score": 4.0, "weight": -0.20, "conf": "estimated"}
  ]
}
```
