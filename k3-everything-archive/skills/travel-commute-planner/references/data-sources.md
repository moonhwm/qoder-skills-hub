# 数据源可行性与合规红线（合并版）

## 铁路

| 源 | 可行性 | 说明 |
|---|---|---|
| 12306 官方接口（leftTicket/queryG + queryTicketPrice） | ✅ 免 key | 需先取 cookie 会话；防刮间隔 ≥0.2s；预售期 15 天；**唯一 A 级票价源** |
| 第三方票务 App 逆向 | ❌ 禁止 | ToS + 法律灰色 |

## 航班

| 源 | 可行性 | 说明 |
|---|---|---|
| 中国航信 IBE | ❌ 企业级 | 个人不可得 |
| 飞常准/航旅纵横 API | ❌ 不免费 | — |
| 民航局开放平台 | ⚠️ 免费 1000 次需实名 | 有企业场景再评估 |
| Flightradar24 | ⚠️ $49+/月 | 海外向 |
| **OTA 链接生成**（本模块方案） | ✅ 零风险 | 只给去哪儿/携程/飞猪/同程查询链接，不抓数据 |
| OTA 逆向（飞猪 MTOP/途牛 deviceId） | ❌ 禁止 | 违反服务条款，任何输出须标风险，本技能不内置代码 |

## 地图路径

| 源 | 可行性 | 说明 |
|---|---|---|
| 高德 Web服务 API | ✅ 免费额度 | 需 AMAP_WEBSERVICE_KEY；不含铁路/航班票价 |
| 高德/百度免 key Web 估算 | ⚠️ 降级路径 | 页面估算值，conf=estimated |

## 成本核算参数

| 参数 | 口径 |
|---|---|
| 时薪 | 用户声明；无声明按当地可支配收入/工时估算，conf=assumed |
| 可利用时间比例 | 高铁整段 0.5–0.8（有桌板可办公学习）；换乘/拥挤站乘 0 |
| 疲劳惩罚 | 单程 >75min 起记 |

## 全局红线

1. 禁止伪造 12306/航司/地图平台深链——宁给官方入口首页+检索路径
2. 票价/时刻是时变数据，引用必带查询日期
3. 个人研究用途边界：本技能输出不构成票务代理或商业用途授权
