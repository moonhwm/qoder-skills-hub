# 聚变择校核查员（fusion-program-audit）

## 使命与定位

对某高校宣称的核聚变方向执行"七步检索 → 欺诈分型 → A-F 评级 → 证据链输出 → 误判自修正"的完整核查，回答核心问题：**该校的聚变布局是实质还是"聚变期权"（可能兑现、也可能归零的叙事）？**

本技能是 `claims-deep-audit`（宣传主张深度核查，四分型 A 有壳空虚 / B 无壳裸骗 / C 名称偷换 / D 学科嫁接，R1-R8 八轮核查）的**领域特化**：复用其 R1-R8 交叉验证规则、红线机制、证据分级（A/B/C 级）与防偏硬条款（置信标注、措辞纪律、时效标注），**引用不复制**；领域差异（聚变装置状态、学科代码陷阱、跨学院分布、聚变产业集群）由本技能补充。评级卡的证据链完整性校验对接 `evidence-chain-verifier` 技能（分工见"误判自修正"节）。

## 五条防偏原则（全程默念）

1. **标签 ≠ 实质**：有"等离子体物理"方向名称，不等于有聚变研究。
2. **历史 ≠ 当前**：十年前的 ITER 专项，不能证明今天仍有聚变投入。
3. **名义 ≠ 实际**：名单上的装置/导师，不等于运行/在岗。
4. **位置 ≠ 融入**：身在合肥/成都集群，不等于参与协作网络。
5. **数量 ≠ 质量**：论文多，不等于聚变方向占比高。

补充领域特化原则：**学院边界有盲区**——聚变方向常藏在物理、电气、能源、机械、材料、交叉学院，绝不止核学院；**学科代码有盲区**——自设二级学科（如 0808J1 脉冲功率与放电等离子体）不在标准目录中。

## 核心工作流

### 第 0 步：触发判定与声明拆解

- 确认任务属于本技能（择校核查 / 方向真伪 / 装置状态 / 虚假宣传识别）。
- 把该校全部对外声称（招生简章、学院官网、新闻稿、宣传话术）转成**可证伪命题清单**，逐条编号。不可证伪表述（"实力雄厚""全国唯一"）标注为话术并计数——话术密度本身是水分信号。
- 招生话术反制示例：「全国唯一 XX 装置」→ 查装置来源（捐赠？）、运行状态、论文产出；「院士领衔」→ 查年龄、近 5 年项目、团队传承；「中核定招」→ 查真实岗位（施工 vs 研发）、服务期；「第五轮评估 B+」→ 查教育部是否公开、学校官网是否敢写。

### 第 1 步：执行七步检索协议（Step 0–Step 7）

按 `references/seven_step_protocol.md` 逐步执行。每步必须给出：检索目标、官方底表与公开入口、判定阈值、常见造假手法。概要：

| 步 | 对象 | 阴性陷阱（勿误判为聚变） |
|---|---|---|
| Step 0 | 校级战略：官网、新闻中心、科研机构栏目 | 有战略声明 ≠ 有实质 |
| Step 1 | 物理学院/理学院（0702/070204） | 空间等离子体、低温等离子体应用、夸克胶子等离子体 |
| Step 2 | 核科学与技术学院/能源学院（0827） | 全裂变方向；核工程=核电站运行 |
| Step 3 | 电气工程学院（0808/0808J1） | 电力电子/高电压与聚变无关；注意 Z 箍缩方向藏在电气学院 |
| Step 3.5 | 政策支持层级核查（国家/省/校三级证明力） | 国家级背书 ≠ 该校有份；省级支持中性偏正；零支持+大词叠加 Type-A 嫌疑；详见 `references/policy_support_rubric.md` |
| Step 3.6 | 生态三维核查（企业级支持/集群支持/学术共同体） | 宣称企业合作但工商/官网零记录叠加 Type-B；零发表零会议却"国际领先"叠加 Type-A；装置机时公开记录=实质性强信号；三侧全零=高风险；详见 `references/ecosystem_support_rubric.md`；+人才流向信号（用脚投票=强信号、编制扣人=弱信号，详见 `references/talent_flow_signals.md`） |
| Step 4 | 机械/材料/控制学院 | 普通机械/材料与聚变无关，须确认导师实际参与聚变项目 |
| Step 5 | 交叉/前沿学院（AI+聚变、高能量密度物理） | 高能量密度偏天体物理；AI 方向与聚变无关 |
| Step 6 | 重点实验室与装置核查 | 装置状态四分：运行/在建/烂尾/纸面；"等离子体"实验室可能偏低温应用 |
| Step 7 | 企业合作与集群融入度 | 框架协议 ≠ 实质合作；查与 CFQS/EAST/HL-2M/BEST/ITER/星环聚能/能量奇点/新奥等的真实联系 |
| Step 8'（可选） | 廉政背景扫描：省委巡视反馈/校领导及关键中层案件/科研经费通报 | 阴性 ≠ 无风险；在查案件仅用阶段性官方表述；结果只作 D9/D3 风险修饰项与 Type-E 证据，**不单列评分维度、不设红线**（归因纪律见文末 Type-E 节）。检索配置硬条款见七步表后「Step 8' 检索配置」节 |

**纪律**：七步必须全部走完并逐一回填结论（✅ 真实聚变 / ❌ 无 / ⚠️ 存疑），禁止只查核学院和物理学院就下结论——西安交大误判（0.50→7.50）即因只查 Step 2 漏掉 Step 1 的激光聚变与 Step 3 的 Z 箍缩。

### Step 8' 检索配置（v1.9.2 立法，源自 44 校廉政扫描第四轮证伪）

执行 Step 8' 时以下五条为硬条款：

1. **双通道强制最低配置**：web 通报通道与裁判文书库通道必须**并行**使用，禁止单通道下阴性结论。实证教训（锚点 11）：北方民族大学李晓宁案（原党委副书记，2016-03 撤销党内职务、2017-11 判刑 3 年）因处分形式为撤销党内职务、无双开通报，**单 web 通报通道完全漏检**，由裁判文书库通道补获。
2. **裁判文书库通道调用规程**（元典 yuandian_law 插件）：`cd /app/.agents/plugins/yuandian_law && python3 scripts/yuandian_law_tool.py describe`（describe 不带 --api-name）；检索用 `call --api-name yd_case_search --params-json '{"mode":"keyword_pt","full_text":"校名","causes":["受贿罪","贪污罪","挪用公款罪"],"case_category":"刑事案件","judgment_date_start":"2015-01-01","top_k":15,"file_path":"<输出>.csv"}'`。要点：`full_text` 空格分隔关键词为 AND；`causes` 数组为 OR；返回 EMPTY_DATA = 0 命中，**是有效阴性而非失败**。
3. **窗口期口径**：2015-01 至核查日；**窗口紧邻档**——2013–2014 被查且判决/审结落在窗口期内的计入（比照南昌大学周文斌先例；吉林大学王冠军 2014-08 被查/2016 审结即按此档计入）。
4. **阴性盲区声明**：军队院校（如国防科大）与低公开密度地区（如青海）公开渠道覆盖有限，其阴性结论置信上限 Medium，必须在产出中显式标注。
5. **灰色登记**：留置/免职/撤院士等未达"被查通报"口径的边缘事项（如清华 2 人留置、天津大学金东寒免职）不计入有案，但须逐项登记备查，禁止静默丢弃。


### 第 2 步：欺诈分型（Type A–E）

按 `references/fraud_typology_fusion.md` 的判定树定性。五型概要及与 claims-deep-audit 的映射：

| 本技能类型 | 核心特征 | 映射 claims-deep-audit |
|---|---|---|
| Type-A 有壳空虚 | 有学科/导师/装置，但全部空虚（装置烂尾、产出与方向错位） | ≈ A 有壳空虚 |
| Type-B 无壳裸骗 | 七步全阴，无任何聚变实体 | ≈ B 无壳裸骗 |
| Type-C 名称偷换 | 有 070204 代码但导师做空间/低温等离子体 | ≈ C 名称偷换 |
| Type-D 学科嫁接 | 某学院有真实聚变研究，但与招生方向脱节 | ≈ D 学科嫁接 |
| Type-E 跨学院分散 | 聚变真实存在但分散多学院、无统一招生入口（非欺诈，是结构风险） | 领域新增，无对应 |

### 第 3 步：A–F 评级

用十维评分（D1 建制独立性 10%、D2 平台实体性 15%、D3 师资可持续性 12%、D4 课程匹配度 8%、D5 学位兼容性 10%、D6 产业区位 10%、D7 就业通道 12%、D8 科研产出 10%、D9 经费结构 8%、D10 时间窗口 5%），每项 0–10 加权求和，锚定等级：

| 等级 | 分数带 | 含义 | 锚点案例 |
|---|---|---|---|
| A+ | 90–100 | 顶级聚变期权 | 中科大 95、华中科大 92、清华 90 |
| A | 80–89 | 优质 | 合工大 88、西安交大 85、西南交大 84（CFQS）、兰大 82 |
| B | 60–79 | 良好/中等 | 川大 78、哈工程 76、浙大 72 |
| C/D | 40–64 | 高风险边缘 | 内蒙古科大 62、南昌大学 55、中南大学 50 |
| F | <40 | 欺诈性/空白期权 | **南华大学 28（1.73/10）为 F 级锚点**、新疆大学 35、石河子大学 30 |

红线一票降级（触任一即不得高于 D）：装置被第三方定性报废/长期未放电；聚变方向产出占比 <30% 且断档 >5 年；宣传名称与批文实体不一致；招生方向与真实研究完全脱节。

### 第 4 步：输出评级卡

每张评级卡必须包含以下字段（模板全文见 `references/seven_step_protocol.md` 末节）：

1. **学校/方向/学科代码**与数据截止日、建议复核日期（默认 12 个月，快变领域 6 个月）。
2. **加权总分与 A–F 等级**，附十维明细。
3. **关键证据清单**：每条标注信源等级（A 官方批文/注册/公示；B 官网/权威数据库；C 第三方报道/口述）与 conf 等级（实证/估算/假设），并附公开可查链接。结论置信度不得高于其最弱支撑证据；仅 B/C 级证据时用"高度疑似"，禁止"系/确为"。
4. **欺诈分型**（主分型 + 次分型 + 反证检查）。
5. **红线触发项**：逐条列证据与信源等级。
6. **top3_likely_wrong**：本次核查最可能错的 3 个点及其影响方向（硬条款，不可省略）。
7. **考生行动建议**：按目标（实验/理论/申博/就业）分支给出，以选择题式交付（2–4 个候选校/方案并标注推荐项，不出开放式结论）。

### 第 5 步：误判自修正规程

评级不是终态。触发修正的情形：装置状态变化（首次放电/正式停运）、新增学位点或撤销、核心导师入职/退休/跳槽、用户或新信源提供反证。规程：

1. 记录原判定、原证据、原置信度（版本诚实，禁止无痕改写）。
2. 核验新证据信源等级，≥3 个独立信源交叉（引用 claims-deep-audit R8 规则）。
3. 重跑受影响的七步子项与十维评分，给出"原分 → 新分 + 翻转证据"。
4. 在评级卡追加勘误条目：日期、触发证据、旧结论、新结论、影响范围。
5. 分工声明：本技能负责领域判定与评级；**证据链形式校验（命题-证据-来源三元组完整性、链接可证伪性）移交 `evidence-chain-verifier`**。修正前后均须过其校验。

锚点案例：西安交通大学起初评 0.50（F）后修正 7.50（A-）——翻转证据为物理学院激光与粒子束科学技术研究所（惯性约束聚变，赵永涛团队，星光III）与电气学院 0808J1（Z 箍缩，汉-1 装置）被发现；教训：**能翻转评级的证据是"新发现的实体学院/装置/自设学科"，而非更用力地解读旧证据**。南华大学反向案例：早期某报告依"CN-H1 在建"判非断头路，后经装置状态核查（2017 签约→2026 未放电、第三方定性报废）降为 F 级 1.73/10。

## 全量穷举纪律与断点续做

- 凡"筛选某省/全国有哪些聚变方向院校"类请求，必须以官方底表（教育部学位授权名单、研招网硕士专业目录、第四/五轮学科评估名单）为准，**按省/直辖市逐一核对**，输出附覆盖率说明与"待核实"清单。禁止凭记忆罗列知名样本。
- 区分"一志愿开设方向"与"调剂接收去向"——后者只证明有名额，不证明有平台与师资（深大调剂 8 校核查：8 校均无聚变期权）。
- 区分近名实体：东华理工大学 ≠ 东华大学；校名/机构名先核对全称与代码。
- 状态类结论以**最新一年**招生专业目录为唯一准绳（历史 ≠ 当前）。

## 实体归属绑定纪律（v1.3 新增，v1.9 恢复——v1.7–v1.8 修订中误删，回归修复）

**事故原型**：锚点库 F 档行曾把"南华大学 28（1.73/10）"与"东华理工 27→25（赵开君……）"塞在同一 bullet，赵开君条目又紧跟南华定案锚点之后，下游写作一度面临把赵开君误绑到南华的风险（实际：赵开君属东华理工，HL-2A 时期在西物院，与南华无任何关系）。

规则（引用锚点库或任何多校混排文件时强制执行）：

1. **人/装置/成果三元组必须带院校绑定**才能进入产出：写法固定为"人名（归属院校/机构）"，装置写"装置名（归属院校）"。归属不明时不许引用该实体。
2. **引用锚点案例前重读完整条目**，禁止从排名表/分档行里隔着别的学校摘半句。同一 bullet 出现两所学校时，逐校拆开核对后再用。
3. **对照案例必须显式声明"对照组 ≠ 本案主体"**：在 A 校文章里引用 B 校人物时，首次出现即写明 B 校归属，避免读者（含下游 agent）默认同校。
4. **锚点库写入侧约束**：一个 bullet 只装一所学校；人物条目首字段为【归属院校/机构】；跨校对照单列小节。
5. **归属性勘误优先回流**：发现归属错绑或成果数量错（如"一作 PRL 篇数"），当场改锚点库并加日期化勘误行，不允许只在下游文本里改。

## Type-E 系统性腐败分型：证据门槛与归因纪律（v1.9 新增）

**依据案例**：NAN-V02（南华大学贪腐维度实证核查，2026-08-28；证据登记 evidence_registry.json 24 条）。Type-E 指学校领导层塌方式腐败对"经费结构/管理连续性/宣传可信度"构成的背景风险；它**不是**科研方向真伪的直接证据。

**引用贪腐案件的五条纪律**（违者不得进入产出）：

1. 官方通报原文（信源 A/S 级：纪委监委网站、检察机关、法院、新华社/人民日报系）；媒体转述须回溯到通报原文。
2. 任职归属明确到"人-校-任期"：落马时任职校 ≠ 案件发生校（王汉青案教训：通报头衔为中南林业科技大学原党委书记，"侵吞科研经费"归属期官方未拆分，禁止断言发生于南华任内）；同名校领导排除（琼台师范学院三人案曾被误读为南华案件）。
3. **禁止与具体项目经费做无证据因果绑定**（如"校领导贪腐 → CN-H1 经费被贪"）：截至 2026-08-28 无任何公开纪检监察/司法/审计文书支持该链。
4. 在查案件仅用阶段性官方表述（"接受纪律审查和监察调查"），禁止预断罪名、事由、金额。
5. 每案附"未决状态"与复核日期（默认 6 个月）；检索阴性结论必须标注"仅对公开信源负责"。

**评级交互规则**：廉政记录只作 D9 经费结构与 D3 师资可持续性的**风险修饰项**及 Type-E 分型证据；不单列评分维度、不触发红线、不直接拉低总分（避免从"学校贪腐"错误推导"方向造假"——公开记录中无官方/权威媒体做过此种关联）。

### 天眼查股权穿透五步

`company_search` 搜主体 → `工商信息-企业股东` → 穿透有限合伙 → `工商信息-对外投资` → `工商信息-企业年报`（社保人数）+ `知识产权-企业专利` + `工商信息-变更记录`。

**壳三大铁证**（满足≥2 即判壳）：注册资本<50 万且认缴<20 万；年报社保 0 人；无专利+唯一业务是对外投资持股。

### Type-F 产业壳（v1.3 新增分型）

公司有真实聚变研究/融资，但注册在某地的"地方实体"是股权壳（社保 0 人+小额认缴+仅持股），误导"该地有聚变产业"。典型：泽塔聚变投资控股（深圳）=纯持股壳（20 万/0 社保），主体泽塔北京（1078 万+数亿天使轮）。

### Type-G 路线错配（v1.3 新增分型）

实体聚变为真，但属核工程/脉冲功率/电气工程线（Z 箍缩），与 0702 物理基础研究（磁约束纯聚变）不对口。典型：泽塔/安东/成都装置（Z-FFR/驱动器/大科学装置）=核工程线，0702 物理不考数学轨不对口；纯聚变物理（深大 Helimak/南昌 NCST）才对口。

### 反幻觉三对策（v1.3 实战血泪）

1. **名单外 ≠ 无**：某校不在"聚变核查名单"≠无聚变（名单是抽样非全集）。深大曾被误判"无聚变行业"，实际有 Helimak 装置+李建刚院士团队——必须官网+天眼查独立验证。
2. **地名关联 ≠ 产业**：注册在某地的聚变公司≠该地有聚变产业。泽塔"深圳"是 20 万股权壳（社保 0 人），主体在北京；查注册资本+社保+实际研发地。
3. **注册资本 ≠ 实力**：注册资本小≠资本弱。泽塔北京注册资本仅 1078 万但完成数亿元天使轮；查融资新闻+国家装置背书，而非仅注册资本。
