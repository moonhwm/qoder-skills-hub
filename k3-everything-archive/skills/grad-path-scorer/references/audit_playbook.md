# 初次核查操课表（audit_playbook）

让初次核查即达到深度口径的照表操课规程。全部条目来自 2026-08-28 会话实战教训。**核查任何新校前按 §1 顺序走，禁止跳步。**

## 目录
1. 核查顺序（装置驱动，非院校名单驱动）
2. 装置状态四分与"在建叙事"红线

4. 三事实采集模板与信源层级
5. 每校最小核查清单（checklist）

## 1. 核查顺序：装置驱动穷举

**院校名单驱动必漏**（实战：按已知校名漏掉华科 J-TEXT/清华 SUNIST/ASIPP/西南交大 CFQS 四大正统）。正确顺序：

1. 先列**装置清单**（磁约束：EAST/HL-2M/HL-3/BEST/CFETR | J-TEXT | SUNIST | CFQS | NCST | EXL-50 | KTX；ICF：神光 II/III/星光 III/DCI | 直线装置：MPS-LD 等；Z 箍缩：汉-1/50MA；Z-FFR）；
2. 每个装置问"**归属单位+共建单位+人才培养通道**"（装置所有者≠唯一受益方，共建单位常藏高校——北师大/人大靠 DCI 名单入池）；
3. 装置无归属高校的，查**教育部磁约束聚变研究中心分中心**与**国家磁约束核聚变专家委员会委员**单位；
4. 最后才按省份长尾补扫（此步收益最低，可截断）。

## 2. 装置状态四分与"在建叙事"红线

| 状态 | 判据 | 对 has_platform 的含义 |
|---|---|---|
| 运行 | 有近期放电/实验产出 | true |
| 在建 | 有明确工期+里程碑达成记录 | **仍判 true 但 conf≤estimated 且 notes 必须写"在建"** |
| 烂尾 | 签约/运抵多年未放电（南华 CN-H1：2017 签约→2026-08 未放电，官网推进会承认"经费人员管理问题"） | **false**（红线） |
| 纸面 | 仅协议/规划无实体（东华理工"天环一号"） | false |

**红线**：禁止仅凭校方"在建/重建中/即将放电"表述判 platform=true——必须找到**放电或实验产出证据**；宣传稿时间线要与第三方信源对表（南华教训：期刊 S 级"正在重建"叙事 vs 招标/推进会/自媒体报废定性的细颗粒时间线，后者为准）。

## 3. 名称混淆陷阱表（实测踩坑记录）

| 易混对 | 区分锚点 |
|---|---|
| 西北大学 ≠ 西北师范大学 | 前者西安（等离子体二级学科空转）；后者兰州（董晨钟团队，激光等离子体实质） |
| 内蒙古大学 ≠ 内蒙古工业大学 | 前者物理一级博士点（ICF 火种刘正东）；后者等离子体=低温应用硕士点 |
| 东华理工 ≠ 东华大学 | fusion-program-audit 纪律：校名先核全称与代码 |
| 磁约束传承 ≠ 等离子体存在 | 郑大案例：霍裕平系磁约束断裂（锚点 F 级）与万阳激光等离子体（ICF 火种）并存——同校两路径分开判 |

## 4. 三事实采集模板与信源层级

每校必填（可空=null，null 触发 conf 强制降档）：

```
has_phd_program:       相关方向博士点（看博士培养方案方向列表，不看学院简介宣传）
advisor_phd_qualified: 该方向博导（查师资名录职称+"博导"字样+在带学生证据，如答辩公示）
has_platform:          运行中装置/中心（按 §2 四分，烂尾/纸面=false）
exit_channel:          跨校申博出口（公开就业报告多无细分，不可得时=null 保守 hard）
```

信源层级：A=官网/纪委通报/教育部名单；S=学术期刊/中科院系统；B=百科/研招网转述/主流媒体报道；C=自媒体（仅作线索索引）。结论置信度不得高于最弱支撑证据。

## 5. 每校最小核查清单

- [ ] 博士培养方案方向列表里有无等离子体/聚变（学院简介说了不算）
- [ ] 该方向至少 1 名博导的职称页 + 在带学生证据
- [ ] 装置/平台按 §2 四分定状态（要放电证据）
- [ ] 检索一次"校名+等离子体/聚变"零命中则标"无证据"，conf=assumed
- [ ] 过 §3 混淆表核对校名
- [ ] 已入 fusion-program-audit 锚点库的校直接迁移评级，不重复核查（管线契约，见交接 U9）
- [ ] 治理核查仅在用户要求时启动，走 methodology §8 纪律
