## 1. 常见公证类型与费用档位

费用 = 公证费 + 翻译费 + 副本费 + （可选）加急费 + （可选）认证费。**给用户报价一律给区间 + 拆分 + 总预算表**，并标注"以当地公证处当次报价为准"。

**先定档位再花钱——学校要求三档**：

| 档位 | 内容 | 常见预算区间 |
|---|---|---|
| 档1 | 仅翻译公证（三件套） | 约 800–2600 元（小语种偏上限） |
| 档2 | 翻译公证 + 附加证明书（Apostille） | 档1 + 约 50–100 元/份 |
| 档3 | 抵达目的国后在当地办理 | 常更便宜，但需学校认可且有时间成本 |

案例参考价（2026 年，单点不构成档位边界）：三线城市公证处学历三件套+俄文翻译整套约 2600 元；一线城市身份证公证约 700 元；无犯罪记录公证为百元级公证费 + 翻译费（需先开无犯罪记录证明）。

规律：小语种翻译费是大头；同一事项不同城市报价可差数倍；报价显著偏离档位时，问清漏项与加价项即可，**不要假定"便宜必有诈"或"贵即合理"**；加急通常另收且不是所有公证处都提供。

## 2. 涉外学历公证标准流程

1. **确认收文要求**：学校/留服中心要哪些件（毕业证、学位证、成绩单三件套最常见）、什么语种、是否需要认证、认多久内出具的公证书。
2. **备料**：身份证、户口本、毕业证、学位证、成绩单原件；成绩单一般需学校教务盖章版本，部分公证处要求另开学历证明。
3. **公证处受理**：现场或线上（多地支持微信小程序/政务平台预约）。明确告知"涉外 + 语种 + 用途国家"。
4. **翻译与校对**：公证处指定或认可的翻译机构完成；拿到译文后**逐字核对姓名拼音、出生日期、专业名称**——这是出错率最高的三处。
5. **出证**：普通件约 5–10 个工作日，加急可压缩（是否提供、加价多少各公证处不同）。
6. **如需认证**：见下节路由。

## 3. 海牙认证（附加证明书）vs 领事双认证

- 中国 2023 年 3 月递交加入书，《取消外国公文书认证要求的公约》2023-11-07 起对中国生效。**去缔约国（含俄罗斯）使用：办公证书后加办"附加证明书"（Apostille）即可，无需再走领事双认证。**
- 附加证明书由外交部领事司（受理全国文书）或其授权的地方外办签发，约 50–100 元/份；部分城市支持线上领事服务渠道办理；不少公证处可代办，办公证时一并询问最省事。
- 去非缔约国使用：仍需"外交部认证 + 目的国使领馆认证"双认证老流程。
- 行动口诀：**先确认目的国是不是缔约国 → 是：公证 + 附加证明书；否：公证 + 双认证。**

## 4. 材料清单模板

涉外学历三件套公证（以留学俄罗斯为例）：

- 身份证原件及复印件
- 户口本（本人页）原件及复印件
- 毕业证、学位证原件
- 学校盖章成绩单原件
- 护照信息页复印件（用于核对拼音，强烈建议带）
- 收文机构的书面要求（邮件/招生简章截图，防止公证处做错规格）

## 5. 省钱与避坑清单

- **问清翻译费是否另计、按页还是按本计费**；三线城市小语种整套约 2600 元属正常档位，明显低于此要警惕漏项。
- **公证书份数一次办够**：加副本便宜，事后补办按新件收费。
- **核对再核对**：姓名拼音必须与护照逐字母一致（复姓如"欧阳"以护照写法为准，不得自创拆分或大小写变体）；专业名称与学校官方译名一致。
- **时效意识**：学历学位公证本身长期有效，但收文机构常要求"近 3–6 个月内出具"；无犯罪记录公证通常只有 3–6 个月使用期，**算准时间再办，别提前办早**。
- **保留受理单与缴费凭证**：出证进度、后续上链或维权都用得上。
- 中介代办公证溢价常见，自己跑公证处通常可控；时间成本确实高时，优先选择"公证处代办认证"而非纯中介。
