# 语义精度利刃：维特根斯坦 + 罗素可操作化审计清单

## 目录

- 第 0 节 方法论声明（必读）
- 第 1 节 维特根斯坦侧清单（W1-W4）
- 第 2 节 罗素侧清单（R1-R3）

## 第 0 节 方法论声明（必读）

本清单引用维特根斯坦与罗素的哲学概念**仅作方法论类比**：借用其问题意识组织审计动作，不声称文本符合或违背任何哲学立场，哲学论证本身不构成任何结论的证据。因此：

- 由本清单得出的全部审计结论，conf 一律记 **"方法论"档**：报告层不得标 High，数据流层喂引擎时按 `assumed` 处理；
- 审计发现的是"语义风险候选"，是否成立须由人工结合语境裁决；语义清晰的文本不等于内容为真（语义精度是核查的必要条件而非充分条件）。

## 第 1 节 维特根斯坦侧清单

类比来源：《哲学研究》的意义即使用、语言游戏、家族相似、私人语言论证。核心问题意识：词的意义活在具体使用场景中，脱离用法的词是空转。

### W1 用法一致性检查（意义即使用 → 可操作化）

- **检查动作**：同一关键术语在全文的各次出现，是否在同一用法上使用？抽取该词每次出现的搭配（主语/宾语/谓语/修饰语），两两比对用法是否兼容。
- **触发例**："该平台的**交易量**突破百亿"（前文指撮合成交额）与后文"按**交易量**计提的佣金为零"（实指订单笔数）——同词换用，中间无声明。
- **处置**：标注 `W1 用法漂移候选`；要求作者在首现处锁定定义，后续换用处显式声明"此处 X 指……"；若用于数据结论，该结论降级并转 evidence-chain-verifier 登记为待核。
- **自动化**：`scripts/semantics_audit.py` 的 `ambiguous_term` 候选做初筛（量化词域混用与常见多义词），用法漂移的最终判定靠人工。

### W2 语境游戏标注（语言游戏 → 可操作化）

- **检查动作**：标注每段陈述所处的"游戏"——科学报告/营销文案/法律文本/社交闲聊/内部行话。不同游戏有不同的真值规则与措辞惯例；把一种游戏的语句搬进另一种游戏而不换规则，即为风险。
- **触发例**：把宣传册话术"行业领先水平"直接搬进尽调报告正文作为事实陈述；把法庭上的"无罪推定"措辞搬进产品安全宣传。
- **处置**：标注 `W2 游戏错位`；营销游戏语句进入严肃文档时，改写为可证伪命题或标注"话术"并单独统计（话术密度本身是风险信号——与 claims-deep-audit Step 0 一致）。
- **自动化**：脚本不判定游戏类型；由审计者在 `semantics_audit.py` 输出的对冲密度（hedging_density）异常低且满篇绝对化措辞时人工警觉。

### W3 家族相似边界警示（家族相似 → 可操作化）

- **检查动作**：对无清晰定义、靠相似性聚类的范畴词（"AI 产品""新能源企业""核心团队""活跃用户"），检查是否利用范畴边界的模糊性把边缘成员算入、把不利成员剔出。
- **触发例**："我们服务了 500 家**新能源企业**"——其中过半是仅有零星业务的边缘相关公司；"**活跃用户**超千万"——口径含 180 天登录一次的用户。
- **处置**：标注 `W3 边界操纵候选`；要求给出范畴的纳入/排除标准（哪怕只是工作定义），统计口径写入 `data_cutoff` 旁的口径注记；无标准时用词降级为"自称的 X"。
- **自动化**：`semantics_audit.py` 的 `undefined_term` 候选（首现未定义的专业词/缩写）是 W3 的入口信号之一。

### W4 私人语言警示（私人语言论证 → 可操作化）

- **检查动作**：寻找只有作者内部可判定、外部无任何公共校验标准的表述——内部代号、未公开口径、"我们内部认定"的评级。无法被第三方按公共规则复核的语义，等同空转。
- **触发例**："该系统达到 **P4 级稳定性**"（P4 为公司内部等级，无公开定义）；"经**内部专家委员会**评定为优质资产"。
- **处置**：标注 `W4 公共可校验性缺失`；要求换算为外部公共标准（行业等级、国标、可公开复核的测试方法），无法换算的结论 conf 封顶 Low/assumed 并标注"不可公开复核"（对接 evidence-chain-verifier 的 no_public_url_reason 纪律）。
- **自动化**：`undefined_term` 候选中的大写缩写与自造等级词是 W4 的初筛信号。

## 第 2 节 罗素侧清单

类比来源：摹状词理论（《论指谓》）、逻辑原子主义、类型论。核心问题意识：看似指称的短语可能无所指；复合命题可分解为原子命题逐一检验；跨层级的自指陈述产生悖论式混乱。

### R1 指称消解检查（摹状词理论 → 可操作化）

- **检查动作**：把每个定冠词短语（"该公司""该政策""现任 CEO""上述文件"）当作存在性断言来检验：它指的对象存在吗？唯一吗？先行词在文本中可回溯吗？
- **触发例**："**该公司**已于去年完成整改"——全文从未指明是哪家公司（母公司？子公司？）；"**这一政策**导致成本上升"——指代的三项政策中哪一项？
- **处置**：标注 `R1 指称悬空/歧指`；无先行词的改写为全称名词首次引入；多候选先行词的强制显式指明；指称未消解前，含该短语的命题不进入结论。
- **自动化**：`semantics_audit.py` 的 `dangling_reference` 候选专门扫"该/此/上述/这一 + 名词"无先行词的情形。

### R2 原子命题分解（逻辑原子主义 → 可操作化）

- **检查动作**：把复合断言拆成不可再分的原子命题，逐个标注可证伪性与 conf；复合断言的置信度 = 其最弱原子命题的置信度（与 evidence-chain-verifier "结论置信度不得高于最弱支撑证据"对齐）。
- **触发例**："该实验室**拥有国际先进装置且团队稳定、经费充足，因此值得报考**"——拆为：装置存在？装置在役？装置水平国际先进？团队稳定？经费充足？（事实原子）+ 值得报考（价值命题，非事实，不可证伪）。
- **处置**：每个原子命题编号登记，可证伪的转 evidence-chain-verifier / claims-deep-audit 流程；价值命题标注"非事实"不得混入事实结论；含不可证伪原子的复合句整体降级。
- **自动化**：脚本不自动分解命题；由审计者对 `semantics_audit.py` 命中的长句（多量化词混用句）手工执行分解。

### R3 层级类型混淆检测（类型论 → 可操作化)

- **检查动作**：检测把不同逻辑层级混为一谈的陈述：集合与成员混用（"全校师生都支持，所以每个学生都支持"）、自指（"本报告所述全部属实"）、以部分口径冒充整体口径（样本=总体）。
- **触发例**："**这些高校**的就业质量都很高，其中包括 X 校"（由集合特征直接断言成员）；"我们的用户调研显示**所有人**都满意"（样本 37 人自称代表全体用户）。
- **处置**：标注 `R3 类型/层级混淆`；集合→成员的推断必须补成员级证据；样本→总体的推断必须补样本量、抽样方法、置信区间，缺失则结论限定到样本域内。
- **自动化**：`semantics_audit.py` 的 `quantifier_mixing` 候选（"所有/有些/可能"同域混用）是 R3 的主要入口信号。

## 第 3 节 自动化初筛与人工裁决的分工

| 脚本输出类型 | 对应清单项 | 机器能做 | 必须人工做 |
|---|---|---|---|
| `undefined_term` | W3/W4 入口 | 首现未定义专业词/缩写的定位 | 判定是否真需定义、是否公共可校验 |
| `ambiguous_term` | W1 入口 | 常见多义词与语境冲突候选定位 | 用法漂移的最终裁决 |
| `quantifier_mixing` | R3 入口 | 同主语"所有/有些/可能"混用定位 | 判定是否构成口径欺骗 |
| `hedging_density` | W2 辅助 | 对冲词密度统计 | 判定密度异常的含义（过度对冲 vs 绝对化） |
| `dangling_reference` | R1 入口 | "该/此/上述"无先行词定位 | 确认先行词是否真缺失 |

原则：脚本输出全部带 `candidate` 性质——宁多报（由人工剔除）不漏报；人工裁决结果写回审计报告，每条含：候选编号、清单项、触发原文、裁决（成立/不成立）、处置改写法。

## 第 4 节 处置话术模板与 conf 记档

- 标注模板：`[语义审计 W1] 术语"交易量"在 ¶3 与 ¶7 用法不兼容（成交额 vs 订单笔数），处置：已在 ¶3 锁定定义为成交额，¶7 改为"订单量"。conf=方法论`
- 报告汇总时，语义审计节的 confidence 统一标注 Medium 封顶（方法论档的报告层映射）；进入评分引擎的相关数据点 conf 写 `assumed` 并在 top3_likely_wrong 中说明依据为语义分析而非实证。
- 审计中发现的可证伪实质命题，不在本文件流程内验证——登记后转 claims-deep-audit（评分）或 evidence-chain-verifier（附链）。
