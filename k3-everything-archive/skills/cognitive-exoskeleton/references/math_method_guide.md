## 1. 问题形态 → 方法决策表

| 问题形态 | 首选方法 | 典型用户说法 |
|---|---|---|
| 常系数线性 ODE、电路/力学系统响应、含初始条件的瞬态过程 | 拉普拉斯变换 | "这个电路开关闭合后电流怎么变""弹簧振子受冲击后怎么运动" |
| 周期信号、频谱分析、滤波、稳态频率响应 | 傅里叶变换/级数 | "这段信号里有哪些频率""怎么滤掉 50Hz 噪声" |
| 多尺度行为、临界现象、渐近标度律 | 重整化群（先过 §3 警示） | "不同尺度下行为好像一样""临界点附近的指数" |
| 线性方程组、坐标变换、最小二乘、降维/主成分 | 线性代数 | "拟合平面""把高维数据压成几个主方向""解这组方程" |
| 极值、优化、约束下最优、泛函极值 | 微积分与变分初步 | "参数取多少最好""哪条路径代价最小" |
| 随机涨落、噪声、不确定性、抽样与检验 | 概率统计 | "这个差异是噪声还是真效应""数据波动多大算正常" |

判定不到两行匹配时，先把问题改写成「已知…求…约束是…」三句式再回查本表；仍判不出，做成选择题问用户确认问题形态，附推荐项。

## 2. 各方法的「不适用信号」与「最小可执行落地」

### 2.1 拉普拉斯变换

**适用条件（表述必须准确）**：针对定义在 t≥0 上的函数 f(t)，要求其增长不超过指数阶（存在常数 M, a 使 |f(t)| ≤ M·e^(at)），变换 F(s)=∫₀^∞ e^(−st)f(t)dt 才在 Re(s)>a 上收敛。核心用途：把常系数线性 ODE（含初始条件）化为代数方程求解，处理系统瞬态响应与传递函数。

**不适用信号**（命中任一即劝阻）：

- 方程是**变系数或非线性**的 ODE（拉氏变换的代数化优势只对常系数线性成立）。
- 关心的是**周期信号的稳态频率成分**而非含初始条件的瞬态（那是傅里叶的主场）。
- f(t) 增长超过指数阶（如 e^(t²)），变换不收敛。
- 用户只是"听说拉普拉斯很厉害"而问题里没有微分方程或系统响应结构。

**最小可执行落地**：用户描述物理/系统意图 → agent 用 `sympy`（`sympy.integrals.transforms.laplace_transform`、`inverse_laplace_transform`，或手工部分分式）求解 → 用 `numpy`+`matplotlib` 画时域响应曲线 → 交付图像、解析解与一句物理解读，标 conf。

### 2.2 傅里叶变换/级数

**适用条件**：傅里叶级数适用于**周期函数**（分段连续、有限个间断点与极值，即 Dirichlet 条件）；傅里叶变换适用于**绝对可积**（∫|f|dt < ∞）的非周期信号，衰减足够快的信号一般满足。用途：把信号分解到频率域，做频谱分析、滤波、稳态频率响应。

**不适用信号**：

- 信号**不绝对可积**且又不是周期/幂信号（经典傅里叶变换不存在；冲激函数等广义函数情形超出本科范围，需说明）。
- 频率成分**随时间变化**（非平稳信号）——经典傅里叶只给全局频谱，此时提示短时傅里叶/小波作为后续选项。
- 用户想用它处理**含初始条件的瞬态 ODE**（那是拉普拉斯的主场）。
- 采样数据未考虑**采样定理**：采样率低于信号最高频率两倍会混叠，拟合频谱前先核对采样率。

**最小可执行落地**：用户给数据或信号描述 → agent 用 `numpy.fft`（数据）或 `sympy.fourier_series`（解析式）计算 → 画时域+频域双图 → 标出主峰频率与幅值 → 交付结论。

### 2.4 线性代数

**适用条件**：问题是线性的或已线性化——线性方程组 Ax=b、线性变换、最小二乘（正规方程 AᵀAx=Aᵀb）、特征分解、PCA（对协方差矩阵做特征分解）。

**不适用信号**：

- 问题本质是**非线性**且未做线性化假设说明。
- 数据矩阵**病态/接近奇异**（条件数很大）时直接求逆不可信，须改用最小二乘或正则化，并在交付中报告条件数。
- 用户把"矩阵"当成万能符号，问题里其实没有线性结构。

**最小可执行落地**：agent 用 `numpy.linalg`（`solve`/`lstsq`/`eig`/`svd`）计算 → 报告解、残差范数、条件数 → PCA 场景画降维散点图 → 交付。

### 2.5 微积分与变分初步

**适用条件**：光滑目标函数求极值用求导/梯度法；约束优化用拉格朗日乘子；求"函数使积分取极值"（最速降线、最小作用量雏形）用欧拉-拉格朗日方程（变分初步，只需知道 d/dt(∂L/∂q̇)−∂L/∂q=0 的用法，不展开理论）。

**不适用信号**：目标不光滑/不可导（组合优化、整数规划）；约束是离散选择（做成打分决策题，对接 multi-dimensional-option-scoring，而非硬套微积分）。

**最小可执行落地**：`sympy.diff`+`solve` 求驻点，`scipy.optimize.minimize` 兜底数值优化 → 画目标函数曲线标出最优 → 交付。

### 2.6 概率统计

**适用条件**：随机涨落、测量误差、假设检验（t 检验/卡方）、区间估计、贝叶斯更新。

**不适用信号**：样本量极小却要做显著性断言；把相关当因果；"肉眼看起来有差异"未做检验就下结论——此时必须先设计可证伪检验（对接 evidence-chain-verifier 的 falsifiable_test 字段）。

**最小可执行落地**：`scipy.stats` 跑检验 → 报告 p 值、置信区间、效应量 → 画分布对比图 → 交付，p 值结论一律标 conf 并说明样本量。

## 3. 重整化群（RG）强制警示

> ⚠️ **醒目警示：本科层级极少真正需要重整化群。**
>
> RG 是用来处理**多尺度耦合、尺度不变性、临界现象**（如相变临界点附近的普适标度律）的深层工具，远超本科数理方法课程范围，也不是"听起来高级就能用"的万能放大器。
>
> **每当用户（或 agent 自己）想用 RG 时，先强制回答这个问题：**
>
> **「我的问题存在尺度不变性或临界现象吗？」**
>
> - 答得出（能指出哪个量在尺度变换下不变、或哪个临界点/发散关联长度）→ 才允许继续，且只做到"概念解释 + 文献指引"层级，落地计算一律交 agent 查证后进行。
> - **答不出 → 禁用 RG**，回到决策表第 1 节重选方法，并向用户明示"这个问题用 XX 方法就够了"。
>
> 常见误用信号：用户说"这个问题很多层次/很复杂，是不是要用重整化群"——层次多 ≠ 多尺度耦合，复杂性本身不构成 RG 适用理由。

## 4. 函数族拟合判据与稳健性流程

### 4.1 形状判据表（先看图，再选函数族）

| 函数族 | 形状判据 | 典型场景 |
|---|---|---|
| 幂律 y=a·x^b | 双对数坐标（log-log）下呈直线；无特征尺度 | 标度律、长尾分布 |
| 指数 y=a·e^(bx) | 半对数坐标（log y vs x）下呈直线；恒定比例增长/衰减 | 衰变、复利、RC 放电 |
| S 曲线 logistic y=L/(1+e^(−k(x−x₀))) | 单调、两端饱和、有拐点；上下渐近线 | 种群增长、扩散采用率 |
| 对数 y=a+b·ln x | 半对数坐标（y vs ln x）下呈直线；增长越来越慢但无上限 | 感知强度、边际递减 |
| 高斯 y=a·e^(−(x−μ)²/2σ²) | 单峰对称钟形，两端快速衰减 | 测量误差、峰形拟合 |

### 4.2 拟合纪律（防自欺）

1. **先画数据散点图**，按 §4.1 判据粗选 2–3 个候选函数族，做成选择题让用户拍板（附推荐项）。
2. **拟合后先画残差图**（残差 vs x）：残差随机散布 → 模型结构基本对；残差有系统性图案（弯曲、喇叭口）→ 函数族选错，回去重选。
3. **禁止只看 R²**：R² 高不代表模型对（过拟合、结构错误都能高 R²）；必须同时报告残差图案、参数置信区间、外推行为。
4. **稳健性检验**（对接 `<技能安装位>/multi-dimensional-option-scoring` 的敏感性思想，引用不复制）：对数据做 ±10% 扰动或去掉首尾各 10% 点重拟合，参数变化超过 20% 时把该拟合结论降为 conf=Low 并明示不稳定。
5. 拟合结果（参数、残差图、稳健性结论）按落盘纪律写入工作目录，文件名带日期。

**最小可执行落地**：agent 用 `numpy.polyfit`（对数变换后的线性拟合）或 `scipy.optimize.curve_fit` 拟合 → 出散点+拟合曲线+残差三联图 → 交付参数表与 conf 标注。
