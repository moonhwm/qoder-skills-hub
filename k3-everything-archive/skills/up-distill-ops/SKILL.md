# UP 主信息蒸馏规程（up-distill-ops）

## 铁律（先于一切操作）

1. **只碰公开面**：免登录 API 与公开页面；不绕登录、不爬付费/会员内容、不批量下载视频本体（元数据与公开文案不在此限）。
2. **盗版源同禁**：z-lib / Sci-Hub 类一律不下载；教材需求走「版本登记+替代源建议」。
3. **一技通用**：禁止为单个 UP 主造技能；个体差异走 references/cards/ 档案卡。
4. **引文幻觉闸**：蒸馏产物中任何文献/数据断言须标 conf 级；学术条目须过 Crossref 作者-题名双核验（SCH-Q-01 第 10 条）。
5. **台账纪律**：每次蒸馏落盘档案卡 + 登记台账（项目侧沿用 交割台账.jsonl）。

## 蒸馏流水线（五段）

1. **身份锚定**：space 页面/搜索拿到 UID、认证信息、粉丝量级、签名；跨平台身份（公众号/微博/学术实名）交叉确认——同名仿号必须排除（实例：搜「小Q」大量电影解说仿号干扰）。
2. **内容地图**：`scripts/bili_meta.py` 抓代表作/系列的标题、时长、播放量、更新节奏；公众号走 web 抓取文章页。
3. **主题聚类**：按系列合集聚类（实例：小Q=会议解说/鉴定热门/探店联合国/课程；自爱风铃=陈鄂生量子习题逐题讲解）。
4. **可信度定级**：沿用五级制（S/A/B/C/D）——创作者本人学术实名可查者升档；纯营销号降档。
5. **产出档案卡**：references/cards/<uid或拼音>.md 固定八段式（身份锚/平台矩阵/内容地图/主题聚类/可信度/适用场景/风险与争议/待复核队列）。

## 脚本

- `scripts/bili_meta.py` — 免登录元数据探针：
  - `python3 bili_meta.py video <bvid>` → 标题/UP主/UID/时长/播放
  - `python3 bili_meta.py search <关键词>` → 前 10 条（标题/UP/播放/日期）
  - 已实测：space 视频列表 API 需 wbi 签名（免登录不可用）——空间信息用 web_open_url 抓 space 页替代；video view API 免登录可用。

## 参考件

- `references/platforms.md` — 各平台适配细则（B站/公众号/学术库）与已知坑（wbi 签名、微信防爬、仿号干扰）。
- `references/cards/` — 已蒸馏档案卡（首张：xiaoq_546189.md 实战样本）。

## 备考线专用补丁（量子力学等课程蒸馏）

- 逐题精讲类 UP 主：蒸馏目标=「题号×讲解时间戳」索引而非全文转写；与 doc-image-solver/exam-isolation-ops 衔接（视频定位→截图做题→盲考）。
- 教材版本登记：作者/版次/出版社/ISBN 四字段必填，禁幻觉（用户原话立法）；缺证标「未核」。
