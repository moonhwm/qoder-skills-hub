## 1. SIRD 四室 ODE（传染病式信息扩散）

方程：dS/dt=-βSI/N，dI/dt=βSI/N−γI−δI，dR/dt=γI，dD/dt=δI。

| 假设 | 内容 | 破坏时的后果 |
|---|---|---|
| 均匀混合 | 任意易感者接触任意传播者概率相同 | 社群分层/平台隔离被忽略，峰值被高估 |
| 参数恒定 | β/γ/δ 在模拟期内不随时间漂移 | 平台算法调整、节假日效应使预测失真 |
| 室容守恒 | 总人群 N 不变，无进出 | 话题破圈引入新人群时低估总感染量 |
| 单向流转 | S→I→R/D 不可逆 | "二次传播者"（复吸、谣言复燃）无法表达 |
| 指数分布滞留 | 传播期服从指数分布（隐含假设） | 实际滞留期集中时，曲线形状偏差 |

适用边界：舆情/观念/欺诈信息传播、产品口碑扩散、订阅制用户流失。
不适用：强网络结构传播（用网络渗流）、多话题竞争（需多室扩展）。

参数校准参考：
- β：用爆发初期 I 近似指数增长段的倍增时间反推，β≈ln2/t_double + γ + δ
- γ：从"不再转发/热度衰减"的半衰期估计，γ≈ln2/t_half
- δ：从永久流失（卸载、被证伪后退出）比例估计

## 2. Fick-Gravity 空间流动模型

通量：flux_i = A_i/(C_i·d_i²)；壁垒系数 = 1 − 实际份额/理论份额。

| 假设 | 内容 | 破坏时的后果 |
|---|---|---|
| 距离平方衰减 | 摩擦随 d² 增长 | 高铁/远程办公场景衰减更慢，壁垒被高估 |
| A 可观测代理有效 | 用薪资差/岗位数代理引力 | 代理与真实引力脱钩时理论通量失真 |
| C 可比较 | 各目的地摩擦系数口径一致 | 口径不一致会把测量误差当作壁垒 |
| 份额可加性 | 各目的地份额归一可比 | 存在模型外目的地（出国、退出劳动力）时偏差 |
| 差值即壁垒 | 理论−实际差值全部由壁垒造成 | **最大风险**：见第 4 节循环论证 |

适用边界：就业流动、人口迁移、门店/服务区域渗透、资本区域配置。
不适用：跳跃式流动（远程、移民链）、单目的地垄断（归一化失效）。

## 3. Logistic-扩散密度场

方程：∂ρ/∂t = D∇²ρ + rρ(1−ρ/K) + S − L（Fisher-KPP 型）。

| 假设 | 内容 | 破坏时的后果 |
|---|---|---|
| 空间连续 | 密度场可用连续 PDE 近似 | 小样本/离散个体涨落主导时失效 |
| 承载力 K 恒定 | 环境容纳量不随时间变化 | 市场扩张/政策放开改变 K 时低估终态 |
| 前沿速度 2√(rD) | 拉速波（pulled wave）假设 | 长距离跳跃扩散（种子空投）使前沿更快 |
| 一维近似 | 真实空间可投影到一维 | 二维各向异性（走廊/山脉）时定量失真 |
| 源/损耗外生 | S、L 不依赖密度 | 密度依赖损耗（拥挤驱赶）需扩展项 |

适用边界：产业/门店密度长期演化、物种/植被扩张、用户密度区域渗透。
不适用：短期爆发动态（用 SIRD）、纯跳跃扩散（需积分-差分模型）。

## 4. 通用误用与循环论证案例警示

### 4.1 循环论证（最高危）

**反面案例**：某研究先用引力模型算"理论人才流动"，发现实际流动只有理论
值的 30%，随即宣布"壁垒系数 0.7"，再用该系数回算"壁垒导致人才损失 X 万"，
最后用"损失 X 万"论证"壁垒严重"——壁垒系数、损失估计、结论三者互相循环，
全程无独立证据。

**正确做法**：
- 差值推出后，一律标 verification_status="待验证假设"；
- 独立验证渠道：行政壁垒清单（落户限制、资格互认）、问卷（"未流动原因"）、
  自然实验（政策放开前后的差分）；
- 验证前报告中只能写"若差值主要由壁垒造成，则……"。

### 4.2 置信度冒标

- 禁止给估算参数标"实证"。判定标准：有直接观测数据拟合→实证；
  用邻域/类比/专家经验→估算；无任何依据的合理区间→假设。
- 报告措辞梯度：实证参数→"模型显示"；估算参数→"在……假设下估计"；
  假设参数→"示意性测算，数量级参考"。

### 4.3 复杂度与数据质量错配

- 只有 3 个时间点数据时禁止拟合 5+ 参数模型；参数数 ≤ 独立观测数 − 1。
- 数据只支持单区域总量时，不要跑空间密度场——用 SIRD 集总模型。

### 4.4 其他高频误用

- 用 SIRD 的 R₀ 直接当"传播力"跨话题比较（R₀ 依赖 γ、δ 口径）；
- 欧拉法 dt 过大导致密度出现负值后不做数值防护；
- 把稳态终态当作"必然结局"，忽略参数漂移与外生冲击；
- 干预情景只改 β 不改 γ/δ，夸大干预效果（干预通常多通道作用）。
