# 额度守护运维（「额度守护件」）

> **能力自报块**（总接口 I3）：能力域=管理｜输入型=额度信号/查档请求｜输出型=当前档位+动作边界｜只读性=否（写额度台账，只读 JSON）｜依赖=python3 标准库
> **纪律继承声明**（I4）：本技能继承 conf 词表统一、红线条款、写类例外、信息充分性条款、全局共同遵守（autonomous-advance-ops 为准）。

## 一、检测层（四通道，诚实边界置顶）

**诚实边界**：精确余额不可机读（平台无开放额度 API；未来开放时接入点预留本节末）。一切档位判定=信号+代理量，conf=estimated。
1. **错误信号**：工具/子代理返回 quota exhausted / account quota 类错误 → `signal quota_error`（→Q3）。
2. **加油包提示**：出现「加油包」「额度不足 去升级」徽标 → `signal pack_prompt`（→Q2）——此信号=计费窗口开启，继续使用须用户知情同意（单独一句明示，k3 条款1）。
3. **遥测代理量**：每轮 cost 块（写动作/子代理/工具轮次）连续 3 轮超基线 2 倍 → 建议升 Q1（人工确认）。
4. **用户 UI 上报**：用户粘贴账户页/徽标状态 → 按用户口径 `set` 入档（用户上报=最高证据级）。

## 二、分档程式（Q0–Q3）

| 档 | 触发 | 动作边界 |
|---|---|---|
| Q0 绿灯 | 默认/复位 | 全栈常态；Swarm 可用；遥测照常 |
| Q1 黄灯 | 遥测连续高耗/用户上报偏紧 | 单线程优先；子代理 ≤2；非必要不派多席表决 |
| Q2 橙灯 | 加油包提示/计费窗口 | **骨架先行**；禁派子代理；加油包消耗须用户知情同意（单独一句明示）；每轮结束报预估剩余轮次 |
| Q3 红灯 | quota 耗尽错误 | **止损**：不推新任务；成果即刻落盘；交接等重置或用户拍板（等主额度周期/接受加油包消耗，两选摆给用户） |

**铁则**：信号只升不降——降档只能 `set` 显式确认（防错误信号复位后自动放大消耗）。

## 三、不逃逸高性能运作

1. **目的轮优先**：高档位下写动作优先给目的层（双标的监控/父亲可见产出），治理动作合批。
2. **便宜通道优先**：能用搜索就不用爬取；能用既有台账就不重拉数据；已核验事实不重核（最小作用量）。
3. **合批降耗**：同类查询合并单次调用；多席表决降 Q1+ 后才启用。
4. **逃逸三问照常**：省额度不等于省纪律——红线条款全档有效，Q3 也不豁免。

## 四、操作

```bash
python3 scripts/quota_state.py show                      # 查当前档位
python3 scripts/quota_state.py signal <quota_error|pack_prompt|ok>
python3 scripts/quota_state.py set <Q0|Q1|Q2|Q3> <理由>   # 显式到档/降档
```

台账：`<注册处>/额度状态台账.json`（档位+变更史，注册处随队列可审计）。

## 五、与既有立法关系

k3-interaction-ops quota 止损条款（条款1）> 本技能一切推进义务；本技能是其检测与分档的操作化，不修改条款本体。计时器任务台账联动：cron 日检含额度信号检查（Q2+ 时当日告警入推送候选，受每日≤3 与安静时段约束）。
