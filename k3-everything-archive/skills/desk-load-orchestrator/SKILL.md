# 案头负载一拖十编排（desk-load-orchestrator）

> 溯源：2026-09-01《案头待办全景技术尽调报告 v1.0》（穷举研究总署·首单）方法论技能化。立法口径：「以目前能力标准取上限」；排除边界：用户明示的若干验证/测试用途**不写入本技能**（已遵守，一字未入）。

## §0 性质与红线

- 编排件：各文体权威规程在其本体技能（report-writing / paper-writing / kimi-slides / humanizer-zh），本件只做**同源调度**，引用不复制。
- **红线**：一切事实（数据/成果/完成人/分工）以《项目事实底册》为唯一来源；禁止虚构数据、禁止把未发生成果写成已发生；应用证明等对外函件留「待对方确认」槽位，未确认不外发。
- 脱敏：底册与产物遵守隐私红线（家庭成员姓名/证件号不入任何落盘件）。

## §1 管线（四段，顺序不可跳）

```
S1 母文档 → S2 文体蒸馏 → S3 冲刊梯度（涉论文时）→ S4 排期与冲突处置
```

1. **S1 母文档先行**：以 `assets/项目事实底册_模板.md` 收拢事实层（背景/指标/数据/图/成果/完成人分工）——此后九件材料只做「选段+调口径」，**不再从零写**；
2. **S2 文体矩阵蒸馏**：技术方案=报告体、学会论文=论文体（IMRaD+GB/T 7714 或 IEEE 式）、简讯=200-400 字消息体、PPT=kimi-slides、年终总结=个人叙事体、应用证明=函件体（待确认槽）——文体各异，**事实只有一份**；逐件过 `scripts/deliverables_check.py` 覆盖核验；
3. **S3 冲刊梯度**：上限=中科院 1/2 区 SCI（对口刊先行枚举），腰部=中文核心/CSCD，刚需=学会版——**学会版即 SCI 扩版的中文稿（一鱼两吃）**；诚实判据：先用一句话写下「本文比已有工作多做了什么」，写不出就先补工作再谈投稿（无例外）；
4. **S4 排期**：母文档 1 天→方案与论文骨架 2 天→衍生件批量 1 天；汇报材料**提前 48h 定稿**（车上不改稿）；材料族清完后每日固定时段进复习轮，不断线。

细则与高压议程裁决（汇报冲突/软考三轮/非全硕博五案）见 [references/playbook.md](references/playbook.md)。

## §2 燧炉课程化接口

本技能可作为燧炉心跳课程入池：`queue.json` 增 `{"id":"C-0xx","title":"案头一拖十管线","stage":"init"}`，心跳按 init（建底册骨架）→edit（事实填充）→test（deliverables_check 全绿）→package（十件成稿归档）逐次推进；零新信息即休眠（退化门），禁空转。

## §3 质量标准

- 一源多曝核验：十件产物同一事实的表述逐一对账（数字/日期/人名一致），漂移即返工；
- 对外件双闸：应用证明/简讯发出前过事实闸（底册对账）+ 脱敏闸；
- 论文三问不过不投：创新点一句话/实验或仿真完整/对口刊已枚举——三缺一直言补工作。
