# 证据分级、时效与命名契约

SKILL.md Step 2/4 的细则。登记与分级时读本文件。

---

## 1. 证据等级金字塔（从高到低）

| 等级 | 信源类型 | 举例 | 可用于 |
|---|---|---|---|
| E1 | 官方底表 / API 导出 | 教育部名单全量导出、监管平台批量查询结果、官方数据库 API 返回 | 穷举、状态、存在性断言的唯一准绳 |
| E2 | 监管平台（逐条查询） | 企业信用信息公示系统、裁判文书网、学信网、备案系统 | 状态、资质、法律事实 |
| E3 | 主体官网 | 机构官网公告、年报、招生目录 | 主体自述类断言；**自述实力类不算硬证据** |
| E4 | 权威媒体 | 新华社/人民日报、主流财经/科技媒体的署名报道 | 事件类断言；注意转载链溯源 |
| E5 | 自媒体 / 社交 / 口述 | 公众号、知乎、论坛、聊天截图 | 仅作线索，**不得单独支撑关键判断** |

规则：

- 关键判断（数字/排名/状态/资质/存在性）必须有 E1–E3 中至少一级支撑；E4 可升至 Medium，E5 永远 Low。
- confidence 定级：High = ≥2 独立信源且含 E1/E2；Medium = 1 个权威信源（E1–E4）；Low = 单一 E5 或推断；Conflict = 信源矛盾。
- 信源互相引用（媒体转官网通稿）**不算独立**，按 1 个信源计。
- 结论置信度不得高于其最弱支撑证据。

## 2. 各类证据最大有效期表

超过有效期即视为"历史 ≠ 当前"风险，须重新查证后方可引用；状态类断言一律以最近一期官方口径为准。

| 证据类型 | 最大有效期 | 备注 |
|---|---|---|
| 招生/招聘/资质目录类 | 12 个月（一期） | 以最新一期目录为唯一准绳 |
| 工商/注册/备案状态 | 3 个月 | 变更频繁，出报告前复核 |
| 诉讼/失信/处罚记录 | 6 个月 | 新增记录随时可能出现 |
| 经费/项目立项 | 24 个月 | 查近 3 年滚动窗口 |
| 产出物（论文/专利/产品） | 36 个月 | 同时做断档检测（>5 年为空壳信号） |
| 媒体报道事件 | 事件后 12 个月 | 此后引用须确认无反转/更正 |
| 官网页面（自述） | 以快照日期为准 | 建议存历史快照对比 |

## 3. 证据命名契约

所有落盘的证据文件与中间产物统一命名：

```
{主题}_{类型}_{日期}
```

- `主题`：核查对象或断言主题，短横线连接，如 `shihezi-univ`、`acme-corp`；
- `类型`：`register`（登记表）/ `search`（检索记录）/ `conflict`（冲突表）/ `errata`（勘误表）/ `snapshot`（页面快照）/ `report`（报告）；
- `日期`：`YYYY-MM-DD`。

示例：`acme-corp_register_2026-08-23.json`、`shihezi-univ_conflict_2026-08-23.md`。

同主题多次修订时在日期后追加版本号：`..._2026-08-23_v1.1.md`（版本规则见 `self_correction_protocol.md`）。

## 4. Conflict 处理细则

触发条件（任一）：

- 两个信源对同一断言给出互相矛盾的事实；
- **时间口径不一致**：如旧名单含 X、新名单不含 X；旧年报数字与新披露数字不符；
- 官方底表与主体自述不一致（默认信官方底表，但仍须记录冲突）。

处理流程（对应 SKILL.md Step 4）：

1. **登记冲突表**（落盘 `{主题}_conflict_{日期}.md`），每条含：断言、冲突双方（信源 + 等级 + 日期 + 各自说法）、当前倾向；
2. **≥3 次补充检索**：至少覆盖——换关键词检索一次、换一种信源类型一次（如从媒体转官方底表）、核对时间口径一次；
3. **消解**：写明消解路径（哪条证据压倒了哪条，为什么）；
4. **解不了标 unresolved**：相关结论降级为"存疑"，正文措辞必须体现矛盾（"信源 A（E2, 2025）称 X，信源 B（E3, 2026）称 Y，未能消解，倾向 A 因为底表口径"），**禁止悄悄二选一**；
5. unresolved 条目自动进入报告的 `top3_likely_wrong` 候选。
