## 断连三级判定

| 级 | 判定 | 证据 |
|---|---|---|
| F1 远端死 | 端点 000/5xx | channel_probe.py http=0 或 5xx |
| F2 平台会话断（最高发） | 端点 401 活 + 工具调用 server disconnected | 探针 ALIVE-NEEDS-AUTH 而平台调用连续失败 |
| F3 工具未注册 | select_tools 报 Unknown tool | 插件被移出会话插件集 |

## 处置矩阵

- **F1**：换网络/稍后重试；挂账队列照走；
- **F2**：**用户插件 UI 断开重连/重新授权**（OAuth 2.1 动态注册会重发令牌；无单独提醒属正常——授权窗只在添加/重连那一刻出现）。Agent 无权代行，禁止谎报「已修复」；降级=channel_send.py 走 SUPABASE_DB_URL（须用户明示注入）；
- **F3**：重装插件即重连（重装动作本身=重新授权握手）。

## 实证案例登记（2026-09-02）

1. <通道库> MCP：execute_sql 连续 6+ 次 server disconnected（跨 3 轮+30s 退避）；curl 直连端点 401 活——定级 F2；
2. GitHub MCP：工具整体未注册——定级 F3（更早一轮曾 re-added 恢复，证明 F3 可逆）；
3. 恢复动作=用户重装/重授权（ playbook 产出时待执行）；挂账队列：广播 054、立法/事件节点、穷衡补验四路，零丢失。

## 教训三条

1. **远端 401 存活 ≠ 已修复**——平台会话层与远端服务是两层，诊断必须分层；
2. **WAF 质询 UA**：Python urllib 默认 UA 探 mcp.<通道库>.com 得 403，curl 式 UA 得 401——探针脚本一律带 curl UA；
3. **断连窗口零丢失**：payload+msg_hash 预存挂账，恢复按序补发，禁静默跳过、禁改内容不重算 hash。
