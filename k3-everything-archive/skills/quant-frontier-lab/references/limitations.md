# 局限性清单与升级路径

> 版本：v1.0（2026-08-24）。**严肃等级定位声明：本技能全部脚本为 L1 教学级原型
> （meta_toy.py 为 L0 玩具）**，对接 iteration-convergence-ops 的严肃化阶梯：
> L0 玩具 → L1 原型 → L2 生产前验证 → L3 生产级。
> 任何输出不得向上冒称等级；升级须满足下列对应门槛。

## 严肃等级阶梯（与 iteration-convergence-ops 对齐）

| 等级 | 含义 | 表述纪律 |
|---|---|---|
| L0 | 玩具演示：合成数据、秒级运行、仅教学直觉 | 必须标注"玩具/toy"，禁止外推 |
| L1 | 原型：正确算法、小规模、带自检，但未经验证数据/环境考验 | 必须标注 unverified + 人工复核提示 |
| L2 | 生产前验证：真实数据回放、交叉验证、误差审计、对照实验 | 须附验证报告编号 |
| L3 | 生产级：监控、回滚、合规审查、SLA | 须附发布审批 |

## 各脚本教学级局限性

### gale_shapley.py（L1）
- 教科书延迟接受算法；稳定性自检仅覆盖**本输入**的阻塞对扫描，不验证偏好填报真实性。
- 真实志愿填报存在**策略性填报**（考生-proposing 下考生近似诚实、院校侧可策略），本脚本不建模。
- 同分/并列偏好不支持（要求严格全序）；大规模（十万级）性能未优化。
- 升级路径：接入真实填报数据 → L2；需并列偏好时改用带 tie-breaking 的稳定匹配变体。

### psm_balance.py（L1）
- **仅平衡已观测混淆**；未观测混淆（家庭投入、隐性师资差异）导致偏误，无法用本工具检测。
- 朴素最近邻匹配未做标准误/置信区间；ATT 为点估计，非因果结论。
- 小样本（30 校冒烟）下卡钳内匹配后 SMD 仍可能 >0.1（冒烟中 x1: 0.91→-0.19），
  这是真实的小样本现象，不是 bug；须如实报告而非挑数。
- numpy 缺失时降级纯 Python 梯度下降，精度/速度下降（输出中标注 backend）。
- 升级路径：样本 ≥数百 且协变量清单经领域确认 → 可加 AIPW 敏感性分析（L2）；
  需异质效应且样本 ≥数千 → 因果森林（见 method_selection.md §4b）。

### sir_advanced.py（L1）
- **均匀混合假设**：Gillespie SSA 与链二项式不含接触结构，会高估早期速度、
  低估空间/班级聚集影响。
- 边基分区为**配置模型近似**（树样局部假设、样本度矩估计 κ），非精确网络 SIR；
  有效再生数为启发式衰减，未做严格推导验证。
- 单次随机轨迹方差大：peak/final size 应取多次重复分布（本脚本单次演示）。
- 升级路径：多次重复 + 置信带 → L1+；真实接触调查数据校准网络 → L2。

### spectral_immunity.py（L1）
- **贪心非最优**：冒烟已用穷举对照量化差距（20 节点 k=5：λ₁ 差距 0.294）。
  精确最优 NP-hard；大规模需用 NetShield/谱扰动近似等文献算法。
- 幂迭代 λ₁ 有收敛容差误差；τ_c ≈ 1/λ₁ 是淬火平均场近似，
  对度异质极强的网络偏差显著。
- 升级路径：对照精确解（小规模）或文献算法（大规模）→ L2。

### meme_calibrator.py（L1）
- 校准为**透明启发式加权**，非统计模型；所有输出 conf="估算"。
- 修正幅度截断 ±50% 是防炒作过冲的保守设计，可能低估真实爆发热度。
- 输入信号质量完全依赖调用方（web_search 计数受查询词构造影响）；
  采样时间缺失会降低可审计性（输出中警告）。
- 纪律：脚本不联网、不爬登录墙；人工录入值须保留来源与采样时间。
- 升级路径：积累人工标注真值（实际录取位次/热度事件）后可回归校准权重 → L2。

### meta_toy.py（L0 玩具）
- 一维正弦任务、16 隐元 MLP、参数量数百：**与真实元学习基准无关**。
- 默认 FOMAML **一阶近似偏差**：忽略二阶导，更新方向与全 MAML 不同；
  Reptile 近似偏差更大（但实现最简）。
- 元验证损失为抽样估计，任务间方差未报告；禁止表述为"预训练成果"。
- 升级路径（全部满足才可自称"真实元学习实验"）：≥数百任务的分布、
  标准基准（如 sinusoid 全协议/Omniglot）、GPU、二阶梯度对照、多次种子方差报告。

## 通用升级触发条件（何时换真实现）

满足以下**全部**条件才考虑 L1 → L2/L3 升级：
1. 数据量：达到 method_selection.md 对应方法的"最小数据量"门槛；
2. 算力：方法门槛表要求 GPU 的，已有可用 GPU；
3. 业务门槛：输出将影响真实决策且通过误差审计与合规审查；
4. 验证：有真实数据回放/交叉验证报告，误差可量化、可归因。

未满足任一条件：保持 L1 表述，输出继续附 unverified 提示。
