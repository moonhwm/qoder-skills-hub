来源：2026-08-26 实测（APP 包名 com.huawei.eplussoho，8×AP162 + AC，WiFi 名 Huawei-Net）。各数值为真实校准锚点。

## 1. 找AP

路径：我的工具 → 找AP。

- 顶部可搜索关键词；排序选「按信号强度排序 → 从强到弱」。
- 条目显示：WiFi 名、绿勾（=当前手机所连 BSSID）、信号 dBm、厂家、频段/频宽/信道（如 2.4G 20Mhz CH4，-39 dBm）。
- 列表偶发"暂无数据，请下拉刷新重试"——下拉刷新即可，扫描需要数秒。
- 同一 SSID 的多台面板会显示为多条同名条目，按信道区分（实测 Huawei-Net 同现 2.4G CH1 -80 / CH4 -50 / CH9 -72 dBm，5G CH64）。

**物理定位 SOP**（建 SN↔房间映射表）：见 SKILL.md「找AP 速查」五步。信号经验值：-30~-50 同房间，-55~-65 隔一墙，-70 以下偏远。

## 2. Wi-Fi 体检

路径：本地 → Wi-Fi 体检。三大板块：

| 板块 | 子项 | 实测判读 |
|---|---|---|
| 覆盖测试 | 信号测试 | 「信号强」= 平均 ≥ -67 dBm（实测 -40 dBm，CH64，160MHz） |
| 覆盖测试 | Wi-Fi 干扰 | 「干扰很小」= 受干扰强度 ≤ 40（实测 5） |
| 业务体验 | Ping | 网关 ≤50ms、互联网 ≤200ms（实测 13.2ms / 21.1ms） |
| 业务体验 | 互联网性能 | 下行/上行速率（实测 783.3↓ / 55.0↑ Mbps，China Telecom 优选节点） |
| 业务体验 | 网页连通性 | **可能"测试失败"但 Ping/测速全绿——多为该检测点自身超时超阈值，不影响实际上网**；关闭后台耗流应用后复测 |
| 网络安全 | Wi-Fi 密码 / DNS 劫持 | 已设置 / 安全 |

体检详情页还会给信道受干扰强度、同频/邻频干扰数。建议每月跑一次留档。

## 3. 干扰分析工具

- 柱状视图：逐信道「受干扰强度」（基准线 40）与「干扰数」。2.4G 实测 CH1~CH7 干扰 58~86 普遍偏高，CH11~CH13 最低（5~16）→ **2.4G 推荐信道 CH11**；5.1G 实测各信道均 78（仅 CH64 有 1 个干扰源 = 自家 AP）。
- 曲线视图（dBm）：同 SSID 各 BSSID 的信道分布与强度，用于数"同名 AP 有几台、各占哪个信道"。
- 顶部「信道推荐」可直接采纳；改信道走「手动调优」。

## 4. Tracert 测试

路径：我的工具 → Tracert 测试，目标如 baidu.com。逐跳显示 3 次时延与 IP：

- 第 1 跳请求超时 = 网关不回应 TTL 超时报文，常见且**不代表故障**。
- 实测健康样本：第 2 跳 100.77.128.1 约 45ms，末跳 111.63.65.103 约 38ms；中间个别跳 200ms+ 或 2.03s 单点尖峰、后续跳恢复，属运营商路径波动，非家庭侧问题。
- 大量连续跳超时且终跳不可达 → 才判定路径故障。

## 5. Ping 测试与一键测速

- Ping 测试（我的工具 → Ping）：实测 baidu.com 5/5 收、丢包 0%、平均 39.2ms、时延得分 80。
- 一键测速（我的工具 → 一键测速）：选测速服务器（如 Shanghai）；若提示"待测速网络无法连通"，先确认手机已连上目标 WiFi 且该网络能出公网。安卓 15 有兼容性问题，结果仅供参考。
- 视频体验检测：实测 4K 超高清可观看 = 下载 150.3 Mbps、秒开 653ms、卡顿 0.0%；链路追踪给内网/外网平均时延（标准 ≤50ms / ≤150ms）。

## 6. 设备详情页

设备 → 无线AP → 点某台：型号（AP162）、SN（如 2150085707LDP9003838）、MAC、软件版本（V200R024C00SPC100）、补丁版本、上线/离线时间、管理 IP（192.168.1.x）、公网 IP；操作：重启、登录设备 Web。监控页：故障告警数、CPU/内存利用率（实测 1% / 62%）、无线终端列表（终端名/MAC/IP/所连 WiFi/实时速率）。接口页：GE0/0/0 已连接 1000M——**速率列是排查"非千兆协商"的第一现场**。

## 7. AP 手动调优

设备详情 → 配置 → 手动调优：

- 2.4G：频宽/信道/发送功率建议保持自动；冗余频宽调整可开。
- 5G-1：频宽可选「极速(160MHz)」（实测配 160MHz + CH64）；信道结合干扰分析推荐值手选；天线增益 1 dB 勿乱改。
- 改完点底部「调优」下发。

## 8. 漫游调优

路径：无线 → 漫游调优（开启中）。默认：终端重连阈值 -75 dBm、强制下线阈值 -80 dBm。

**别墅/多层场景建议改为 -65 / -70**：终端信号掉到 -65 时 AP 主动发解除关联报文促其重连到更近 AP，掉到 -70 强制下线。默认 -75/-80 会让 iPhone 等老终端"粘"在楼下远 AP 上死撑。开启"粘滞终端优化"。

## 9. 无线黑白名单与防环路

- 无线黑白名单：全局设置 + 单个 WiFi 设置两级，可设为白名单模式（仅允许名单内终端接入）。
- 防环路：总开关默认开（仅 V200 版本 S210 需手动配）；开启后 S210 经 RLPP 协议阻塞环路接口，防止重复报文拖垮转发能力。

## 10. APP 权限边界（必须转电信/装维的事）

APP 侧**不能**强制端口千兆——「接口配置」只有场景选项（默认/上行交换机/下行交换机/下行PC），速率双工属交换机底层配置。发现"端口协商非千兆全双工"告警时：

1. 截图告警页（含异常 AP 的 SN 列表）。
2. 发装维/电信，话术：*"我家 N 台 AP 上联端口没协商到千兆，麻烦远程把对应交换机端口改强制千兆全双工；改不了需上门查网线水晶头是否只压了 4 芯或用的是 CAT5 老线。"*
3. AP162 硬件支持 IEEE 802.3ab 千兆自协商，协商不到千兆 100% 是网线/水晶头/交换机端口问题，不是 AP 硬件限制。
