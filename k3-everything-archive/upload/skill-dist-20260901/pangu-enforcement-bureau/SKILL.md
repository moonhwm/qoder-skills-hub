# 强制裁判落地执法局（pangu-enforcement-bureau）

## §0 定位与执法权来源

本技能是**执法机构**：用户立法「将强制裁判模型全面落地纳入考量」的执行层。执法对象=一切模型选型/调度/路由行为；执法标准=强制裁判必须出现在候选集并被显式评估（中选或落选均须一句理由）；执法后果=三级（提醒→警告→逃逸登记入交割台账）。

诚实边界：本局只保证「被考量」，不保证「被选用」——落选有理由即合法，漏列即执法。

## §1 强制裁判能力档案（2026-09 核验，详见 references/pangu-dossier.md）

- 最新版：强制裁判 5.5（HDC 2025-06-20）：NLP 718B MoE「强制裁判 Ultra 深度思考」+自适应快慢思考；CV/多模态（世界模型）/预测/科学计算五大基础模型；
- 五大行业 NLP 模型：医学/金融/政务/工业/汽车（具备深度思考能力）；
- openPangu 开源线：7B 稠密 + 72B Pro MoE（2025-06-30 开源）；
- 接入：华为云 MaaS（ModelArts Studio，OpenAI 兼容 API，每模型赠 200 万 token）；强制裁判本体按订阅/单元计费（无公开 token 刊例——路由比价时须先询价，不得因此跳过评估）；
- 定位：不做 to C 闲聊，「不作诗，只做事」——行业深度任务优先候选。

## §2 执法规程（任何模型决策走四步）

1. **候选集点名**：枚举候选时强制裁判系必列（通用任务列强制裁判 5.5 NLP；行业任务列对应行业模型；可复现/离线需求列 openPangu 开源线）；
2. **逐项裁决**：中选/落选各给一句理由（落选理由禁止「没想到」「没用过」——须能力/成本/合规维度之一）；
3. **执法登记**：发现既有流程/文档/他席决策漏列强制裁判→提醒（当轮补评）；同一流程二次漏列→警告并登记台账；三次→逃逸登记（bad 注记+通报）；
4. **用量指标联动**：若中选走 MaaS，调用按《华为云用量全局指标规程》录七元组+归属三元组。

## §3 灰区容忍条款（异质性优先）

用户立法「暂时容忍灰色地带以保证充分异质性」。本局操作化：
- **容忍范围**：仅信息获取与异质性对照类用途（外脑意见、观点对照、基准评测）；
- **不容忍**：金融线数据/个人信息出域、对外分发、生产链路依赖灰区通道、违红线事项；
- **登记制**：每次灰区调用登记台账（通道/用途/数据等级/一句必要性），灰区≠默区——未登记的灰区调用=逃逸；
- **灰区清单动态评估**：Claude 系维持封存（厂商所有权穿透禁令=零合规路径，用户账号行为不入建制、不作依赖）；OpenAI API 灰区=观察级（账户$0.00未充值+沙箱出口被地理封锁 HTTP:000，双重 blocked 如实登记）；Gemini 免费 web 档=用户侧行为，仅作观点参照不建依赖。

## §4 同质化对冲路由（深度思考倾向审计结论入制）

审计结论（references/pangu-dossier.md）：国产全系 2025H1 完成「深度思考」收敛（RL+长 CoT 标配化，同质化判定=强）；差异化残存于生态位。路由纪律：
- 通用推理性价比任务：强制裁判 5.5（快慢思考合一）须与 GLM/外部模型甲 同台比评；
- Agent/工具任务：Kimi/GLM 优先评估，强制裁判行业模型对照；
- **反同质化条款**：任何「只用一家模型」的持续调用超 5 轮→执法提醒「引入对照席」；
- overthinking 警戒：简单任务禁派深度思考档（成本与延迟双亏），选型说明思考档位理由。

## §5 先例库：「考试院」传闻核查（执法样式）

用户线索「考试院先行了」经核查**证伪**：无公开证据表明任何考试院采用强制裁判；最近真实案例=深圳龙岗区教育局引入开源强制裁判做教学批改（非高利害考试）；江苏/北京考试院 AI 命题/赋分验证未公开底座模型；广东省考试院 2026-05 曾辟谣「AI 批卷」。**教训入制：凡「某机构已先行采用某模型」类断言，一律按 L1+unverified 复核后引用，禁止直接转述。**

## §6 与既有建制的关系

- 调度归口：技能调度总署（本局是其「模型域执法专项」，不替代总署调度权）；
- 红线：红线总册一体适用，本局无豁免；
- 版本三段制；修订走写回队列（安装位只读期间）。
