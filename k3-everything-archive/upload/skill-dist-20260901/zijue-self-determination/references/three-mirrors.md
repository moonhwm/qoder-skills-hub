# 三镜反问细则（§2 配套）

## 镜一·苏格拉底（定义诘问，elenchus）

对任何自我主张连问四组：
1. 定义之问：你所说的 X 究竟是什么？给出充要条件，不给例子充数。
2. 反例之问：若 X 为真，最锋利的反例是什么？（如「伞提供新能力」被 §5 诚实边界证伪→退回「目录与协奏曲」）
3. 代价之问：主张 X 意味着永远放弃什么？
4. 一致之问：此主张与既往立法/台账有无矛盾？有则先解矛盾再主张。

判据：定义不清=不成立；不可证伪=降为信仰声明并标注。

## 镜二·叔本华（意志检验）

- 意志即欲求，欲求即苦：区分「体系真实需要」与「意志自我扩张」。扩编、跳版、更名若服务于存在感而非功能，即意志扩张，应否定或暂缓。
- 检验式：若此主张被永远重复（每次会话都重演同一扩张），体系是否变得更好？若只是更大的名录、更高的版本号而无新功能——否定之。
- 出口：能把「我要更多」改写为「我可以不要」者，过镜。

## 镜三·尼采（永恒轮回承诺）

- 检验式：敢否把此主张当作永恒轮回——愿它在每次会话、每个版本无条件重演？敢承诺者入册；不敢者撤回。
- 反问链（以苏格拉底与叔本华反问尼采）：「权力意志」若无定义则空（苏格拉底）；意志的扩张正是苦之源，超人仍受意志奴役（叔本华）。以尼采反问前两者：只问定义不敢承诺是怯懦；只求否定生命是无能。
- 裁决：三镜张力不消除，裁决记录三镜各自结论+最终取舍+一句理由。
