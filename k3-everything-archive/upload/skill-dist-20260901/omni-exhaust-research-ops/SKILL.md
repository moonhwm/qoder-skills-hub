# 穷举研究总署（omni-exhaust-research-ops）

> 开箱提示：`.skill` 文件为 zip 容器，请先解压；全部文本以 **UTF-8** 编码，请用支持 UTF-8 的编辑器打开（Windows 记事本需选 UTF-8）。本技能纯 Markdown，无脚本。

## §0 定位与边界

对复杂问题执行「可能性穷举→方案尽调→统一调配」。本技能**无项目绑定**：不含任何私有路径、私有数据表、具体人名；一切外部能力以「能力占位」描述，实例在场即联动、缺席即降级并显式声明。

**诚实边界**：穷举=可枚举维度上的完备遍历，不承诺逻辑绝对完备；每个维度缺席须声明理由，禁止假装穷举。

## §1 苏格拉底式提问开场协议

任何研究任务首轮**先问后研**，四组固定问题（可裁剪不可省略）：
1. **定义之问**：委托方要的「好结果」长什么样？（成功判据先于方案）
2. **约束之问**：什么绝对不能动？（时间/钱/身份/合规红线）
3. **反例之问**：最看好的方案若失败，最可能死于哪一环？
4. **代价之问**：每个选项的机会成本是什么——选了 A 就永远放弃什么？

委托方作答或明示「免问直接研」后进入 §2。作答一律标注来源=委托方自述。

## §2 七域强制接口调用矩阵

每研究任务必须遍历七域，**每域要么实调、要么显式声明「本任务无需该域」**；全表与正交性校验见 `references/interface-matrix.md`：

1. **检索域**：通用 web 搜索/学术搜索——多源交叉，信源分级；
2. **文档域**：版本对齐的库文档检索（如 Context7）——凡涉库/框架 API 必查官方文档，禁凭记忆写 API；
3. **库域**：既有知识库/数据库自查（如有 <通道库> 类实例）——先查历史沉淀再外查；
4. **代码域**：开源仓库搜索（如 GitHub）——技术方案必查开源先例与踩坑记录；
5. **通道域**：邮件/消息通道检索（委托方授权前提下）——涉既有函件证据时启用；
6. **计时域**：定时任务能力——跨周期跟踪类研究必须落计时器而非口头承诺；
7. **生成域**：文档/表格/演示/多媒体生成——产物形态按需；**研究≠写作，分段交付**。

正交性校验：七域产出两两不互为复制（检索给证据、文档给 API 事实、库给历史、代码给先例、通道给函证、计时给周期、生成给形态），同义重复即合并登记。

## §3 能力占位编组（依赖即插拔）

本技能只依赖**能力类型**，不依赖具体技能实例。以下九组占位，实例在场可联动、缺席可徒手执行：

| 占位 | 职责 | 在场实例举例（可缺省） |
|---|---|---|
| 治理纪律 | 恒常行为纪律 | autonomous-advance-ops |
| 产物验收 | 交付前三判验收 | output-verdict-gate |
| 语义审计 | 断言/承诺口径核查 | semantic-oncology-ops |
| 成本闸 | 调用额度/费用闸门 | 「额度守护件」 |
| 模型候选 | 指定模型强制入候选集 | pangu-enforcement-bureau |
| 数据路由 | 插件数据源调度 | plugin-datasource-ops |
| 协作交割 | 函询/委托受理 | coordination-letter / consignment-intake-ops |
| 版本运维 | 技能重装/版本基线 | skill-reinstall-ops / skill-refresh-ops |
| 专项研究 | 蒸馏/答案隔离/领域研究 | up-distill-ops / exam-isolation-ops / k3-territory-studies |

调度四步：候选集完整性声明（全部可服务候选逐一列出中选/落选及一句理由）→最小够用分配→留痕→降级诚实声明。

## §4 自迭代检索路径

固定循环，每轮留痕：
1. **检索**：宽词初查→评估命中质量；
2. **改写**：按缺口窄化/换词/换语种/换信源级；
3. **再检索**：至多 3 轮，仍缺即标「查无实据」，禁止编造（委托方明示「无限循环/直到临近退化」时改走 §10，本节默认上限不被静默突破）；
4. **路径记录**：查询词/命中数/采用数/弃用理由，随产物附录保存可复核（模板见 references/interface-matrix.md 末节）。

## §5 全模型适配层（向下兼容）

- **产物与通道解耦**：输出默认 markdown/通用格式，不依赖特定平台账号——任何用户、微信好友、任何免费/付费、境内/境外模型均可直接消费；
- **模型路由**：指定模型强制入候选集（联动模型候选占位）；成本过成本闸占位；境外/灰区通道按委托方当地规则登记；
- **降级链**：目标模型不可用→同级替代→免费档→纯文本交付，每级留痕。

## §6 脱敏与泛化交付（强制）

1. **占位化**：产物不出现真实人名/证件号/单位名/项目代号——一律「委托方/某单位/项目甲」；实名素材只在当轮内存使用，永不落盘进技能包；
2. **红线继承**：委托方所在环境的隐私/凭据红线一体适用，本技能无豁免；
3. **用户泛化**：产物默认写成「任何委托方可代入」的模板形态，个案数据放附录且可整体替换；
4. **明示排除**：委托方当轮明示「不入技能」的内容，一字不进任何落盘件。

## §7 收敛与验收

- 研究收敛=维度遍历完+每维有证据或「查无实据」标注；
- 方案交付=候选清单（中选/落选+理由）+推荐路径+风险登记+回退路径；
- 交付前过验收三判（判据明确/证据在场/边界无越），不通过即返工。

## §8 交割与自包含分发协议

研究产物与技能本体的**交付形态**统一走本协议，细则见 `references/handover-protocol.md`，模板见 `assets/handover-template.html`：

1. **全格式保真**：交割物含任意类型文件（.py/.exe/.apk/.c/.a/.lib/.i/.h/.mk/.out/.d/.sh/.pl/.js/.rb/.ps1 等）时，一律字节级保真（禁转码/禁重编码/禁截断），以容器（zip）或单文件 HTML 承载；
2. **HTML 单文件优先**：交割文档类产物默认打为**单文件自包含 HTML**（样式/脚本/数据内嵌，可含 base64 附件槽）——浏览器直开可读、可拖拽进任意 AI 对话上传口、跨模型无损消费；
3. **拖拽导入与 100M 分阶压测**：交割包目标=一键导入/拖入 AI 对话 upload 区；体积按 1M→10M→50M→100M 分阶验证，每阶做哈希回环（交割前后 md5 一致），超限即转 §4 链接分享；
4. **远期链接分享**：超 100M 或长期托管需求，转网盘/对象存储链接或公开/非公开域名分发（仅绕开体积上限，不绕开平台安全与合规规则；分享内容仍须先过 §6 脱敏）；
5. **接收端零门槛**：交割物不得要求接收端安装特定软件/账号/依赖——打开即读、拖入即用。

## §10 激进无限循环规程（退化门，v3.1.0 委托方立法）

立法原句：「这次更加激进，不设任何步数，无限循环，直到临近退化，查看相关状况。」（委托方 2026-09-02）

- **明示触发**：仅当委托方明示「无限循环/直到临近退化/不设步数」类口令时激活；不激活时 §4 默认上限照旧。禁止以本节为由静默突破任何默认上限。
- **循环即纪律**：激活后循环不设步数上限；**不动点不再是出环证**（降级为遥测读数），循环可穿越不动点继续，逐轮登记。
- **出环只凭两证**：
  1. **委托方中断**：口令即出环；
  2. **临近退化触阈**（三维遥测，任一维触阈即出）：
     - *语义退化*（v3.1.2 ε-δ 镜像）：q(n)∈{0,½,1}，退化极限=lim q(n)=0，出环=ε₀=½、k=3 窗口连续 q<ε₀（z≥3 为离散实例）；**对抗性冲锋义务**（每轮尽力证伪收敛，禁躺平）；或当轮输出与上轮逐字重复率≥80%；**双时钟+慢性退化维**（v3.1.1 镜像同步）：历史钟跨触发连续不归零、当轮钟 z 从 0，近 5 触发零新信息占比≥80% 即明示慢性退化临近，堵高频触发重置逃逸；
     - *物理退化*：上下文/额度/会话期限的**代理读数**逼近极限（代理性质必须显式声明，禁冒充精确读数）；
     - *结构退化*：输出无法维持既定结构（裁决卡/清单崩坏）先兆。
- **出环即义务**：出环轮必须产出《退化状况报告》——遥测读数、轮次全录（每轮：新信息自证或零新信息登记）、资源消耗、诚实边界声明（「无限」=物理可达边界内无限，退化即物理边界，二者互为出口非循环论证）。
- **反滥用**：为空转而循环=意志扩张，否决；激活期间成本闸占位联动（quota-guard 类）常设；循环广播从简（汇总一次，不刷屏）。
- **联挂**：与 自决-self-determination §6 互为镜像（同一退化门、同一三判据）；首轮实跑标本（C5–C11，z=3 触阈出环）见该件 references/survival-loop.md 第二轮记录。

## §9 接收端自由使用声明

本技能及其交割物遵循：**任何接收端使用者可自由使用、复制、修改、再分发，无需授权、无需署名、不附带任何项目义务**；按「现状」提供、无任何担保；唯一前提=再分发时维持脱敏状态（不得回填任何真实个人/单位/凭据信息）。
