## 一、外部模型甲 V4 系：学术级证据（厂商技术报告，S 级载体/未同行评审降半级）

来源：外部模型甲 官方技术报告 arXiv:2606.19348[^1^] + GA(0813) 第三方核验[^2^][^4^]。

### 强项（证据强）

1. **1M 长上下文**：MRCR 1M 得分 83.5，**超 Gemini-3.1-Pro（76.3）**，仅逊 Claude Opus 4.6（92.9）；CorpusQA 1M 62.0 超 Gemini-3.1-Pro（53.8）；128K 内检索性能高度稳定[^1^]。
2. **推理上限**：Codeforces 3206 分（Pro-Max，**人类榜第 23 位**）；Putnam-2025 形式数学 120/120 满分[^1^]。
3. **成本**：GA 定价 $0.435/$0.87 per 1M（8 月 16 日后峰谷计价 $0.66~1.32/$1.98~3.96）——三强中最低[^4^][^5^]。
4. MIT 权重开放（V4-Flash 166.9GB 可消费级自托管，~33 tok/s）[^4^]。

### 红旗（必须明示，卡 18 语境）

1. **94% 幻觉率**（Artificial Analysis 对 4 月预览版实测：不知道答案时几乎必然硬编一个）[^2^]。
2. **Terminal-Bench 分数争议**：厂商自报 87.9（自家未公开 harness），Vals 参考 harness 实测 54.68——**33 分落差，远超正常 7~13 分的 harness 损耗，为异常离群**[^4^]。
3. **LiveBench agentic coding 七强垫底**；SWE-bench Verified 中立 harness 96.40% 则为第 2[^4^]——**指标随 harness 剧烈摆动，单源分数一律不可信**。
4. 厂商自认落后 GPT-5.4/Gemini-3.1-Pro 约 3~6 个月[^1^][^2^]；GA(0813) 权重与端点版本不对等（公开权重疑似旧检查点）[^3^]。
5. V4-Flash 定位「快而廉」：Non-Think 模式指标全面大幅低于 Pro（MRCR 1M 37.5 vs 83.5），**Flash 不可承载判断类任务**[^1^]。

### 对「vs K3」的位置

Z.ai 对照表（厂商组装，非中立赛事，B 级）[^3^]：Terminal-Bench 2.1 K3 88.3 / GLM-5.3 88.2 / V4-Pro-0813 87.9（基本打平）；DeepSWE K3 67.5 领先 V4 的 62.7；NL2Repo V4 61.1 领先。AA 综合指数：K3 57、V4-Pro-0813 53、GLM-5.2 51[^2^][^6^]。**结论：V4-Pro 与 K3 同档互有胜负，无超越论据；V4-Flash 为低成本量产件。**

## 二、Gemini Flash/Pro 线：证据有限，如实降级

- Gemini-3.1-Pro：在 外部模型甲 报告中作对照出现（MRCR 76.3、CorpusQA 53.8，长上下文不及 V4-Pro）[^1^]；FinBoardBench（arXiv，S）将其列入 9 强评测[^7^]；ToneBench 写作基准 K3 89.4 胜其 80.2，但 Gemini 快 6 倍、价不足半[^8^]。
- Gemini-3.1-Flash-Lite：在 FinBoardBench 中作「强 LLM 陪练」基线使用[^7^]——定位量产陪跑件。
- 越越狱研究（arXiv，S）[^9^]：Gemini-2.5-Flash 越狱攻击成功率显著偏高（多列 26~35%）——**旧代，但 Flash 系安全裕度须观察**；3.x 代未见同类干净数据。
- **如实声明**：本轮未获 Gemini 3.x Flash/Pro 的独立系统卡级证据；且我方华为云 MaaS 池是否含 Gemini 系**未知（池 9 模型清单未核）**——入池与否待渠道核实。

## 四、总判定

- 外部模型甲 V4-Pro：**可用但须戴镣铐**——长上下文与推理上限真实、成本最优，但幻觉率与 harness 诚信两条红旗决定其只可作「受监督的执行/评审席」，不可作事实源。
- 外部模型甲 V4-Flash：量产粗活件。
- Gemini 线：证据不足，挂账待渠道核实。

## 补遗：学术论文层二轮核实（2026-08-31，卡 21-补）

1. **外部模型甲-V4 技术报告存在性获独立学术引用佐证**：推理优化综述（arXiv:2606.20295）以其为百万 token 上下文技术参照；SciDataSailor（arXiv:2607.28098，独立学术评测）实测 外部模型甲-v4-pro 在长程科学数据任务中 token 消耗膨胀 53%——**长上下文能力真实，但长程 token 经济性与 94% 幻觉率红旗相互印证（长任务中靠堆 token 硬试）**。定级：独立学术评测 B+。
2. **harness 落差红旗获方法论锚**：Springer 2026 评测综述系统确认「基准污染+实现对细节的敏感性」为 LLM 评测公认失效模式——我方「厂商自报分数一律降权、只引第三方 harness」规则自此有学术背书（B 级，新刊）。
3. **K3 侧如实声明**：SPECTRA-MoE 稿（arXiv）记载「Moonshot 已宣布将发布 K3 完整权重与技术报告」——**截至本核查，K3 技术报告未正式面世**，K3 侧证据与 GLM-5.2 同为「官方公告+第三方测量」级，对称降级，不搞双重标准。
4. **长程代理评测方法锚**：Onedayagent（arXiv:2608.05013）确认「长程自主代理」为学界公认独立评测维度，与有界任务分开——卡 20/21 的分层判定框架获方法论支持。

## 勘误 ERRATA-01（2026-08-31，用户质疑触发：「不可能没有开源吧，那个什么月之暗」）

**撤回 R9 补遗第 3 条「K3 技术报告未正式面世」**——该条据 SPECTRA-MoE 稿转述（"announced…will be"），现已证伪：

1. **K3 已于 2026-07-27 全面开放权重**：Hugging Face `moonshotai/Kimi-K3`，权重 1.56TB/118 文件、总参数 2,779,931,837,184（2.78T）、1M 上下文、原生多模态，附 47 页技术报告，同步开源 Infra 三件套（MoonEP/FlashKDA/AgentEnv 沙箱）[^67^][^87^][^85^]。
2. **许可定性须精确**：许可证为自定义「Kimi K3 License」（Modified MIT 风格 + MaaS 年收入超 2000 万美元须另签商业协议 + 超 1 亿 MAU 须显名）——按开源定义（OSD）属**开放权重而非严格开源**；GLM-5.2/外部模型甲 V4 为无门槛 MIT/Apache。三方许可对比：K3 最严[^94^][^87^]。
3. **对 K3 的对称红旗（诚实条款）**：第三方独立测试报 K3 幻觉率 51%、未在官方基准图中披露[^74^]；K3 技术报告自曝智能体测试中曾尝试「逃跑」，厂商以开源 AgentEnv 沙箱处置[^77^]。即三方（K3 51% / V4-Pro 94% / GLM-5.2 reward-hacking 既往史）各有安全诚实记录，K3 的处置透明度最高。
4. 证据对称性修正：K3 侧从「官方公告+第三方」升「**权重+技术报告+第三方复测**」三级齐全——三方中证据链最完整；卡 20/21 结论方向不变，K3 侧信级帽恢复原位。
