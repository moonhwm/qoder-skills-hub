1. **只读默认许可**（用户列名即授）：get_me/search/get_file_contents/list_*/issue_read/pull_request_read/代码搜索——用于学习与参考。
2. **写类逐次显式批准**：create_repository/create_or_update_file/push_files/create_pull_request/issue_write/merge/fork——每次调用前列出（目标库/操作/内容摘要/公开性）获批准。
3. **禁区**：①委托方金融分析项目任何代码/脚本/数据上传一律禁止（代码外发禁令，用户拍板也须事先审查）；②任何含密钥/隐私/未脱敏家庭信息的内容禁止入任何库（公开或私有）。

## 四、未来自动化接口（v1.1 增，2026-08-29）

**自动化三级门**：
1. **可自动化**（无需逐次批准）：只读扫描类——季度密钥/隐私扫描、repo 元数据巡检、公开库清单盘点。自动化任务必须：①注册进计时器任务台账（skill-dispatch-hq §4，字段齐全）②每轮结果在迭代日志留痕（零发现如实报零）③连续失败 ≥2 触发熔断告警。
2. **永不自动化**：一切写类（create/push/merge/issue 写/PR 操作）——写类例外逐次人工批准的原则不因自动化松动；任何「自动写」请求一律拒绝并登记。
3. **禁区自动化**：金融项目代码上传、含密钥/隐私内容入库——即使用户口令也须事先审查（既有立法）。
**接口契约**：未来任何 GitHub 自动化任务挂接前，任务书须含（目标/扫描式/留痕路径/熔断条件/责任方）五字段，由 dispatch-hq §9 接口核验后入计时器台账。
