## 二、回来时请带齐的料（每只 bot 一组）

**A. 改名（开发者后台，每个应用一次）**：飞书开发者后台 → 应用 →「凭证与基础信息」→ 应用名称改成分辨名（建议格式：用途白描，如「席位戊」「席位辛」「集群」——最终名以您拍板为准）。

**B. 凭证（每个应用两项）**：
- `App ID`（形如 cli_xxxxxxxxxxxxxxxx）
- `App Secret`（同页「App Secret」字段，可重置）
- 位置：开发者后台 → 应用 → 凭证与基础信息。_secret 属密钥，给我后只进配置、永不落盘正文。_

**C. 权限（每个应用按需勾选，勾完须「创建版本并发布」才生效——上次 scope 没生效就卡在这步）**：
- 最小集：`im:message`（发消息）、`im:message:send_as_bot`（如有）、`im:chat:readonly`（读群信息）、`im:chat.members:read`（读成员）
- 路径：后台 → 权限管理 → 搜索勾选 → **版本管理与发布 → 创建版本 → 发布**。

**D. 拉群**：改名+发布后，在会客厅群设置 → 群机器人 → 添加（或我拿到 appId+secret 后用 API 拉）。
