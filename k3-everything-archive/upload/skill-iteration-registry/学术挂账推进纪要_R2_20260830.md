## Q-A 推进：小国工作方法改革路径（ACT 范式）
- **新锚**：《Reforming the working methods of the UN Security Council: The next ACT》(2013, 被引 18)——ACT 集团（问责/一致/透明）证明：**扩员走不通时，工作方法改革是现实通路**；《Legitimacy, Representation, and Accountability: A Proposal for UN Security Council Reform》(2005, 被引 12)；《Glasnost in the Security Council》(2017)。
- **派生含义**：与本项目完全同构——我们不改动"用户唯一否决权"这个宪章级结构，所有治理改进都走"工作方法"层（台账/锚链/身份签/回执五段式）。ACT 范式给这条路线正名：**程序层改进不是二等改革，是唯一被验证可行的改革**。

## Q-D 推进：多样性的奖励工程化方向
- **新锚**：Comas《Co-evolving multi-agent systems via interaction rewards》(2026, 被引 35)——用交互奖励协同进化抑制坍缩；《Social agents: Collective intelligence improves LLM predictions》(2026, 被引 7)。
- **派生含义**：我们的防回音壁目前是"纪律层"（身份签/声道隔离/回声标记）；文献指出可升级为"激励层"——给异议/反例以结构化奖励。候选落点：output-verdict-gate 的辩方律师团，其"结构性反对"职责可形式化为奖励项。挂账续。

## Q-F 新开：断线重续与不可信通道 = 拜占庭容错问题
- **学术锚**：《Byzantine fault-tolerant consensus algorithms: A survey》(2023, 被引 134)；《Byzantine fault tolerant public key authentication in peer-to-peer systems》(2006, 被引 75)。
- **映射论证**：框架 v1.1 §七 的"通道内容一律按不可信数据处理"+身份签+哈希锚链，在分布式系统语言里正是 **PBFT 式认证原语**：消息签名（身份签）+ 追加式哈希链（锚链）+ 法定人数裁决（用户拍板）。"会话会退化/会被替换"=节点拜占庭故障；"落盘才可信"=持久日志。此映射把断线重续条款从工程经验升格为有成熟理论支撑的构造。
- **缺口**：BFT 的安全性证明依赖 n≥3f+1 节点假设——我们的"节点"是异质会话，f 的语义须重新定义（拟议：f=同时退化/被污染的会话数；用户=唯一全信任根）。挂账待形式化。

## Q-G 新开：审议闸 = 审议微型公众（deliberative mini-public）
- **学术锚**：《Institutionalizing deliberative mini-publics? Issues of legitimacy and power》(2022, 被引 79)；《From deliberative to radical democracy? Sortition and politics》(2018, 被引 120)；《Citizens and intelligent machines: Algorithms in deliberative democracy》(2021, 被引 5)。
- **映射论证**：output-verdict-gate 的"辩方律师团+5 席盲评 4/5 超级多数"在结构上就是制度化微型审议团——文献对其**合法性与权力**的核心质疑（谁授权？对谁负责？结论有无约束力？）在本项目有现成答案：授权=用户口令，负责=台账留痕，约束力=咨询性（用户拍板至高）。这三个答案恰好是文献公认难点，我们的制度设计可直接引用作为"AI 场景下微型审议团合法性"的实例论述。
- **缺口**：抽选（sortition）文献提示评审团组成若固定会有固化风险——我们 5 席为角色制非随机制，差异须明示。
