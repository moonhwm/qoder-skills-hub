# 集群甲长对话回跑·试点卡 v1.0

> 2026-08-30 · 依据 semantic-oncology-ops §1/§2/§3 + k3-interaction-ops L0–L4 光谱制定
> 性质：有界试点（非全面回跑）。一次一负载，验收后由委托方裁定是否扩量。

## 一、试点边界
- **负载选型**：治理类轻负载 + 目的类轻负载各一件（呼应目的预算护栏 B1 待拍板项，试点本身治理:目的=1:1，不超 3:1 起试值）。
- **时长/轮次上限**：单会话 ≤3 个工作轮；出现 L2 信号即熔断写交割卡（§2.3 五字段）。
- **模式**：当前会话内模拟试点（K3 单线程长对话形态）；集群并行形态留待第二试点，须用户另行批准。

## 二、熔断条件（任一命中即停）
1. 思考块同族 token 碎片串苗头（L2 前兆）；
2. 写入后核验失败 ≥1 次（指纹/落位/回放任一 MISMATCH）；
3. 工具调用 504/deadline_exceeded 连续 2 次；
4. quota 档位信号升至 Q2 及以上。

## 三、验收标准（ε-δ 口径）
- 全部写动作落盘且回放 MATCH；
- 退化特征扫描零命中（§3 早期筛查）；
- 试点结束产出本卡的验收段，收敛结论禁形容词式（须带核验证据指针）。

## 四、试点负载
- 负载甲（治理类）：写回本卡+验收段（即本文件自身的生命周期）；
- 负载乙（目的类）：双标的项目可见产出一件——为父亲可见层写一段本周项目进展白话小结（适老呈现层 v1.4 口径：技术细节不进可见层）。

## 五、登记事项
- 「输出阀门 skill」用户来函提及其在审议中——登记为外部在审项，本试点不依赖、不预判其结论；若过审，后续接入须走 dispatch-hq 入册核验（§9）+ I1–I9 接口检查。
