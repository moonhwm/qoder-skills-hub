## 一、候选通道清单与必要性裁决（G1 必要性门）

| 通道 | 能力 | 与既有资产重叠 | 必要性裁决 |
|---|---|---|---|
| AgentArts 工作流/多智能体 | 可视化编排+触发器+KMS | 与 K3 子代理 swarm 高度重叠 | **低**——仅当父亲公司侧立项方案三时才必要（见审计总报告：暂缓） |
| AgentArts 对外 RESTful API | 业务系统反调智能体 | 无重叠（Kimi 侧无对应物） | **中**——moonclaw.top 门户化后或需，挂观察 |
| CodeArts（码道）CI/CD | 代码托管+流水线 | GitHub 插件在轨（只读为主） | **低**——代码外发禁令下，托管需求弱；若华为云全栈深化再评 |
| CodeArts Artifact/部署 | 制品库+发布 | FunctionGraph 外包路径已选 | **低**——serverless 免制品库 |
| MaaS 蜂群通道 | GLM/DS 模型批量调用 | **已在轨**（外部席实调） | **已满足**——无需新建 |
| 启信慧眼 MCP/REST | 企业征信数据 | 天眼查插件同域 | **中（公司侧）**——见提案审计，家庭侧无需求 |
| 云空间 Drive Kit | 消费云盘读写 | OBS 正道 | **否**——spike 已销号（足够脆弱），转观察 |

## 二、结论
线一当前**无必须新建通道**；唯一已带电通道=MaaS 蜂群（外部席）。两个观察触发器：①父亲公司方案三若立项→AgentArts 通道必要性升级重评；②moonclaw.top 门户化启动→对外 API 通道重评。码道线在「代码外发禁令」解除前维持冻结。
