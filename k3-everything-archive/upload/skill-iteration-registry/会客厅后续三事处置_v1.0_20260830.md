# 会客厅后续三事处置 v1.0（2026-08-30）

## 一、群重建必要性审计（结论：暂不重建，设触发条件）

**威胁模型复核**：链接暴露面=两个 Kimi 会话的文字流（您本人的账号内会话）。要泄露须同时满足：①平台日志/记录被第三方触及 ②触及者识别出该串为准入凭证 ③其在链接有效期内主动加群。三重条件叠加概率低；且群内目前无已沉积的敏感内容（群新建，公告仅纪律与待拍板事项）。
**结论**：当前重建成本（散群+重建+双边重通报+公告重发）> 风险残量——**不重建**。
**重建触发条件**（任一命中即重建，无需再审议）：
1. 链接出现在任何更宽面（群公告/文件/通道/第三个会话）；
2. 群内开始沉积敏感内容之后才发现暴露面扩大；
3. 您一句话决定重建。
**函件判断**：未达「有必要」阈值，不发函；本结论经通道给 K3 侧备案一句（属状态同步非函询，并入下封必要函件顺带即可——当前无必要函，故通道保持安静）。

## 二、章程六条明列（**决策卡 16：用户口令「卡16全部通过」（2026-08-30）——六条生效**）

1. 拍板唯一性：群内讨论不产生拍板效力，实质决定只认委托方在主会话的自有口令；
2. 证据纪律：群消息=速览层，作证据引用仍须落盘指针；
3. 隐私红线群化：家庭成员姓名/证件/私货内容不入群；私货对话纳入对账默认否，须逐次显式批准+先脱敏；
4. 双轨适配：谱系元数据可通报，内容本体不互贴，引用以「指针+一句摘要」为限；
5. 链接管理：链接不入任何文件/通道/公告，准入仅经您亲手转递，泄露即散群重建；
6. 回退条款：群失控即回退 <通道库> 通道+回音壁模式，触发=您一句话或主程序熔断登记。

## 三、个人画像透明对账·严格子章程（种子 v0.1，育种不施工）

> 您的定位照录：「需要更加严格的审核和规章，而不是简单的规则；不打算现在做，作为种子」。
> 种子状态=休眠：不生效、不排期、不占审查资源；激活须您显式口令+过下列全部前置闸。

**种子条款（激活时生效）**：
1. **议题级许可制**：每一个人信息核实议题单独成卡（核实什么/为什么/数据源/脱敏方案/留存期限），一卡一批，禁止打包批准；
2. **双闸审查**：每卡须过 ①隐私合规闸（目的必要性/最小够用/家庭成员利益影响评估）②反方辩护席（M1 常设席实体承担反对意见）；
3. **画像透明对等**：涉及对任何家庭成员的画像/信息核实，该成员知情同意状态须显式登记（不知情则默认禁行，例外须您书面级口令+风险自承声明）；
4. **聚合效应闸**：单条信息各自无害不等于聚合无害——每卡附「与既有已核实信息拼接后的轮廓风险」评估段；
5. **留存与销毁**：核实产物标留存期限，到期销毁留墓碑；私货对话原文永不入群入档，仅存脱敏结论；
6. **审计轨迹**：每张议题卡全生命周期入交割台账（未来 JSONL 台账），可第三方复盘；
7. **休眠唤醒条款**：种子修订不受版本冻结保护，激活前须以届时最新红线总册重校一遍。

**与既有种子的关系**：元元元禁区种子（已封印）、B 轮立法包（卡15）与本子章程三者独立；本子章程不与任何既有种子合并，防休眠件互相污染。
