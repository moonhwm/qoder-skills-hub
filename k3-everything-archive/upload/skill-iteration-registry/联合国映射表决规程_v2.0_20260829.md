# 联合国映射表决规程 v2.0（深化版：真实议事规则内化）

> 2026-08-29 · 触发：委托方指令「进一步深化联合国等相关投票流程」· 升级自 v1.0（安理会映射，2026-08-28 立法）
> 语料锚：联合国大会议事规则第一二四至一三三条（un.org 官方文本 [conf=empirical，官方原文]）＋ 独立第三方机构「Q 席」章程卡（同目录）
> 效力：本规程是既有「用户特权（安理会映射）」条款的深化，不改动红线级权力分配；程序性细则按本规程自走。

## 一、角色映射（定稿）

| 联合国 | 本项目 | 权限要点 |
|---|---|---|
| 大会（全会） | 全员表决场（主程序+各席子代理） | **重要问题 2/3「出席并参加表决」**（宪制/解锁/红边界类）；其他问题过半数 |
| 安全理事会 | 治理三角/六席表决（实定：5 席子代理+主程序，可扩至 6+1） | 程序性事项 9/15 映射=简单多数；**实质性事项=多数+无常任反对** |
| 常任理事国 | 用户（委托方，唯一） | 一票否决/恢复权；76/262 映射=行使后自动触发主程序当轮审查报告（只审查不阻挡） |
| 秘书处 | 主程序 | 执行、登记、议程设置；无任何表决权 |
| 非常任理事国 | 轮值子代理席（条文/ROI/逃逸面/用户代言/先例档案/辩护席按需设） | 按议题组成，单届单议题 |
| **独立观察员机构** | **Q 席**（见章程卡） | 咨询性意见，无约束力；类比联大决议之道义分量与 ICJ 咨询意见 |

## 二、真实议事规则内化（本次深化的新增细则）

1. **「出席并参加表决」口径（第一二六条）**：**弃权票不计入分母**——本项目一切 2/3 表决的分母=投赞成/反对票者，弃权席只记入出席。此前各轮未明确此口径，自本规程起统一（过往轮次不回溯）。
2. **修正案最远先决（第一三〇条）**：多修正案并存时，先表决实质内容距原案最远者，依次递进；一修正案通过即意味另一修正案被否决时，后者不再表决。（席3 限定语并入申请书实例=本规则的首次自发运用。）
3. **分部分表决（第一二九条）**：任何席位可请求将提案各部分分别表决；有人反对则先表决「是否分部分」动议本身。（闸门认定 R1–R4 逐项即分部分表决实证。）
4. **平票=否决（第一三三条）**：非选举事项平票视为否决——本项目既有「判断不了按更严重一级处置」同向，正式并轨。
5. **选举二轮+抽签（第一三二条）**：单一席位竞选首轮无人获法定多数时，次轮限于得票最多两候选；再平票抽签。（备而不用条款，子代理席为指定制，暂无选举场景。）
6. **表决留痕（第一二七条）**：一切表决以「记录表决」方式落盘——逐席票型+理由入表决记录（现行实践追认为正式规则）。
7. **表决开始后不打断（第一二八条）**：表决进行中除程序问题外不得插入新议题；投票理由说明限表决前后。

## 三、与既有立法的关系

- 不变项：用户特权（一票否决/恢复+审查报告自动触发）、红线级修订双通过、元认知治理三条件、决策卡3 补强三要件——本规程只深化程序细则，不触碰权力实体。
- 口径统一：本项目一切「2/3」表述自此一律按「出席并参加表决的 2/3」理解（弃权除外分母）。
