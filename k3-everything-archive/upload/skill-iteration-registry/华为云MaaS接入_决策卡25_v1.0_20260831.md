## 二、华为云 MaaS 接入契约（OpenAI 兼容，external_seat.py v0.3.0 契约扩展）

用户动作（网页，无服务器登录）：华为云控制台 → ModelArts Studio（MaaS）→ API Key 管理 → 创建 key → 开通所需模型服务（外部模型甲 系 / GLM 系按 MaaS 当时目录勾选）。

凭证文件 `<用户配置目录>/external_seat.json` 扩展为多模型格式（向后兼容单模型三段式）：

```json
{
  "base_url": "https://<MaaS 接入点>/v1",
  "api_key": "您的华为云 MaaS key",
  "models": {
    "glm52":  "<GLM-5.2 的 MaaS 模型名>",
    "glm51":  "<GLM-5.1 的 MaaS 模型名>",
    "v4pro":  "<外部模型甲-V4-Pro 的 MaaS 模型名>",
    "v4flash": "<外部模型甲-V4-Flash 的 MaaS 模型名>"
  }
}
```

- 一钥多模型：同一 api_key + 同一 base_url，按 models 表换模型名调四席。
- 纪律不变：key 永不入正文/不落盘回执；脱敏评审包（P0/P1）；调用记录入台账；删文件=全体停件；rate≤0.5。
- 「已内置」澄清登记：MaaS 内置的是**模型目录**，**不含本沙箱可用凭证**；实测扫描（env/配置文件/agent-gw 工具表）确认无现成华为 key，如实上报，不假装连通。
