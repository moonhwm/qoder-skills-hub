# 华为云用量全局指标规程 v1.0（2026-08-31 立法）

> 用户立法原文（登记式转录）：「同时注意华为云用量，先实现落实固化这个为所有模型、对话、项目、skill 等的全局性指标。」

## 一、指标定义（全局统一口径）
每一次华为云 MaaS 外部模型调用，必录七元组+归属三元组：
- **用量七元组**：ts / model / prompt_tokens / completion_tokens / reasoning_tokens / cost / ok（+md5 回执指纹）
- **归属三元组**：project（项目）/ skill（技能）/ conv（会话）——缺省记「未归属」，归属缺失本身即为可审计缺口
- **真源**：`registry/蜂群消耗台账.jsonl`（追加式，永不清零，烟测条目即回收）

## 二、适用范围（全局性四域）
1. **所有模型**：glm-5.2 / glm-5.1 / deepseek-v4-pro / deepseek-v4-flash 及未来新增模型一体适用；新增模型先登记刊例价入 hwc_usage.py PRICE 表再调用。
2. **所有对话**：任何会话发起的蜂群调用，conv 字段必填会话标识；会话收尾遥测须附「本轮华为云用量」一行（零调用如实报零）。
3. **所有项目**：蜂群工单（ext_swarm order）必带 project 字段（已实装）；项目档案月度汇总用量。
4. **所有 skill**：技能创建/修订凡涉外部模型调用，必须埋 hwc_usage 记录点（挂接 §11 创建规则，引用不复制）；无埋点的涉模技能=不合规，入册核验退回。

## 三、闸门联动（与卡 29 修正案、阀门 2.0 并轨）
- **日闸 ¥5**：调用前必过 `hwc_usage.py gate`，触及即 ALARM+L1 即报用户，禁止继续扣费调用；
- **总额闸门**：华为云充值总额由用户控制，台账累计为对账真源；
- **单笔上限**：单批工单预算声明制（工单须预估成本，超估 2 倍即熔断该批并 L1 即报）；
- **刊例价漂移**：PRICE 表以官方页面为准，价格调整当轮更新并登记（漂移未更新=台账失真，按缺陷登记）。

## 四、报表与审计
- `hwc_usage.py report [--day]`：总量/分模型/分日/分项目/分技能五维汇总；
- 每轮收尾遥测含用量行；每 3 轮 ROI 回顾时用量为成本项（conf=estimated→台账化后为 empirical）；
- 台账入锚链指纹范围，篡改即链断。
