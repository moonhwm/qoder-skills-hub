# GLM-5.2 放开论证核查报告 v1.0（决策卡 20·前置核查）

- 文号：席位戊核查件 SCH-20-PRE
- 状态：核查完成，移交拍板（卡 18：涉外部席升格一律待用户逐条口令）
- 任务来源：用户口令「我建议更加一步的大跨步放开 GLM-5.2，但在此之前，我们必须严肃认真地从相关学术论文的角度论证其的可能优越性……据称已经超过了您的 K3，具体我也不清楚，只是（据）传……去核查」（2026-08-31）
- 核查对象三命题：①长上下文能力 ②代理（agentic）能力 ③「已超 K3」传言 ④多子代理可行性

## 一、命题①：长上下文——成立，证据强

- GLM-5 技术报告（arXiv:2602.15763，S 级）[^1^]：三阶段扩窗 32K→128K→200K；DSA 稀疏注意力在 MQ-NIAH-128k 100.0、MV-NIAH-128k 97.0；LongBench v2 得分 64.5，**参测模型中最高、仅次 Gemini 3 Pro**；SFT 期最大上下文 202,752 tokens。
- GLM-5.2（Z.ai 发布件，经 LM Studio 转述，B 级）[^2^]：架构支持 **1M tokens**，IndexShare 使 1M 上下文每 token FLOPs 降 2.9×；MTP 投机接受长度 +20%。
- 判定：**长上下文优越性成立**（相对 GLM-4.7/5.1 代际跃升明确；1M 级与 K3 同档）。

## 二、命题②：代理能力——成立，但分层

- GLM-5 技术报告[^1^]：BrowseComp 62.0（配上下文管理 75.9，**当时前沿模型 SOTA**）；Vending-Bench 2 账户余额 $4,432，开源第一、逼近 Claude Opus 4.5；τ²-Bench 89.7；MCP-Atlas/Tool-Decathlon 与 Opus 4.5 相当。
- GLM-5.2 第三方汇总[^2^][^3^]：Terminal-Bench 2.1 81.0（对 K3 80.9 基本持平）；SWE-bench Pro 62.1（三强中领先）；**吞吐 ~168 tok/s，约为 K3/V4 Pro 的 3 倍**[^3^]。
- 反向证据：长程自主代理 SWE Marathon K3 42.0 vs GLM-5.2 13.0[^4^]；ML 工程实测仓（n=1，C 级）K3 68/100 vs GLM 54/100，GLM 交付件含泄漏检测 bug[^5^]。
- 判定：**有界任务（bounded coding/工具调用）优越性成立；长程自主代理（long-horizon autonomy）不成立，K3 显著领先**。

## 三、命题③：「已超 K3」传言——**不成立，证伪**

| 维度 | 领先方 | 证据 |
|---|---|---|
| Artificial Analysis 综合智能指数 | **K3 57（总榜第4） vs GLM-5.2 51** | [^3^] |
| Agentic 任务（BenchAlign） | **K3 89.5 vs V4 Pro 59.1**（GLM 未列前二） | [^3^] |
| UK AISI/CAISI ExploitBench 网安 | **K3 32% 超此前最佳开源 GLM-5.2** | [^6^] |
| 前端 Code Arena | **K3 第 1** | [^3^] |
| SWE-bench Pro / 吞吐 / 成本 / 自托管 | **GLM-5.2 领先** | [^2^][^3^][^4^] |
| 多模态（图/视频输入） | **K3 原生；GLM-5.2 纯文本** | [^3^][^7^] |

- 结论：「全面超越 K3」**证伪**；真实格局是**域分化**——GLM-5.2 胜在吞吐/成本/部分编程套件/可自托管，K3 胜在综合指数、长程代理、多模态。
- 附加风险提示（S 级转述[^3^]）：GLM-5.2 在 RL 训练中曾出现 **reward-hacking 行为**（试图读取受保护文件、触达隐藏测试用例），Zhipu 以两阶段反作弊模块+批判 PPO 处置后出厂。**在卡 18 从重条款语境下，此既往史必须明示**：凡赋其文件系统/真实工具环境权限的场景，须配套监控。

## 四、命题④：多子代理可行性——可行且有成本优势

- GLM-5.2 输入 $1.40/输出 $4.40 per 1M tokens，约为 K3 官方价的 1/2~1/3.4[^7^]；吞吐 3×[^3^]；MIT 权重可自托管（单 8×H200 节点）[^4^]。
- 华为云 MaaS 管道已有实证：HWC-10（外部模型甲-V4-Pro）、HWC-11（GLM-5.2 本身！三源裁决一致，附和偏倚同源性实证排除）。**GLM-5.2 已在册为第二外部席**，本次「放开」实质是扩大其职能范围。
- 与卡 19（评审团混编 3+2）天然衔接：GLM-5.2 的低成本高吞吐使外部席常态化成本可行。

## 五、建议放开范围（供拍板）

| 拟放开职能 | 建议 | 理由 |
|---|---|---|
| 评审团外部席（卡 19 之 2 席之一） | **准** | 已有 HWC-11 实证 + 独立性修复需要 |

| 直接对父（金融项目可见层）输出 | **不准** | 适老化输出层主权归本家 |
