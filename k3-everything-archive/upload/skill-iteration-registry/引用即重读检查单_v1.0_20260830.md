# 引用即重读·半机检检查单 v1.0（2026-08-30 设立）

> 来源：《减回忆依赖机制有效性评估》增量建议②（B 轮附随工程项）。ops §11⑫ 的半机检化起步件。
> 触发：任何编辑动作中，new/old_string 含①引文（「」内引述他文）②行号引用③版本号+文件名组合 时，执行本单。

## 三步（当次执行，禁凭记忆）
1. **重读原文**：对被引文件当次 grep/直读（不得以会话记忆中的内容替代）；
2. **比对留痕**：在编辑当轮记录 [被引文件路径｜行号｜版本语境｜核验结果 MATCH/MISMATCH]；
3. **不一致处置**：MISMATCH → 编辑作废，按原文重做；漏留痕 → 视同未核验，逃逸登记。

## 配套机检现状
- 全自动探针待 B 轮（verify_legislation 增红线探针组候选之一）；
- 本单为人工+grep 半机检，成本每个引用点约一次 grep。

## 启用登记
- 2026-08-30 设立即生效（操作级纪律，非红线，无需双通过；违反后果沿用 §11⑫：编辑作废重做+逃逸登记）。
