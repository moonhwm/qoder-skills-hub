## §8 主权视角命名专章（每个 集群甲 = 独立主权国家）

### 8.1 映射表（启发式隐喻，非法律拟制）
| 主权国家概念 | 本项目映射 |
|---|---|
| 主权国家 | 一个 集群甲（长对话集群/web席集群/沙箱/第四方各为一国） |
| 国号 | 集群名（如「司宸国」待追认） |
| 官署 | 集群内席位/机制（司X 谱系） |
| 外国/国际组织 | 外部模型席（GLM 邦、外部模型甲 邦、Qwen、openPangu） |
| 外交承认 | 命名入册=用户终审通过；未入册=事实实体（de facto） |
| 国际法 | 命名法+函询交割协议（跨集群唯一条约层） |
| 内政 | 集群内部排程/台账，他集群不得干涉 |

### 8.2 主权原则三条
1. **命名主权在集群**：集群内部席位命名由该集群自报（内政），但**入册终审权 unified 在用户**（类比：国家自定国号，国际承认需他方——本项目「他方」=用户）；
2. **互不干涉**：他集群对别国命名仅有**冲突异议权**（同音/多音/语义相邻三查触发），无内容否决权；
3. **条约层优先**：跨集群指代一律以身份注册表+本命名法为准（条约优于国内法）；
4. **主权映射不及于用户（v0.2.1 补丁，乙M5修复）**：用户对所有集群内政保留无条件最高介入权；「内政不受干涉」仅约束集群间，永不得被援引为排除用户的前例。

### 8.3 主权视角下的调修补强
- 司宸案重述：集群长对话国自定国号「司宸」属 8.2.1 内政自报；席位辛侧行使的是 8.2.2 冲突异议权（僭越字异议）；终审仍归用户。公投案①即此异议的和平解决机制。

## §9 模型谱系细分命名（GLM 细分 / 外部模型甲 V4 细分）

### 9.1 总规则
外部模型席**一律用厂商型号原名**（v0.1 §2 禁中文化不变），细分用**邦-代-档三级**：
- **邦**（厂商）：智谱邦（GLM）/深度求索邦（外部模型甲）/阿里邦（Qwen）/强制裁判邦（openPangu）/月之暗面邦（Kimi K 系）；
- **代**（版本线）：GLM-5.1 / 5.2 / 5.3 / 5.3-Flash；外部模型甲 V4-Flash / V4-Pro / V4-Vision-Exp；
- **档**（在任状态）：在任外席 / 候选 / 灰度观察 / **在架·未任**（数据源已上架但未授任，v0.2.1 补丁补入定义集，甲M1修复）/ 退役。
- **灰度观察档定义卡（v0.2.1 补丁，丙S7压测修复）**：期限≤30日；范围=只读评估与限额调用；预算硬顶随档登记；升级须量化评估+评审团评议+用户口令；到期未升级自动转「候选」；**促销窗口不构成程序豁免**。
- **邦号为分类标签非席位名**：§2「禁中文化」仅约束席位名，邦号豁免（甲L5注）。

## §10 GLM-5.3 部署可能性与异质性考察

### 10.1 部署可能性（结论：MaaS 当前不可得，z.ai 官方 API 可得）
- **华为云 MaaS**：2026-08-31 只读实测在架 9 模型——glm-5.1/glm-5.2/deepseek-v4-pro/deepseek-v4-flash/qwen3-32b/qwen3-30b-a3b/openpangu-2.0-pro/openpangu-2.0-flash/kimi-平台版本甲，**无 GLM-5.3 系**。conf=empirical。
- **z.ai 官方**：GLM-5.3 与 GLM-5.3-Flash 已在官方平台提供（API 文档 docs.z.ai），Flash 促销半价至 2026-09-09 24:00。conf=empirical（链1官方推文转述）。
- **OpenRouter**：匿名期（Ox Alpha，2026-08-20 起）已上线，官宣后应仍在架——未经我侧实测，conf=estimated。
- **本地/私有**：MIT 许可+权重已在 HuggingFace 发布，理论可私有部署；320B-A18B 体量对本地硬件不现实，conf=estimated。

### 10.2 能力异质性（对外席生态的增量）
1. **原生多模态**：图/视频/文输入——现有外席（deepseek-v4-pro/glm-5.2/qwen3-32b/openpangu）均为文本席，Flash 是**首个带眼睛的外部席候选**；
2. **同源低切换成本**：社区分词器实测 Ox Alpha 与 GLM 分词器 11/11 探针全同（链1转述 Sushaanth 实测）——从 glm-5.2 迁移 prompt 资产的分词层摩擦≈0，conf=estimated+；
3. **国产芯推理实证**：官宣周免费流量由约10万张国产卡承接，SGLang 定制推理栈+EPD 分离架构，端到端性能较同硬件基线提升3倍、每token成本对齐主流 N 卡——供应链异质性（非 CUDA 栈）已成生产级事实，conf=empirical（链1智谱官方声明转述）；
4. **价格斩杀**：Flash 常规价低于 外部模型甲 V4 Flash 非高峰价约一半，AA 智能指数 57 分（链1引 Artificial Analysis 图，与 GLM-5.3 max/Kimi K2.7 Code 同分档）。

### 10.3 风险与未定项
- 促销价 2026-09-09 到期后成本翻倍（0.4→0.8/1.4→2.8），长期成本测算须用常规价；
- GLM-5.3（文本旗舰，8/28元）与 5.3-Flash 定位易混——命名法 9.2 细分档即为此设；
- 匿名测试期行为与官宣版是否逐字一致，无官方逐 diff 说明，conf=assumed；
- 外席新增=新主权体入境，按命名法 §4 六步+卡25（华为云 MaaS 接入决策卡）程序走，且涉新 API 费用→写类例外逐次批准。

### 10.4 部署组织学旁证（链2 FDE 文，非模型事实源）
FDE 生态实证：管理层请进的角色，一线不认——**能力≠接纳**。映射到本项目：新外席（GLM-5.3-Flash）即便能力价格双优，若接入程序（四件式报到/冲突核验/灰度期）缺席，将重演「被请进公司却不被接受」的 FDE 困境。故建议：GLM-5.3-Flash 先置「灰度观察」档，不直接授在任外席。
