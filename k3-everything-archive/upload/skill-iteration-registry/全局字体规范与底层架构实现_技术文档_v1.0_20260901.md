# 全局字体规范与底层架构实现技术文档 v1.0（2026-09-01）

> 立法来源：用户口令「全局、全项目周期、全对话、全 skill 及 skill 创建等从此规范有关字体为宋体（中文）、Times New Roman（英文），自主探讨如何从自我底层构架实现」。
> 性质：全局规范（G 级），一体适用于一切产出物与一切未来技能；修订走版本三段制。

## 1 规范本体

### 1.1 字体对（唯一法定）
- 中文：**宋体**（SimSun / Songti SC / Noto Serif SC，按平台可得性回退）；
- 西文/数字：**Times New Roman**（回退：Times → serif）。

### 1.2 适用范围（全局四域）
- 全项目周期：一切文档（md/docx/pdf/pptx/xlsx/html）从立项到归档；
- 全对话：交付给用户的任何排版产物；
- 全 skill：既有技能未来修订时模板对齐；skill 创建时模板即合规；
- 例外声明：代码块/终端截图等保真场景不受字体规范约束（等宽字体优先），规范管「阅读面」不管「保真面」。

### 1.3 级别语义
- 标题可用宋体加粗；正文常规；**禁止**衬线对之外引入第三字体族（除等宽代码域）。

## 2 底层架构实现（分介质）

### 2.1 Markdown（源码层）
- md 本身无字体语义——规范落在**渲染层**：凡 md→docx/pdf/html 的转换器，样式模板须内置本字体对；
- 技能模板（.skill 内 md）不写字体声明，由消费端渲染器保证。

### 2.2 DOCX（OpenXML 层）
- styles.xml 的 Normal 样式：`w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman" w:eastAsia="宋体"`——eastAsia 管中文、ascii/hAnsi 管西文，一标签双字体即为底层实现；
- 本次已验证：`python-docx` 中 `r.font.name='Times New Roman'` + `r.element.rPr.rFonts.set(qn('w:eastAsia'),'宋体')` 即此机制（备案说明书 docx 已合规）。

### 2.3 HTML/网页（CSS 层）
- 法定栈：`font-family: "Times New Roman", "Noto Serif SC", "Songti SC", "SimSun", serif;`
- 顺序语义：西文先命中 Times New Roman，中文自动落到链上首个可用宋体系字体；
- 单文件交割 HTML（handover-template）v3 已用近似栈，v3.1 起对齐本规范（Times New Roman 提前至链首）。

### 2.4 PPTX / XLSX
- PPTX：主题字体 `majorFont/minorFont` 的 latin=Times New Roman、ea=宋体；
- XLSX：工作簿默认字体同理双轨；图表字体随主题。

### 2.5 PDF
- HTML+Paged.js 管线：随 CSS 栈；LaTeX 管线：`\setmainfont{Times New Roman}` + xeCJK `\setCJKmainfont{SimSun}`。

### 2.6 图表/图像（matplotlib 等）
- rcParams：`font.serif=['Times New Roman','SimSun']`、`font.family='serif'`；注意沙箱已预置中文字体配置时不得覆盖（沿平台约定），图表导出前核对中英文各自命中。

## 3 从自我底层构架实现的探讨（自指条款）

### 3.1 我能自控的层
- 生成层：一切我产出的 docx/html/pptx/xlsx/pdf 模板——**本规范即刻生效**，新产物默认合规；
- 技能创建层：skill-creator 流程产物（SKILL.md 无字体语义）不受影响；但技能 assets 中的模板文件（如 handover-template.html）须合规。

### 3.2 我不能自控的层（诚实边界）
- 对话渲染层：聊天界面字体由 Kimi 客户端样式决定，不在我可写范围；
- 用户侧查看器：用户本地字体缺失时的回退结果不可控（故规范以「字体栈」而非「单字体」立法）。

### 3.3 执行钩
- 产物交付前过闸一句自检：「中文宋体？西文 TNR？」——并入 output-verdict-gate 的样式判据（写回队列登记，安装位只读期间以对话内纪律执行）。

## 4 agent 短文本安装与多子级标题文档（配套规程）

### 4.1 短文本安装（agent 导入）
- 定义：将技能核心指令蒸馏为**短文本块**（≤2KB，frontmatter+核心规程），agent 会话开场粘贴即临时生效——适用无安装位/跨平台/微信好友场景；
- 与 .skill 包的关系：短文本=「平装本」，.skill=「精装本」；内容同源，短文本由 SKILL.md 蒸馏生成，版本号随行；
- 每个技能创刊/修订时同步产出短文本蒸馏版（up-distill-ops 占位能力）。

### 4.2 多子级标题技术文档规程
- 技术文档默认三级起步（#/##/###），层级即论证层级：级内聚合、级间递进；
- 每级标题须可独立成句回答「这节讲什么」；
- 本文档即范本（4 一级/9 二级/5 三级）。
