# flight 模块：航班查询（合规三层路径）

## 定位

国内无免费官方航班 API（中国航信 IBE 企业级/飞常准不免费/民航局开放平台需实名且限次/Flightradar24 付费）。本模块提供**三层合规路径**，按可得性依次降级。

## Layer 1：OTA 查询链接生成（默认）

```bash
python3 scripts/flight_query.py --from 衡阳 --to 广州 --date 2026-09-01
```

- 城市支持中文名（内置拼音码 + IATA 映射，东莞等无机场城市映射最近机场如 SZX）
- 输出四大平台可点击 URL（去哪儿支持中文城市名直链），用户自行打开查价

## Layer 1.5：搜索快照实测（OTA 直连受阻时的实测降级，v1.1 新增）

**触发条件**：自动化环境内 OTA 列表页超时/反爬（实测记录：携程/去哪儿/同程/Trip.com 在本沙箱全部直连失败，2026-08-24）。

**流程**：
1. 生成查询串：`python3 scripts/flight_snapshot_queries.py --from 长沙 --to 成都 --date 2026-09-10`（`--batch routes.json` 批量）
2. agent 用 web_search 执行 4 条查询/航线，从快照提取**带日期的真实报价**
3. 数据源优先级：**OTA m 站航线页快照（dated 低价日历）> 天巡 Skyscanner 航线页（含"整月最低价"）> 媒体行情稿（新浪/澎湃出行版）**
4. 登记纪律：conf=**C级（快照实测）**；必须记录①快照日期②来源 URL③"快照价≠下单页价"声明④机建燃油口径——**禁止硬编码费率，引用时须用 web_search 核当月值**：机建（民航发展基金）国内线 ¥50 固定；燃油附加按出票月航司公告（锚点：2026-08-05 起 800km+ ¥70 / 以下 ¥40，合计 800km+ ¥120；2026 年内曾 ¥20→170→70 八倍摆幅，S级源：央视/人民网/新华网）
5. 复核纪律：出行前 30/14/7 天三次在 OTA 下单页复核；旺季/临期可上浮 40–100%
6. 诚实声明：引用时写明"OTA 直连受阻，改用搜索快照"——禁止把快照价表述为"实测下单价"

**产出格式**：`| 航线 | 快照数据点(dated) | 裸票区间 | 含税估算 | 来源 |`，多个数据点取 min–max。

## Layer 2：估算锚点（无网/无快照时兜底）

- 按航距档位给历史区间（如 800–1500km 干线淡季 ¥300–600），conf=estimated，且必须给 Layer 1 链接供复核

## 红线

- 禁止实现/调用飞猪 MTOP、途牛 deviceId 等逆向接口（ToS + 法律灰色地带）
- 禁止伪造航司官网深链；如需官网，给航司首页 + 检索路径
- Layer 1.5 仅限"公开搜索结果快照"，禁止模拟登录/绕反爬抓取 OTA 页面本身
- 链接查到的票价由用户侧截图/录入，引用时标 conf=estimated（OTA 动态定价）
