## 拔插规程

**拔出模块**：删除 `scripts/<脚本>` + `references/module-<名>.md` + SKILL.md 注册表一行。其余模块零影响（模块间无 import 依赖，仅文档级组合）。

**插入新模块**：
1. 脚本进 `scripts/`，必须纯标准库或自带依赖说明；无外部服务时要能优雅降级（exit code 约定：2=缺配置、3=数据源不可用）
2. 写 `references/module-<名>.md`：用法/依赖/降级/红线
3. SKILL.md 注册表加一行 + 路由表加一行
4. 本文件登记来源与验证记录

**模块自检**（每次任务路由前）：
```bash
ls scripts/                    # 模块在位？
echo $AMAP_WEBSERVICE_KEY      # amap 模块需 key？
```
缺失即走降级列，如实告知用户，禁止假装模块存在。

## 退出码约定（全模块统一）

| code | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 参数/查询错误 |
| 2 | 缺配置（如 key），输出申请指引 |
| 3 | 数据源不可用/被拒（如反爬），输出降级建议 |
