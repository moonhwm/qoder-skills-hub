## 1. 通道总览与选择

| 通道 | 适用 | 入口 | 稳定性 |
|---|---|---|---|
| 官方 xpan API | 用户**本人网盘**文件 | `baidu_share_browse.py --token T --dir 路径` | 官方文档化，较稳定 |
| 分享页枚举 | 他人/自己生成的**分享链接** | `baidu_share_browse.py --share URL --pwd 提取码` | 逆向接口，可能失效 |

access_token 必须由用户本人在百度网盘开放平台创建应用并走 OAuth 获取；
**脚本只接受 `--token` 参数，绝不代申请、不内置任何 token**。

## 2. 官方通道：xpan 开放平台接口表

| 用途 | 方法 | 端点 | 关键参数 |
|---|---|---|---|
| 列目录 | GET | `https://pan.baidu.com/rest/2.0/xpan/file?method=list` | `dir`, `access_token`, `start`, `limit`（分页，limit≤1000） |
| 取直链 | GET | `https://pan.baidu.com/rest/2.0/xpan/multimedia?method=filemetas` | `fsids`（JSON 数组，**上限 100**）, `dlink=1`, `access_token` |

- 列目录响应：`{"errno": 0, "list": [{"fsid", "path", "server_filename",
  "size", "isdir": 0|1, "server_mtime", "category", ...}]}`；
  `errno != 0` 为确定性失败，如实记录不重试轰炸。
- category 取值：1 视频 / 2 音乐 / 3 图片 / 4 文档 / 5 应用 / 6 其他 / 7 种子。
- filemetas 常见错误码：42211-42214（参数/fsid 相关，详见官方文档）。
- `server_mtime` 为 Unix 秒，登记时转换为本地日期串。

## 3. dlink 使用纪律（UA / 31362 / 时效）

- dlink 是**临时链接，约 600 秒失效**；取到后应立即使用并记录取得时间，
  过期后重新走 filemetas 取新链，**不缓存复用旧链**。
- 下载 dlink 必须携带请求头 `User-Agent: pan.baidu.com`；缺该 UA 时大文件
  （>20M）会报错 **31362 "sign error"**。脚本在下载与冒烟中固定携带该 UA。
- dlink 直通的是文件字节流，仍受账号限速约束（见下节）；拿到 dlink ≠ 高速。

## 4. 限速事实（如实提示，禁止夸大）

- 非会员实测约 **96-170 KB/s**（2025-03 媒体实测，conf=estimated）；
  SVIP 约 7-10 MB/s；2025 年起按资源热度调度，实际速率随时变化。
- 脚本输出与证据中**必须如实附限速提示**；**禁止暗示"可突破限速"**。
- 第三方"不限速解析工具"：只作**风险提示记录**（安全与账号封禁风险），
  绝不集成进本管线。

## 5. 分享页通道（逆向，不稳定）

链路（均为对 pan.baidu.com 的网页逆向调用，**非官方承诺接口**）：

1. `GET https://pan.baidu.com/s/{surl}` 取分享页 HTML，从页面 JS 中提取
   `shareid` / `uk` / `sign` / `timestamp` 等参数（页面结构常变，需现场核对）。
2. `POST /share/verify?surl={surl}&t={ts}` 表单 `pwd=XXXX` 验证提取码，
   成功时服务端置 cookie（BDCLND），后续请求须携带。
3. `GET /share/list?shareid=&uk=&sign=&timestamp=&dir=&page=1&num=100`
   分页枚举；响应 `{"errno": 0, "list": [...]}`，条目同样含
   `server_filename/path/size/isdir/server_mtime`。

**警示**：该通道依赖页面内部 JS 约定，百度可随版本更迭使其失效；每次开跑
前重新核对分享页；失效时如实报告"逆向通道当前不可用"，不伪造枚举结果。

## 7. 合规边界

- 仅限归档**用户本人文件**或**获授权**的分享；分享链接归档沿用
  `legal_notes.md` 的字幕组式注记与"授权范围限定"铁律。
- 403 / errno 权限类失败是确定性结论：不重试、不绕过、不伪造成功。
- 不使用、不集成第三方"不限速/破解"工具；用户询问时只给风险提示。
- 清单与登记册的 license_note 字段如实写明获取方式与授权边界。

## 8. 退出码语义

`baidu_share_browse.py` 沿用本技能统一语义：

| 码 | 含义 |
|---|---|
| 0 | 成功（含"成功枚举、如实登记失败项"的情形） |
| 2 | 环境/依赖类失败（如缺失必需运行条件） |
| 3 | 参数或授权缺失：缺 `--token` / 缺 `--pwd` / 未获授权即触发受限动作 |
| 4 | 网络/接口失败：HTTP 非 200、errno 非 0、超时等，**证据已落盘后诚实退出** |
