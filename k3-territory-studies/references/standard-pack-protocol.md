# 综合指令包标准处置规程（提示词模板）v1.0 — 2026-09-01

> 定位：把所有者语音输入的长篇多指令包（"综合指令包"）固化为可复用的标准处置流程。与 skill-dispatch-hq（治理协议）联挂，本规程为执行侧 playbook。
> 诞生依据：2026-09-01 第8轮实证（指令包原文见 <工作区根>/temp/ 上传件；处置全程见调度留痕第8轮）。

## 0. 触发
所有者发送多主题混杂的长语音指令（特征：多议题交织、口语/谐音变体、含既往指令重述、含玩笑与括号注）。触发后**先写 plan.md 与待办清单**，再动手。

## 1. 解析段（语义校正）
- 查《语音变体注册表》映射变体（conf=High 直接用，Low 登记待确认）；新变体当轮回灌注册表。
- 全句切分为原子指令，二分：**既往已办**（回指留痕编号，不重复执行）与**本轮新增**（入待办）。
- 矛盾点/语义未明处：显式标注，不擅自猜测高影响项。

## 2. 诚实边界先行（开口先报）
- 技术上限实况（蜂群 16 存活/8 并行等）；不可访问资源（需登录链接等）；破坏性操作（删 key 等）一律转"提案+所有者显式复核"，不先斩后奏。
- 沙盘类比声明：国家/主权/公投等词不主张法律效力。

## 3. 扫描段（涉自身事务盘点）
- <通道库>：founding_documents/laws/citizens/ledger/cron_ledger/broadcasts 六表全扫；
- 交割台账（consignment-intake-ops）：`status` 总览 + `overdue 24` 逾期扫描；
- 会话探针：他席在轨事项只读登记，**不代办**；
- 产物：涉本席在途事项清单（含期限），逐条拾取入 broadcasts。

## 4. 凭据段（凭据主权规程）
- 指纹制清点（sha256 前12位+长度，不落明文）；逃逸检查=对 output 与 registry 全文扫明文命中，只报命中数与路径；
- 处置提案分级：删除须所有者显式复核；与他席在轨冲突时建议缓删并说明依赖链。

## 5. 研究段（研究≠写作）
- 外部研究派 explore 子代理（来源须 URL+访问日期+可信度自评，禁止编造）；
- 内部证据主代理只读盘点（registry 留痕，不揣测他席意图）。

## 6. 表决段（涉议案时）
- 蜂群公投标准配置：8 席代表（五常5+非常任2+公民资产民1），后台并行，每席三行回执（表决/理由含风险/修正建议）；
- 计票如实公布（含否决）；修正共识收敛为修正案再交联署。

## 7. 产出段
- writer 子代理成文（卷首边界声明+结构章节+附录证据指针）；评审席三轴验收（严肃性/准确性/诚实边界）；REVISE 则返修；
- docx 经 md2docx 转换并验证；**同一文件禁止并行编辑**（同文串行编辑律）。

## 8. 固化段
- <通道库>：文献入 founding_documents（>10k 字符分块 append）、法案入 laws、账入 ledger、函件入 broadcasts；
- correspondence 落盘（一函一事）+ 调度留痕追加 + verifier run 记录；
- 广播：主通道=落盘恒常；次级通道（服务甲 等）故障即诚实申报并转待重试。

## 9. 回执段
五段式（完成情况/证据指针/偏差与未遂/越界声明/签名）+ **待所有者拍板清单**（带期限者置顶）。

## 附：标准提示词骨架（供实例加载即复用）
```
[角色] 调度总署当值主会话，治理框架=skill-dispatch-hq。
[输入] 综合指令包原文 + 语音变体注册表 + registry 扫描件。
[流程] 解析→边界→扫描→凭据→研究→表决→产出→固化→回执（九段）。
[纪律] 预算先声明；研究写作分离；同文串行；指纹制凭据；五段式回执；待拍板清单收尾。
[输出] plan.md、待办清单、各段产物、verifier run、最终回执。
```
