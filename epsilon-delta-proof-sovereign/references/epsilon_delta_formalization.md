# ε-δ 形式化模板库(epsilon_delta_formalization.md)

> 用途:把自然语言数学分析命题落成机器可处理的形式语句。每族给:形式语句、否定式、机选 δ 的构造法、Lean4 着陆点。

## §1 极限 lim_{x→c} f(x) = L

- 形式语句:`∀ε>0, ∃δ>0, ∀x, 0<|x-c|<δ → |f(x)-L|<ε`
- 否定式:`∃ε>0, ∀δ>0, ∃x, 0<|x-c|<δ ∧ |f(x)-L|≥ε`(反例搜索的语法)
- 机选 δ:①f 线性(ax+b)→ δ=ε/|a|;②f 二次且在 c 的有限邻域→ 用 |x+c|≤2|c|+1 放大,δ=min(1, ε/(|a|(2|c|+1)));③有理函数→ 分母下界估计后化多项式情形。
- Lean4:`tendsto f (nhds c) (nhds L)` 或 `Metric.Tendsto`;Mathlib 证明套路:`rw [Metric.tendsto_nhds_nhds]` 后 intro ε hε 取 δ。

## §2 连续(点态)f 在 c 连续

- `∀ε>0, ∃δ>0, ∀x, |x-c|<δ → |f(x)-f(c)|<ε`(与极限同型,L=f(c),允许 x=c)
- 否定式同 §1 把 L 换成 f(c) 且允许 x=c 占位。
- 机械化:初等函数的连续性走**组合子证明**(连续函数加/乘/复合仍连续),Mathlib:`Continuous.add/.mul/.comp`,优于裸 ε-δ。

## §3 一致连续 f 在 S 上一致连续

- `∀ε>0, ∃δ>0, ∀x y∈S, |x-y|<δ → |f(x)-f(y)|<ε`(δ 不依赖 x,y——机械化的关键是消去点参数)
- 否定式:`∃ε>0, ∀δ>0, ∃x y∈S, |x-y|<δ ∧ |f(x)-f(y)|≥ε`(需构造两列点列)
- 判定辅助:Lipschitz(|f'| 有界)⇒ 一致连续,δ=ε/M;Cantor(紧集上连续)⇒ 一致连续,证明用有限覆盖——Lean:`CompactSpace`/`UniformContinuousOn`。

## §4 导数 f'(c)=A

- `∀ε>0, ∃δ>0, ∀x, 0<|x-c|<δ → |(f(x)-f(c))/(x-c) - A|<ε`
- 机械化:差商模板同 §1;Lean:`HasDerivAt f A c`,组合子链 `hasDerivAt_add/mul/chain`。

## §5 积分/级数收敛

- 定积分(黎曼):`∀ε>0, ∃δ>0, ∀分割 P, mesh(P)<δ → |Σ f(ξ_i)Δx_i - I|<ε`
- 级数收敛:`∀ε>0, ∃N, ∀n≥N → |s_n - S|<ε`(ε-N 语句,δ 的离散对应)
- 机械化:N 的构造同 δ(放大法+单调有界/柯西判据)。

## §6 三类机选 δ 公式卡(管线第2步用)

| 情形 | δ(ε) 候选 | 证明战术 |
|---|---|---|
| 线性 ax+b | ε/|a| | 直接代入 |
| 多项式(局部) | min(1, ε/M),M=邻域放大系数 | 放大法 |
| 1/x 型(x→c≠0) | min(|c|/2, ε|c|²/2) | 分母下界 |

## §7 常见形式化事故

1. 忘写 0<|x-c|(把极限写成连续);2. 否定式量词序错(∃∀∀∃);3. 一致连续把 δ 写成 δ(ε,x);4. Lean 中 nhds 与 atTop 混用;5. 数值侦察通过就当已证(红线,见 SKILL.md §5)。
6. 判分须宽容记号变体(2026-09-02 GLM 压测实证):LaTeX 形态(\exists\varepsilon_0、S_n、\delta)不被朴素关键词覆盖——否定式维关键词命中仅 3/15,人工抽检却满分;凡用关键词判具评本技能答卷,先把 LaTeX/Unicode/口语三种记号形态归一,再命中计数,否则低估约一半。压测档案见 references/pressure_test_20260902.md。
