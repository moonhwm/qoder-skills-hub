# 城市结论 PPP 复核台（ppp-city-verdict-audit）

> v1.0 ｜ 2026-08-25 ｜ 修改人：Orchestrator（Kimi K3），源自项目 med-career-transition-L 的实战方法论沉淀
> 定位：**对既有城市结论做对抗性复核**，不是从零做城市评估。输入=结论清单，输出=维持/翻案/上调判定+留痕登记。

## 何时用 / 不用
- 用：已有一份城市/地区结论（淘汰表、候选表、否决清单），需要逐城验证其成立性；交通/距离是否决理由时需要实测重估。
- 不用：从零开始的城市初选（先完成首筛再来复核）；单个城市的事实问答。

## 三条铁律（血泪教训）
1. **省级均薪≠市直个案**：用省级城镇非私营均薪淘汰城市会系统性误杀（实测误差可达 40%+，贵阳/沈阳翻案即此产物）。任何"工资低"类淘汰理由必须要求**市直/省直公务员或目标岗位个案**再判定。
2. **距离否决须过交通实测双通道**：铁路（12306 全量）+ 航班（直飞/班次密度/含税价快照）。只要存在「直飞 ≤5h 且含税 ≤¥1,200 且周班次 ≥20」，距离否决一律降级为「距离折价」（回家频率从月→季，但非年度事件）。
3. **每条判定必须留痕**：维持/翻案/上调 + 修改人 + 日期 + 证据文件路径 + 旧结论原文。无留痕的复核等于没做。

## 工作流（四阶段）

### 阶段 0：结论登记
把待复核清单整理为 verdict register（每条：城市、原结论、原理由原文、原依据分级）。模板见 [references/verdict-register.md](references/verdict-register.md)。
- **必登基准城**：人物家乡/现居地为基准城，PPP 双锚对基准城同步计算（支配性检验，见 ppp-paradigm.md 相对锚节）。
- **必登原阈值**：原理由含「压线/偏低/偏高」类相对比较词时先登记原阈值；不可得时声明假设阈值并做 ±敏感性。

### 阶段 1：PPP 双锚 + 通勤核查（每城一组数据）
- PPP 范式细则（双口径工资、房价收入比、租售比、引才包折现、判定带）：[references/ppp-paradigm.md](references/ppp-paradigm.md)
- 用 `scripts/ppp_calc.py` 计算：房价收入比、月供占比、租售比、引才包等效年薪加成
- 通勤核查规程（铁路 --full 陷阱、航班 Layer1.5 快照、含税口径、判定树）：[references/commute-audit.md](references/commute-audit.md)
- 铁路/航班工具直接调用 travel-commute-planner 技能脚本（不重复造轮子，仅引用）：`train_query.py --full`、`flight_query.py`、`flight_snapshot_queries.py`

### 阶段 2：Swarm 并行单城补采（尽量多代理）
- 编排规程与代理 prompt 模板：[references/swarm-review.md](references/swarm-review.md)
- 每城 1 个 explore 代理（待遇个案/房价分区/引才原文/医疗体系/气候生活/岗位入口六维），并行上限 8
- 每批后 1 个 verifier 代理做对抗复核（专挑：个案孤证、口径偷换、旧数据、编外陷阱）

### 阶段 3：判定 + 留痕
- **判定前两道闸门**：①结论稳健性（原理由全部被驳倒后，是否存在独立支撑原结论的新证据？红旗清单每项须回答"此项是否改变判定"）；②支配性检验（候选城 vs 基准城零溢价规则）。**驳倒原理由 ≠ 翻案**
- 判定四态：**维持**（证据加固）/ **维持·理由重构**（结论方向不变但理由失实，须给替换理由）/ **翻案**（原结论错误，须写翻案证据链；默认落「观察」，双锚舒适+岗位入口实证可行才落「候选」）/ **上调·下调**（层级移动）
- 写回 verdict register（含修改人/日期/证据路径），输出复核总表 + top3_likely_wrong
- 信源分级沿用 A/S/B/C/D/E；个案 B-/E 级必须 ±误差声明

## 红线
- 不编造任何数字；缺口如实声明并给"推翻方法"
- 不用 OTA 逆向爬虫（携程/去哪儿/MTOP 等），航班价格一律 web 搜索快照口径
- 翻案必须给出证据链（≥2 个独立证据点）且先过双闸门；单孤证只能标记"存疑待复核"不能翻案
- 翻案率自检：一批复核翻案率 >50% 时，逐案复查是否漏做支配性检验

## 实战验证摘要（skill-creator swarm 评估）
- iteration-1（eval-1 合肥配对）：comparator 盲评 with_skill 胜（五维全覆盖+全数字可复算）；analyzer 6 项 issue → v1.1（基准城支配性检验/维持·理由重构/房价双源铁律/单代理降级/原阈值登记）。
- iteration-2（v1.2 复跑合肥）：落「维持·理由重构」命中 analyzer 验收区间（推翻 iteration-1 的漏闸翻案）；独立 verifier 复验 **ACCEPTED**（5/5 pass：register 字节级脚本生成、零溢价比 0.99≤1.1 复算成立、长沙房价独立命中原始信源、ppp_calc×6 情景复算一致、流程无跳步）。瑕疵 2 项：编外证据评级过评（A+C 误写双 A）、ppp_calc 标签口径 → v1.2.1 已修标签；评级过评教训写入 verifier 清单适用注意（证据分级以原始件为准，转述不得升级）。
- iteration-3（排期 2026-11-24）：换城市（郑州）配对 eval 防过拟合 + livability 互链复验。
- iteration-3 前插入自批判轮（2026-08-27，K3 / iteration-convergence-ops 四拍）：9 错点表（含「阈值体系未经外部校准」自曝，High）→ v1.3 修复 8 项：月供分母文档同步、explore 模板去医学化、verifier 补支配性检验项、工具路径核验化、利率快照纪律、津贴龄期警示、register schema 对齐、租售比标签消歧。阈值外部校准未做，列入 P2 排期，禁止提前声称。
