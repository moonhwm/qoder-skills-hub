# 通勤核查规程（铁路 + 飞行双通道）

> v1.0 ｜ 修改人：Orchestrator（Kimi K3），2026-08-25
> 工具全部引用 travel-commute-planner 技能脚本，本文件只定义复核判定逻辑。**安装位先 ls 核验**（候选：`<技能安装位>/travel-commute-planner/scripts/` 与 `~/.agents/skills/travel-commute-planner/scripts/`，以实际存在者为准；2026-08-27 实测前者在位、后者不存在）。

## 通道一：铁路（12306 官方，免 key）
```
python3 train_query.py --batch pairs.json --date <日期> --full --out <csv>
```
- pairs.json 必须是 `[{"from":"X","to":"Y"}]` 对象数组
- **--full 铁律**：不加时 --out 只存样本（3G+2D+2K），做"有无班次/末班车"结论必须 --full（实战教训：险误判"G1747 周五不在列"）
- 看 `历时` 列区分高铁/普速；无直达时查枢纽中转（如衡阳东→贵阳北无直达，走长沙南中转 ≈4.5h）

## 通道二：航班（Layer1.5 快照实测）
1. `flight_query.py` 生成 OTA 查询链接（人工核查入口，永不爬虫）
2. `flight_snapshot_queries.py --batch routes.json`（每条需内置 date 键）生成 4 条/航线搜索串
3. web_search 执行快照：优先 OTA m 站 dated 报价 > 天巡 > 媒体行情；记录【日期+价格+班期+来源URL】，conf=C 级快照
4. 含税口径：机建 ¥50 + 燃油按出票月公告（**禁止硬编码费率**；2026-08-05 起 800km+ ¥70，合计 ¥120——仅当航线存在直飞且价格进入判定时才需当月核对，无直飞不必空耗）

## 距离判定树（否决 vs 折价）
```
有直飞？
├─ 是：≤5h 且含税≤¥1,200 且周班次≥20 → 「距离折价」（回家频率月→季，不否决）
│      否则 → 「距离重折价」（回家=年假级，权重交用户）
└─ 否：高铁/动卧 ≤8h？ → 「距离折价」
       普速 12–24h？ → 「距离重折价」
       >24h 或无直达？ → 「距离否决」候选，但仍需查邻近机场直飞再定
```
- 每周班次 ≥60 的航线票价弹性大（沈阳线 103 班/周 ¥670 起），班期密度本身是宜居性指标

## 门到门口径
报告一律给「门到门」：市区→机场/车站时间 + 候机/候车 + 航程/车程 + 落地后通勤。飞行门到门≈航程+3h。
