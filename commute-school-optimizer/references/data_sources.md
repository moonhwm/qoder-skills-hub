# 数据源与三级降级路径

每个数据源按"实时查询 → 估算模型 → 人工录入"三级降级组织。上一级不可用时立即降级并显式标注 conf（empirical→estimated→assumed），禁止静默降级。

## 1. 铁路（12306）

### L1 实时查询（conf=empirical）

- 官方入口：`https://www.12306.cn`（余票/票价/时刻）。检索路径：官网首页"车票预订"输入发到站与日期。
- **禁止伪造深链**：不要凭记忆拼接 `kyfw.12306.cn/otn/...` 查询 URL 交付给用户，参数格式可能已变更；一律指引官方入口或使用经验证的开源客户端。
- 开源客户端：`leeska/12306-cli`（MIT，Node.js），封装了余票查询/中转方案/车次经停/车站代码。用法示例：
  - `12306 tickets 深圳北 广州南 --date 明天 --g --sort duration --limit 10`
  - `12306 interline 深圳 成都 --date 明天 --limit 10`（中转）
  - `12306 stations 深圳`（车站代码）
- 限频：≤1 次/秒；无需登录但接口可能随 12306 更新而失效，失败时降级 L2。

### L2 估算模型（conf=estimated）

- 高铁二等座基准价经验值：约 0.46 元/公里（G 字头）、0.31 元/公里（D 字头）、普速硬座约 0.06–0.12 元/公里。
- 历时估算：G 字头按 250–300 km/h 含停站、D 字头按 160–200 km/h 估算；再加 15–30 分钟候车与进出站。
- 必须标注"估算值，未与 12306 实时核对"，并在有机会时回填实测值。

### L3 人工录入（conf=assumed）

- 让用户在 12306 App 截图报价，或由用户提供近期购票记录；录入时注明购票日期与席别。

### 铁路局差异化定价核查清单

同一里程不同路局票价可能差异显著（浮动定价机制），核查要点：

1. 查询该车次的担当局（车次信息中的配属/担当）。
2. 重点核查广铁集团管内线路（俗称"抢铁"现象：管内票价上浮明显，同里程高于其他局）；其次核查京沪、沪昆等热门干线的浮动折扣/上浮。
3. 同 OD 存在多路局车次时，逐一比价，取全部而非最便宜的一个样本。
4. 计次/定期票（如 20 次计次票）可显著降低通勤成本，核查该线是否发售。
5. 学生票优惠：普速硬座半价、动车组二等座 75 折，仅限学籍区间；通勤择校场景须先确认区间资格。

## 2. 地图路径规划（高德/百度）

### L1 实时查询（conf=empirical）

- 有 Key：高德 Web Service API（`https://restapi.amap.com`，v3/v5），公交换乘 `transit/integrated`：跨城公交查询建议带 city/cityd 参数（指定出发/到达城市，否则结果可能漂移），同城查询可省略；百度地图类似。
- **已验证的能力边界**：高德 API 提供驾车（含过路费估算）、公交/地铁换乘、步行/骑行的时间与距离；**不提供**火车票价格、机票价格。票价必须走 12306 或内置估算。
- 免 Key 降级：高德/百度地图 Web 版与 App 手动查线（输入起终点截图记录），适合一次性少量查询。

### L2 估算模型（conf=estimated）

- 公交/地铁：站数 × 2.5 分钟 + 换乘次数 × 8 分钟（含步行与候车）。
- 驾车：距离 / 平均速度（市区高峰 20 km/h、平峰 35 km/h、快速路 60 km/h）+ 停车接驳 10 分钟。
- 骑行：距离 / 15 km/h；步行：距离 / 5 km/h。

### L3 人工录入（conf=assumed）

- 用户实测通勤一次并记录门到门时间与费用；这是最可信的 L3 数据，鼓励回填。

## 3. 航班（OTA 数据）

### 合规警示（必读）

- 飞猪 MTOP（Alibaba MTOP + MD5 签名）与途牛 deviceId 逆向方案可实现纯 HTTP 票价抓取，**但仅限个人研究**：
  - 违反平台服务条款，存在封 IP、法律灰色地带风险；
  - 接口随时因风控策略变化而失效（历史项目中已多次失效）；
  - 本技能**不内置**逆向代码；任何使用该途径获得的数据必须在输出中标注"来源为逆向接口，存在失效与条款风险，conf=estimated"。
- 参考开源实现：`yangka1212/JiPiao`（同时爬携程/去哪儿/同程/飞猪/途牛；携程/去哪儿需 Playwright 浏览器自动化）。

### 三级降级

- L1 实时：携程/去哪儿/飞猪官网或 App 手动查询（生成搜索链接给用户自查是零风险方案）。
- L2 估算：国内干线经济舱全价约 0.75–1.0 元/公里，常见折扣 3–7 折；另加机建燃油。
- L3 人工：用户录入实际购票价格。
- 注意门到门：航班必须加"提前 2 小时到机场 + 机场↔市区接驳 1 小时上下"，否则时间会严重低估。

## 4. 官方底表（穷举类查询的权威来源）

| 用途 | 底表 | 入口 |
|------|------|------|
| 高校名单 | 教育部全国普通高校名单 | 教育部官网/阳光高考 |
| 硕士点目录 | 研招网硕士专业目录 | `https://yz.chsi.com.cn` |

用法细则见 `exhaustive_query_protocol.md`。

## 5. 数据落盘与复核

- 每次查询记录：数据源、查询时间、原始值、conf 等级、data_cutoff。
- 票价与时刻为易变数据：data_cutoff 超过 30 天的必须标注"待复核"，超过 90 天的禁止用于正式结论（除非标 assumed）。
