## 第 1 节 三种目标格式

`scripts/arxiv_cite.py --format <fmt>` 从核验过的元数据 JSONL 生成。模板逻辑：

**BibTeX**
- 纯预印本 → `@misc` + `eprint`/`archivePrefix=arXiv`/`primaryClass`，版本写入 `note`；
- 有 journal_ref/DOI → `@article`（期刊信息优先），`note` 回链 `Preprint: arXiv:XXXX.XXXXXvN`。

**GB/T 7714-2015（中文学术写作默认）**
- 纯预印本 → 电子资源 `[EB/OL]`：`作者. 题名[EB/OL]. (年). https://arxiv.org/abs/<id> (arXiv:<id><vN>).`
- 已发表 → `[J]` 期刊条目 + `Preprint: arXiv:...` 回链；
- 作者格式：姓全称大写 + 名首字母，>3 位用 "et al"。

**APA 7th**
- 预印本：`Author, A., & Author, B. (Year). Title [Preprint]. arXiv. https://arxiv.org/abs/<id> (version vN)`
- 已发表：期刊信息 + DOI 优先。

## 第 2 节 版本锁定纪律

1. **引文必须带版本号**（`arXiv:1706.03762v7` 而非 `arXiv:1706.03762`）。
   arXiv 各版本是不同文档：无版本号的引文在论文更新后会指向读者没读过的内容（版本漂移）。
2. 引用时锁**你实际读过并据以立论的那版**——不是最新版。两者不同则说明你读的是旧版，
   并在必要时补一句"最新版 vX 已修改相关表述"。
3. 元数据缺版本号时 arxiv_cite.py 会 stderr 警告"未锁版本"；交付物验证留痕节同步记一条风险。
4. 撤稿论文：三种格式均自动加 [WITHDRAWN] 标记——不撤标记、静悄悄引用撤稿论文是引用事故。

## 第 3 节 预印本 vs 已发表版的取舍

| 情形 | 引哪个 |
|---|---|
| 有正式发表版（journal_ref 经 T2 核验为真） | **引发表版**，note 回链 arXiv 预印本（开放获取便利） |
| 仅预印本 | 引 arXiv 版，[EB/OL]/[Preprint] 体裁标清，锁版本 |
| 发表版与预印本内容差异大（常见：审稿后删改实验） | 引发表版为准；若你立论依据的是预印本独有内容，显式说明并锁预印本版本 |
| journal_ref 未经核验（仅 API 自填字段） | 仍按预印本引，journal_ref 只写进留痕，不进引文 |

## 第 4 节 生成流程与人工核对点

流程：`arxiv_fetch.py`（核验元数据）→ 人工核对 → `arxiv_cite.py`（生成）→ 抽查。

人工核对点（脚本不替你判的）：

1. **作者姓名顺序与拼写**：以 PDF 扉页为准，API 偶有名/姓错位；GB/T 姓名序已内置常见中文姓氏
   启发式（首词命中姓氏表则按"姓前名后"原序处理），但表非穷尽——生僻姓氏、日韩越等姓名仍须人工核对；
2. **题名大小写**：BibTeX 中需保留大小写的词（专有名词）脚本未加花括号保护，必要时手工补 `{GPT}`；
3. **GB/T 7714 年份口径**：脚本取 v1 published 年；若引用的是后续大改版，人工确认是否改用该版年份；
4. **编号**：GB/T 顺序编码制的 [1][2][3] 编号由文稿上下文决定，脚本不生成；
5. 每批引文生成后抽查 ≥1 条到 arxiv.org 摘要页比对（T0 自动判之外的人工兜底）。
