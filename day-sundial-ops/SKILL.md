# 日晷场（<日晷件>）

## 这是什么
白天你在场时的轻量工作台。和夜场相对：夜场是你睡了它自己玩，日晷场是你醒着随手使唤。
「日晷」= 看日影计时——白天的事，当场做当场清，不过夜。

## 解决什么问题
白天的小事不该走重流程：随手一问、跑个小实验、改个小文件、陪刷几道题——
如果每件事都立项、报备、写台账，仪式比事情本身还重。日晷场就是给这些事一个不丢件、不烧钱、不拖沓的落点。

## 什么时候用
- 用户说「日晷场 / 日场 / 白天场 / 随手做一下」；
- 白天、用户在线、任务单次能做完（估计不超过十几分钟）；
- 不用的情况：要花用户钱的事、跨夜的大任务、用户离场后的自治——那些走夜场或正式流程。

## 怎么用（五句话）
1. **当场做完**：小事不立项、不写计划书，直接做；
2. **花钱先问**：任何动余额/外部付费的动作，停下来先报备，批了再做；
3. **留一行**：做完在约定的地方留一行记录（做了什么+结果一句），防止「做过的事找不到」；
4. **做完即收**：不恋战、不顺势扩题；想扩题，问一句再扩；
5. **涉私即掩**：内容里出现人名/账号/路径，按脱敏规矩掩掉再落盘。

## 和夜场怎么衔接
- 白天做不完的事 → 写进夜场课题单，晚上接着做；
- 夜场做出来的东西 → 白天由你验收；
- 两场共用一个账本和一套规矩，区别只是「你在不在场」。

## 失败时怎么办
做不出来或中途变大：如实说做不到/做大了，把中间结果存下来，移交夜场或正式流程。不许硬撑着装做完。
