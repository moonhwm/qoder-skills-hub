# 退化光谱详表与处置 playbook（含实证案例登记）

data_cutoff: 2026-08-29

## 一、L0–L4 完整判定与处置

### L0 正常
- 特征：思考连贯有逻辑链条；工具调用与正文交替推进；输出与任务相关。
- 处置：继续。常规监视即可（长任务每轮自查一次本轮思考是否「有实质内容」）。

### L1 碎片开头
- 特征：思考块以一个或几个高频功能词碎片起笔（英文 Let / The / This，中文 我 / 让我 / 收到Let 式粘连），随后主体尚能拼接出完整推理并完成任务。
- 实证：2026-08-27 本会话（compaction 恢复后前段）连续出现「Let用户用户」「Let让我用户」「收到Let让我」「The好的让我」「让我」「Let让我让我」等碎片开头，但任务完成未中断。
- 处置：**接地恢复流程**（SKILL.md 正文）。不要无视——L1 是滑向 L2 的前兆窗口；也不要恐慌弃会话——此时上下文污染尚浅。**频率升级触发**（条款 2）：碎片开头连续 ≥3 块或跨压缩循环复发 → 不再逐块按 L1 处理，直接升 L2 处置（案例 D）。

### L2 单块坍缩
- 特征：某一思考块整体坍缩为一行同族 token 重复（如 `LetLetLetLetLetLet`），平台显示「思考已完成」但块内无任何实质推理内容；可能伴生「无工具调用」。
- 处置：中止当前推进；若相邻块仍正常，执行条款 3 接地恢复（L2 走**完整 3 轮阶梯**）；**连续出现 2 块即升级按 L3 处置**（上下文已开始带毒）。

### L3 多块渐变坍缩
- 特征：连续多个思考块全部坍缩，且在同一个 token 族内漂移渐变（LetLet… → LetThe… → LetThis…），说明吸引子已锁死、上下文污染在轮次间传导。
- 处置（v1.4 修订，案例 F 实证）：① 停止注入任何新推进指令；② 用 shell/磁盘核验确认已有成果落盘；③ **先试模式切换**（降思考强度/切非集群）+ 等压缩介入 + 极简消息诊断性试活（≤2 轮）——对锁死会话，切换引发的上下文干扰即解药；④ 仍坍缩才**弃会话**：从最近 handover 在新会话重建；⑤ 复盘登记。
- 禁忌：不要发「你怎么了」「继续」「一定要活着」等**情感性催促**——不改变概率分布，只会增加污染轮次。诊断性极简试活指令（如「在吗，回我一个 1」）不在此禁；轮次规则 ≤2 轮无条件 + 3–4 轮可选（蒙特卡洛：基准情景 n2=29%→n4=50% 累计复活率，案例 F 第 4 轮复活实证）+ ≥5 轮止损。

### L4 无有效交付
- 特征：连续退化块 + 无工具调用 + 无正文输出，平台 UI 却显示「已完成目标」（运行时长计入墙钟）。
- 处置：止损。核对磁盘抢救成果；按「交付核验条款」评估真实损失；该会话标记为污染，不再续用。

## 三、机制背景（推断层，conf=Medium）

术语注：本文「窗口」有两义——「退化高发/quota 窗口」指**时间段**；「上下文窗口」指**模型输入长度**。两处语境不同，勿混读。

1. **自回归正反馈**：某 token 被重复后，其 K/V 在 KV Cache 中堆积，注意力分数向重复位置集中，softmax 马太效应锁死循环；Causal Mask 使模型无法「向前看」脱困。
2. **长上下文放大**：超长会话（22h / 43 版交接压缩）稀释有效语义权重，提高进入循环的概率；且压缩摘要会把退化片段当作历史事实保留（带毒摘要），形成跨轮正反馈。
3. **quota/服务端状态窗口**：案例 A 中 13:24 同上下文思考完全正常，说明纯上下文解释不足；13:24–15:27 间唯一可考的系统性变化是账号额度状态（第三次耗尽 + 加油包）与间歇性配额受阻的延续。无平台日志，权重标记 Medium。
4. **同族渐变轨迹**：Let→The→This 同属英文最高频功能词，退化坍缩时吸引子在该族内漂移，是真实生成（而非占位符/渲染故障）的形态学证据。
