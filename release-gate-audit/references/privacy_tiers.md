# 可发布性三级分级 rubric 与脱敏手法表

## 分级

| 级 | 定义 | 处置 | 判定要点 |
|---|---|---|---|
| **P0** | 通用方法论/工具，无个人信息、无第三方隐私、无实名评价 | 可公开 | 扫描 PASS + 通读无项目私语境 |
| **P1** | 含项目语境（院校评价、实名公开记录、个人策略）但无法定隐私 | 脱敏后公开，或先私有观察 | 扫描 REVIEW 或含实名/金额/策略细节 |
| **P2** | 本人或第三方法定隐私（住址/联系方式/身份证/准考证/财务/医疗/凭证/未公开案件细节） | **永不公开**，禁推送 | 扫描 HIGH 或人工判定 |

裁定争议时**从严升级**（P0/P1 拿不准按 P1；P1/P2 拿不准按 P2）。

## 脱敏手法表（P1 → 可公开）

| 手法 | 适用 | 例 |
|---|---|---|
| 删除 | 与方法论无关的隐私段落 | 个人志愿细节、家庭财务 |
| 泛化 | 统计口径保留、个体消失 | 「某中部 211」替代校名（仅在不需要核查结论时） |
| 去标识化 | 人物 | 「用户K」「L 同学」（已见于既有公开库实践） |
| 锚点相对化 | 版本/计数 | 「与交接锚一致」替代硬编码数字（ERR-HWM-01 教训） |
| 环境变量注入 | 测试用隐私名单 | `FAMILY_NAMES_CSV`（既有公开库实践，gitignore 配套） |
| 来源链接替代原文聚合 | 实名公开记录 | 聚合呈现有诽谤相邻风险时，只留链接+口径说明 |

## 私有词表（blocklist）构建规程

推送前从用户处取得或从以下处生成：本人及亲属姓名、详细住址要素（小区/楼栋/室）、手机号、邮箱、身份证号、准考证号、常用户名、凭证 key 值本身、公司/单位全名。词表文件本身**永不入库、永不公开**（它即 PII 清单）。

## 铁律增编（2026-08-29 用户指令固化）

**网盘内容任何程度不对外公开**：百度网盘等个人云存储中的目录名、文件名、文件内容、缩略图/分享链接，一律 P2 永不公开——不进公开库、不进公开文档、不进技能包、不进提示词外发。网盘审计产物（如 baidu_pan_audit/）仅可存本地 output 工作区。私有词表构建时须纳入网盘专有名词模式（目录名、题名、签名链接域名）。
