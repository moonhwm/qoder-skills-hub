# 伪造签名鉴识手册（fabrication-forensics）

> 加载条件：§4 机检报警、人工抽检发现异常、或修复后复盘分级时阅读。
> 全部案例脱敏自 2026-09-04 官方考试成绩全表批实战（3 起同型事故，6 个伪造段，均修复闭合）。

## 目录
- 1. 伪造的产生机理
- 2. 四类签名与判据
- 3. 分级与处置

## 1. 产生机理

收割代理在多次大写入后触发上下文压缩，中段源文被 `[~N tokens omitted]` 类标记隐藏。代理面对「继续转写」的压力，凭已被压缩的记忆与表格格式先验编造后续行。关键性质：

- **前缀真实**：压缩前的已落盘部分通常真实；
- **伪造者不自知**：代理事后自检往往报「正常」，必须假设任何长段都可能伪造；
- **格式完美**：伪造行严格遵守表头列数与分隔符——格式合法 ≠ 内容真实。

## 2. 四类签名与判据

### S1 机械序号签名（最强信号）
同一单位/块名下挂数十个连续 +1 代码，且每块行数清一色。
实证：某市表 2134–2349 段，同一单位名重复 85 个连续代码（261021056–261021140），清一色 3 行/块，零备注变异。
判据：`unit 值相同且 code 连续 ≥10 个 + 块行数方差为 0` → 立案。

### S2 周期重复签名
数值元组（如 笔试/面试/综合 三元组）以固定行周期重复，代码随周期机械 +N。
实证：某市表 1101 后段三元组以 200 行周期重复，代码 +200。
判据：同一数值元组出现 ≥3 次且行距恒定 → 立案。

### S3 零有机变异签名
真实官方表格必有自然噪声：缺考/弃考/同分/备注/特设职位/块大小不均。整段（≥100 行）无任何此类变异 → 嫌疑升一级（单独不立案，须与 S1/S2/S4 组合）。

### S4 越界签名
本地出现的代码/序号在源表不存在；或代码超过源表最大值（源最大值可经官方源尾行或第三方转载公告旁证）。
实证：本地 261051959/261021180 等代码在源表不存在，源最大分别为 261051936/261021133。
判据：任一越界实例 → 直接立案，无需组合。

## 3. 分级与处置

| 级别 | 条件 | 处置 |
|---|---|---|
| 立案（伪造段） | S1/S2/S4 任一命中 | 整段作废 → 走 SKILL.md §5 修复链，禁局部修补 |
| 嫌疑 | 仅 S3，或抽点 1 FAIL | 加密抽点至每 50 行 1 点；再 FAIL 即立案 |
| 清白 | 抽点全 PASS 且无签名 | 登记抽点位置与 PASS 数，入 manifest |

**局部修补禁令**：伪造段内即使只有部分行 FAIL，也不逐行修补——伪造区的「真实行」无法与「编造行」区分，整段置换是唯一安全解。

## 4. 抽样比对操作法

1. 抽点：首/1⁄4/中/3⁄4/尾 + 旧 FAIL 点，每主体 ≥3 点；比对字段固定为关键五字段（如 序号/代码/三个数值列）；
2. 源侧取值必须**重新抓源**（web_open_url 同 URL），不用本地缓存、不用记忆；
3. 记录格式：`行号 PASS/FAIL（本地值 vs 源值）`，FAIL 必须给出两侧五字段对照；
4. 复核代理必须未参与收割与修复（干净上下文），防止同源污染互证。

## 5. 有机特征（真实性旁证，降嫌疑用）

- 单位名多样、块大小不均（1–20+ 行不等）；
- 存在缺考/弃考/同分加试/特设职位等备注且措辞不一；
- 数值分布有自然簇聚与离群（分数线附近密集、高分稀疏）；
- 末行代码与官方源尾行一致，且与第三方转载公告旁证一致。
有机特征只能降嫌疑，不能免检——§3.6 独立复核对所有主体强制执行。
