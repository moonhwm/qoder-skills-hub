# 蒸馏规程（distill-spec）——源技能 → 便携引导件

> 目的：把有技能系统/代码环境才跑得动的源技能，蒸馏成「全文粘贴即激活」的单文件引导件，供无技能系统的异模型（DeepSeek/GPT 系/Hy4 等）当轮使用。蒸馏=纪律语义保真，不是内容复印。

## 一、转化原则：人工骨架模式

1. **引擎类逻辑转自然语言规程**：代码引擎（脚本/正则/状态机）不翻译代码，翻译其**约束语义**——输入输出契约、阈值、禁项、流程次序。依据：多数引擎输出本就是「结构骨架+最低文本层」，差异化渲染由模型负责，故人工模式无损核心能力；真正的计算硬依赖（如 hash 链、状态持久化）须显式声明「人工模式下降级为留痕纪律」。
2. **结构保留**：源件的章节骨架（如九段+三镜+两述）逐字保留为清单；骨架内渲染交给接收模型。
3. **纪律不稀释**：禁项、红线、阀门、退化门逐条携带，一条不丢；解释性文字可压缩，判据不可压缩。

## 二、私藏层剔除铁则（不可豁免）

- 私藏词表/映射表/实名信息/凭证形态/内部路径指纹**一律不随便携件**；便携件里只写「按私藏层管理，不随本件」。
- 完稿必过脱敏闸（desensitize_gate.py + 私藏词表）：BLOCK 即返工，PASS 才上架。扫描结果如实入留痕，禁编造。
- 功能性标识（URL/表名类）走注入式口径：值不落文档，只写取得渠道。

## 三、形态契约

- **单文件自包含**，体积 ≤10KB（超出即再压缩解释性文字，保判据）。
- **文首版本戳**：`（vX.Y.Z-portable · YYYY-MM-DD）`，版本号跟随源件三段制 + `-portable` 后缀。
- **激活复述段**：文首给出用法与「激活确认」动作（复述边界条），文末放激活确认指令——接收模型无系统提示入口，激活靠用户粘贴+模型复述。
- **溯源行**：注明源件名与版本、「冲突时以源件安装位为准」。
- 变更注记：便携件自身修订在文首注记区逐条登记（与源件注释同款纪律）。

## 四、上架五拍（每次重蒸馏必走）

1. **读源**：读源件当前安装位 SKILL.md（及必要 references），确认 live version 与变更注记；禁凭记忆蒸馏（R257：长文搬运一律源文复制+复核）。
2. **重蒸**：按一至三节转化；新增章节蒸馏为摘要级并指向源件章节号。
3. **过闸**：脱敏闸 PASS（留 verdict 与命中数）；打包前 `rm -rf scripts/__pycache__`（pyc 混入两回实证）。
4. **替换双处**：覆盖 app/ 正本与镜像目录同名文件，md5 复核两处一致；页面卡片（如有）版本号同步改。
5. **台账同步**：portable_registry.json 的 portable_version 与 sources.version 更新，updated 戳刷新；跑 portable_sync_check.py 复检 SYNC-OK 方算闭合。

## 五、整包便携（.skill）的同步口径

- 整包=源技能原样归档，不蒸馏；同步=源技能版本递增后**重打包**（package_skill.py，包内根目录名须与 SKILL.md name 一致）替换旧包。
- 检测器对 output 目录递归枚举全部 .skill 并读出包内版本；默认不入册（动态枚举），需受控的整包可入册 items（kind=整包便携，sources 指安装位目录）。
