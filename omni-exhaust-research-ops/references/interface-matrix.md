# 七域强制接口调用矩阵（v2.0 泛化版，随 SKILL.md §2 使用）

> 本表只定义「能力类型」与纪律，不绑定任何具体平台/实例；实例列仅为在场时的联动举例，缺席则该域降级并显式声明。

## 七域明细

| 域 | 能力类型 | 强制触发条件 | 产出型 | 正交边界（不给什么） | 在场实例举例 |
|---|---|---|---|---|---|
| 检索 | 通用 web 搜索/网页读取/学术搜索 | 一切研究任务 | 证据（来源+日期+信源级） | 不给 API 用法（→文档域） | web_search / web_open_url / scholar |
| 文档 | 版本对齐的库文档垂直检索 | 涉任何库/框架/SDK | 官方 API 事实 | 不给观点（→检索域） | Context7（resolve→query-docs） |
| 库 | 既有知识库/数据库自查询 | 研究开始前必查沉淀 | 历史研究/留痕指针 | 不给新证据（→检索域） | Supabase 类实例（既有表只读查询） |
| 代码 | 开源仓库/代码/issue 搜索 | 技术方案类任务 | 开源先例/踩坑记录（repo+活跃度） | 不给写入（写类须逐次批准） | GitHub 官方检索 |
| 通道 | 邮件/消息检索（授权前提下） | 涉既有往来证据 | 函证（日期+主题+指针） | 不给外发（发送=写类） | IMAP 邮件检索等 |
| 计时 | 定时/周期任务登记 | 跨周期跟踪需求 | 计时器（表达式+责任方+健康口径） | 不给口头承诺式提醒 | cron 类工具 |
| 生成 | 文档/表格/演示/图/音视频生成 | 产物形态需要时 | 成品文件 | 不给研究内容（研究≠写作） | docx/xlsx/pptx/image 等 |

## 调用纪律

1. 每域「实调或声明无需」二选一，七行每行有落点；
2. 多源交叉：检索域同一事实至少两独立信源，信源分级标注；
3. 写类例外：任何写库/写仓库/发信/对外分发——逐次显式批准，不开闸；
4. 凭据红线：key/secret 永不入正文/产物/技能包；
5. 正交性校验：两域产出同义重复→合并为一域登记，防「接口凑数」；
6. 零发现如实报零，禁止为凑矩阵硬编结果。
