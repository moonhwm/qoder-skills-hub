# 四法操作细则与复合法走查（method-playbook）

> 承 SKILL.md §2。三个完整走查均来自实盘实证（2026-09），非虚构示例。

## 一、二分定位法细则

**前置**：空间有全序关系（时间、价格、排名、版本号）。
**步骤**：
1. 定界：左右端点 L/R（如 120 个交易日的首末）。
2. 中点采样：取中点对象，跑**轻量判据**（非完整详查——如只拉指数涨跌幅，不做五域编码）。
3. 判向：目标特征（剧烈波动/首个异常/阈值穿越）落在哪半，递归该半。
4. 收敛：区间宽 ≤ 预设粒度（如 5 个交易日）即停，转详查段。
**成本**：120 日 → log2(120/5)≈5 次中点采样即可收敛一个剧烈段；多个剧烈段=各段独立二分。
**陷阱**：特征非单调时二分可能判错向——先用网格法粗探单调性，或改用分片。

## 二、无限空间网格法细则

**前置**：空间边界未知或开放（岗位市场、房源、参数空间）。
**步骤**：
1. 初始网格：在已知锚点周围布粗网格（如岗位：城市×行业×薪资带，每维 3–4 格）。
2. 每格采 1–3 个代表样本，记命中密度。
3. 自适应加密：命中密度高的格子四分细化；零命中格标注后可剪枝（留痕）。
4. 外延：网格边缘有命中时，向外延展一圈——空间「无限」时以此逼近真实边界。
**陷阱**：初始网格太粗会把稀疏目标整体漏掉——首轮宁粗勿剪，剪枝只在二轮以后。
**实证**：量化台账 R118 九格网格全灭（3×3 参数网格无一及格）——全灭也是有效结果：证明该参数区整体不可行，避免逐点穷举浪费。

## 三、分片法细则

**前置**：空间可沿正交键无损切分（按日/按地区/按行业），片间无交叉或交界面明确。
**步骤**：
1. 选切分键：使单片大小落在单次调用/单轮处理容量内（如 xhcj 单日 20 条）。
2. 逐片处理：片内独立，失败片单独重试不拖累全局。
3. 合并去重：片间交界对象（跨日事件）按唯一键去重。
4. 断点续扫：seen 索引永不自动删，中断后从末完成片续跑（承管线 §5.6 重置规程）。
**实证**：09-09 逐日热点回填=按日分片×3 片，每片 1 次调用 20 条，零失败。

## 四、张量（矩阵）筛查法细则

**前置**：对象已结构化或可结构化为 对象×属性 矩阵（可升维成张量）。
**步骤**：
1. 建阵：行=对象，列=属性（如 89 件技能×七域调用矩阵；候选岗位×要求项矩阵）。
2. 行列投影：求行和/列和/单维统计，找异常行列（如某域全列空缺=能力缺口；某岗位要求列全不满足=剪枝）。
3. 交集详查：仅对异常行×异常列的交集元素做全量核查。
4. 完备性声明：投影是汇总统计，被投影平均掉的异常须声明。
**实证**：09-09 技能库审计=89 件×七域矩阵，投影发现「文档域/代码域本任务无需」两列缺口，仅对缺口做声明登记，未逐件详查。

## 五、复合法走查 A：金融 120 日逐日回看（SSCI 标准）

```
二分定位（月粒度 6 中点拉指数|涨跌|判据）→ 收敛剧烈段（|涨跌|≥1.5% 段）
→ 段内分片（逐日）→ 每日热点张量编码（20 条×五域矩阵单编码）
→ 详查段只对收敛日做完整 SSCI 记录卡
```
成本实测：定位段 ~10 次调用；详查段 4 次/日 × 收敛日数。三档外推见 09-09 小样本报告（480/100/15 次）。

## 六、复合法走查 B：计算机等岗位筛查

```
无限空间网格（城市×行业×薪资带×学历要求四维粗网格）
→ 格内采样 1–3 岗，判据=硬门槛匹配（双证/全日制等，承案头深研 v1.5 实证）
→ 命中格自适应加密（目标城市细分到区/薪资带细分到 1k）
→ 张量详查（收敛岗位×要求项矩阵逐格核）→ 多维打分（移交 multi-dimensional-option-scoring）
```
关键纪律：硬门槛（如「博士研究生学历（双证）」）在网格段即作判据，不打分——承案头深研实证：单证排除类岗位先剪枝，避免打分浪费。

## 七、复合法走查 C：技能库正交性审计

```
张量建阵（89 件×能力域）→ 行列投影找缺口/重叠
→ 缺口列声明登记；重叠行交集详查（同义重复合并登记）
→ 退役/合并裁决移交排期表
```
实证：总目录 v0.4.0 + 七域矩阵对照（09-09 呈报口径）。
